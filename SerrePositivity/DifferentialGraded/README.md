# DifferentialGraded：dg 理論の入口

## 概要

任意の可換環上の非有界複体から、dg 圏・dg 加群、導来圏、相対テンソル、
perfect 加群、dg 商、Morita 理論までを扱う。Morita（U16）、Verdier 商の比較（U17）、
Perf の実装は完成している。一般の射影モデル構成を扱う U12e-general は中断中であり、
局所条件のもとで完成した経路と区別する。

本番 API の入口は [DifferentialGraded.lean](../DifferentialGraded.lean)。
StageOne〜StageEight の入口は退役し、この集約に置き換えた。

## 方針

| ディレクトリ | 内容 |
| --- | --- |
| Complexes・Category・Functor | 複体の閉対称モノイダル構造、dg 圏と dg 関手 |
| Module・Bimodule・Tensor | dg 加群、双加群、Hom と balanced tensor、単位・結合の整合性 |
| Derived・Resolution | 導来局所化、導来 Hom・テンソル、解像度と比較 |
| Perfect・Endomorphism | perfect・compact 加群、小さい増強と自己準同型の表示 |
| Quotient・Morita・Verdier | dg 商、Morita 同値、Verdier 商と三角構造の比較 |
| Presentation | dg 圏の表示とその構成 |
| Checks | 型照合・example・受入の検査 |

本番の集約は検査と Archive を import しない。全宣言の公理監査は
`scripts/make_area_audits.py` が追跡中のモジュールから生成する `scripts/audit/dg.lean` を使う。
中断した U12e-general の検査は
[Archive/DifferentialGraded/Checks/U12e](../Archive/DifferentialGraded/Checks/U12e/) に全文を保存し、
監査・集約・通常のビルド対象には含めない。

## 規約

- 環は任意の可換環。複体は非有界で、追加の有限性・平坦性・small 性は各 API の仮定に明示する。
- 微分はコチェイン次数 +1、ホモトピーは次数 −1。原論文のホモロジー次数 i はコチェイン次数 −i に対応する。
- 環と Hom 加群の宇宙と、dg 圏の対象の宇宙を区別する。既存の仮定・宇宙・符号規約を維持する。
- Mathlib の豊穣圏の構造と既存の複体・局所化・三角圏の API を再利用する。
- U12e-general の個別の証明済み API と、一般経路全体の未受入を区別する。
- 旧 `Verdier/ChecksU17Integration`・`ChecksOrderSquare` は `Asymptotic/DGVerdier/` に移設済み。

## 使われ方

本番入口と受入検査：

```sh
source ~/.zshenv
zsh scripts/refactor/with_build_lock.sh -- lake build SerrePositivity.DifferentialGraded
zsh scripts/refactor/with_build_lock.sh -- lake build SerrePositivity.DifferentialGraded.Checks.StageSeven SerrePositivity.DifferentialGraded.Checks.StageEight
zsh scripts/refactor/with_build_lock.sh -- lake build SerrePositivity.DifferentialGraded.Checks.U12eLocal SerrePositivity.DifferentialGraded.Checks.Morita.U16Checks
zsh scripts/refactor/with_build_lock.sh -- lake build SerrePositivity.Asymptotic.DGVerdier.ChecksU17Integration
```

監査の import 先を先にビルドしてから、監査を実行する：

```sh
source ~/.zshenv
zsh scripts/refactor/with_build_lock.sh -- lake build $(grep '^import ' scripts/audit/dg.lean | sed 's/^import //')
zsh scripts/refactor/with_build_lock.sh -- lake env lean scripts/audit/dg.lean
```

監査の再生成はリポジトリルートで `python3 scripts/make_area_audits.py` を実行する。
このスクリプトは他領域の監査も生成するため、所有範囲外の差分を混入させない。
整理の範囲と受入条件は [DG-W1](../../formalization-plans/dg-codex-w1.md)、
中断経路の再開条件は [U12e の目録](../../formalization-plans/archive/dg-theory-u12e-general-inventory.md) を参照する。

## 統合後の依存順

W2 の 78 統合先と W3 の 48 統合先、計 126 本を以下に示す。別に統合対象外の本番モジュールが 37 本ある。Checks と Archive はこの一覧の外にある。

依存の向きは「この行のモジュール → 直接依存先」。順位は DG 内の import DAG の深さで、各依存先の順位は必ず小さい。同順位の行どうしに依存辺はない。型クラスや演算の推移的な到達範囲は、直接依存先をさらにたどった閉包で決まる。

DG が外部へ import するのは Mathlib・CategoryTheory・HomologicalAlgebra。strictly perfect 複体と PerfectHomotopy の共有 API は `HomologicalAlgebra.Complex.StrictlyPerfect` にあり、PerfectComplex への例外辺は解消した。

ディレクトリ単位では Category・Module・Derived などに相互参照があるため、単純なディレクトリ順位は `layers.json` に登録しない。DG の外部依存規則は同ファイルで検査し、内部の順序は下のモジュール単位の表で示す。
