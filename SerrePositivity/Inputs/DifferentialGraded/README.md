# M5 の引用台帳

所有：dg 理論系列。2026-10-15 時点で採用済み引用は **0 件**。
U0〜U3 はすべて証明し、このディレクトリには Lean の引用・axiom を追加していない。

候補 ID（DG-DR、DG-PER、DG-GEN、DG-MOR、DG-TAB、DG-INFTY、DG-SHIP）と採用ゲートは
[dg-theory.md §7](../../../formalization-plans/archive/dg-theory.md#7-引用候補台帳型の案採用ゲート) にある。
対象・宇宙・射クラス・比較関手を定義した後にのみ、固定した適用について採用する。
版・番号・ページ、環・smallness・flatness、次数変換、自然性、使用先、axiom 依存を記録する。
一般モデル圏論・Quillen・転送・SM7 の引用はここにも一般層にも導入しない。
