# Lech の論文 §2（Theorem 2.1 (b)）の代数的な書き直しの設計

> 数学的な解説・調査記録。記載日の仮定・証明方針を保持し、現在のLean実装と未証明状態は [README](../README.md) と解説（`exposition/ja/exposition-ja.tex`）の付録 A を正本とする。

2026-10-10 作成。OpenAI, *Lech's multiplicity conjecture* §2.3–2.6 を、スキーム論を使わずに次数付き環・加群の言葉で書き直すための設計メモ。主張と証明の概略は [lech-overview.md](lech-overview.md) を参照。ここでの検討は論文の §2.3–2.6 を読んだ段階のもので、細部は形式化の前に紙の上で詰める必要がある。

## 結論

- Theorem 2.1 (b) にスキーム論は要らない。§2 のコホモロジーは全て有限個の標準アフィン被覆の Čech 複体で、被覆の開集合は次数 1 の元の非零点なので、次数付き加群の Čech 複体（安定 Koszul 複体）とそのホモロジーで書ける。
- C の非 Noetherian 性は問題にならない。論文自身、C が非 Noetherian であることに合わせて、有限フィルトレーション・切り詰め写像の安定像・余極限という代数的な議論で証明している。
- 設計上の工夫として、Lemma 2.6 のベクトル束 V を「ℙ^{h−1}_ℤ 上の直線束の有限直和からなる有限複体 W」に置き換える。これでベクトル束の局所自由性、Lemma 2.5 の (2.8)、Lemma 2.3 の V 一般の主張が不要になり、扱う対象は全て次数付き自由加群になる（§4）。
- 残る本質的な難所は二つ：Lemma 2.5 前半（2 つの塔の比較）と、W の存在（Lemma 2.6 の書き換え）。後者は当面引用で置ける。

## 2. 新設する基本の道具：次数付き Čech 複体

**設定**：S = ⊕_{n∈ℤ} S_n を次数付き可換環、y_1, …, y_h ∈ S_1、N を次数付き S 加群とする。

**定義**：層の Čech 複体に当たるもの

　Č^p(y; N)_j = ⊕_{|T| = p+1} (N_{y_T})_j　（p = 0, …, h−1）

を、y_T = ∏_{i∈T} y_i による局所化の j 次部分として定め、通常の交代和の微分を入れる。Ȟ^v(y; N)_j をそのコホモロジーとする（「ℙ 上の Ñ(j) の H^v」に当たる）。有界な次数付き複体 D には二重複体の全複体をとる。

**必要な性質**

1. **関手性と完全性**：局所化は完全なので、N の短完全列から長完全列が出る。複体 D の三角（写像錐）からも長完全列が出る。
2. **有限フィルトレーション**：Čech 複体は h 段の有限フィルトレーションをもつ。論文の「フィルトレーションを保つ写像が E₁ で 0 なら、h 回の合成はホモロジーで 0」はそのまま使える（Lemma 2.4）。
3. **余極限**：局所化の次数 0 部分は、N の斉次成分の有向余極限で書ける。これと λ の余極限の性質から、「N の各斉次成分が長さ 0 なら Č(y; N) の各項が長さ 0」が出る（Lemma 2.3）。
4. **多項式環の計算**：A[Z₁..Z_h] について、t ≥ 0 で Ȟ⁰(Z; A[Z])_t = A[Z]_t、Ȟ^v(Z; A[Z])_t = 0（v > 0）。Čech 複体は Koszul（余）複体 K(Z^v) の有向極限なので、Z^v が正則列であることと、リポジトリの Koszul 基盤（`CommutativeAlgebra/Koszul`、`KoszulResolution`、`RegularSequence`）が使える。局所コホモロジー H^h_{(Z)}(A[Z]) が次数 ≤ −h にしかないことからも従う。
5. **底変換**：A[Z] の Čech 複体は各項が自由 ℤ 加群（無限階数）の有界複体。ℤ 上のコホモロジーが自由なら、任意の A への底変換と両立する（有界な自由 ℤ 加群の複体の Künneth）。

**実装の見通し**：有限集合 T の添字による交代和は、Koszul 複体の実装と同型の作業。リポジトリの `koszulComplex`、`koszulComplexOn` の作り方が参考になる。Mathlib の局所コホモロジー（`localCohomology`）はこの用途には使わない。

## 3. 各補題の書き直し

### Lemma 2.3（gr_I C と (C/I)[Z] の比較）

- 前半「(C/I)[Z] → gr_I C の核は各次数で長さ 0」：もともと代数の主張。J_a = (z^a) と I^{h(a−1)+1} ⊆ J_a による長さの比較（論文どおり）。
- 後半の比較：上の性質 3 で、核 N の Čech 複体の各項が長さ 0。よって (C/I)[Z] と gr_I C の Čech 複体は長さ 0 を法として同型。
- 「t ≥ 0 で gr^t_I C → Ȟ⁰(E, O_E(t)) は長さ 0 を法として同型、高次は長さ 0」：(C/I)[Z] 側で性質 4 を使い、比較で移す。
- §4 の置き換えにより、V 一般ではなく O(t) についてだけ示せばよい。有限性は性質 4 の明示計算（C/I 上の有限階数自由加群、λ = 階数 × μ）から出るので、論文の「V の有限分解」は不要。

### Lemma 2.4（ひねりの写像が超ホモロジーで 0）

- 各チャート (D_{y_i})₀ の複体は有限射影加群の複体で、z_i を逆元にすると可縮。可縮化ホモトピーの分母を払って、z_i の冪が零ホモトピーになる。リポジトリの `HomologicalAlgebra/NullHomotopy`、`UniformNullHomotopy` が使える。
- 性質 2 で、D(j + hm) → D(j) は超ホモロジーで 0。
- 論文どおり代数的に書ける。§4 の置き換えで D は次数付き自由加群の有界複体だけになる。

### Lemma 2.5（χ_λ(F_Y) = λH₀(F)、ひねりでの不変性）

**前半 (2.7)**：論文の証明は二つの塔の比較で、全て代数的。

- 比較写像 (2.9)：F/I^M F → Č(y; F ⊗ ℛ/I^Mℛ)₀。両辺を I と L の冪でフィルトレーションすると、各段は gr^l_I C → Ȟ(E, O_E(l))（Lemma 2.3）。
- 幾何的な塔：A = Č(F ⊗ ℛ)₀、B_M = Č(F ⊗ ℛ/I^Mℛ)₀ と三角 A → B_M → Č(F ⊗ I^Mℛ)[1]。Lemma 2.4 で、最終的な像 im(H(B_N) → H(B_M)) = H(A)。
- Koszul の塔：A_a = F ⊗ K_a と F/J_aF。分裂 (2.3)（Lemma 2.2、リポジトリにある）で、最終的な像は H(F)。
- I^{h(a−1)+1} ⊆ J_a ⊆ I^a で Koszul の冪と普通の冪の塔を行き来する。
- 結論 λH^k(Y, F_Y) = λH_k(F)。

難所はここで、複数の塔の最終的な像を長さ 0 を法として同一視する議論の形式化。Serre 商（リポジトリの `LengthAlgebra/SerreQuotient`）の中で「長さ 0 を法とした同型」を扱えば見通しがよくなる。

**後半 (2.8)**：交代階数 0 なら、F_Y(j)/F_Y(j+1) の各項は gr^j_I C^{b_i} で Euler 特性は Σ(−1)^i b_i χ(O_E(j)) = 0。よって χ_λ(F_Y(j)) は j によらない。§4 の置き換えで、論文の「V を直線束の和で分解する」議論は不要になり、この j 不変性だけで足りる。

### Lemma 2.6 と §2.6（下界の本体）

§4 で扱う。§2.6 の組合せ論・解析の部分（ρ_j の選び方、層ごとの消滅の数え上げ、Riemann 和の評価）は、既に純粋な計算。

## 4. 設計上の工夫：ベクトル束 V を直線束の複体 W に置き換える

論文で V に要求している性質は次の三つ：

1. V(a) のコホモロジーが単一の次数 v(a) = #{j : r_j > a} にだけあり、自由で、Euler 標数が ∏(a − r_j)。任意の環 A への底変換と両立する。
2. Y への引き戻しが局所自由（Lemma 2.3、2.4 で、チャート上で有限射影であることに使う）。
3. (2.8)：χ_λ(F_Y ⊗ V) = rank V · χ_λ(F_Y)（V を直線束の和で分解して示す）。

**置き換え**：V の代わりに、次の性質をもつ有限複体 W を使う。

> **(W)** W は ℤ[Z₁..Z_h] 上の次数付き自由加群（有限階数の ℤ[Z](−c) の直和）の有界複体で、全ての整数 a について、Čech 超コホモロジー Ȟ^*(Z; W(a)) は単一の次数 v(a) にだけあり、有限階数の自由 ℤ 加群で、階数の Euler 標数は ∏_{j=1}^{h−1}(a − r_j)。

V の有限自由分解（Hilbert の syzygy 定理による）をとれば (W) を満たすので、(W) は論文の Lemma 2.6 から従う。

**置き換えの効果**

- 性質 2 は自動的（直線束はチャート上で自由）。
- 性質 3 は、W の各項が O(−c) の直和なので、Lemma 2.5 後半の j 不変性から直ちに χ_λ(F_Y ⊗ W) = (Σ_k (−1)^k rank W_k)·χ_λ(F_Y) = (h−1)!·χ_λ(F_Y)。
- 性質 1 の底変換は、§2 の性質 5（有界な自由 ℤ 加群の複体の Künneth）から出る。
- §2.6 の論証では、G ⊗ V の代わりに G ⊗ W を使う。各層の項が W(l − is)|_E^{b_i} という複体になるが、超コホモロジーのスペクトル系列が有限なので、「単一の次数に集中」の数え上げはそのまま動く。

**(W) の証明の選択肢**

- (a) **引用で置く**（第 1 段階の推奨）。根拠は Eisenbud–Schreyer, Theorem 6.1 と論文の Lemma 2.6、Hilbert の syzygy 定理。名前つきの sorry 定理として `Inputs` に置く。
- (b) **論文の構成を代数化する**。S = ℤ[s₁, t₁, …, s_n, t_n]（n = h − 1）を多重次数付きとし、Z_k を ∏_i(s_i X + t_i Y) の X^{n−k}Y^k の係数に送る。M = ⊕_a S_{(a−1−r₁, …, a−1−r_n)} を ℤ[Z] 加群とみる。
  - コホモロジー：ℙ¹_A 上の O(m) は A[s, t] の (s, t) による Čech 複体で明示計算できる。(ℙ¹)ⁿ は Čech 複体のテンソル積（Künneth）。押し出しでコホモロジーが変わらないことは、「(Z)S と ∏_i (s_i, t_i) の根基が等しいので Čech 複体のコホモロジーが一致する」という主張になる（Čech 複体の根基不変性を §2 に追加する必要がある）。
  - 問題：論文は f の平坦性（V の局所自由性）を、Cohen–Macaulay 性と次元の判定法、ファイバーごとの平坦性判定法で示している。代数化するとき、チャート Z₀ ≠ 0 では ℤ[e₁..e_n] → ℤ[x₁..x_n]（多項式環は対称式の環の上で階数 n! の自由加群、Artin 基底）に帰着できるが、他のチャート Z_k ≠ 0 では積のチャートにならない。SL₂(ℤ) の作用で Z₀ ≠ 0 のチャートを動かす方法は、剰余体が小さい有限体では被覆にならないので使えない。
  - (W) の形なら局所自由性は直接は要らないが、M の有限自由分解の存在に Hilbert の syzygy 定理（ℤ[Z] 上の次数付き版）が要る。Mathlib にあるかは要確認。
- (c) **(W) を満たす複体を直接構成する**。Eisenbud–Schreyer の supernatural bundle と純な自由分解の対応（Boij–Söderberg 理論）を使えば明示的な複体が得られる可能性があるが、未検討。

## 7. 形式化の前に紙の上で確かめること

- §4 の置き換えで、§2.6 の (2.14) の議論（各層の超コホモロジーの次数の数え上げ）が複体 W でもそのまま動くか。
- Lemma 2.5 前半の、二つの塔の最終的な像の同一視を、長さ 0 を法とした Serre 商の中で書き直したときの正確な主張。
- (C/I)[Z] → gr_I C の核の Čech 複体が長さ 0 になる議論で、各項が「共通の I の冪で消される」条件を満たしていること（λ の余極限の性質の前提）。
- Mathlib の Rees 代数（`RingTheory.ReesAlgebra`）と対称式（`MvPolynomial.esymm`、基本定理）の現状。
