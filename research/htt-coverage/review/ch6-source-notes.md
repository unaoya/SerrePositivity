# 第6章：原典の記述についての注意

採用版は `toc.md` の HTT 2017-04-09 版。以下の5箇所は本文と該当頁の画像の両方で確認した。いずれも `none`。原文を修正して対応宣言に数えていない。修正の要否と Lean 側の不足は別に記録する。

## §6.2.3.8（印刷頁588）

有効全射 f:X→T の基底変換の結論が X×T S→X と印刷されている。f の通常の基底変換の終域は S である。記載された終域 X のままなら、空間のトポスで X=T=一点、f=id、S=空とすると空→一点となり有効全射でない。同頁の後続の説明にも引き戻し関手の slice の向きが逆の箇所がある。照合では終域を読み替えていない。

## §6.3.3.5（印刷頁606）

p:X→N(A)op と書く一方、切断圏は MapN(A)(N(A),X) と記す。また、この命題自体には p が topos fibration という仮定が明示されていない。いずれも本文のまま記録し、前後の命題から向きや仮定を補って一致としない。一般の評価が左完全な左随伴を持つという native 比較もない。

## §6.5.2.3（印刷頁666–667）

ファイバー内の C′D-localization を仮定した後、結論の文字は C-localization で、C に prime がない。次頁の証明末尾は C′-localization を結論する。照合では結論を C′ と黙って読み替えない。Lean の一般反射局所化には、この Cartesian fibration の fiber の unit を全体に貼る比較もない。

## §6.5.2.7（印刷頁667）

D(n) を Fun(Δ¹,X) の n-connective morphisms の full subcategory として導入するが、末尾は X の accessible subcategory かつ X の colimits で安定と記す。どの ambient category の主張かを補正していない。一般の強飽和閉包は存在するが、元の n-connective morphisms とその閉包の同定はない。

## §6.5.2.16（印刷頁671）

条件(2)は u を量化して f*u が同値なら f が ∞-connective と記す。ここで f は先に定めた幾何学的関手側の記号であり、証明では u の連結性を示している。照合では量化した射を u に修正して一致としない。mono の反転の反映と ∞-connective 射の同定を結ぶ native 判定もない。
