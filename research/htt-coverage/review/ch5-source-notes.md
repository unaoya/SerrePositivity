# 第 5 章：原典の記述についての注意

原典は `toc.md` に記録した HTT 2017-04-09 版。以下はこの照合で見つけた記述上の問題であり、原文を読み替えて一致件数を増やしていない。

## §5.3.2.6（印刷頁 392）

仮定は Cartesian fibration B′→B、B の始対象 b、B′ の filtered 性である。一方、結論は b 上のファイバーが可縮 **Kan** 複体となっている。採用 PDF の該当頁を画像でも確認した。

このままでは Kan 性が成り立たない。反例は `N(ℕ) → Δ⁰`（ℕ は通常の順序圏）。一点への任意の準圏の射は Cartesian fibration で、N(ℕ) は filtered だが、非可逆な辺 0→1 があるため Kan ではない。ファイバーは N(ℕ) 自身である。

右ファイブレーションという仮定ならファイバーの Kan 性は確保されるが、これは修正案であり原文の仮定ではない。照合表の当該行は `none` とし、右ファイブレーションの別の定理を元の主張の証明に数えない。

## §5.4.1.8（印刷頁 423）

冒頭は C が locally small、D が essentially small なら Fun(D,C) が **essentially small** としているが、直後の証明末尾は **locally small** を結論している。

冒頭を文字通り読むと、C を小集合全体の圏の神経、D=Δ⁰ とした場合に反例となる。C は局所小さいが、本質的小さくない。最後の「小 D に対して P(D) は局所小さい」という個別の結論はこの問題を持たない。

照合表では、実証済みの P(D) の局所小性だけを `partial / component` として採用した。冒頭の essentially small を locally small に黙って修正して `own` とはしていない。

## §5.5.2.1（印刷頁 462）

採用 PDF には f:S→Space、F:P(Sᵒᵖ)→Space が f により corepresented、j:S→P(Sᵒᵖ) と記載されており、該当頁の画像でも外側の op がないことを確認した。通常の米田埋め込みの定義では P(Sᵒᵖ) への米田写像の始域は Sᵒᵖ なので、記載された合成の向きが整合しない。

米田で f を回収する比較は Map(j(s),f)≃f(s) である。P(Sᵒᵖ) の上で f が corepresent する関手は Map(f,−) であり、これとは引数の位置が逆である。外側の反対圏を用いた正しい型の比較と、記載のままの主張は区別した。照合表は `none` とし、正しい型の近傍候補を理由に記した。
