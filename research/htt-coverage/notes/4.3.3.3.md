# HTT 4.3.3.3

[Remark 4.3.3.3・原典 PDF](https://www.math.ias.edu/~lurie/papers/HTT.pdf#page=304)

写像柱体を標識付きの因子分解で比較し、向きを反対化した模型の Cartesian 性を使う。この結論は指定された模型についてであり、任意の写像柱体の射影を直接扱う主張ではない。
