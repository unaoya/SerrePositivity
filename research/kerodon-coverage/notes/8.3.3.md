## f-b-literature-yoneda.html — 6. Yoneda の補題 — 6.3 証明の部品

<!-- source: exposition/ja/infinity/f-b-literature-yoneda.html:156; block: nbw3-f-b-literature-yoneda-l156 -->
<a id="nbw3-f-b-literature-yoneda-l156"></a>

部品 A：\(\mathrm{id}_b\) は \(B_{b/}\) の始対象

<!-- source: exposition/ja/infinity/f-b-literature-yoneda.html:157; block: nbw3-f-b-literature-yoneda-l157 -->
<a id="nbw3-f-b-literature-yoneda-l157"></a>

\(\partial\Delta^n\to B_{b/}\)（頂点 0 が \(\mathrm{id}_b\)）の延長は、join で翻訳すると \(\Delta^0\star\partial\Delta^n\to B\) を \(\Delta^{n+1}\) に延ばすこと。\(\Delta^0\star\partial\Delta^n\) は \(d_0\) 以外の面をすべて含むので外側の horn \(\Lambda^{n+1}_0\) の充填で、最初の辺が恒等射（同値）なので Joyal の定理で埋まる。写像空間の立方体で言えば、\(f_1=\mathrm{id}\) なので whisker を割る必要がない。

<!-- source: exposition/ja/infinity/f-b-literature-yoneda.html:160; block: nbw3-f-b-literature-yoneda-l160 -->
<a id="nbw3-f-b-literature-yoneda-l160"></a>

部品 B：始対象の包含は left anodyne

<!-- source: exposition/ja/infinity/f-b-literature-yoneda.html:164; block: nbw3-f-b-literature-yoneda-l164 -->
<a id="nbw3-f-b-literature-yoneda-l164"></a>

部品 C：left anodyne に沿った相対関手空間の制限は trivial fibration

<!-- source: exposition/ja/infinity/f-b-literature-yoneda.html:165; block: nbw3-f-b-literature-yoneda-l165 -->
<a id="nbw3-f-b-literature-yoneda-l165"></a>

\(i\colon K\hookrightarrow L\) が \(B\) 上の left anodyne、\(E\to B\) が左 fibration なら \(i^*\colon\mathrm{Fun}_{/B}(L,E)\to\mathrm{Fun}_{/B}(K,E)\) は trivial Kan fibration。\(\partial\Delta^n\subseteq\Delta^n\) の持ち上げは \(\partial\Delta^n\times L\cup\Delta^n\times K\hookrightarrow\Delta^n\times L\) に沿った延長と同じで、単射と left anodyne の pushout-product は left anodyne（HTT 2.1.2.7、join の補題の直積版）。

<!-- source: exposition/ja/infinity/f-b-literature-yoneda.html:167; block: nbw3-f-b-literature-yoneda-l167 -->
<a id="nbw3-f-b-literature-yoneda-l167"></a>

**組み立て**：A で \(\mathrm{id}_b\) が始対象、B で \(\{\mathrm{id}_b\}\hookrightarrow B_{b/}\) が left anodyne、C で \(\mathrm{Fun}_{/B}(B_{b/},E)\to\mathrm{Fun}_{/B}(\{\mathrm{id}_b\},E)=E_b\) が trivial Kan fibration。straightening も \(\mathcal S\) も写像空間の関手性も使わない。Lean では leftFibration_cosliceIdentityEvaluation_trivialKanFibration（import の閉包は約 256 モジュール、関手版は約 1,750）。

<!-- source: exposition/ja/infinity/f-b-literature-yoneda.html:168; block: nbw3-f-b-literature-yoneda-l168 -->
<a id="nbw3-f-b-literature-yoneda-l168"></a>

**逆写像の直観**：切断が与える \(\sigma_e\colon B_{b/}\to E\) は \(f\colon b\to c\) を \(f_!e\) に送り、2 単体 \(b\to c\to d\) で \((gf)_!e\simeq g_!f_!e\) を与える。\(e\) から出るすべての transport を高次の整合性まで一度に選んだもので、部品 C の持ち上げがそれを引き受ける。St を「表現可能関手の Un（\(B_{b/}\)）からの写像」と見る見方はこれ。

<!-- source: exposition/ja/infinity/f-b-literature-yoneda.html:169; block: nbw3-f-b-literature-yoneda-l169 -->
<a id="nbw3-f-b-literature-yoneda-l169"></a>

**系（fibration レベルの Yoneda 埋め込み）**：\(E=B_{c/}\) とすると \(\mathrm{Fun}_{/B}(B_{b/},B_{c/})\simeq\mathrm{Map}(c,b)\)。\(b\mapsto B_{b/}\) は \(B^{\mathrm{op}}\) から左 fibration の ∞ 圏への充満忠実な対応で、第 6 章 §6.4 の \(\mathcal Z\) の構成案で使う事実そのもの。

<!-- source: exposition/ja/infinity/f-b-literature-yoneda.html:170; block: nbw3-f-b-literature-yoneda-l170 -->
<a id="nbw3-f-b-literature-yoneda-l170"></a>

**前層版**：前層 ⇔ \(C\) 上の右 fibration、\(h_y\) ⇔ \(C_{/y}\to C\)、主張は \(\mathrm{Fun}_{/C}(C_{/y},E)\to E_y\) が trivial Kan fibration。

## f-b-literature-yoneda.html — 6. Yoneda の補題 — 6.4 関手版

<!-- source: exposition/ja/infinity/f-b-literature-yoneda.html:173; block: nbw3-f-b-literature-yoneda-l173 -->
<a id="nbw3-f-b-literature-yoneda-l173"></a>

Hom 関手 \(C^{\mathrm{op}}\times C\to\mathcal S\) の作り方は三つ：twisted arrow の straightening（Kerodon 第 8 章、いまの形式化）、\(\mathfrak C[C]\) による厳密化（HTT §5.1.3、モデル構造を使うので不採用）、関手を作らない（∞-cosmos。前層 = 関手の比較が別に要る）。形式化の証明は次の合成。

<!-- source: exposition/ja/infinity/f-b-literature-yoneda.html:174; block: nbw3-f-b-literature-yoneda-l174 -->
<a id="nbw3-f-b-literature-yoneda-l174"></a>

\[\mathrm{Map}(h_y,F)\xrightarrow[h_1]{\simeq}\mathrm{Fun}_{/C^{\mathrm{op}}}(\mathrm{Un}(h_y),\mathrm{Un}(F))\xrightarrow[h_2]{\cong}(\text{小さい模型})\xrightarrow[h_3]{\simeq}\mathrm{Un}(F)_y\xrightarrow[h_4]{\simeq}F(y)\]

<!-- source: exposition/ja/infinity/f-b-literature-yoneda.html:175; block: nbw3-f-b-literature-yoneda-l175 -->
<a id="nbw3-f-b-literature-yoneda-l175"></a>

| 段 | 内容 |
| --- | --- |
| \(h_1\) | 前層の写像空間 ≃ unstraightening の相対関手空間（最も重い入力） |
| \(h_2\) | 宇宙の調整（厳密な同型） |
| \(h_3\) | 表現可能前層の Un はスライスで、恒等点での評価は同値（核心、中身は fibration 版） |
| \(h_4\) | \(\mathrm{Un}(F)\) の \(y\) 上のファイバーは \(F(y)\) |

<!-- source: exposition/ja/infinity/f-b-literature-yoneda.html:182; block: nbw3-f-b-literature-yoneda-l182 -->
<a id="nbw3-f-b-literature-yoneda-l182"></a>

充満忠実性（yonedaInfinityMap_isFullyFaithful）は、同値 \(\mathrm{Map}(h_x,h_y)\simeq\mathrm{Map}(x,y)\) の存在ではなく、Yoneda 写像そのものの Hom 作用が同値であることを示す必要がある。Hom 作用を恒等点で評価したものが \(\mathrm{Tw}(C)\) の恒等点からの transport と一致することを示して結論する。straightening の同値定理そのものには依存しない。

## f-b-literature-yoneda.html — 9. straightening の構成と \(h_y\) の関手性 — 9.9 全体の流れ：fibration 版 Yoneda → St → Map → 関手版 Yoneda

<!-- source: exposition/ja/infinity/f-b-literature-yoneda.html:352; block: nbw3-f-b-literature-yoneda-l352 -->
<a id="nbw3-f-b-literature-yoneda-l352"></a>

1. **fibration 版 Yoneda**（§6、§7）：\(\mathrm{Fun}_{/B}(B_{b/},E)\to E_b\) は trivial Kan fibration。straightening も \(\mathcal S\) も使わない。

<!-- source: exposition/ja/infinity/f-b-literature-yoneda.html:353; block: nbw3-f-b-literature-yoneda-l353 -->
<a id="nbw3-f-b-literature-yoneda-l353"></a>

2. **St の構成**（9.3〜9.7）：第一段で値を切断空間 \(\mathrm{Fun}_{/N(C)}(N(C_{c/}),X)\) に置き換え、その値が正しいことに 1 を使う。第二段は局所化 \(\mathrm{fv}\)。St の同値定理は要らない。

<!-- source: exposition/ja/infinity/f-b-literature-yoneda.html:354; block: nbw3-f-b-literature-yoneda-l354 -->
<a id="nbw3-f-b-literature-yoneda-l354"></a>

3. **Map と Yoneda 埋め込み**（9.8）：\(\mathrm{Tw}(C)\) の St を curry する。

<!-- source: exposition/ja/infinity/f-b-literature-yoneda.html:355; block: nbw3-f-b-literature-yoneda-l355 -->
<a id="nbw3-f-b-literature-yoneda-l355"></a>

4. **関手版 Yoneda**（§6.4）：\(\mathrm{Map}(h_y,F)\xrightarrow{h_1}\mathrm{Fun}_{/C^{\mathrm{op}}}(\mathrm{Un}h_y,\mathrm{Un}F)\xrightarrow{h_2}\cdots\xrightarrow{h_3}\mathrm{Un}(F)_y\xrightarrow{h_4}F(y)\)。\(h_1\) は Un の写像空間の比較（§8）、\(h_3\) は 9.8 のスライスとの比較のうえで 1 をもう一度使う。充満忠実性は Yoneda 写像の Hom 作用を \(\mathrm{Tw}(C)\) の transport と比べて示す。

<!-- source: exposition/ja/infinity/f-b-literature-yoneda.html:357; block: nbw3-f-b-literature-yoneda-l357 -->
<a id="nbw3-f-b-literature-yoneda-l357"></a>

fibration 版 Yoneda は二度使われる：St の値が正しいことを保証するため（2）と、関手版の値を計算するため（4 の \(h_3\)）。St の同値定理（充満忠実・本質的全射）そのものはこの流れに入らない。

## route-yoneda.html — 2. 証明の本体：四つの同値の合成

<!-- source: exposition/ja/infinity/route-yoneda.html:47; block: nbw3-route-yoneda-l47 -->
<a id="nbw3-route-yoneda-l47"></a>

証明は短く、四つの同値を合成するだけである。

<!-- source: exposition/ja/infinity/route-yoneda.html:48; block: nbw3-route-yoneda-l48 -->
<a id="nbw3-route-yoneda-l48"></a>

```text
lemma yonedaPresheafEvaluation_isQCatEquivalence ... := by
  have h₁ := small_leftUnstraighteningPinchedMappingSpaceMap_isQCatEquivalence
    (representablePresheafInfinity y) F
  have h₂ := (qCatEquivalenceOfIso
    (smallLeftUnstraighteningRelativeFunctorIso (representablePresheafInfinity y) F).symm).isQCatEquivalence
  have h₃ := (representableUnstraighteningEvaluation_isQCatEquivalence
    (smallLeftUnstraighteningProjection F) y).ulift.{u, u + 1}
  have h₄ := (smallLeftUnstraighteningLiftedFiberValueEquivalence F
    (SSet.opObjEquiv.symm y)).isQCatEquivalence
  exact h₁.comp (h₂.comp (h₃.comp h₄))
```

<!-- source: exposition/ja/infinity/route-yoneda.html:58; block: nbw3-route-yoneda-l58 -->
<a id="nbw3-route-yoneda-l58"></a>

数学として書くと次のようになる。\(\mathrm{Un}(G)\to C^{\mathrm{op}}\) は前層 \(G\) の unstraightening（左 fibration）、\(\mathrm{Fun}_{/C^{\mathrm{op}}}(-,-)\) は相対関手空間である。

<!-- source: exposition/ja/infinity/route-yoneda.html:59; block: nbw3-route-yoneda-l59 -->
<a id="nbw3-route-yoneda-l59"></a>

\[
\mathrm{Map}(h_y,F)\;\xrightarrow[h_1]{\ \simeq\ }\;\mathrm{Fun}_{/C^{\mathrm{op}}}\bigl(\mathrm{Un}(h_y),\mathrm{Un}(F)\bigr)\;\xrightarrow[h_2]{\ \cong\ }\;(\text{小さい模型})\;\xrightarrow[h_3]{\ \simeq\ }\;\mathrm{Un}(F)_y\;\xrightarrow[h_4]{\ \simeq\ }\;F(y)
\]

<!-- source: exposition/ja/infinity/route-yoneda.html:63; block: nbw3-route-yoneda-l63 -->
<a id="nbw3-route-yoneda-l63"></a>

1. **h₁　写像空間の比較**：前層の間の写像空間は、unstraightening の間の相対関手空間と同値（F1/CoherentUnstraighteningMappingEquivalence、SmallCoherentMappingEquivalence）。**この証明全体で最も重い入力**。

<!-- source: exposition/ja/infinity/route-yoneda.html:64; block: nbw3-route-yoneda-l64 -->
<a id="nbw3-route-yoneda-l64"></a>

2. **h₂　宇宙の調整**：大きい unstraightening と小さい模型の相対関手空間は厳密に同型（F1/SmallLeftUnstraighteningMappingSpace）。数学的な内容はない。

<!-- source: exposition/ja/infinity/route-yoneda.html:65; block: nbw3-route-yoneda-l65 -->
<a id="nbw3-route-yoneda-l65"></a>

3. **h₃　表現可能前層での評価**：**任意の**左 fibration \(p\colon E\to C^{\mathrm{op}}\) について、\(\mathrm{Fun}_{/C^{\mathrm{op}}}(\mathrm{Un}(h_y),E)\to E_y\)（恒等点での評価）は同値（F1/RepresentableUnstraighteningEvaluation）。Yoneda の補題の数学的な核心はここにある。

<!-- source: exposition/ja/infinity/route-yoneda.html:66; block: nbw3-route-yoneda-l66 -->
<a id="nbw3-route-yoneda-l66"></a>

4. **h₄　fiber の値**：\(\mathrm{Un}(F)\) の \(y\) での fiber は \(F(y)\) と同値（F1/SmallLeftUnstraighteningFiber）。

## route-yoneda.html — 2. 証明の本体：四つの同値の合成 — h₃ の中身

<!-- source: exposition/ja/infinity/route-yoneda.html:78; block: nbw3-route-yoneda-l78 -->
<a id="nbw3-route-yoneda-l78"></a>

二段に分かれる。

<!-- source: exposition/ja/infinity/route-yoneda.html:80; block: nbw3-route-yoneda-l80 -->
<a id="nbw3-route-yoneda-l80"></a>

1. **表現可能前層の unstraightening は coslice**：比較写像 \(C^{\mathrm{op}}_{y/}\to\mathrm{Un}(h_y)\) は前合成同値（`representableCosliceUnstraighteningComparison_isPrecompositionEquivalence`）。前合成同値に沿った制限は、左 fibration への相対関手空間の同値を与える（`relativeFunctorOverPre_isQCatEquivalence`）。

<!-- source: exposition/ja/infinity/route-yoneda.html:81; block: nbw3-route-yoneda-l81 -->
<a id="nbw3-route-yoneda-l81"></a>

2. **coslice は恒等点を始対象に持つ**：\(\mathrm{Fun}_{/C^{\mathrm{op}}}(C^{\mathrm{op}}_{y/},E)\to E_y\)（恒等錐 \(\mathrm{id}_y\) での評価）は自明 Kan fibration（`leftFibration_cosliceIdentityEvaluation_trivialKanFibration`）。自明 Kan fibration は同値（第 2 章）。

<!-- source: exposition/ja/infinity/route-yoneda.html:83; block: nbw3-route-yoneda-l83 -->
<a id="nbw3-route-yoneda-l83"></a>

古典的な Yoneda の補題の証明（「\(\mathrm{id}_y\) の行き先で自然変換が決まる」）が、2 の「始対象への制限は自明 Kan fibration」にそのまま対応している。
