定理

<!-- source: exposition/ja/infinity/f-03-localization.html:82; block: nbw3-f-03-localization-l82 -->
<a id="nbw3-f-03-localization-l82"></a>

任意の単体的集合 \(X\) と辺の集合 \(W\) について、quasicategory \(Q\) と、\(W\) での局所化 \(F : X \to Q\) が存在する。

<!-- source: exposition/ja/infinity/f-03-localization.html:83; block: nbw3-f-03-localization-l83 -->
<a id="nbw3-f-03-localization-l83"></a>

```text
theorem exists_quasicategory_localization (X : SSet.{u}) (W : Set (X _⦋1⦌)) :
    ∃ (Q : SSet.{u}) (F : X ⟶ Q), Quasicategory Q ∧ IsLocalization F W
```

## f-03-localization.html — 3. 存在：任意の辺の集合で局所化できる — 3.2 段 2：W の辺ごとに J を貼り付ける

<!-- source: exposition/ja/infinity/f-03-localization.html:99; block: nbw3-f-03-localization-l99 -->
<a id="nbw3-f-03-localization-l99"></a>

\(W\) の各辺 \(w\) について、\(\Delta^1 \xrightarrow{w} X\) と \(\Delta^1 \to J\) の pushout をとる（全部まとめて）。

<!-- source: exposition/ja/infinity/f-03-localization.html:100; block: nbw3-f-03-localization-l100 -->
<a id="nbw3-f-03-localization-l100"></a>

\[
P \;=\; X \sqcup_{\coprod_{w \in W} \Delta^1} \coprod_{w \in W} J
\]

<!-- source: exposition/ja/infinity/f-03-localization.html:103; block: nbw3-f-03-localization-l103 -->
<a id="nbw3-f-03-localization-l103"></a>

（`inverseAttachment X W`、InfinityCategories/Kerodon/AdjointFunctors/Localization/InverseAttachment.lean:47）。\(X \to P\) は \(W\) の辺を可逆な辺に送る。

<!-- source: exposition/ja/infinity/f-03-localization.html:104; block: nbw3-f-03-localization-l104 -->
<a id="nbw3-f-03-localization-l104"></a>

**主張**：どの quasicategory \(Y\) についても、制限写像 \(\mathrm{Fun}(P, Y) \to \mathrm{Fun}_W(X, Y)\) は**自明 Kan fibration** である（`inverseAttachmentRestriction_trivialKanFibration`、InfinityCategories/Kerodon/AdjointFunctors/Localization/InverseAttachmentUniversal.lean）。

<!-- source: exposition/ja/infinity/f-03-localization.html:105; block: nbw3-f-03-localization-l105 -->
<a id="nbw3-f-03-localization-l105"></a>

理由は次のとおり。\(P\) への関手は「\(X\) への関手」と「各 \(J\) への延長」の組である。
\(W\) を可逆に送る関手なら、各 \(w\) の像は \(Y\) の可逆な辺で、可逆な辺は \(Y\) の core（Kan 複体）に入る。
\(\Delta^1 \to J\) は anodyne なので、Kan 複体への写像は延び、延長の空間は可縮になる。
境界からの延長の問題に直すと、ちょうど自明 Kan fibration の持ち上げ条件になる。

<!-- source: exposition/ja/infinity/f-03-localization.html:109; block: nbw3-f-03-localization-l109 -->
<a id="nbw3-f-03-localization-l109"></a>

自明 Kan fibration は同値なので（§1）、\(X \to P\) は局所化である（`inverseAttachment_isLocalization`）。ただし \(P\) は quasicategory とは限らない。

## f-03-localization.html — 3. 存在：任意の辺の集合で局所化できる — 3.3 段 3：quasicategory に置き換える

<!-- source: exposition/ja/infinity/f-03-localization.html:112; block: nbw3-f-03-localization-l112 -->
<a id="nbw3-f-03-localization-l112"></a>

\(P \to \ast\) を「inner anodyne の後に inner fibration」に分解する（第 1 章 §1.4 の `exists_quasicategory_resolution_over`）。

<!-- source: exposition/ja/infinity/f-03-localization.html:113; block: nbw3-f-03-localization-l113 -->
<a id="nbw3-f-03-localization-l113"></a>

\[
P \xrightarrow{\ j\ (\text{inner anodyne})\ } Q \to \ast,\qquad Q \text{ は quasicategory}
\]

<!-- source: exposition/ja/infinity/f-03-localization.html:116; block: nbw3-f-03-localization-l116 -->
<a id="nbw3-f-03-localization-l116"></a>

inner anodyne \(j\) について、どの quasicategory \(Y\) でも前合成 \(j^* : \mathrm{Fun}(Q, Y) \to \mathrm{Fun}(P, Y)\) は同値である（`isPrecompositionEquivalence_of_innerAnodyne`）。
局所化に前合成同値を後ろから合成しても局所化なので（`localization_postcomp_precompositionEquivalence`）、\(X \to P \to Q\) が求める局所化になる。

<!-- source: exposition/ja/infinity/f-03-localization.html:120; block: nbw3-f-03-localization-l120 -->
<a id="nbw3-f-03-localization-l120"></a>

この証明の性格

<!-- source: exposition/ja/infinity/f-03-localization.html:122; block: nbw3-f-03-localization-l122 -->
<a id="nbw3-f-03-localization-l122"></a>

- 使っているのは、Kan 置換、pushout、自明 Kan fibration、inner anodyne 置換だけで、モデル構造も straightening も使わない。

<!-- source: exposition/ja/infinity/f-03-localization.html:123; block: nbw3-f-03-localization-l123 -->
<a id="nbw3-f-03-localization-l123"></a>

- 得られるのは**存在と普遍性**で、\(Q\) の写像空間は分からない（\(J\) を貼り付けて置き換えた後の形は具体的に計算しにくい）。写像空間の計算には、§5 の hammock 局所化や、第 5 章の分数を使う。

<!-- source: exposition/ja/infinity/f-03-localization.html:124; block: nbw3-f-03-localization-l124 -->
<a id="nbw3-f-03-localization-l124"></a>

- この定理は InfinityCategories/Kerodon/AdjointFunctors/Localization にある（`exists_quasicategory_localization`、LocalizationResolution）。
