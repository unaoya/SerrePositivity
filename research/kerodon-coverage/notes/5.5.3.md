## route-6ff-definition.html — 6. \(\mathrm{QCat}^\Delta\) の記号と core の有無 — 6.1 上付きの \(\Delta\)

<!-- source: exposition/ja/infinity/route-6ff-definition.html:161; block: nbw3-route-6ff-definition-l161 -->
<a id="nbw3-route-6ff-definition-l161"></a>

\(\Delta\) は「単体的圏として見たもの」（Hom に単体的集合の構造を入れたもの、HTT の記法）。「小さい」は対象の大きさ、\(\Delta\) は Hom の構造についての記号で独立。

<!-- source: exposition/ja/infinity/route-6ff-definition.html:162; block: nbw3-route-6ff-definition-l162 -->
<a id="nbw3-route-6ff-definition-l162"></a>

| 記号 | 何か | Hom |
| --- | --- | --- |
| \(\mathrm{QCat}\) | 普通の圏 | 関手の集合 |
| \(\mathrm{QCat}^\Delta\) | 単体的圏 | \(\mathrm{Fun}(\mathcal C,\mathcal D)^{\simeq}\)（0 単体は関手、1 単体は自然同値、…）。0 単体だけ取ると \(\mathrm{QCat}\) |

<!-- source: exposition/ja/infinity/route-6ff-definition.html:167; block: nbw3-route-6ff-definition-l167 -->
<a id="nbw3-route-6ff-definition-l167"></a>

**普通の圏では足りない**：\(N(\mathrm{QCat})\) では、準圏の同値 \(F\) は \(GF\simeq\mathrm{id}\) が等号でないので可逆な辺にならず、自然変換の情報もない。\(\mathrm{QCat}^\Delta\) では自然同値が Hom の 1 単体として入り、\(N^{hc}\) で 2 単体（補章 3 の \(H_{012}\)）になって \(F\) が可逆な辺になる。同値を同値として扱うために Hom の高次構造が要る。同じ記法：\(\mathrm{Kan}\)（\(\mathcal S=N^{hc}(\mathrm{Kan})\)）、HTT の \(\mathrm{Cat}_\infty^\Delta\)（Def. 3.0.0.1）。

## route-6ff-definition.html — 6. \(\mathrm{QCat}^\Delta\) の記号と core の有無 — 6.2 \(\mathrm{Cat}_\infty\) の射と写像空間

<!-- source: exposition/ja/infinity/route-6ff-definition.html:171; block: nbw3-route-6ff-definition-l171 -->
<a id="nbw3-route-6ff-definition-l171"></a>

- \(\mathrm{QCat}^\Delta\) の Hom を \(\mathrm{Fun}^{\simeq}\) にするのは**定義**。

<!-- source: exposition/ja/infinity/route-6ff-definition.html:172; block: nbw3-route-6ff-definition-l172 -->
<a id="nbw3-route-6ff-definition-l172"></a>

- \(N^{hc}\) の**辺**は単体的関手 \(\mathfrak C[\Delta^1]\to\mathrm{QCat}^\Delta\) で、\(\mathrm{Map}(0,1)=\Delta^0\) なので、二つの準圏と \(\mathrm{Fun}^{\simeq}\) の 0 単体、すなわち**関手そのもの**（定義を計算した結果）。

<!-- source: exposition/ja/infinity/route-6ff-definition.html:173; block: nbw3-route-6ff-definition-l173 -->
<a id="nbw3-route-6ff-definition-l173"></a>

- **写像空間** \(\mathrm{Map}_{\mathrm{Cat}_\infty}(\mathcal C,\mathcal D)\)（pinched Hom など）は単体ごとには \(\mathrm{Fun}^{\simeq}\) と一致しないが、ホモトピー同値（写像空間の比較定理、`coherentHomEquivalence`）。

<!-- source: exposition/ja/infinity/route-6ff-definition.html:174; block: nbw3-route-6ff-definition-l174 -->
<a id="nbw3-route-6ff-definition-l174"></a>

- 低次元の確認：\(\mathrm{Map}_{\mathrm{Cat}_\infty}\) の道 \(F\to G\) は辺 \(\{1,2\}\) が恒等な 2 単体で、データは \(f_{01}=F\)、\(f_{12}=\mathrm{id}\)、\(f_{02}=G\) と \(\mathrm{Map}(0,2)\) の辺 \(G\Rightarrow F\)、つまり \(\mathrm{Fun}^{\simeq}\) の 1 単体（自然同値）。

## route-6ff-definition.html — 6. \(\mathrm{QCat}^\Delta\) の記号と core の有無 — 6.3 core を取るかどうか

<!-- source: exposition/ja/infinity/route-6ff-definition.html:178; block: nbw3-route-6ff-definition-l178 -->
<a id="nbw3-route-6ff-definition-l178"></a>

|  | core を取る | core を取らない |
| --- | --- | --- |
| Hom | \(\mathrm{Fun}^{\simeq}\)（Kan 複体） | \(\mathrm{Fun}\)（準圏） |
| 関手の間の 2 射 | 可逆な自然変換だけ | 全ての自然変換 |
| 得られるもの | \(\mathrm{Cat}_\infty\)：\((\infty,1)\) 圏 | \(\mathrm{Cat}_{(\infty,2)}\)：\((\infty,2)\) 圏 |
| \(N^{hc}\) が準圏か | なる | ならない（空洞の立方体の包含はアノダインだが内アノダインでなく、非可逆な辺を逆にたどれない）。scaled 単体的集合など別のモデルが要る |
| 1 圏での類似 | \((2,1)\) 圏としての \(\mathrm{Cat}\) | 2 圏としての \(\mathrm{Cat}\) |

<!-- source: exposition/ja/infinity/route-6ff-definition.html:186; block: nbw3-route-6ff-definition-l186 -->
<a id="nbw3-route-6ff-definition-l186"></a>

**失われるもの**：\(\mathrm{Cat}_\infty\) の中で非可逆な自然変換が高次の射として見えない。lax な構成（[補章 2](../../../exposition/ja/infinity/unstraightening-analogy.html) で coslice の fiber が core になった）、lax 関手（[補章 7](../../../exposition/ja/infinity/fibered-descent.html) §1：\(B\to\mathrm{Cat}_\infty\) は擬関手の ∞ 版）、随伴の単位・余単位。**残るもの**：\(\mathrm{Cat}_\infty\) はデカルト閉で \(\mathrm{Fun}(\mathcal C,\mathcal D)\) が内部 Hom として対象になるので、非可逆な自然変換はその中の射として取り出せる。随伴は \(\Delta^1\) 上の両側 fibration（対象のレベル）で表され、lax な情報は fibration 側で扱う。

<!-- source: exposition/ja/infinity/route-6ff-definition.html:187; block: nbw3-route-6ff-definition-l187 -->
<a id="nbw3-route-6ff-definition-l187"></a>

**六関手形式との関係**：基底変換・射影公式の比較写像は可逆でなければならないので、値は core を取った \(\mathrm{Cat}_\infty\) で足りる。随伴まで一つの関手で書こうとすると \((\infty,2)\) 圏が現れる（Gaitsgory–Rozenblyum）。Mann・Scholze は右随伴の存在を性質として課して \((\infty,2)\) 圏を避ける。

## route-classification.html — 5. 段 3：\(\mathcal S=N^{hc}(\mathrm{Kan})\) と写像空間の比較定理 — 5.5（3.5）\(\mathrm{Cat}_\infty\) の場合

<a id="nbw3-route-classification-l729"></a>

**段 3 で押さえること**：局所 Kan な単体的圏の \(N^{hc}\) は準圏（内ホーンの延長は蓋のない箱から立方体への延長で、アノダイン）。\(hN^{hc}(D)=\pi_0D\)。写像空間の比較定理：\(\mathrm{Hom}^L_{N^{hc}\mathcal C}(X,Y)\) は \(\Phi(K)=\mathfrak C[\Sigma K](x,y)\) の右随伴で、\(\Phi(\Delta^n)\) は \(\Delta^n\) を太らせたもの（\(\rho\) が圏同値）なので \(\mathcal C(X,Y)\) とホモトピー同値。よって \(\mathrm{Map}_{\mathcal S}(K,L)\simeq\mathrm{Fun}(K,L)\)、合成も一致、\(\mathrm{Map}_{\mathcal S}(\Delta^0,-)\) は恒等。\(\mathrm{Cat}_\infty\) では \(\mathrm{Fun}(\mathcal C,\mathcal D)^{\simeq}\) で、点で表現される関手は core（coslice は普遍 cocartesian fibration にならない）。大きさは宇宙 \(u\) と \(u+1\) で管理し、大きい底では本質的に小さい fiber を扱う。
