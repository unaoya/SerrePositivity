## f-01-simplicial-kan.html — 3. ホモトピー群（Kan） — 3.5 弱同値の三つの見方

<!-- source: exposition/ja/infinity/f-01-simplicial-kan.html:170; block: nbw3-f-01-simplicial-kan-l170 -->
<a id="nbw3-f-01-simplicial-kan-l170"></a>

単体的集合（Kan とは限らない）の間の写像 \(f : A \to B\) が「弱同値」であることには、このリポジトリでは三つの言い方がある。

<!-- source: exposition/ja/infinity/f-01-simplicial-kan.html:171; block: nbw3-f-01-simplicial-kan-l171 -->
<a id="nbw3-f-01-simplicial-kan-l171"></a>

| 言い方 | 定義 | 宣言 |
| --- | --- | --- |
| Kan 複体への写像で見る | すべての Kan 複体 \(Z\) について、\(\pi_0\mathrm{Fun}(B, Z) \to \pi_0\mathrm{Fun}(A, Z)\) が全単射 | `IsWeakHomotopyEquivalence`（InfinityCategories/Kerodon/KanComplexes/TheHomotopyTheoryOfKanComplexes/WeakHomotopy.lean:42） |
| anodyne 局所化で見る | 単体的集合の圏を anodyne 射で局所化した 1 圏（空間のホモトピー圏）で、\(f\) が同型になる | `anodyneQ`（HomotopicalAlgebra/Simplicial/AnodyneHomotopyLocalization.lean:101） |
| Kan 置換してから π_* で見る | Kan 置換したものの間の写像が π_* 同型 | §1.4 の置換と §3.2 |

<!-- source: exposition/ja/infinity/f-01-simplicial-kan.html:177; block: nbw3-f-01-simplicial-kan-l177 -->
<a id="nbw3-f-01-simplicial-kan-l177"></a>

関係を示す結果として、Kan 複体の間の anodyne 射は π_* 同型である（`kanPiIsomorphism_of_anodyne`、KST/Spectra/AnodyneHomotopyEquivalence.lean:98）。三つが一致することは、第 2 章で「モデル圏を使わない基礎」としてまとめる。

## f-02-model-free.html — 4. 弱同値の三つの見方が一致すること

<!-- source: exposition/ja/infinity/f-02-model-free.html:78; block: nbw3-f-02-model-free-l78 -->
<a id="nbw3-f-02-model-free-l78"></a>

第 1 章 §3.5 で、単体的集合の写像 \(f : X \to Y\) が「弱同値」であることの三つの言い方を挙げた。ここで、それらがモデル構造なしで一致することを確かめる。

<!-- source: exposition/ja/infinity/f-02-model-free.html:80; block: nbw3-f-02-model-free-l80 -->
<a id="nbw3-f-02-model-free-l80"></a>

| 見方 | 定義 | 宣言 |
| --- | --- | --- |
| (a) anodyne 局所化 | \(\texttt{anodyneQ}(f)\) が同型 | `IsIso (anodyneQ.map f)` |
| (b) Kan 複体による判定 | すべての Kan 複体 \(K\) について、前合成 \([Y, K] \to [X, K]\)（ホモトピー類）が全単射 | `KanTestDetection.Tests f`（HomotopicalAlgebra/Simplicial/KanTestDetection.lean:47）。`IsWeakHomotopyEquivalence`（Kerodon/KanComplexes）（\(\pi_0\mathrm{Fun}(-, Z)\) で同じことを言う）もこの形 |
| (c) Kan 置換と π_* | \(Rf : RX \to RY\) が π_* 同型 | 第 1 章 §3.2 の `KanPiIsomorphism` |

<!-- source: exposition/ja/infinity/f-02-model-free.html:87; block: nbw3-f-02-model-free-l87 -->
<a id="nbw3-f-02-model-free-l87"></a>

**(a) ⇔ (b)**：`anodyneQ_isIso_iff_tests`（KanTestDetection.lean:111）。証明の流れは次のとおり。

<!-- source: exposition/ja/infinity/f-02-model-free.html:89; block: nbw3-f-02-model-free-l89 -->
<a id="nbw3-f-02-model-free-l89"></a>

1. (a) ⇒ (b)：Kan 複体 \(K\) へのホモトピー類 \([-, K]\) は、anodyne 射を全単射に送る（Kan 複体への写像は anodyne に沿って延び、延長はホモトピーを除いて一意）。したがって \([-, K]\) は anodyneQ を経由し、\(\texttt{anodyneQ}(f)\) が同型なら全単射（`tests_of_anodyneQ_isIso`）。

<!-- source: exposition/ja/infinity/f-02-model-free.html:90; block: nbw3-f-02-model-free-l90 -->
<a id="nbw3-f-02-model-free-l90"></a>

2. (b) ⇒ (a)：Kan 置換 \(X \to RX\) は anodyne なので、anodyneQ の中で \(f\) と \(Rf\) は同型の違いしかない。Kan 複体の間では、(b) は米田の議論により「ホモトピー同値」を意味する。ホモトピー同値は §3.2 により anodyneQ で同型になる（`replacement_tests`・`map_isIso_of_tests`）。

<!-- source: exposition/ja/infinity/f-02-model-free.html:93; block: nbw3-f-02-model-free-l93 -->
<a id="nbw3-f-02-model-free-l93"></a>

**(b) ⇔ (c)**：Kan 複体の間の写像については、(b) はホモトピー同値と同じで、ホモトピー同値は Whitehead の定理により π_* 同型と同値である（第 1 章 §3.4）。
一般の \(f\) については、Kan 置換を経由して (b) と (c) が比べられる。Kan 置換の単位 \(X \to RX\) は anodyne なので、(b) の判定を変えない。

<!-- source: exposition/ja/infinity/f-02-model-free.html:97; block: nbw3-f-02-model-free-l97 -->
<a id="nbw3-f-02-model-free-l97"></a>

ポイント

<!-- source: exposition/ja/infinity/f-02-model-free.html:98; block: nbw3-f-02-model-free-l98 -->
<a id="nbw3-f-02-model-free-l98"></a>

「弱同値」を、モデル構造の公理から出すのではなく、Kan 複体へのホモトピー類（(b)）で定義してしまう。そうすれば、局所化（(a)）や π_*（(c)）との一致は、持ち上げ性質と small object argument だけで示せる。
これが「モデル圏を使わない基礎」の中心である。
