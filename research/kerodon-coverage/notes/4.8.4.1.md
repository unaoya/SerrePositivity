## 02-mapping-limits.html — 4. 充満忠実性と同値の判定 — 主定理

<!-- source: exposition/ja/infinity/02-mapping-limits.html:108; block: nbw3-02-mapping-limits-l108 -->
<a id="nbw3-02-mapping-limits-l108"></a>

**定理**（HTT §1.2.10。コードの docstring は Kerodon Thm. 4.8.4.1・Prop. 4.8.4.5 を参照）. quasicategory の間の \(f\colon X\to Y\) について、\(f\) が同値 ⇔ \(f\) が充満忠実かつ本質的全射。

<!-- source: exposition/ja/infinity/02-mapping-limits.html:110; block: nbw3-02-mapping-limits-l110 -->
<a id="nbw3-02-mapping-limits-l110"></a>

Lean では `isQCatEquivalence_iff_fullyFaithful_essentiallySurjective`（Core/EquivalenceFullyFaithful）。難しいのは ⇐ で、次の三段で示す。

<!-- source: exposition/ja/infinity/02-mapping-limits.html:112; block: nbw3-02-mapping-limits-l112 -->
<a id="nbw3-02-mapping-limits-l112"></a>

1. **isofibration への置き換え**（Core/EquivalencePath*）。\(Y\) の可逆な辺がなす path の空間 \(\mathrm{Path}^{\simeq}(Y)\) で \(f\) を引き戻し、\(\tilde X=X\times_Y\mathrm{Path}^{\simeq}(Y)\) を作る。射影 \(\tilde X\to X\) は trivial Kan fibration で、終点の評価 \(\tilde f\colon\tilde X\to Y\)（`equivalencePathReplacementMap f`）は inner fibration になる。\(f\) が同値であることと \(\tilde f\) が同値であることは同値。

<!-- source: exposition/ja/infinity/02-mapping-limits.html:113; block: nbw3-02-mapping-limits-l113 -->
<a id="nbw3-02-mapping-limits-l113"></a>

2. **性質の移送**。\(\tilde f\) も充満忠実で、本質的全射性は頂点上の**全射**に強まる（可逆な辺を経由して像を動かせるため）。

<!-- source: exposition/ja/infinity/02-mapping-limits.html:114; block: nbw3-02-mapping-limits-l114 -->
<a id="nbw3-02-mapping-limits-l114"></a>

3. **trivial Kan fibration であることの証明**（Core/FullyFaithfulBoundary）。頂点上で全射な充満忠実 inner fibration \(p\) が \(\partial\Delta^{n+1}\hookrightarrow\Delta^{n+1}\) を持ち上げることを示す。\(p\) を \(\Delta^{n+1}\) に引き戻す（充満忠実性は引き戻しで保たれる。`IsFullyFaithful.pullback_snd`）。\(\Delta^{n+1}\) の最後の頂点は終対象で、充満忠実な inner fibration は終対象性を反映するので、引き戻した側でも最後の頂点が終対象になる。終対象の境界充填性から持ち上げが得られる。\(n=-1\)（頂点）の場合が全射性である。

<!-- source: exposition/ja/infinity/02-mapping-limits.html:116; block: nbw3-02-mapping-limits-l116 -->
<a id="nbw3-02-mapping-limits-l116"></a>

このとき trivial Kan fibration は同値なので、\(\tilde f\)、したがって \(f\) が同値になる。

<!-- source: exposition/ja/infinity/02-mapping-limits.html:119; block: nbw3-02-mapping-limits-l119 -->
<a id="nbw3-02-mapping-limits-l119"></a>

Lean の構造：写像空間の写像を trivial fibration に上げる

<!-- source: exposition/ja/infinity/02-mapping-limits.html:120; block: nbw3-02-mapping-limits-l120 -->
<a id="nbw3-02-mapping-limits-l120"></a>

3 段目の「充満忠実な inner fibration は終対象性を反映する」の内部では、次の組み合わせが繰り返し使われる。

<!-- source: exposition/ja/infinity/02-mapping-limits.html:122; block: nbw3-02-mapping-limits-l122 -->
<a id="nbw3-02-mapping-limits-l122"></a>

- `pinchedHomMap_rightFibration`：写像空間の写像は右 fibration、とくに Kan fibration

<!-- source: exposition/ja/infinity/02-mapping-limits.html:123; block: nbw3-02-mapping-limits-l123 -->
<a id="nbw3-02-mapping-limits-l123"></a>

- `trivialKanFibration_of_fibration_of_simplicialHomotopyEquivalence`：Kan fibration かつホモトピー同値なら trivial

<!-- source: exposition/ja/infinity/02-mapping-limits.html:125; block: nbw3-02-mapping-limits-l125 -->
<a id="nbw3-02-mapping-limits-l125"></a>

二つを合わせると `IsFullyFaithful.pinchedHomMap_trivialKanFibration` が得られる。「ホモトピー同値」という性質を「持ち上げ性」という具体的な道具に変えることが、この層の証明の基本の型になっている。

## route-classification.html — 3. 段 1：写像空間・同値・関手の ∞ 圏 — 3.6（1.6）∞ 圏の同値

<!-- source: exposition/ja/infinity/route-classification.html:477; block: nbw3-route-classification-l477 -->
<a id="nbw3-route-classification-l477"></a>

- **(⇐)**（Kerodon Theorem 4.8.4.1）：1 圏のように \(x_d\) と同型を選んで \(G\) を作ると高次の整合性の選択が要るので、三段階で示す。

1. **置換**：\(\mathcal C':=\mathcal C\times_{\mathcal D}P(\mathcal D)\)（\(P\) は 3.5 の同値な辺の path 空間）、\(F'\colon\mathcal C'\to\mathcal D\) は終点。\(\mathcal C\to\mathcal C'\) は同値（始点評価が自明 Kan fibration）。\(F'\) は内 fibration、充満忠実、本質的全射性は「頂点の上で全射」になる。
2. **鍵の補題**：頂点の上で全射かつ充満忠実な内 fibration は自明 Kan fibration。\(n=0\) は全射性。\(n=1\) は \(\pi_0\) の全射で \(Ff\simeq\bar u\) を取り、2 単体 \((Ff,\mathrm{id},\bar u)\) の上で \(\Lambda^2_1\) を持ち上げる。\(n\ge2\) は写像空間の写像が右 fibration（よって Kan fibration）かつホモトピー同値なので自明 Kan fibration、に帰着（一般の境界の帰着の細部は未確認で、段 1 に戻るときに詰める）。
3. **自明 Kan fibration は同値**：切断 \(s\) を取り、\(\mathrm{Fun}(\mathcal C',\mathcal C')\to\mathrm{Fun}(\mathcal C',\mathcal D)\) も自明 Kan fibration なので \(p\) 上の fiber は可縮な Kan 複体。\(sp\) と \(\mathrm{id}\) は辺で結べ、Kan 複体の辺は同値。

<!-- source: exposition/ja/infinity/route-classification.html:485; block: nbw3-route-classification-l485 -->
<a id="nbw3-route-classification-l485"></a>

**定理 I での使われ方**：強い形 \(\mathrm{Fun}(B,\mathcal S)\simeq\mathrm{LFib}(B)\) はこの判定法の形で示す。段 6 が充満忠実性、段 7 が本質的全射性。
