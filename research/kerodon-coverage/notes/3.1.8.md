## f-01-simplicial-kan.html — 1. 単体的集合の組合せ論（Simplicial） — 1.4 分解と置き換え

<!-- source: exposition/ja/infinity/f-01-simplicial-kan.html:81; block: nbw3-f-01-simplicial-kan-l81 -->
<a id="nbw3-f-01-simplicial-kan-l81"></a>

small object argument から、どんな射も「anodyne の後に fibration」に分解できる。これを使って、任意の単体的集合を Kan 複体や quasicategory に置き換える。

<!-- source: exposition/ja/infinity/f-01-simplicial-kan.html:82; block: nbw3-f-01-simplicial-kan-l82 -->
<a id="nbw3-f-01-simplicial-kan-l82"></a>

| 置き換え | 主張 | 宣言（いまの所在） |
| --- | --- | --- |
| inner anodyne と inner fibration への分解 | 任意の \(f : X \to Y\) は \(X \xrightarrow{i} Z \xrightarrow{p} Y\)（\(i\) は inner anodyne、\(p\) は inner fibration）と分解する | `exists_innerAnodyne_innerFibration_factorization`（InfinityCategories/Kerodon/TheHomotopyTheoryOfInfinityCategories/InnerFibrations/InnerAnodyneReplacement.lean:39） |
| quasicategory への置き換え | 上で \(Y\) が quasicategory なら \(Z\) も quasicategory にできる。第 3 章の「局所化の存在」の証明で使う | `exists_quasicategory_resolution_over`（同 :47） |
| Kan 置換（関手的） | 関手 \(R\) と自然変換 \(X \to RX\) で、\(X \to RX\) は anodyne、\(RX\) は Kan 複体 | `AnodyneKanReplacement.functor`・`unit_anodyne`・`terminal_rlp`（HomotopicalAlgebra/Simplicial/AnodyneKanReplacement.lean:53〜68） |
| Kan の Ex∞ | \(\mathrm{Ex}^\infty X = \operatorname{colim}_n \mathrm{Ex}^n X\) は Kan 複体で、\(X \to \mathrm{Ex}^\infty X\) は anodyne。Ex∞ は有限極限を保ち、Kan fibration を保つ | `exInfinity_kanComplex`・`exInfinityUnit_anodyne`・`exInfinity_preservesFiniteLimits`・`exInfinity_map_rlp`（KST/Comparison/ExInfinity*）。Ex（一回分）は Mathlib の `SSet.ex` |

<!-- source: exposition/ja/infinity/f-01-simplicial-kan.html:89; block: nbw3-f-01-simplicial-kan-l89 -->
<a id="nbw3-f-01-simplicial-kan-l89"></a>

二つの Kan 置換の違いは次のとおり。small object argument による置換は作り方が抽象的で、Ex∞ は具体的（細分を使う）。Ex∞ は有限極限を保つので、fiber や pullback と相性がよい。

## f-02-model-free.html — 2. 道具 1：small object argument と Kan 置換

<!-- source: exposition/ja/infinity/f-02-model-free.html:48; block: nbw3-f-02-model-free-l48 -->
<a id="nbw3-f-02-model-free-l48"></a>

持ち上げ性質で定まる射の族 \(I\) について、small object argument は、任意の射を「\(I\) の pushout の超限合成」と「\(I\) に対する右持ち上げ性質を持つ射」に、関手的に分解する。
\(I\) を horn の包含の集合 \(J\) にとれば、次が得られる。

<!-- source: exposition/ja/infinity/f-02-model-free.html:50; block: nbw3-f-02-model-free-l50 -->
<a id="nbw3-f-02-model-free-l50"></a>

\[
X \xrightarrow{\ \text{anodyne}\ } RX \xrightarrow{\ \text{Kan fibration}\ } \ast
\]

<!-- source: exposition/ja/infinity/f-02-model-free.html:53; block: nbw3-f-02-model-free-l53 -->
<a id="nbw3-f-02-model-free-l53"></a>

つまり、関手的な Kan 置換 \(X \to RX\) である（`AnodyneKanReplacement.factorization : FunctorialFactorizationData anodyneExtensions J.rlp`、HomotopicalAlgebra/Simplicial/AnodyneKanReplacement.lean:44）。
これは small object argument（Mathlib）と anodyne の定義だけから作られており、モデル構造は使っていない。

<!-- source: exposition/ja/infinity/f-02-model-free.html:56; block: nbw3-f-02-model-free-l56 -->
<a id="nbw3-f-02-model-free-l56"></a>

関連する一般的な補題もある：`generatedLeft_map`（HomotopicalAlgebra/Generated/FunctorClosure.lean:70）。余極限を保つ関手 \(F\) が \(I\) を \(W\) に送るなら、\(I\) から生成される射（\({}^{\text{⧄}}(I^{\text{⧄}})\)）もすべて \(W\) に送る。
これは、宇宙の持ち上げが anodyne を保つこと、inner anodyne を保つことなどに使われる。
