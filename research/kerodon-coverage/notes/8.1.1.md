## f-c-spaces.html — 11. \(\mathrm{Map}\) を関手にする：twisted arrow の straightening — 11.6 ファイバーの計算

<!-- source: exposition/ja/infinity/f-c-spaces.html:244; block: nbw3-f-c-spaces-l244 -->
<a id="nbw3-f-c-spaces-l244"></a>

\((x,y)\) 上のファイバーの \(n\) 単体は、左半分がすべて \(x\)、右半分がすべて \(y\) の \(\Delta^{2n+1}\to C\)（TwistedArrow/HomSpace）。

<!-- source: exposition/ja/infinity/f-c-spaces.html:246; block: nbw3-f-c-spaces-l246 -->
<a id="nbw3-f-c-spaces-l246"></a>

- 0 単体：射 \(f\colon x\to y\)。

<!-- source: exposition/ja/infinity/f-c-spaces.html:247; block: nbw3-f-c-spaces-l247 -->
<a id="nbw3-f-c-spaces-l247"></a>

- 1 単体：3 単体 \(x\xrightarrow{\mathrm{id}}x\to y\xrightarrow{\mathrm{id}}y\)。辺 \(f_0=(\bar0,0)\)、\(f_1=(\bar1,1)\)、\(a=(\bar1,0)\)、\(b=(\bar0,1)\)。四つの三角形は一辺が恒等射で \(f_0\sim a\)、\(f_0\sim b\)、\(a\sim f_1\)、\(b\sim f_1\)、3 単体がそれらを整合させる。\(\mathrm{Hom}^L(x,y)\) の 1 単体（三角形 \((x;y,y)\) 一つ）よりデータは多いが同値。

<!-- source: exposition/ja/infinity/f-c-spaces.html:249; block: nbw3-f-c-spaces-l249 -->
<a id="nbw3-f-c-spaces-l249"></a>

**比較写像**（`cosliceTwistedHomMap`）：左半分を錐点につぶす崩壊 \((\Delta^n)^{\mathrm{op}}\star\Delta^n\to\Delta^0\star\Delta^n\) の前合成で、\(n\) について自然な \(\mathrm{Hom}^L(x,y)\to\mathrm{Tw}(C)_{(x,y)}\)。\(n=1\) では三角形 \(\tau\) を退化した 3 単体に送り、\(a=f_0\)、\(b=f_1\)。素朴な逆「\(\bar0\star\Delta^n\) に制限」は、\(d_0\) が \(\bar0\) と \(0\) を同時に除くので面写像と可換にならない（\(N^{hc}\) の \(s_n\) と同じ種類の難点）。

<!-- source: exposition/ja/infinity/f-c-spaces.html:250; block: nbw3-f-c-spaces-l250 -->
<a id="nbw3-f-c-spaces-l250"></a>

**証明**（TwistedHomRows、TwistedHomDiagonal、Joins/CosliceTwistedHomEquivalence）：前に候補として挙げた二重単体の対角の方式。

<!-- source: exposition/ja/infinity/f-c-spaces.html:252; block: nbw3-f-c-spaces-l252 -->
<a id="nbw3-f-c-spaces-l252"></a>

1. 左の大きさ \(m\) と右の大きさ \(n\) を別々に動かした二重単体集合 \(R_{m,n}=\{(\Delta^m)^{\mathrm{op}}\star\Delta^n\to C\mid\text{左は }x\text{、右は }y\text{ で一定}\}\)。

<!-- source: exposition/ja/infinity/f-c-spaces.html:253; block: nbw3-f-c-spaces-l253 -->
<a id="nbw3-f-c-spaces-l253"></a>

2. \(m\) を固定した行は、退化単体 \(\sigma\)（\(x\) の \(m\) 単体）の下のスライス \(C_{\sigma/}\) の \(y\) 上のファイバーそのもの。崩壊 \(\Delta^m\to\Delta^0\) による比較 \(\mathrm{Hom}^L(x,y)\to R_{m,\bullet}\) は同値（`cosliceSimplexExpansion_isQCatEquivalence`）。頂点への制限 \(C_{\sigma/}\to C_{x/}\) が trivial fibration で、join の持ち上げの補題で端の頂点の包含が anodyne であることに帰着する。

<!-- source: exposition/ja/infinity/f-c-spaces.html:254; block: nbw3-f-c-spaces-l254 -->
<a id="nbw3-f-c-spaces-l254"></a>

3. 各行で同値なら対角でも同値（`localized_diagonal_map`）。

<!-- source: exposition/ja/infinity/f-c-spaces.html:255; block: nbw3-f-c-spaces-l255 -->
<a id="nbw3-f-c-spaces-l255"></a>

4. \(R\) の対角 \(R_{n,n}\) は \(\mathrm{Tw}(C)_{(x,y)}\)、定数の側の対角は \(\mathrm{Hom}^L(x,y)\)。

<!-- source: exposition/ja/infinity/f-c-spaces.html:257; block: nbw3-f-c-spaces-l257 -->
<a id="nbw3-f-c-spaces-l257"></a>

自然性の問題は行ごとに \(m\) を固定して避け、対角補題が全体をまとめる。
