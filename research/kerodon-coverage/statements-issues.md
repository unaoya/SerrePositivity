# Kerodon の主張表に関する原典の注記

| 項目 | 原典の表記と要約で採った読み |
|---|---|
| [3.3.7.5](https://kerodon.net/tag/0105) | 図の \(u\) の向きと本文のファイバー写像の向きが逆になっている。要約は同じ底上のファイブレーション間の射と、そこから誘導されるファイバー写像を述べる。 |
| [6.1.2.12](https://kerodon.net/tag/02D1) | 冒頭で \(g:C\to D\) とあるが、\(\eta:\mathrm{id}_C\Rightarrow gf\) と \(cg\) の型、および 6.1.2.9 の設定から \(g:D\to C\) と読む。 |
| [6.1.3.7](https://kerodon.net/tag/02DB) | 冒頭で \(f,g\) を二射と呼ぶが、対象間の射として随伴をなす一射と読む。 |
| [7.1.9.1](https://kerodon.net/tag/06AA) | 第一結論の余極限の存在は印字上 \(C\) に対するものになっている。図 (7.12) と、同じ正方形で各図式の余極限の存在を述べる [7.1.9.8](https://kerodon.net/tag/06AJ) に従い、引き戻し \(C_{01}\) に対する結論として要約した。 |
| [7.3.1.4](https://kerodon.net/tag/02YB) | 参照先 7.3.1.2 は右 Kan 拡張の極限を扱うが、後半の本文は左 Kan 拡張の余極限の添字と記号を使う。要約では、共通するホモトピー類への依存を記した。 |
| [7.3.8.18](https://kerodon.net/tag/031A) | 表示された余スライスの圏は印字上 \(C\) である。図式 \(F,F_0\) の値域と直前の 7.3.8.17 に従い、要約では \(D\) の余スライスとした。 |
| [7.3.9.5](https://kerodon.net/tag/031W) | 図 (7.52) は \(D\to E\) を使うが、本文の後半に \(C\)、底の射の所属に \(D\) が現れる。要約は図と移送 \(D_e\to D_{e'}\) の型に従う。 |
| [7.6.2.40](https://kerodon.net/tag/03FZ) | (2) では左正方形を \(U\)-押し出しと仮定してから、同じ左正方形と外枠を比較している。(1) の双対となる、右正方形と外枠の比較として要約した。 |
| [8.5.6.13](https://kerodon.net/tag/05MJ) | (4) の前合成は印字上 \(F\) とあるが、直後の前層の反変な型と (3) に合わせて \(F^{\mathrm{op}}\) に沿う制限と読んだ。 |
| [9.4.9.12](https://kerodon.net/tag/06U9) | \(F:C\to D\) に沿う逆像を本文末尾では \(D\) の部分圏と呼ぶ。要約では逆像の型に合わせて \(C\) の部分圏とした。 |
