# 概念の定義書：E モデル圏

小概念の名前は `remap-C.csv`・`remap-E.csv`・`remap-Z.csv` の new_subconcept と一致する（C・E・Z の三つの表から来るものを載せた。ほかの大分類の表から来るものは含まない）。［足場］は aux=1、［止めた経路］は stopped のあるもの。文献は入力の reference にあるものだけ。

## E モデル圏/Quillen 関手と生成

**入るもの**：Quillen 関手・Quillen 双関手、モノイダルモデル圏と monoid axiom、余ファイブラント生成、Smith の定理の入力。

**入らないもの**：
- モデル圏の定義・弱同値・（余）ファイブレーションの基本は「モデル圏（基本）」へ
- 単体集合の anodyne 射と小対象の議論による Kan 置換は「単体的モデルと anodyne」へ
- 図式圏の射影モデル構造は「図式のモデル構造とホモトピー余極限」へ
- 通常の圏の射の因子分解のデータ（モデル構造なし）は「Z/圏・関手・極限」へ
- 局所表示可能圏・到達可能性は「Z/圏・関手・極限」へ

**小概念**：
- Quillen 双関手とモノイダルモデル圏
- Quillen 関手
- Smith の定理の入力（解集合・accessible な因子分解）
- 余ファイブラント生成

**文献**：（reference の記載なし）

## E モデル圏/Reedy

**入るもの**：Reedy 圏と Reedy モデル構造：latching・matching の添字圏と対象、Reedy の射の類、次数による切り詰め、因子分解と持ち上げの次数帰納、Reedy 構造の例。

**入らないもの**：
- Reedy 余ファイブラント解像・cosimplicial frame は「ホモトピー関数複体と分解」へ
- 複体の Δ 添字の strict な図式の Reedy モデル構造は「D/導来 ∞ 圏」へ
- 射影モデル構造は「図式のモデル構造とホモトピー余極限」へ

**小概念**：
- Reedy の射の類（相対 latching・matching 条件）
- Reedy 構造の例と構成
- latching・matching の添字圏と対象
- 次数による切り詰めと一対象の付加
- Reedy の因子分解と持ち上げの次数帰納［足場］

**文献**：（reference の記載なし）

## E モデル圏/ホモトピー関数複体と分解

**入るもの**：モデル圏の余単体的分解と frame、ホモトピー関数複体（導来写像空間）、実現と単体集合によるテンソル、分解の bar 構成、持ち上げの空間、語による表示。

**入らないもの**：
- frame の Hom と hammock 局所化の比較、自由解像、zigzag は「C/局所化（Dwyer–Kan）」へ
- frame と重みによる実現・ホモトピー余極限は「図式のモデル構造とホモトピー余極限」へ
- 単体的 bar 構成（相対 bar）・anodyne は「単体的モデルと anodyne」へ
- ∞ 圏の写像空間は「C/写像空間」へ
- dg 関手の半自由分解は「B/導来圏と Perf（dg 加群）」へ
- 神経の単体の上の整合的な族は「C/神経」、Kan 複体の中の比較三角形は「C/Kan 複体とホモトピー群」へ

**小概念**：
- 余単体的分解と frame
- ホモトピー関数複体（導来写像空間）
- 分解の bar 構成［止めた経路］
- 実現と単体集合によるテンソル
- 持ち上げの空間［止めた経路］
- bar の厳密化：選択の圏と自由図式の延長［足場・止めた経路］
- 持ち上げの選択の整合化［足場・止めた経路］
- 語で表示した圏［足場・止めた経路］
- 語の区間［足場・止めた経路］

**文献**：
- ホモトピー関数複体（導来写像空間）：Hirschhorn 17.1–17.4；Dwyer–Kan Function complexes §4
- 余単体的分解と frame：Hirschhorn 16.1・16.6；Hovey 5.2
- 実現と単体集合によるテンソル：Hirschhorn 16.3；Hovey 5.4
- 持ち上げの空間：Hirschhorn 16.1.5・17.5 に対応
- 語で表示した圏：計画書 §396「任意モデル源への一般化（中断、2026-10-17）」（ファイル冒頭）
- 語の区間：計画書 §396（ファイル冒頭）

## E モデル圏/単体的モデルと anodyne

**入るもの**：単体集合の anodyne 射とリフト性、Kan–Quillen モデル構造、小対象の議論による関手的分解と Kan 置換関手、anodyne 射の局所化、単体的 bar 構成、骨格に沿う貼り合わせ、選択の空間。

**入らないもの**：
- Kan 複体・Kan ファイブレーション・Ex∞ による Kan 置換は「C/Kan 複体とホモトピー群」へ
- 左・右 anodyne と左・右ファイブレーションは「C/ファイブレーションと straightening」へ
- 内 anodyne だけ・準圏の条件は「C/準圏（基本）」へ
- ホーン・境界・骨格そのものは「C/単体集合（基本）」へ
- ホモトピー余極限は「図式のモデル構造とホモトピー余極限」へ
- 対称スペクトルの水準ごとのモデル構造は「G/対称スペクトル」へ

**小概念**：
- anodyne 射・リフト性・Kan–Quillen モデル構造
- Kan 置換と関手的分解
- anodyne 射の局所化と単体的ホモトピー類
- 単体的 bar 構成（相対 bar）
- 骨格・境界に沿う貼り合わせ

**文献**：
- anodyne 射・リフト性・Kan–Quillen モデル構造：Kerodon 3.1; HTT 2.1–2.3
- Kan 置換と関手的分解：Kerodon 00UV（AnodyneKanReplacement.factorization の属性）
