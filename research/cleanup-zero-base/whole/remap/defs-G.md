# 概念の定義書：G スペクトル

`out/remap-G.csv`・`out/remap-H.csv` の new_subconcept と一致させてある。（足場）は aux=1 の小概念。

## G スペクトル/Ω スペクトル（Bousfield–Friedlander）

- **入るもの**：スペクトルの水準の宣言。点つき Kan 複体の列（Kan 列）と Ω スペクトル、その射・写像空間・∞ 圏 Sp、ホモトピー群、loop と delooping、fiber、cotensor、スペクトルのホモトピー極限・Tot・homotopy fixed points、filtered 余極限・逐次余極限・有理化。
- **入らないもの**：
  - 点つき単体集合（空間）の水準の loop・path・fiber・cofiber・点つき内部 Hom・持ち上げの空間・連結準同型は「C 単体集合と ∞ 圏/基点付き空間」へ。基点なしの path 対象と単体的ホモトピーは「C 単体集合と ∞ 圏/Kan 複体とホモトピー群」へ。
  - 点つき空間の重みつき end・余単体対象の Tot・fibration の塔（スペクトルを主語にしないもの）は「C 単体集合と ∞ 圏/基点付き空間」へ。単体集合の正規化 cochain は「B 複体と dg 圏/単体的鎖・Dold–Kan・シャッフル」へ。
  - 厳密な豊穣自然変換を coherent 神経へ移す道具、Path の分割は「C 単体集合と ∞ 圏/単体的圏と coherent 神経」へ。
  - K スペクトル K(X) の構成は「H K 理論/S 構成と K スペクトル」へ、非連結 K の逐次列そのもの（懸垂の反復）は「H K 理論/非連結 K」へ。ここに入るのは一般のスペクトルの逐次余極限だけ。
  - Sp 値関手が局所化不変量であるという条件は「H K 理論/lax 引き戻しと局所化不変量」へ。
  - 対称スペクトルは「G スペクトル/対称スペクトル」へ（模型が別）。
- **小概念**：
  - Ω スペクトルと Kan 列
  - スペクトルの写像空間と Sp
  - スペクトルのホモトピー群と π_* 同型
  - loop スペクトルと delooping
  - スペクトルの fiber と homotopy fiber
  - 点つき単体集合による cotensor
  - スペクトルのホモトピー極限・Tot・homotopy fixed points
  - filtered 余極限と有理化
  - スペクトルの逐次余極限（「H K 理論/非連結 K」から）
  - （足場）loop 関手の随伴の比較（相対 BF 分解）
- **文献**：BF 1978 §2、HA §1.4.2、HTT A.3.3、Goerss–Jardine I §§7–8・III §2・VIII §§1–2。

## G スペクトル/対称スペクトル

- **入るもの**：対称スペクトル（Sym(K) 上の加群、一般の対称モノイダル圏と対象 K の版と、点つき単体集合と円の版）の定義・段・構造射、球面スペクトル、自由スペクトル F_n、smash 積、内部 Hom、係数対象による tensor・cotensor、写像対象。
- **入らないもの**：
  - モノイド対象の上の加群の一般論（釣り合いテンソル、加群の内部 Hom、自由加群）は「Z 圏論一般/モノイダル圏の中の加群」へ。
  - 対称列そのもの（convolution、Sym(X)、自由対称列）は「G スペクトル/対称列」へ。
  - 豊穣圏の tensor・cotensor の表現データの一般の定義は「Z 圏論一般/豊穣圏」へ。
  - Ω スペクトル（列の模型）は「G スペクトル/Ω スペクトル（Bousfield–Friedlander）」へ。
- **小概念**：
  - 対称スペクトルの定義・段・構造射
  - 自由スペクトル F_n
  - 球面上のテンソル積（smash 積）
  - 内部 Hom スペクトル
  - 係数対象による tensor・cotensor
  - 写像対象（豊穣 Hom）
- **文献**：小概念の reference に記載なし。

## G スペクトル/対称列

- **入るもの**：有限集合と全単射の圏からの関手としての対称列、段、Day convolution と単位、内部 Hom、自由対称列と誘導の商表示、反復テンソルの対称列 Sym(X)、段ごとのテンソル。添字の圏（有限集合と全単射の圏、直和）も今はここ。
- **入らないもの**：
  - 対称モノイダル圏の対象の反復テンソルと対称群の作用（TensorPowers.power など、対称列を使わないもの）は「Z 圏論一般/モノイダル圏」へ。
  - Sym(K) 上の加群としての対称スペクトルは「G スペクトル/対称スペクトル」へ。
  - 球面の対称列を作る元の点つき球面は「C 単体集合と ∞ 圏/基点付き空間」へ。
  - 隣接互換などの置換の組合せ論は「Z 圏論一般/組合せと順序」へ。
- **小概念**：
  - 対称列の定義と段
  - 有限集合と全単射の圏
  - Day convolution
  - 対称列の内部 Hom
  - 自由対称列と誘導の商表示
  - 反復テンソルの対称列 Sym(X)
  - 段ごとのテンソル
- **文献**：小概念の reference に記載なし。
