# 概念の木の直し：決定（2026-11-20）

答えを見ない二度目の分類（`check/`）で、同じ内容が複数の概念の下に並んでいる所と、概念でないものが木に入っている所が分かった。ここに、ユーザーと決めた規則と、重なりの整理を書く。

## 規則（ユーザー決定）

1. **止めた経路かどうかは分類に使わない。** 宣言は内容で整理する。止めた経路上にある宣言には印（タグ）を付ける。
2. **補助かどうかも印にする。** 補助＝一つの定理の証明のためだけにある宣言。分類は内容で行う。
3. **分類は、主張に現れる概念で決める。** 一般的な補題が特定の理論のために書かれていても、主張に現れるのが一般の概念だけなら、一般の概念に入れる。
4. **主張に複数の概念が現れるとき**：概念どうしの上下を定義の依存で決め（B の定義が A の定義を使って作られていれば、A が土台、B が下流）、土台の概念を除く。残りが一つならそこに入れる。互いに土台でない概念が複数残るときは、「A と B の関係」という小概念にする。

## 重なりの整理

### A 可換代数と数論幾何
- **Rees 代数**（Hilbert–Samuel、blowup、Koszul の三か所）：「Rees 代数と I 進フィルター」を一つ立て、Rees 代数・Rees 加群・進フィルター・I 進閉厚化をそこへ。Hilbert–Samuel は関数と重複度だけ、blowup は Proj と blowup だけ。
- **根の添加・δ 除算・分冪包絡**：δ 除算＝A{a/d} の構成と表示、平坦性の計算（BS Rem 7.15、prismatic envelope）。分冪包絡＝分冪構造と包絡。根の添加＝根を添加した環と André の補題だけ。今「根の添加」にある包絡の計算は δ 除算へ。
- **根の塔・パーフェクトイド・根の添加**：根の塔＝論文 §2 の塔 A_n とその極限。パーフェクトイド＝定義とパーフェクトイド化。p 冪根つき多項式環は根の添加へ。
- **正規化長さ・ほとんど数学・根の塔**：結論が長さについての補題は正規化長さ。almost zero の定義と基本性質は「ほとんど数学」。冪ねじれ（IsPowTorsion、Γ_I）は「台つきの加群と複体」へ。
- **台つきの加群と Tor・完全複体と K₀**：台の条件（閉集合によるもの、冪零によるもの）は「台つきの加群と複体」に一本化。台つきの K₀・G₀ は「完全複体と K₀」。
- **完備平坦と整閉**：概念として解く。三つの性質は「環と加群」の小概念へ。
- **導来完備化**：完備化の一般論は導来完備化。特定の環の完備化の計算は、その環の概念へ。
- **プリズム／プリズマティックコホモロジー**、**δ 環／δ 除算**、**導来完備化／上に有界な導来圏と導来底変換**：版 5 で分けたまま。
- **スキーム**：残りの中心は「有限表示の模型による近似と降下」。blowup・Čech・Frobenius に属するものはそちらへ。
- **Čech**：余単体的可換環のコホモロジーと cup 積（`Cosimplicial.*`）は Čech の下の小概念でよい。Čech–Alexander 模型はプリズマティックコホモロジー、分冪 Čech は分冪包絡へ。

### B 複体と dg 圏、D 安定 ∞ 圏と導来 ∞ 圏
- **Dold–Kan と正規化**（複体、単体集合、単体的鎖の三か所）：「単体的鎖・Dold–Kan・シャッフル」に一本化。
- **三角圏**（三か所）：「三角圏と t 構造」を一つ（一般論）。複体のホモトピー圏・導来圏は「複体」に残す。
- **dg 加群・導来圏と Perf・導来 ∞ 圏**：dg 加群＝厳密な水準（対象、Hom 複体、写像錐、K(D)、半自由・ホモトピー射影的、分解）。導来圏と Perf＝D(D) と Perf を三角圏として、有限 cell、Perf の dg 増強。導来 ∞ 圏＝dg 神経による ∞ 圏の模型。
- **係数の取り替え**：底変換の関手が主語の宣言は、複体・dg 加群・Perf・dg 商のどれでも「係数の取り替え」へ。
- **kernel の導来作用**：「双加群とテンソル」へ。
- **K-flat**：「双加群とテンソル」の小概念のまま（四つの水準は整理の候補として記録）。
- **lax 引き戻し**（三か所）：∞ 圏の lax 引き戻しの定義、Cat^perf、局所化不変量の定義、差の関手と Tamme 商、Land–Tamme の ⊙ の dg 模型は「lax 引き戻しと局所化不変量」（H）へ。dg の貼り合わせ圏そのもの（対象、Hom 複体、cone、Milnor 四角形）は「dg の貼り合わせ」。両者の比較定理も「dg の貼り合わせ」。
- **Verdier 列・安定 ∞ 圏・極限**：零対象・cofiber・四角形で安定性を使うものは安定 ∞ 圏。一般の四角形は極限と余極限。
- **coherent bar・導来 ∞ 圏・極限**：coherent bar は独立のまま。複体の strict な図式の ∞ 局所化は導来 ∞ 圏へ。
- **複体の dg 神経での fiber 四角形・cofiber 四角形**：どちらも導来 ∞ 圏へ。
- **dg 代数**：「dg 圏と dg 関手」に統合（版 5）。Postnikov の中の dg 代数の一般のホモトピー論（胞体分解、path 対象、ホモトピー引き戻し、写像空間）は「dg 代数のホモトピー論」として H から B へ出す。
- **dg 商と cell 分解**：そのまま（path 複体の重複は整理の候補として記録）。

### C 単体集合と ∞ 圏、E モデル圏、Z 圏論一般
- **局所化**（三つ）：通常の圏の局所化と射の類は Z（圏論一般）に一つ（「局所化と射の類」）。hammock・zigzag・自由解像・両側 Grothendieck 構成は「局所化（Dwyer–Kan）」。frame と余単体的分解は「ホモトピー関数複体と分解」。モデル圏の局所化との比較定理は Dwyer–Kan の側。
- **冪等完備**：C は「冪等完備（∞ 圏）」、Z は「冪等完備（通常の圏）」。
- **極限・ファイブレーション・∞ 層**：重み付き切断とホモトピー極限は極限。相対関手空間はファイブレーション。層の条件が主語のものは ∞ 層。
- **necklace と立方体・coherent 神経**：coherent 神経の Hom の計算（necklace、coherent resolution、Path の分割）は「単体的圏と coherent 神経」へ。立方体の組合せ論（立方体の頂点・正規形・cubical 集合）は「立方体の組合せ論」。

- **単体集合（基本）・Kan 複体**：単体的ホモトピーと Kan ファイブレーションは「Kan 複体とホモトピー群」へ。
- **随伴の単位の空間**（表示可能 ∞ 圏の下）、準圏の随伴（結とスライスから移した分）：「随伴（∞ 圏）」へ。

- **止めた経路「任意のモデル圏への一般化」**：概念としては解く。中の宣言は内容で分ける（語と道の分解 → ホモトピー関数複体と分解、神経の図式の延長 → 神経 または 図式のモデル構造、選択の空間 → 単体的モデルと anodyne、など）。印を付ける。
