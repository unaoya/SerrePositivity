# EN-W1 段1　豊穣化を受け取る構成

同じ入力構造の補題を構成ごとにまとめた。通常の `EnrichedCategory` が与えるのは Hom 対象・単位・合成。`EnrichedOrdinaryCategory` は既存の通常圏との一致を加え、`TensorCotensor` は二つのパラメータ付き随伴を加える。単体的 Hom の Kan 性、モデル構造の pushout-product、導来置換はさらに別の入力になる。構成の供給元の宣言は [constructions.csv](constructions.csv) に掲げる。

| 構成 | 仮定と出力 | 実際に渡される豊穣化 |
|---|---|---|
| 通常の Hom・豊穣 Hom の関手 | `EnrichedOrdinaryCategory V M` で、通常の射による前後合成を `eHomFunctor V M` に束ねる。`TransportOrdinaryEnrichment.homFunctorIso` と `RepresentedHomFunctor.homFunctorIso_ofParametrized` は、基底変更と表現右随伴の Hom をそれぞれ比較する。 | 一般対称スペクトルの `mappingEnrichedOrdinaryCategory`。円周スペクトルと基点付き単体集合で基底変更の版を使用する。 [表現による比較](../../../SerrePositivity/CategoryTheory/Enriched/RepresentedMapping.lean#L910) · [基底変更の比較](../../../SerrePositivity/CategoryTheory/Enriched/Transport.lean#L288) |
| テンソル・余テンソル・モデル圏適合性 | `TensorCotensor` とモデル圏構造の下で、作用の pushout-product と余テンソル・写像対象の pullback-Hom 条件を同値にする。単体集合の版では境界・ホーンから豊穣 Hom の Kan 性や写像のファイブレーション性を導く。 | `spectrumTensorCotensor` は一般対称スペクトルの二つの随伴から供給。円周の場合は基点付き単体集合での自由第0段と相対テンソル、および選んだレベルモデル構造を使う。固定 Quillen 類の一般定理は任意の渡された `TensorCotensor SSet M` を使う。 [モデル圏の同値](../../../SerrePositivity/HomotopicalAlgebra/Enriched/TensorCotensor.lean#L30) · [固定した単体的条件](../../../SerrePositivity/InfinityCategories/Project/ModelCategoryComparison/Replacements/FixedSimplicialModelCompatibility.lean#L31) · [スペクトルの供給元](../../../SerrePositivity/Spectra/General/TensorCotensorEnriched.lean#L24) |
| ホモトピー関数複体・豊穣局所化 | `TensorCotensor SSet M` で標準単体をテンソルした余単体図式の Hom を、実際の豊穣 Hom と比較する。置換関手を通して導来 Hom を取り、局所対象と局所同値を試す。 | 単体的モデル圏の選んだテンソル・余テンソル。Barratt–Eccles の右・左 frame 比較は重み付き実現と置換を別に通すため、任意のモデル圏に厳密な豊穣化があるとの仮定を加えない。 [単体テンソル](../../../SerrePositivity/HomotopicalAlgebra/HomotopyFunctionComplex/SimplicialTensorHom.lean#L67) · [導来 Hom](../../../SerrePositivity/HomotopicalAlgebra/Enriched/DerivedMapping.lean#L32) · [豊穣局所化](../../../SerrePositivity/HomotopicalAlgebra/Localization/Enriched.lean) |
| 豊穣関手と図式の圏 | 一般の `EnrichedFunctor` は二つの既存豊穣化と Hom の射、恒等・合成保存を取る。通常図式の豊穣 Hom は Mathlib の `Enriched/FunctorCategory.lean` で end。dg 関手では Hom 複体を dg 自然変換の複体として構成する。 | dg 圏 `D` と dg 関手を出発点にした `dgFunctorEnrichment`、完全部分圏、dg Module 圏。単体的図式・collage では既定の単体的 Hom と `SimplicialCategory` を使う。 [dg 関手圏](../../../SerrePositivity/DifferentialGraded/Functor/DGFunctorEnrichment.lean#L93) · [単体的図式の collage](../../../SerrePositivity/KST/SConstruction/EnrichedFunctorCollage.lean) |
| Coherent 神経 | `SimplicialCategory M` または単体的 Hom を持つ圏と豊穣関手から `SimplicialNerve M`、その射、頂点・辺・合成の公式を作る。局所 Kan から準圏、点ごとの Hom の比較から充満忠実性を示す。 | 離散豊穣、Kan 複体の充満部分圏、dg 圏の Dold–Kan/Alexander–Whitney 豊穣、hammock / free hammock の Kan 化、`OmegaSpectrum.simplicialCategory`。これらは同じ神経の入口を通す。 [神経の辺](../../../SerrePositivity/InfinityCategories/Kerodon/ExamplesOfInfinityCategories/SimplicialCategories/Edges.lean#L25) · [充満忠実性](../../../SerrePositivity/InfinityCategories/Kerodon/TheHomotopyTheoryOfInfinityCategories/FullFaithfulAndEssentiallySurjectiveFunctors/NerveFullyFaithful.lean#L72) · [Ω スペクトルの神経](../../../SerrePositivity/KST/Spectra/CoherentNerve.lean#L25) |

| 単体的局所化とモデル圏比較 | 相対圏の指定した弱同値を使い、hammock/free resolution の Hom を合成可能な単体集合にする。豊穣関手・神経でこれらとモデル圏の余ファイブラント・ファイブラント対象を比較する。 | `localizationEnrichedCategory`、`hammockEnrichedCategory`、`freeHammockEnrichedCategory` と各 Kan 置換を受ける。左作用の豊穣化を仮定する一般定理としては扱わない。 [局所化の豊穣化](../../../SerrePositivity/InfinityCategories/HA/ModelCategoryComparison/SimplicialLocalization/Enrichment.lean#L35) · [Kan 側の神経](../../../SerrePositivity/InfinityCategories/HA/ModelCategoryComparison/SimplicialLocalization/KanComparisonNerves.lean) |
