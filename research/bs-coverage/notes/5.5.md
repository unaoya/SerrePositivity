## 系 5.1.5（原典 Cor 5.5：標数 p の HT 比較） — 主張

<!-- source: exposition/ja/bs/05-hodge-tate.html:132; block: bs-05-l132 -->
<a id="bs-05-l132"></a>

結晶 prism \((A,(p))\) と smooth な \(A/p\) 代数 \(S\) について、定理 4.2.3（原典 Thm 4.11）の比較写像は同型
\[H^i(\overline\Delta_{S/A})\;\cong\;\Omega^i_{S/(A/p)}\{-i\}\]
を与える。特に、\(R\mapsto\Delta_{R/A}\) は prism \((A,(p))\) の任意の p 完備な底変換と可換である。

## 系 5.1.5（原典 Cor 5.5：標数 p の HT 比較） — Lean

本体にあるのは \(A=\mathbb Z_p\)、\(S=\mathbb F_p[X_1,\dots,X_r]\)（有限変数）の場合：`hodgeTate_iso_polynomial_Zp`（[HodgeTateCartierAssembly:212](../../../SerrePositivity/BhattScholze/Prismatic/HodgeTateCartierAssembly.lean)）。主張の型 `HodgeTateIsoStatement`（[HodgeTateCompletedMap:461](../../../SerrePositivity/BhattScholze/Prismatic/HodgeTateCompletedMap.lean)）は、各 i で多項式の HT 写像 `hodgeTateMap`（:398、定義 4.2.1 の \(\eta^i\) の模型での形）が全単射であること。証明は定理 5.1.2 の Lean の加法同型 `crystallineChain` に次の二段を足す。

<!-- source: exposition/ja/bs/05-hodge-tate.html:140; block: bs-05-l140 -->
<a id="bs-05-l140"></a>

1. **Cartier 同型**：`finitePolynomialCartier`（[FinitePolynomialCartier:46](../../../SerrePositivity/BhattScholze/Prismatic/FinitePolynomialCartier.lean)）。型 `PolynomialCartier`（:35）は各次数の加法同型 \(\Omega^i\to H^i(\Omega^\bullet)\) と、次数 0 で \(f\mapsto[f^p]\)、次数 1 で \(dX_j\mapsto[X_j^{p-1}dX_j]\)、外積との両立の組。加法同型は単項式基底で、指数と一次形式の重みがすべて p の倍数の単項式だけを残すホモトピー同値から作る（`finiteCartierLinearEquiv`、[CartierFinite:213](../../../SerrePositivity/CommutativeAlgebra/DeRham/CartierFinite.lean)、`cartierMonomialEquiv`、[CartierWeight:146](../../../SerrePositivity/CommutativeAlgebra/DeRham/CartierWeight.lean)）。

<!-- source: exposition/ja/bs/05-hodge-tate.html:141; block: bs-05-l141 -->
<a id="bs-05-l141"></a>

2. **生成元での照合**：`crystallineChain_generators`（[CrystallineGeneratorClasses:83](../../../SerrePositivity/BhattScholze/Prismatic/CrystallineGeneratorClasses.lean)）は、`crystallineChain` が \(\eta^0(X_j)\) を \([X_j^p]\) に、\(\eta^1(dX_j)\) を \([X_j^{p-1}dX_j]\) に送ることを示す。零次・一次の一致を加法と外積で全次数へ延ばし、HT 写像を二つの同型の合成と同一視して全単射性を得るのが `hodgeTate_of_deRham_cartier`（:180）。

## 系 5.1.5（原典 Cor 5.5：標数 p の HT 比較） — 証明

<!-- source: exposition/ja/bs/05-hodge-tate.html:147; block: bs-05-l147 -->
<a id="bs-05-l147"></a>

原典の筋：Lemma 4.21（命題 4.3.6）で S を多項式代数 \(A/p[X_1,\dots,X_n]\) に帰着し、Lemma 4.20（命題 4.3.5）で \(A=\mathbb Z_p\) に帰着する。すると \(S=R^{(1)}\)（\(R=\mathbb F_p[X_1,\dots,X_n]\)、\(\psi\) は恒等）で、定理 5.1.2 と Cartier 同型から従う。

<!-- source: exposition/ja/bs/05-hodge-tate.html:148; block: bs-05-l148 -->
<a id="bs-05-l148"></a>

（補った）各段の中身。(a) \(A\) は p ねじれなし（\((p)\) が prism のイデアル）なので \(\mathbb Z_p\to A\) は p 完全平坦で、Lemma 4.20 により \(\overline\Delta_{S/A}\simeq\overline\Delta_{\mathbb F_p[X]/\mathbb Z_p}\widehat\otimes^L_{\mathbb Z_p}A\)。\(\Omega^i\) も底変換と可換で、\(\{-i\}\) の捻りは生成元 p で自明化される。(b) \(A=\mathbb Z_p\) では定理 5.1.2 と多項式の場合の結晶 Poincaré 補題により \(\Delta_{\mathbb F_p[X]/\mathbb Z_p}\simeq R\Gamma_{\mathrm{crys}}(\mathbb F_p[X]/\mathbb Z_p)\simeq\widehat\Omega^\bullet_{\mathbb Z_p[X]/\mathbb Z_p}\) で、mod p で \(\overline\Delta\simeq\Omega^\bullet_{\mathbb F_p[X]/\mathbb F_p}\)。(c) Cartier 同型 \(C^{-1}\colon\Omega^i_{\mathbb F_p[X]}\xrightarrow{\sim}H^i(\Omega^\bullet_{\mathbb F_p[X]})\)（\(f\mapsto[f^p]\)、\(df\mapsto[f^{p-1}df]\)、外積と両立）と合わせて \(H^i(\overline\Delta)\cong\Omega^i\)。(d) この同型が Thm 4.11 の比較写像 \(\eta^i\) と一致すること（原典は述べない）：両辺とも外積と両立するので \(\eta^0(X_j)\) と \(\eta^1(dX_j)\) を見れば足りる。\(\eta^0(X_j)\) は Frobenius 捻りを通って \([X_j^p]\)。\(\eta^1(dX_j)\) は Bockstein の像で、整係数の総次数 0 の余鎖 \(X_j^p\) の総微分の横成分 \(X_{j,1}^p-X_{j,0}^p\) と縦成分 \(pX_j^{p-1}dX_j\) がともに p で割れ、その商の mod p の二つの射影が Bockstein の代表と Cartier の代表 \([X_j^{p-1}dX_j]\) を与えるので一致する。

<!-- source: exposition/ja/bs/05-hodge-tate.html:149; block: bs-05-l149 -->
<a id="bs-05-l149"></a>

後半（補った）：prism の射 \((A,(p))\to(B,(p))\) と smooth な \(R\) について、比較写像 \((\Delta_{R/A}\widehat\otimes^L_AB)\to\Delta_{R_B/B}\) は、両辺導来 p 完備なので導来 Nakayama で mod p を見ればよい。前半により \(H^i(\overline\Delta_{R/A})\cong\Omega^i_{R/(A/p)}\) は射影的なので、底変換の \(H^i\) は \(\Omega^i_{R/(A/p)}\otimes_{A/p}B/p\cong\Omega^i_{R_B/(B/p)}\) で、比較写像はこの同型にあたる（系 4.2.4 と同じ議論）。
