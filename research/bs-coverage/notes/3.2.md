## 定義 3.1.2（原典 Def 3.2：prism の圏） — 主張

<!-- source: exposition/ja/bs/03-prism.html:59; block: bs-03-l59 -->
<a id="bs-03-l59"></a>

δ 環 \(A\) とイデアル \(I\subset A\) の組 \((A,I)\) を **δ 対**と呼ぶ。δ 対全体は圏（δ 対の圏）をなす（射 \((A,I)\to(B,J)\) は \(f(I)\subset J\) となる δ 射 \(f\colon A\to B\)）。

(1) \((A,I)\) が **prism** であるとは、\(I\subset A\) が \(\mathrm{Spec}(A)\) の Cartier 因子を定め、\(A\) が導来 \((p,I)\) 完備で、\(p\in I+\varphi(I)A\) であること。prism の圏は δ 対の圏の対応する充満部分圏。

(2) prism \((A,I)\) は次のように呼ばれる。

・**完全**：\(A\) が完全 δ 環、すなわち \(\varphi\colon A\to A\) が同型。

・**有界**：\(A/I\) の \(p^\infty\) ねじれが有界。

・**向き付け可能**：イデアル \(I\) が単項。\(I\) の生成元の選び方を**向き**と呼ぶ。

・**結晶**：\(I=(p)\)。このような prism は有界かつ向き付け可能。

(3) prism の射 \((A,I)\to(B,J)\) が**（忠実）平坦**であるとは、\(A\to B\) が \((p,I)\) 完全（忠実）平坦であること。

## 定義 3.1.2（原典 Def 3.2：prism の圏） — Lean

<!-- source: exposition/ja/bs/03-prism.html:70; block: bs-03-l70 -->
<a id="bs-03-l70"></a>

(1) は向き付きの形。構造 `OrientedPrism`（[OrientedPrism:120](../../../SerrePositivity/BhattScholze/Prism/Basic/OrientedPrism.lean)）の欄は δ 構造 `deltaStructure`、生成元 `generator`、生成元の正則性 `generator_regular`（Cartier 因子にあたる）、導来 \(p\) 完備性 `complete_p` と導来生成元完備性 `complete_generator`（二つを合わせて導来 \((p,d)\) 完備）、\(p\in(d,\varphi(d))\) `p_mem`。イデアル `OrientedPrism.ideal`（:132）は \((d)\)、原典の形 \(p\in I+\varphi(I)A\) は `OrientedPrism.p_mem_sup_map`（:139）。distinguished な正則元からの構成 `OrientedPrism.ofDistinguished`（:146）。導来完備性は共通基盤の `DerivedCompletion.IsModuleComplete`（[HomologicalAlgebra/DerivedCompletion/ModuleComplete/Basic:140](../../../SerrePositivity/HomologicalAlgebra/DerivedCompletion/ModuleComplete/Basic.lean)）で、生成元が非零因子なので古典的 \(d\) 進完備性と同値（`OrientedPrism.isAdicComplete_generator`、OrientedPrism:153）。導来完備な環ではパラメータが Jacobson 根基に入る `OrientedPrism.p_mem_jacobson`・`OrientedPrism.generator_mem_jacobson`（:165・169）。

射は δ 対の射の形 `OrientedPrism.Hom`（:210）：δ 射 `map_delta` と \((d)\subset f^{-1}(J)\) `ideal_le`。生成元そのものの保存は要求しない。恒等射・合成 `Hom.id`・`Hom.comp`（:226・230）と結合律 `Hom.comp_assoc`（:245）。`Category` のインスタンスは置いていない。

(2) 完全は述語 `DeltaStructure.IsPerfect`（[DeltaRing:166](../../../SerrePositivity/BhattScholze/Delta/Basic/DeltaRing.lean)）を δ 構造に課す仮定として使う。有界は述語 `Prismatic.IsBoundedPrism`（[Prismatic/PrismOver:41](../../../SerrePositivity/BhattScholze/Prismatic/PrismOver.lean)）（\(A/d\) の \(p\) 冪ねじれが一様な冪 \(p^N\) で消える）。向きは構造のデータ（生成元）。結晶は例 3.1.3。

(3) 完全（忠実）平坦性は `IsCompletelyFlat`・`IsCompletelyFaithfullyFlat`（[CommutativeAlgebra/CompletelyFlat/Basic:42・48](../../../SerrePositivity/CommutativeAlgebra/CompletelyFlat/Basic.lean)）を \(I=(p,d)\) で使う。prism の射についての述語は、site の射について `Prismatic.PrismOver.IsFaithfullyFlat`（[Prismatic/FlatCover:40](../../../SerrePositivity/BhattScholze/Prismatic/FlatCover.lean)）がある。

## 定義 3.1.2（原典 Def 3.2：prism の圏） — 証明

<!-- source: exposition/ja/bs/03-prism.html:77; block: bs-03-l77 -->
<a id="bs-03-l77"></a>

確かめることは (2) の最後の一文だけ（補った）。\(I=(p)\) は単項なので向き付け可能。\(A/I=A/p\) は \(p\) で消えるので \(p^\infty\) ねじれは \(p^1\) で消え、有界。

Lean の形との関係（補った）：(i) Cartier 因子 \(I\) が単項 \((d)\) なら \(d\) は非零因子である：局所的に \(I=(g)\)、\(g\) 非零因子と書くと \(d=ug\)、\(g=vd\) で \((1-uv)g=0\) から \(uv=1\)、よって \(d\) は局所的に非零因子の単元倍。(ii) 有限生成イデアル \((f_1,\dots,f_r)\) についての導来完備性は、各 \(f_i\) についての導来完備性と同値。よって導来 \((p,d)\) 完備性は欄 `complete_p`・`complete_generator` の組と同じ。

## 定義 3.1.2（原典 Def 3.2：prism の圏） — 原典との差（D5・D19）

<!-- source: exposition/ja/bs/03-prism.html:82; block: bs-03-l82 -->
<a id="bs-03-l82"></a>

Lean の対象は向き付き prism（単項イデアルと生成元を持つ）だけで、局所単項な一般の Cartier 因子 \(I\) は扱わない（D5）。射は向きを保つことを要求しないので、`OrientedPrism` と `OrientedPrism.Hom` の圏は向き付け可能な prism の充満部分圏と同値になる（同じイデアルの別の生成元を選んだ対象どうしは恒等写像で同型）。固定した向き付きの基底の上では、剛性（命題 3.2.1）により相手も自動的に向き付き（D19）。
