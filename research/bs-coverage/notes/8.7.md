# BS 8.7　p 進形式スキームの arc 位相

原典 Definition 8.7

照合先（本文外）：`SerrePositivity.BhattScholze.Perfectoidization.Arc.IsArcCoverFamily`、`SerrePositivity.BhattScholze.Perfectoidization.Arc.arcTopology`、`SerrePositivity.BhattScholze.Perfectoidization.Arc.arcTopologyPerfd`。既存 review の記載。

## 定義 8.3.1（原典 Def 8.7） — 主張

<!-- source: exposition/ja/bs/08-perfection.html:195; block: bs-08-l195 -->
<a id="bs-08-l195"></a>

p 進形式スキームの圏 fSch を考える。qcqs な p 進形式スキームの射 \(Y\to X\) が **arc 被覆**であるとは、p 進完備な階数 1 の付値環 \(V\) と射 \(\mathrm{Spf}V\to X\) のそれぞれについて、p 進完備な階数 1 の付値環の忠実平坦な拡大 \(V\subset W\) と、持ち上げ \(\mathrm{Spf}W\to Y\) があることをいう。arc 被覆と開被覆が生成する位相で fSch を site にし、これを fSch 上の **arc site** と呼ぶ。

\(\mathrm{Perfd}\subset\mathrm{fSch}\) を、局所的に perfectoid 環 \(R\) により \(\mathrm{Spf}R\) と書ける p 進形式スキームの充満部分圏とし、誘導位相を入れる。

## 定義 8.3.1（原典 Def 8.7） — Lean

<!-- source: exposition/ja/bs/08-perfection.html:200; block: bs-08-l200 -->
<a id="bs-08-l200"></a>

affine 版が本体にある。site の台は濃度 \(\le\kappa\) の導来 p 完備環の圏 `AffCompl`（[Derived/ArcSite:96](../../../SerrePositivity/BhattScholze/Perfectoidization/Derived/ArcSite.lean)）（その opposite が affine の p 進形式スキームにあたる）、その perfectoid 環の充満部分圏 `AffPerfd`（:112）。試験環の条件 `IsRankOneCompleteValuationRing`（[Derived/ArcPerfectoidBase:437](../../../SerrePositivity/BhattScholze/Perfectoidization/Derived/ArcPerfectoidBase.lean)）は「整域・付値環・Krull 次元 1・p 進完備」。有限族の arc 被覆 `IsArcCoverFamily`（Derived/ArcSite:126）は、試験環 \(V\) への任意の \(R\to V\) が、忠実平坦な \(V\to W\)（\(W\) も試験環）とある \(R_i\to W\) に持ち上がることで、これが生成する位相 `arcTopology`（:138）と、`AffPerfd` への誘導位相 `arcTopologyPerfd`（:147）を置く。被覆族は底変換・合成・有限積と両立する（`isArcCoverFamily_baseChange`・`isArcCoverFamily_comp`・`isArcCoverFamily_prod_iff`、:156, :193, :212）。

drafts には、arc 位相を一点 arc 被覆の coverage と有限直積の射影族（空族を含む）の coverage の上限として書く `arcTopology_eq_sup`（[drafts/A6/ArcSite:170](../../../formalization-plans/bhatt-scholze/drafts/A6/ArcSite.lean)）と、層条件を「有限積を保つ」と「一点被覆の Čech 条件」に分ける `isSheaf_arc_iff_cech`（:200）がある。

## 定義 8.3.1（原典 Def 8.7） — 証明

<!-- source: exposition/ja/bs/08-perfection.html:205; block: bs-08-l205 -->
<a id="bs-08-l205"></a>

定義なので証明はない。affine の場合、\(\mathrm{Spf}\) の有限族 \(\{\mathrm{Spf}R_i\to\mathrm{Spf}R\}\) が arc 被覆であることは、\(\mathrm{Spf}\prod_iR_i=\bigsqcup_i\mathrm{Spf}R_i\to\mathrm{Spf}R\) が arc 被覆であることと同じ（\(\mathrm{Spf}W\) は連結なので、\(\prod_iR_i\to W\) はある成分を通る）。affine な開被覆は有限族で、それ自身 arc 被覆なので、affine の上では開被覆を別に加える必要がない。

## 定義 8.3.1（原典 Def 8.7） — 原典との差（D53・D54）

<!-- source: exposition/ja/bs/08-perfection.html:209; block: bs-08-l209 -->
<a id="bs-08-l209"></a>

D53：原典の site は p 進形式スキーム全体の fSch と \(\mathrm{Perfd}\subset\mathrm{fSch}\)。Lean は affine の部分だけを、台の濃度 \(\le\kappa\) で切った圏の上に定義し、非 affine の形式スキームは扱わない。D54：原典は一つの射の arc 被覆と開被覆で位相を生成する。Lean は [BM18, Def 1.2] の有限族の形で定義する。affine の上では上の証明の囲みのとおり同じ位相になる。
