# BS 10.1　J-almost zero

原典 Definition 10.1

照合先（本文外）：`SerrePositivity.BhattScholze.Almost.perfectoidKernel`、`SerrePositivity.Almost.IsAlmostZero`。既存 review の記載。

## 定義 10.1.1（原典 Def 10.1） — 主張

<!-- source: exposition/ja/bs/10-almost.html:36; block: bs-10-l36 -->
<a id="bs-10-l36"></a>

導来 p 完備な R 加群 \(M\) が **J-almost zero** であるとは、\(J_{\mathrm{perfd}}M=0\) となること。

<!-- source: exposition/ja/bs/10-almost.html:37; block: bs-10-l37 -->
<a id="bs-10-l37"></a>

\(J=(p)\) のときは \(J_{\mathrm{perfd}}=\sqrt{pR}\) であり、この概念は perfectoid 環上の加群に対する通常の「almost zero」と一致する。

## 定義 10.1.1（原典 Def 10.1） — Lean

<!-- source: exposition/ja/bs/10-almost.html:41; block: bs-10-l41 -->
<a id="bs-10-l41"></a>

零化の述語は任意の環・イデアル・加群について `IsAlmostZero`（[CommutativeAlgebra/Almost/Basic:38](../../../SerrePositivity/CommutativeAlgebra/Almost/Basic.lean)、\(I\le\operatorname{Ann}(M)\)。完備性は述語に含めない）。任意の \(J\) の \(J_{\mathrm{perfd}}\) は `perfectoidKernel`（[Almost/AlmostConnectivity:38](../../../SerrePositivity/BhattScholze/Almost/AlmostConnectivity.lean)）で、古典的な商 \(R/J\) の perfectoid 化への写像 `quotientPerfdMap`（:34）の核。その全射性（Thm 7.4）`quotientPerfdMap_surjective`（:100）、\(R/J_{\mathrm{perfd}}\) が perfectoid であること `perfectoidKernel_quotient_isIntegralPerfectoid`（:108）、\(J\subset J_{\mathrm{perfd}}\) `le_perfectoidKernel`（:41）、普遍性 `perfectoidKernel_le`（:47、\(J\) を殺す perfectoid 環への写像は \(J_{\mathrm{perfd}}\) も殺す）、単調性 `perfectoidKernel_mono`（:61）、根基で決まること `perfectoidIdeal_radical`（:67）。複体版の J-almost 零性 `IsJAlmostZero`（:86）は命題 10.1.4 で使う。

<!-- source: exposition/ja/bs/10-almost.html:42; block: bs-10-l42 -->
<a id="bs-10-l42"></a>

単項 \(J=(g)\) の場合は別の定義 `perfectoidIdeal`（[PerfectoidIdeal/Basic:37](../../../SerrePositivity/BhattScholze/PerfectoidIdeal/Basic.lean)）もあり、定義を展開すると `perfectoidKernel` の \(J=(g)\) の場合と同じ式になる。\(\sqrt{(g)}\subset(g)_{\mathrm{perfd}}\) は `radical_span_le_perfectoidIdeal`（[PerfectoidIdeal/Powers:147](../../../SerrePositivity/BhattScholze/PerfectoidIdeal/Powers.lean)）、\((g^n)_{\mathrm{perfd}}=(g)_{\mathrm{perfd}}\) は `perfectoidIdeal_pow_eq`（:154）。\(J=(p)\) での等式 \(J_{\mathrm{perfd}}=\sqrt{pR}\) は本体にない（包含 \(\supset\) だけが上の補題）。

## 定義 10.1.1（原典 Def 10.1） — 証明

<!-- source: exposition/ja/bs/10-almost.html:46; block: bs-10-l46 -->
<a id="bs-10-l46"></a>

\(J=(p)\) の場合の等式（補った）。\(R\) は perfectoid なので \(R/p\) は semiperfect（Frobenius が全射）。すると \(R/\sqrt{pR}\) は被約かつ semiperfect、すなわち完全な \(\mathbb F_p\) 代数であり、特に perfectoid。一方 \(\mathbb F_p\) 代数 \(S\) の perfectoid 化は完全化 \(S_{\mathrm{perf}}=\operatorname{colim}_\varphi S\) で、semiperfect な \(S\) では \(S_{\mathrm{perf}}=S/\sqrt0\)。\(S=R/p\) に当てると \((R/p)_{\mathrm{perfd}}=R/\sqrt{pR}\) なので \(J_{\mathrm{perfd}}=\sqrt{pR}\)。通常の almost 数学は \(\sqrt{pR}\)（\(p\) が p 冪根を持つときは \((p^{1/p^\infty})\)）を基本のイデアルに取るので、両者は一致する。
