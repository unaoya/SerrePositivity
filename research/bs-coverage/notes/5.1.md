# BS 5.1　標数 p の記法（結晶 site）

原典 Notation 5.1

照合先（本文外）：`SerrePositivity.BhattScholze.Prismatic.CrysOver`、`SerrePositivity.BhattScholze.Prismatic.crysAlgebras`、`SerrePositivity.BhattScholze.Prismatic.crystallineBasePrism`。既存 review の記載。

## 定義 5.1.1（原典 Notation 5.1） — 主張

<!-- source: exposition/ja/bs/05-hodge-tate.html:35; block: bs-05-l35 -->
<a id="bs-05-l35"></a>

\((A,(p))\) を結晶 prism（例 3.1.3）とし、\(I\subset A\) を \(p\in I\) となる pd イデアルとする。このとき \(A/p\) の Frobenius は商 \(A/p\to A/I\) を経由し、写像 \(\psi\colon A/I\to A/p\) を誘導する。\(R\) を smooth な \(A/I\) 代数とし、\(R^{(1)}:=R\otimes_{A/I,\psi}A/p\) とおく。

## 定義 5.1.1（原典 Notation 5.1） — Lean

<!-- source: exposition/ja/bs/05-hodge-tate.html:39; block: bs-05-l39 -->
<a id="bs-05-l39"></a>

結晶 prism の一般形は第 3 章の `OrientedPrism.crystalline`（[OrientedPrism:308](../../../SerrePositivity/BhattScholze/Prism/Basic/OrientedPrism.lean)）。この節で本体が使う基底は \((\mathbb Z_p,(p))\) の `crystallineBasePrism`（[CrystallineBase:83](../../../SerrePositivity/BhattScholze/Prismatic/CrystallineBase.lean)、Frobenius の持ち上げは恒等射）と、その剰余 `cartierBase`（:102、\(\cong\mathbb F_p\)）。一般の pd イデアル \(I\ni p\) は結晶 site の基底 \((k,J,\gamma)\) として `CrysOver`（[CrystallineSiteBasic:41](../../../SerrePositivity/BhattScholze/Prismatic/CrystallineSiteBasic.lean)）の引数に現れる（定理 5.1.2 の Lean の囲み）。\(\psi\) と \(R^{(1)}\) を一般の \((A,I)\) で定める宣言は本体にない。\(A=\mathbb Z_p\)、\(I=(p)\) では \(\psi\) は \(\mathbb F_p\) の恒等射で \(R^{(1)}=R\) なので、本体はこの区別を立てない。

## 定義 5.1.1（原典 Notation 5.1） — 証明

<!-- source: exposition/ja/bs/05-hodge-tate.html:43; block: bs-05-l43 -->
<a id="bs-05-l43"></a>

（補った）\(x\in I\) について \(x^p=p!\,\gamma_p(x)\in pA\)。よって \(A/p\) の Frobenius \(\bar x\mapsto\bar x^p\) は \(I/p\) を零に送り、\(A/I\) から \(A/p\) への環準同型 \(\psi\) が降りる。これは \(A/I\) の元 \(\bar x\) を \(\bar x^p\in A/p\) に送る写像で、\(A/p\to A/I\xrightarrow{\psi}A/p\) は \(A/p\) の Frobenius に等しい。
