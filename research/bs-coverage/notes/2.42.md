# BS 2.42　相対的 \(I\) 完全正則性

原典 Definition 2.42

照合先（本文外）：`SerrePositivity.BhattScholze.Prismatic.IsCompletelyRegularRel`、`SerrePositivity.BhattScholze.Prismatic.relativeKoszulComparison`。既存 review の記載。

## 定義 2.6.1（原典 Def 2.42） — 主張

<!-- source: exposition/ja/bs/02-delta.html:924; block: bs-02-l924 -->
<a id="bs-02-l924"></a>

単体的可換環 \(A\) と有限生成イデアル \(I=(f_1,\dots,f_n)\subset\pi_0(A)\)、導来 \(I\) 完備な単体的可換 \(A\) 代数 \(B\) を固定する。列 \(x_1,\dots,x_r\in\pi_0(B)\) が **\(A\) 上相対的に \(I\) 完全正則**（\(I\)-completely regular relative to \(A\)）であるとは、
\[ \mathrm{Kos}(A;f_1,\dots,f_n)\longrightarrow\mathrm{Kos}(B;f_1,\dots,f_n,x_1,\dots,x_r) \]
が単体的可換環の平坦な射であること。

<!-- source: exposition/ja/bs/02-delta.html:927; block: bs-02-l927 -->
<a id="bs-02-l927"></a>

\(A,B\) が離散なとき、平坦性をほどくと次の三条件になる：(i) \(B\) が導来 \(I\) 完備（定義の前提）、(ii) \(H_0(\mathrm{Kos}(B;f,x))=B/(f,x)\) が \(A/I\) 上平坦、(iii) すべての \(q\) で標準射 \(B/(f,x)\otimes_{A/I}H_q(\mathrm{Kos}(A;f))\to H_q(\mathrm{Kos}(B;f,x))\) が同型。たとえば \(B=A[x_1,\dots,x_r]^\wedge_I\)（変数）なら \(\mathrm{Kos}(B;f,x)\simeq\mathrm{Kos}(A;f)\) なので変数の列は相対的に \(I\) 完全正則。prism \((A,(d))\) では \(I=(p,d)\) とする。

## 定義 2.6.1（原典 Def 2.42） — Lean

<!-- source: exposition/ja/bs/02-delta.html:931; block: bs-02-l931 -->
<a id="bs-02-l931"></a>

古典的な環の場合（\(A,B\) が離散）を (i)〜(iii) の形で定義：`IsCompletelyRegularRel`（[Prismatic/RelativeCompleteRegularity:149](../../../SerrePositivity/BhattScholze/Prismatic/RelativeCompleteRegularity.lean)）。\(A\) の有限列 \(a\) と \(B\) の有限列 \(x\) について、三つの連言がそれぞれ (i)（各 \(a_i\) について導来完備）、(ii)、(iii)（全次数 \(q\in\mathbb Z\) で全単射）。比較射 `relativeKoszulComparison`（:120）は、係数拡大と列の付加が誘導する Koszul 複体の射を剰余環上の線形射に降ろし、スカラー拡大の随伴でテンソル積からの射にしたもの。\(H_q(\mathrm{Kos}(A;a))\) は \(a\) で消えるので \(A/(a)\) 加群になる（`koszulResidueModule`、:95）。prism の \((p,d)\) への特殊化は `IsPrismCompletelyRegularRel`（:156）。単体的可換環の版は本体にない。

## 定義 2.6.1（原典 Def 2.42） — 原典との差（D20）

<!-- source: exposition/ja/bs/02-delta.html:935; block: bs-02-l935 -->
<a id="bs-02-l935"></a>

原典の「\(\mathrm{Kos}(A;a)\to\mathrm{Kos}(B;a,x)\) が平坦」（単体的可換環の射の平坦性）を、連結な環の射の平坦性の判定（\(\pi_0\) の平坦性と、全次数の \(\pi_i\) の底変換同型）でホモロジーに書いたもの（D20）。高次ホモロジーの消滅で定義すると、基底の \(H_1\) が零でない結晶 prism \((\mathbb Z_p,(p))\) で原典と食い違う。
