# BS 2.31　完全 δ 環 ↔ 完全 F_p 代数

照合先（本文外）：`SerrePositivity.BhattScholze.DeltaStructure.IsPerfect.perfectRing_mod_p`、`SerrePositivity.BhattScholze.existsUnique_wittDeltaStructure`、`SerrePositivity.BhattScholze.perfectDeltaWittRecoveryEquiv`、`SerrePositivity.BhattScholze.wittDeltaStructure_ringHom_isDeltaHom_of_complete`、`SerrePositivity.BhattScholze.perfectSource_ringHom_isDeltaHom`。既存 review の記載。

## 系 2.4.6（原典 Cor 2.31：完全 δ 環） — 主張

<!-- source: exposition/ja/bs/02-delta.html:651; block: bs-02-l651 -->
<a id="bs-02-l651"></a>

次の三つの圏は同値である。

(1) 完全 \(p\) 完備 δ 環の圏 \(C_1\)。

(2) \(p\) 進完備で p ねじれなし、かつ \(A/p\) が完全な環 \(A\) の圏 \(C_2\)。

(3) 完全 \(\mathbb F_p\) 代数の圏 \(C_3\)。

(1) と (2) の間は忘却関手で、特に完全 \(p\) 完備 δ 環の間の**任意の環準同型は自動的に δ 射**。(2) と (3) の間は \(A\mapsto A/p\) と \(R\mapsto W(R)\) で、特に標数 \(p\) の完全環 \(R\) について \(W(R)\) 上の δ 構造はただ一つ。

## 系 2.4.6（原典 Cor 2.31：完全 δ 環） — Lean

<!-- source: exposition/ja/bs/02-delta.html:659; block: bs-02-l659 -->
<a id="bs-02-l659"></a>

圏同値としてではなく、対象ごと・射ごとの部品で。

\(C_1\to C_2\)：p ねじれなしは命題 2.4.3、\(A/p\) の完全性 `DS.IsPerfect.perfectRing_mod_p`（[PerfectDelta:243](../../../SerrePositivity/BhattScholze/Delta/Perfect/PerfectDelta.lean)）（完備性は不要）。

\(C_3\to C_1\)：Witt Frobenius を持ち上げとする δ 構造の存在と一意性 `existsUnique_wittDeltaStructure`（[PerfectDelta:349](../../../SerrePositivity/BhattScholze/Delta/Perfect/PerfectDelta.lean)）、標準構造 `wittDeltaStructure`（:367）、完全性 `wittDeltaStructure_isPerfect`（:376）、\(p\) 進完備性 `wittDeltaStructure_isAdicComplete`（:382）、一意性 `wittDeltaStructure_unique`（:386）、関手性 \(W(f)\) が δ 射 `wittDeltaStructure_map_isDeltaHom`（:392）。

\(C_1\cong W(C_3)\)：復元同型 \(W(A/p)\cong A\) `perfectDeltaWittRecoveryEquiv`（[PerfectDelta:419](../../../SerrePositivity/BhattScholze/Delta/Perfect/PerfectDelta.lean)）（零環も含む）、その mod \(p\) が第 0 Witt 座標 `perfectDeltaWittRecoveryEquiv_mod_p`（:425）、順・逆が δ 射 `perfectDeltaWittRecoveryEquiv_isDeltaHom`（:457）・`perfectDeltaWittRecoveryEquiv_symm_isDeltaHom`（:467）（\(A/p\) が標数 \(p\)、すなわち \(A\ne0\) のとき）。復元そのものは共通基盤の strict p 環の復元 `strictPRecoveryEquiv`（[Lift:250](../../../SerrePositivity/CommutativeAlgebra/Witt/Lift.lean)）。

**射**：\(W(k)\) から p ねじれなし \(p\) 進完備 δ 環への任意の環準同型は δ 射 `wittDeltaStructure_ringHom_isDeltaHom_of_complete`（[PerfectDelta:434](../../../SerrePositivity/BhattScholze/Delta/Perfect/PerfectDelta.lean)）。証明は \(f\circ\varphi_W\) と \(\varphi_A\circ f\) が mod \(p\) で一致することと、mod \(p\) で一致する \(W(k)\to A\) は等しいこと `wittLift_unique`（[Lift:74](../../../SerrePositivity/CommutativeAlgebra/Witt/Lift.lean)）（Teichmüller 元で比べて \(p\) 進分離性で極限へ）から \(\varphi\) と可換になり、終域が p ねじれなしなので命題 2.1.5 (3)。より一般に「完全 δ 環から \(p\) 進分離な δ 環への任意の環準同型は δ 射」が `Andre.perfectSource_ringHom_isDeltaHom`（[PerfectPrismHomLift:343](../../../SerrePositivity/BhattScholze/Prism/PerfectPrismHomLift.lean)）（終域の p ねじれなしも不要。原典 Lemma 4.8 のために第 4 章側にある）。

## 系 2.4.6（原典 Cor 2.31：完全 δ 環） — 証明

<!-- source: exposition/ja/bs/02-delta.html:667; block: bs-02-l667 -->
<a id="bs-02-l667"></a>

命題 2.4.3 により δ 構造を忘れる関手 \(F_{12}\colon C_1\to C_2\) が定まる（\(A/p\) の完全性は、\(\varphi\) が \(A/p\) の Frobenius を誘導し、\(\varphi\) が全単射で \(\varphi(pA)=p\varphi(A)=pA\) なので \(\varphi^{-1}(pA)=pA\) となることから）。\(F_{12}\) は定義から忠実。\(F_{23}\colon C_2\to C_3\) は \(A\mapsto A/p\)、\(F_{31}\colon C_3\to C_1\) は \(R\mapsto W(R)\)（Witt 環の Frobenius を \(\varphi\) とする δ 構造。\(W(R)\) は p ねじれなしで Frobenius は mod \(p\) で \(p\) 乗なので命題 2.1.3 (2) から）。\(F_{32}:=F_{12}\circ F_{31}\) が \(F_{23}\) の逆であることはよく知られている（変形理論など。\(p\) 進完備で p ねじれなしの \(A\) で \(A/p=R\) 完全なら \(W(R)\cong A\)）。同値 \(F_{32}\) が忠実な \(F_{12}\) を経由するので、\(F_{12}\) も同値になる。これが「環準同型は自動的に δ 射」の意味。

## 系 2.4.6（原典 Cor 2.31：完全 δ 環） — 原典との差

<!-- source: exposition/ja/bs/02-delta.html:672; block: bs-02-l672 -->
<a id="bs-02-l672"></a>

原典は三つの圏の同値として述べ、\(W(R)\cong A\) を「よく知られている（変形理論）」で済ませる。Lean は圏や関手を立てず、対象の対応（\(A/p\) の完全性、\(W(k)\) の δ 構造、復元同型 \(A\cong W(A/p)\)）と射の性質（環準同型が δ 射、\(W(f)\) が δ 射）を個別の定理として持つ。復元は変形理論ではなく、Teichmüller 元による \(W(k)\to A\) の構成（Fontaine の θ）と \(p\) 進完備性で単射・全射を示す共通基盤による。
