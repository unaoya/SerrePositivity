# BS §4　導入・つなぎ

原典 §4

## 導入

<!-- source: exposition/ja/bs/04-site.html:24; block: bs-04-l24 -->
<a id="bs-04-l24"></a>

固定した有界 prism \((A,I)\) と p 完全 smooth な \(A/I\) 代数 \(R\) について、prismatic site \((R/A)_\Delta\) とその構造層のコホモロジー \(\Delta_{R/A}\) を定義し（4.1）、HT 比較を定式化し（4.2）、Čech–Alexander 複体で \(\Delta_{R/A}\) を具体的に計算する（4.3）。本体にあるのは、affine な \(R\) の site の圏・平坦位相・構造層の層性、多項式代数の HT 写像 \(\eta^*\) と Lemma 4.10、HT 比較の主張の型と結晶基底 \((\mathbb Z_p,(p))\) での証明、Čech–Alexander 模型の組み立て・弱始性・余積・底変換との項ごとの両立。\(\Delta_{R/A}\) を site の \(R\Gamma\) として定義すること、模型がそれを計算すること、Lemma 4.20・4.22 は drafts にある。形式化の設計の決定（site の大きさの切り落とし、\(R\Gamma\) の意味など）は [a0-design.md](../../../formalization-plans/bhatt-scholze/design/a0-design.md) にあり、原典との差として各項目の下に引く。

## 4.1 prismatic site

<!-- source: exposition/ja/bs/04-site.html:27; block: bs-04-l27 -->
<a id="bs-04-l27"></a>

有界 prism \((A,I)\) を固定し、\(A\) 上の形式スキームには \((p,I)\) 進位相、\(A/I\) 上の形式スキームには \(p\) 進位相を入れる。この小節では \(p\) 進形式 \(A/I\) スキーム \(X\) の prismatic site \((X/A)_\Delta\) を定め（定義 4.1.1）、その topos の見方（注意 4.1.3）、étale 位相との関係（定義 4.1.4）、位相の取り替え（注意 4.1.5）、完全 site と絶対 site（注意 4.1.6・4.1.7）を述べ、最後に完全 prism からの射の一意な持ち上げ（命題 4.1.8）を示す。本体にあるのは affine の場合の site・平坦位相・構造層が層であること（定義 4.1.1）と、標的が有界な場合の命題 4.1.8。注意 4.1.6 は drafts、他の注意と定義 4.1.4 は本体にない。

## 4.2 HT 比較の定式化

<!-- source: exposition/ja/bs/04-site.html:186; block: bs-04-l186 -->
<a id="bs-04-l186"></a>

この小節では有界 prism \((A,I)\) と、\(A/I\) 上の smooth な p 進形式スキーム \(X\) を固定する。prismatic site の構造層を \(X_{\mathrm{\acute et}}\) へ押し出して \(\Delta_{X/A}\) と \(\overline\Delta_{X/A}\) を作り、Bockstein で \(H^*(\overline\Delta_{X/A})\{*\}\) を dg 代数にして、de Rham 複体からの HT 比較の写像 \(\eta^*_X\) を構成する（4.2.1〜4.2.2）。それが同型であるという HT 比較（4.2.3）の証明は §5（標数 p）と §6（一般）で与えられ、ここではその帰結（4.2.4〜4.2.7）を述べる。

<!-- source: exposition/ja/bs/04-site.html:187; block: bs-04-l187 -->
<a id="bs-04-l187"></a>

Lean の本体はこの小節を**多項式代数の場合**に限って持つ：基底は一般の有界向き付き prism \((A,(d))\)、\(X=\mathrm{Spf}\,R\) で \(R=(A/d)\langle X_1,\dots,X_r\rangle\)（`affineAlgebra`（[HodgeTateAffineModel:38](../../../SerrePositivity/BhattScholze/Prismatic/HodgeTateAffineModel.lean)））。\(\overline\Delta_{R/A}\) の代わりに Rem 4.19 の小さい Čech–Alexander 模型 `cechAlexanderAffine`（[AffineEnvelopeConstruction:243](../../../SerrePositivity/BhattScholze/Prismatic/AffineEnvelopeConstruction.lean)）の各項を d で割った余単体的環 `reducedModel`（[HodgeTateAffineModel:93](../../../SerrePositivity/BhattScholze/Prismatic/HodgeTateAffineModel.lean)）を使い、そのコホモロジーを `hodgeTateCohomology'`（[HodgeTateZero:39](../../../SerrePositivity/BhattScholze/Prismatic/HodgeTateZero.lean)）と書く。HT 比較が全単射であることが証明済みなのは結晶基底 \((\mathbb Z_p,(p))\) の場合。

## 4.3 Čech–Alexander 複体

<!-- source: exposition/ja/bs/04-site.html:330; block: bs-04-l330 -->
<a id="bs-04-l330"></a>

prismatic cohomology を具体的な余単体的環で計算する一般論。affine の場合の記号を定め（4.3.1）、多項式代数からの全射の envelope で site の弱始対象を作り（4.3.2）、その Čech 脈体が \(\Delta_{R/A}\) を計算することを示す（4.3.3）。affine 空間の場合には prism の底変換と両立する模型があり（4.3.4）、これを使って底変換（4.3.5）と étale 局所化（4.3.6）を示す。どちらも純代数の補題 4.3.7 に帰着する。

<!-- source: exposition/ja/bs/04-site.html:331; block: bs-04-l331 -->
<a id="bs-04-l331"></a>

Lean では site の対象は、固定した向き付き有界 prism \((A,(d))\) の上の有界な向き付き prism \((B,dB)\) と \(R\to B/dB\) の組で、台の濃度が \(\le\kappa\) のもの（原典 Def 4.1 の affine の場合。D5・D16・D19）。剛性（命題 3.2.1、原典 Lemma 3.5）により \(IB=dB\) なので、以下 \(I=(d)\) と書く。
