# DG-W3：内部ビルド round 2 で STOP（2026-11-02）

## 判断

`dg-codex-w3.md` §5-4「宣言の本文・型・名前を変えないと直らない」に該当すると判断し、停止。
`infra/dg-w3`、起点 `b23296091`。main の作業木での変更・ビルドはしていない。

失敗は `SerrePositivity.DifferentialGraded.Functor.QuasiEquivalence` の
`SerrePositivity.DifferentialGraded.DGFunctor.ofHomMaps`（268–273 行、元は `Functor.Components` 18–23 行）。

```lean
def ofHomMaps (F : D → E) (H : ∀ x y, (x ⟶[Complex A] y) ⟶ (F x ⟶[Complex A] F y))
```

最初の診断（268:60、続いて 269・272・273 行に派生エラー、計 5 件）：

```text
overloaded, errors
Application type mismatch: The argument
  x
has type
  Complex A
but is expected to have type
  D
in the application
  F x
```

型が省略された `H` の束縛変数が `Complex A` と推論されている。新しい `Category.Basic` は
旧 `Category.Examples` の `complexEnrichment : DGCategory A (Complex A)`（546 行）と
`complexEnrichedOrdinary`（642 行）を含む。旧 `Functor.Components` の閉包には `Category.Examples` がなかった。
この import の拡大によるインスタンス探索の早期確定が原因と考えられる。短い宣言名の隠蔽としての修飾ではない。

次の 1 箇所で、既存の `D` を型注釈として明示する案がある。ただし §4 の許可範囲にはないため、**未適用・未検証**。

```diff
- (H : ∀ x y, (x ⟶[Complex A] y) ⟶ (F x ⟶[Complex A] F y))
+ (H : ∀ (x y : D), (x ⟶[Complex A] y) ⟶ (F x ⟶[Complex A] F y))
```

許可された場合は、変更した宣言の before/after の型・本体ハッシュ、公理・属性が一致することを確認する必要がある。
