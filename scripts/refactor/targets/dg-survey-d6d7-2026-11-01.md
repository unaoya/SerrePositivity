## D7　Complexes と Mathlib

Complexes の追跡中の全 117 ファイルを既存の lean_source.parse_source で読み、名前付きの 495 宣言を一度ずつ分類した。Mathlib は lake-manifest.json と一致する e6bbacd0e1b7307ff6e17da09cd2455f60804fa6。宣言の type・本体と、使用する Mathlib 側の API を比較したソース調査。

**115 / 495 宣言**に下表の置換案がある。A（61 件）は既存 API の特殊化・射影・等式による引数の置換。B（54 件）はさらに成分または元での評価、同値の合成、Subtype への詰め直し、次数や線形性の証明を要する。A+B をこの調査の「薄い言い換え」の全数とする。内訳は abbrev 12, def 34, lemma 69。残りは 380 宣言。標本 6/15 の比率からの外挿ではない。

判定単位は Lean ソースの名前付き宣言（private を含む、生成補題・証明内の局所名を除く）。候補には、利用側が既に持つ引数・明記した局所補題から Mathlib の API へ移す具体的な手順を要求した。局所の構造を単に rfl で展開する式や、別の DG/HA の補題だけへの転送は数えない。一つの Mathlib の補題を証明中に用いても、別途 DG の作用や coherence 自体を証明するものは別扱い。薄さはこの基準によるソース分類であり、判定・置換は Lean ビルドを伴わない。
