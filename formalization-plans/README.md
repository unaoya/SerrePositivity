# 形式化の計画

このディレクトリには、今後の形式化について、対象・証明方針・引用境界・依存関係・完了条件をまとめる。
実装状況の正本は各 Lean モジュールと公理監査であり、計画の記述を証明済みの主張として扱わない。

| 計画 | 目標 | 状態 |
| --- | --- | --- |
| [残る形式化の全体像](overview.md) | 外部引用1〜13と二つのK理論入力の役割・依存関係を整理する | 現状・範囲の整理 |
| [外部引用1〜5の調査と計画](classical-inputs-1-5.md) | 剰余体拡大・正規化・古典的交点重複度の証明経路と引用境界を整理する | 調査・設計段階 |
| [K理論・スペクトル・dg 理論の形式化](k-theory.md) | 定理3.1と補題4.6を形式化し、既存の二つの降下入力の直接の `sorry` を解消する | 設計・調査段階 |
| [CLMST とその準備の形式化](clmst.md) | CLMST の結果を原典の形で引用し、定理2.5への接続を `sorry` なしで証明する | 設計段階 |
| [Frobenius 高次ホモロジー消滅](frobenius-homology.md) | 引用6の証明経路を比較し、まず必要な Koszul 版の正規化消滅を形式化する | 調査・設計段階 |

リポジトリ全体の現状は [README](../README.md)、論文と実装の対応は
