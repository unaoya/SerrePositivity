### 1.1 G3 の主張

ζ を 1 の原始 5 乗根、L = ℚ₅(ζ)、V = 𝒪_L、π = 1 − ζ とする。
𝒳 ⊂ ℙ²_V を (X − Z)⁵ − XY⁴ + Y⁵ + ζZ⁵ = 0 で定め、特殊ファイバーの点 m = [0:0:1] で A = 𝒪_{𝒳,m} とおく。

- A は 2 次元の Noether 正則局所整域で、混標数 (0, 5)、π ∈ 𝔪_A²。
- 整数係数の類 c ∈ K₃(A) があって、c|_{Frac A} = 0 かつ c|_{A[1/π]} mod 5 ≠ 0（G₃(A[1/π]; ℤ/5) の中で）。
- とくに K₃(A) → K₃(Frac A) は単射でない。

### 1.2 G5 の主張

V を ℚ₅ の 8 次不分岐拡大の整数環とし、A = (V[x, y]/(5 + x⁴ + y⁴))_{(5,x,y)} とおく。

- A は 2 次元の Noether 正則局所整域で、5 ∈ (x, y)⁴（分岐していて V 上滑らかでない）。
- K₅(A) → K₅(Frac A) の核は 0 でない。

付録（Mochizuki の preprint v8 の Lemma 13(III) の構成の失敗）は主定理の証明に使われないので、この計画の範囲外とする。

## 2. 最終目標と完了の意味

最終目標は、二本の主定理を Lean で述べ、正確なステートメントで引用した基礎定理だけに依存して証明することである。

- 整数係数の Quillen K 群、連接 K 理論（G 理論）、mod 5 係数の K 群を具体的に定義した上で主張を述べる。
  名前だけの抽象的な `K` を置いて主張を述べることはしない。
- 深い一般定理（§4 の引用台帳）は、正確なステートメントを持つ名前付きの `sorry` として引用してよい。
- 論文独自の議論（環の構成と正則性、類の構成、検出の議論、有限計算）は証明する。
- 主定理そのものや、論文独自の命題（G3 の Lemma・Proposition、G5 の Prop. Picard specialization など）を
  丸ごと引用して完了とはしない。

段階的な成果として、K 理論を経由しない「検証」の層（§6 の V 段階）を先に完成させてよい。

## 3. 証明の構成と依存

### 3.1 共通の骨格

両論文とも次の形をとる。

1. 正則局所環 A の中の因子 Spec S（または Spec 𝒪）を用意する。
2. 因子の上の類を押し出して c = i_*b ∈ G_n(A) = K_n(A) を作る。台が因子なので Frac A への制限は 0。
3. c が 0 でないことを、平坦基底変換・局所化の後の mod 5 係数の類で検出する。

### 3.2 G3 の構成

| 段階 | 内容 | 主な道具 |
|---|---|---|
| モデル（§2） | A の正則性、S = A/yA が DVR（一意化元 t = x mod y）、D = Frac S は L の 5 次完全分岐拡大で N_{D/L}(t) = π、(1 − t)⁵ = ζ。他の閉点の剰余次数は 5 で割れる | 可換環論、局所体の計算 |
| 整数類（§3） | β ∈ K₂(L; ℤ/5)（係数境界が [ζ]）をとり、a_D = β_D·[t] の係数境界を Steinberg 記号 {1 − t, t} = 0 に帰着して K₃(D) に持ち上げる。K₂(𝔽₅) = 0 と局所化で K₃(S) に持ち上げ、押し出して c を得る | Matsumoto の定理、Quillen の有限体の K 群、局所化列、係数列 |
| 体の計算（§4） | 任意の有限拡大 E/L で β_E を掛ける写像が E^×/E^{×5} ≅ K₃(E; ℤ/5) を与える | Friedlander–Suslin のモチーフ的スペクトル系列、Suslin の積の比較、ノルム剰余定理 |
| 検出（§5） | T = Spec A[1/π] を曲線 C のアフィン開集合の極限として書き、連続性で一つの開集合に下ろす。局所化で支持つきの類の関係に書き直し、転送 ＝ ノルムと正規化付値 mod 5 で矛盾を出す | 連接 K 理論の連続性、局所化、射影公式、転送 |

### 3.3 G5 の構成

| 段階 | 内容 | 主な道具 |
|---|---|---|
| 係数（§2） | mod 5 Moore スペクトル M の単位的な積、Bott 作用素 b と局所化列の両立、低次の体の同型 | 対称スペクトルの smash 積、Friedlander–Suslin、Suslin、ノルム剰余定理 |
| 算術（§3） | S = ℤ[ζ, 1/5]、β ∈ K₂(S; 5)、c ∈ K₅(S) で c mod 5 = b²[ζ − 1]₅。障害 K₄(S)[5] = 0 を Brauer の相互法則と有限生成性で示す | Matsumoto、ノルム剰余定理、類体論、Quillen の有限生成性 |
| 特殊化（§4） | 滑らかな射影的算術曲面上で、支持つき係数類の関係を Bott 作用素 2 回で tame 記号に戻し、coniveau の d₁² = 0 で特殊ファイバーの主因子にする。特殊ファイバーの Picard 群からの準同型で判定する | 算術曲面、Picard 群、coniveau スペクトル系列 |
| 幾何（§5） | A → 𝒪 の全射、平坦基底変換で因子が Fermat 四次曲線上の 4 点に分かれる。次数 2 の写像で楕円曲線 w² = s⁴ + 1 に送り、4 点の和が E(k)/5E(k) で 4Q ≠ 0 | 楕円曲線、有限体上の計算 |
| 主証明（§6） | K₄(𝔽_q) = 0 で c を 𝒪 に持ち上げ、押し出して γ。平坦基底変換と特殊化判定で γ ≠ 0 | 局所化、平坦基底変換、上の判定 |

### 3.4 二本の比較

| 観点 | G3 | G5 |
|---|---|---|
| 次数 | K₃ | K₅ |
| 係数の積 | K₂(L; ℤ/5) × K₁ → K₃ のみ | Moore スペクトル上の積、Bott 作用素の反復 |
| 大域的な算術 | 不要（局所体だけ） | ℤ[ζ, 1/5] の K₄ のねじれ、Brauer 相互法則、類体論 |
| 検出の道具 | ノルムと付値（曲線上の連接 K 理論） | 算術曲面の Picard 群による特殊化、楕円曲線 |
| 幾何の重さ | 平面曲線とその閉点の剰余次数 | 算術曲面と coniveau、楕円曲線の点の計算 |

G3 のほうが前提がかなり軽い。とくに算術曲面の Picard 群を必要としない。
**着手は G3 から**とし、G5 は G3 の基盤が揃ってから追加の幾何を検討する。

## 5. 既存の K 理論計画との関係

[k-theory.md](../archive/k-theory-v1.md) の基盤のうち、次をそのまま使う。

- M1〜M3：対称スペクトル、smash 積、安定同値と π_n。
- M6：環スペクトルと加群、K 理論の局所化・加法性・π₀ の比較。
- mod 5 係数は K(R) ∧ M（M は mod 5 Moore スペクトル）として定め、その積は対称スペクトルの smash 積から作る。

追加で必要になるもの（k-theory.md の範囲外）は次のとおり。

1. **完全圏の K 理論**：k-theory.md は Perf の dg 圏を入力にする。Gersten の論文では
   有限生成加群・連接層の完全圏の K 理論（G 理論）が主役である。Waldhausen の S• 構成を
   完全圏に適用する入口と、dg 版との比較（正則環で G = K）を追加する。
2. **G 理論の基本定理**：局所化列、dévissage、連続性（フィルター付き余極限との交換）、
   固有射に沿った押し出し、平坦射に沿った引き戻し、平坦基底変換、射影公式。
3. **係数付き K 理論**：係数列 K_n → K_n(; ℤ/5) → K_{n−1}、5 が奇素数であることによる単位的な積、Bott 元。
4. **局所体と曲線**：ℚ₅(ζ) とその有限拡大の付値・ノルム・剰余次数、平面曲線の閉点と特殊化。
5. G5 のみ：算術曲面の Picard 群、coniveau、楕円曲線の有限体上の点。

1〜3 は Gersten に限らず K 理論一般の基盤なので、k-theory.md の M6 と共通の層として設計する。

## 6. マイルストーン

各段階は、定義、正確なステートメント、接続の証明、依存監査を一組として進める。

### V：K 理論を使わない検証（先行してよい）

**G3**：
- A の正則性、π ∈ 𝔪_A²、S = A/yA が DVR で t が一意化元であること。
- D/L が 5 次完全分岐で N_{D/L}(t) = π、(1 − t)⁵ = ζ。
- m に特殊化する q₀ 以外の閉点の剰余次数が 5 で割れること（論文 §2）。

**G5**：
- A の正則性と 5 ∈ (x, y)⁴、A → 𝒪 の全射、平坦基底変換で 4 点に分かれること。
- 剰余体 𝔽_{5⁸} 上の楕円曲線 w² = s⁴ + 1 での指標の符号と 4Q ≠ 0（E(k)/5E(k) の中で）。

**完了条件**：論文の具体的な代数・数値の主張が、K 理論の引用なしに Lean で確認されている。

### N1：完全圏の K 理論と G 理論

完全圏の Waldhausen 構成、π₀ と K₀ の比較、解消定理、局所化列・dévissage の正確なステートメント（引用）。

### N2：係数付き K 理論と積

Moore スペクトル M、K(R; ℤ/5)、係数列、奇素数での単位的な積、Bott 元。

### N3：G3 の整数類

Matsumoto と Quillen の有限体の計算を引用し、a_D の持ち上げ、K₃(S) への持ち上げ、押し出し c を構成する。
Frac A への制限が 0 であることを証明する。

### N4：G3 の検出

体の計算の引用、射影公式と転送 ＝ ノルム、連続性による開集合への下降、局所化と付値の議論で c ≠ 0 を証明する。

**G3 の完了条件**：主定理が Lean で述べられ、§4 の引用だけに依存して証明されている。

### N5：G5 への拡張（G3 完了後に再計画）

算術の部分（K₄(S)[5] = 0）、算術曲面の Picard 群による特殊化判定、楕円曲線の計算と接続。

## 8. 注意と未決事項

  Friedlander–Suslin・Suslin・ノルム剰余定理の正確なステートメントまで分解して引用するのが望ましい。
