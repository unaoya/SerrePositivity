## 3. 1番：指定した剰余体の完備平坦局所拡大

### 主張と引用境界

Noether 局所環 `(B,m,k)` と体拡大 `K/k` に対し、完備 Noether 局所環 `B'` と
平坦局所写像 `B → B'` が存在し、`mB'` が `B'` の極大イデアルとなる。
剰余体の同型 `k(B') ≃ K` は、元の `k` からの写像と両立する。
基底環 `B` の完備性は現在の引用の仮定ではない。

引用は環の存在に限る。長さ・次元・正則性・Tor に関する利用側の導出は、
[FlatLocalDimension](../SerrePositivity/CommutativeAlgebra/FlatLocalDimension.lean) と
[IntersectionMultiplicity/BaseChange](../SerrePositivity/IntersectionMultiplicity/BaseChange.lean)
などに分かれている。新しい構成を同じ入口へ接続し、これらを再利用する。

### 調査と証明経路

[Stacks, Tag 03C3](https://stacks.math.columbia.edu/tag/03C3) は、
平坦局所写像、極大イデアルの拡張、指定剰余体を構成する。
単生成体拡大では、超越元を加えて局所化するか、最小多項式のモニックな持ち上げを用いる。
任意の体拡大には、超限の構成と有向極限を使う。

ただし、この補題単独は拡大環の Noether 性・完備性まで主張しない。
現在の引用は EGA I, 2nd ed., 0, Proposition 6.8.3 の gonflement と完備化を含む形である。
EGA のこの箇所の証明全文と、実装する完備化の仮定は別途精読する。
非 Noether な有向極限を単に完備化すれば平坦性が自動的に保存される、としてはいけない。

### 成果物

| 段階 | 成果物 |
| --- | --- |
| R1 | 単生成の代数的・超越的拡大について、具体的な環、局所性、平坦性、剰余体の両立を証明 |
| R2 | 一般の体拡大を扱う図式と有向極限、局所性、剰余体の同定を構成 |
| R3 | 完備 Noether 版に必要な EGA の補助定理を固定し、完備化後の平坦性と極大イデアルの性質を証明 |
| R4 | 現在の宣言と利用先へ接続し、引用依存を監査 |

部分的な区切りとして有限生成体拡大版は有用だが、実際に使う代数閉包等は一般にその範囲に収まらない。
有限生成版の完成だけで1番を解消したとしない。宇宙と型の存在量化も、現在の入口に合わせて確認する。

## 4. 2番：Cohen–Gabber 正規化

### 主張と引用境界

標数 `p > 0`、次元 `h` の完備 Noether 局所整域 `D` に対して、
正則完備局所環 `A` と単射 `A → D` を作り、`D` を `A` 上有限にする。
剰余体への写像は全射で、分数体拡大は分離的。
さらに、`A ≃ k(D)[[t_1,…,t_h]]` と標準座標による極大イデアル生成を指定する。

現在の引用には、正規化の存在だけでなく、冪級数環の正則性・完備性・標準座標の性質も含まれる。
利用先では次元の一致、`D` 側のパラメータ系、分離性から必要な形への変換等を別に導く。
単なる Cohen の有限正規化を作っただけでは、分離性を含む2番の結論には届かない。

### 調査と証明経路

[Kurano–Shimomoto, *An elementary proof of Cohen–Gabber theorem in the equal characteristic p > 0 case*](https://arxiv.org/pdf/1510.03573)
定理1.1は、係数体とパラメータ系を選び、有限性と、最大次元の極小成分での分数体の分離性を与える。
現在の整域版はその特殊例である。
原文の証明には係数体・p-basis・変数や係数の変更などが現れるため、
一般の Cohen 構造定理の単なる包装として実装できるとは考えない。

### 成果物

1. 係数体の埋め込みと剰余写像との両立を、具体的な写像として扱う。
2. 係数体とパラメータからの形式冪級数評価写像を構成し、連続性・収束を確認する。
3. 有限性と単射、正則基底の標準的性質を、共有可能な一般補題として分ける。
4. Cohen–Gabber の分離的な選択を、必要な補助結果の型を固定して形式化する。
5. 分数体の代数構造と `IsScalarTower`、座標同型を含め、現行の入口へ接続する。

実際の適用に合わせて完全剰余体の整域版から始める案もある。
しかし現在の引用は完全剰余体を仮定しないため、その限定版の完成と一般引用の完成は区別する。
完全剰余体の仮定だけで、任意の有限正規化の分離性が自動的に従うとはしない。

## 5. 3番：混標数の Cohen 正規化

### 主張と引用境界

次元 `h > 0`、標数零、剰余標数 `p`、完全剰余体 `k` の完備 Noether 局所整域 `D` に対し、

\[
A\simeq W(k)[[t_2,\ldots,t_h]]\hookrightarrow D
\]

を構成する。`D` は `A` 上有限、剰余体への写像は全射、
`A` は正則完備局所環で、その極大イデアルは `p,t_2,…,t_h` により生成される。

現在の引用には Cohen 係数環を `W(k)` と同定する部分も含む。
分数体拡大の分離性は引用に含めず、標数零から導く。
次元の一致と `D` 側でのパラメータ系も利用側で導く。

### 調査と証明経路

[Stacks の Cohen 構造定理](https://stacks.math.columbia.edu/tag/0323)
定理10.160.8・補題10.160.11は係数環と有限正規化を扱い、
Remark 10.160.9は冪級数環の標準的性質を記す。
現在のステートメントへ接続するには、完全剰余体の Cohen 環と Witt 環の比較も必要である。
Witt vector の型が既に存在することと、この比較・係数環の埋め込みが証明済みであることは別である。

### 成果物

| 段階 | 成果物 |
| --- | --- |
| C1 | `W(k)` の必要な性質を調査・整理：剰余体、`p`、完備性、離散付値／正則性 |
| C2 | `W(k) → D` の係数環としての写像と剰余体の両立を構成 |
| C3 | `p` と残りのパラメータを選び、形式冪級数評価を構成 |
| C4 | 有限性・単射、正則性、極大イデアルの標準座標を証明 |
| C5 | 現行入口へ接続し、既存の分離性・次元・パラメータの導出を再利用 |

2・3の共通部分は、完備環への形式冪級数評価、有限正規化、剰余体、標準座標の性質である。
2の分離的な選択と3の Witt 係数環の構成は分けて実装する。

## 6. 4番：Serre の等標数正値性

### 主張と現在の再利用範囲

体を含む正則局所環 `R` と非零有限生成加群 `M,N` について、
`M ⊗_R N` が有限長で、`dim M + dim N = dim R` なら

\[
\chi^R(M,N)=\sum_i(-1)^i\ell_R\operatorname{Tor}_i^R(M,N)>0.
\]

現在の引用の利用先では、剰余標数零から体の作用を構成する部分を別に証明している。
[CharacteristicZeroReduction](../SerrePositivity/Paper/Section5/CharacteristicZeroReduction.lean) の
接続を、古典定理そのものの証明と区別する。

正則局所環上の有限自由分解、Tor の有限長性と加法性、Koszul、環自身に対する重複度公式などは再利用候補である。
ただし、現在の Koszul 重複度公式を任意の有限生成加群に対する公式として使用してはいけない。

### 対角線への帰着による候補

標準的な方向は、完備化と係数体による表示を経て、`R = k[[x_1,…,x_d]]` とし、
二つの変数組を持つ環上で対角線の元

\[
\delta_i=x_i\otimes1-1\otimes x_i
\]

を使うことである。Tor の Euler 数を、この列の Koszul Euler 数へ移す。
対角線への帰着は Serre の古典的議論であり、
[Skalit の論文](https://arxiv.org/html/1409.3616)にも、その利用とスペクトル系列が記されている。

整備すべき核心は、完備テンソル積の具体的構成、Noether 性・次元、
対角線の商と有限長性、Tor と Koszul の比較である。
通常のテンソル積と完備テンソル積を同一視しない。

最後の重複度への接続には二案がある。

- **一般加群版を作る。** 完備テンソル積の上の `M` と `N` から作る有限加群について、
  次元・非零性・パラメータ条件を確認し、加群版の Koszul 重複度公式と正値性を使う。
- **素因子へ分解する。** 加法性と prime filtration で `R/P,R/Q` へ移し、
  `D=(R/P)\widehat\otimes_k(R/Q)` の環自身に対する公式を使う。
  最大次元の成分で正値性を、次元和が小さい成分で等標数の消滅を示す必要がある。

後者でも「長さ `d` の列に対し、環の次元が `d` 未満なら Koszul Euler 数が零」という接続が必要になる。
これを5番の一般消滅を引用して済ませれば、4番のその証明は5番に依存する。
4番を独立に証明したい場合は、この等標数の消滅を対角線と重複度の議論から導く。

### 段階別計画

1. 現行引用の一般性を保つ、完備化・係数体・冪級数表示への還元を整理する。
2. 完備テンソル積と対角線の具体的な環・加群・写像を作る。
3. 有限長性、支持の次元、対角線 Koszul と Tor の対応を証明する。
4. 一般加群版と prime filtration 版の不足を比較し、重複度に接続する。
5. 等標数正値性を導き、任意の体を含む正則局所環の現行宣言へ戻す。

4番はホモロジー代数と可換環論の両方を使うが、
5番の局所 Chern character や6番の tight closure を先に全面実装する計画にはしない。

## 7. 5番：Roberts–Gillet–Soulé の交点重複度消滅

### 主張

任意の正則局所環 `R` と有限生成加群 `M,N` に対し、テンソル積が有限長で

\[
\dim M+\dim N<\dim R
\]

なら `χ^R(M,N)=0`。現在の引用は体を含む場合に限定されず、混標数も含む。
論文では低次元の項を除くために用いる。
定理3.1・補題4.6の二つの降下入力とは別の外部定理である。

### 候補A：局所 Chern character と Riemann–Roch

[Roberts の一次解説](https://www.numdam.org/article/PSMIR_1985___4_25_0.pdf)
は、局所 Chern character と重複度の関係、および消滅への適用を説明している。

有限自由分解 `F,G` を取り、局所 Riemann–Roch と積の公式を用いて Euler 数を表す。
支持の余次元に応じた Chern character の低次数成分の消滅と、
正則環の Riemann–Roch 類の性質を用い、次元和が小さいと寄与が消えることを導く。

形式化する対象と成果物：Chow 群、支持つき局所 Chern character、積・次数の規則、
局所 Riemann–Roch、正則環での特殊化、必要な余次元の消滅定理。
特に、支持が小さいことから低次数成分が消える部分も数学的な定理であり、定義だけから省略しない。

Ma の Dutta 重複度の公式にも近い言語だが、その交代和の計算から6番の個々の高次ホモロジー消滅が
自動的に得られるわけではない。6番の計画とはこの点を区別する。

### 候補B：支持つきK理論と Adams 操作

Gillet–Soulé の方法では、支持つきK理論の Adams 操作と、支持の余次元に対応する重みを使う。
有限長支持での Euler 数の重み、テンソル積に対する積性を合わせて、次元条件から消滅を導く方向である。

形式化する対象と成果物：支持つきK₀、テンソル積、Adams 操作、
必要な重みの分解または filtration、支持の余次元の制約、有限長支持の Euler 数との両立。
これらの一般結果から具体的な消滅を証明する部分を分離する。

[Brown–Miller–Thompson–Walker, *Cyclic Adams Operations*](https://arxiv.org/abs/1601.05072)
は、循環的 Adams 操作から Serre の消滅を導く経路も提示する。
この版を採用する場合は、操作に使う素数の可逆性、根の追加、係数拡大からの帰着など、
原文の仮定を確認する。全ての正則局所環に直接適用できると仮定しない。

### 経路選択とK理論計画との関係

5番の経路は未確定である。次の調査をしてから選ぶ。

1. 原典の定理の仮定・結論と、一般正則局所環への還元を固定する。
2. Chern／Riemann–Roch と Adams の各経路で、構成すべき具体的対象と引用する一般定理を比較する。
3. [K理論の計画](k-theory.md)と共有できる API を確認する。
4. 必要な一般定理から `intersectionVanishing` を導き、依存を監査する。

K理論降下の計画にはスペクトル・dg 理論の整備が含まれるが、それだけで Adams 操作の証明が完成するわけではない。
逆に、5番に必要な支持つきK₀と操作から始める計画が、非連結K理論全体を必ず先に作ることを意味するわけでもない。
基礎の重複を避けつつ、数学的に必要な追加理論を明示する。

## 9. 完了条件と検証

- 各数学的対象・写像を具体的に定義し、存在定理がそれらについて述べられている。
- 引用する深い結果には、正確なステートメント・出典・適用仮定を記す。
- 利用側の変換・次元・長さ・Tor・座標・分数体の両立は、既存証明を再利用または補って証明する。
- 現行の宣言と同じ一般性を達成したか、適用先だけの限定版かを明記する。
- 対象モジュールと全体ビルド、[公理監査](../scripts/audit_axioms.lean)で利用先まで検証する。
- 直接の `sorry` の除去、補助定理への未証明依存、標準公理だけでの証明を区別して報告する。

新しい一般定理は `CommutativeAlgebra/`、`HomologicalAlgebra/` 等に置き、
論文への接続は `Paper/` が担う。1〜5の具体的な環や引用を、環に独立な共通 Euler 理論へ持ち込まない。
文書だけの変更ではリンクと現行コードとの整合性を確認し、Lean の全体ビルドは不要である。
