# CLMST とその準備の形式化計画

作成日：2026-10-13。更新日：2026-10-14。状態：必要な数値結果・Serre接続を明示引用から証明済み。現在の整理と追加証明の範囲を見直す。
原典は `paper/refs/CLMST-2209.04046v4.pdf`（手元のみ）と
[同じ版の HTML](https://arxiv.org/html/2209.04046v4)。実装の到達点は §0 に記す。

具体的な型の設計、共通基盤の抽出順、接続の受入条件は
[実装境界と作業単位](clmst-interfaces.md)にまとめる。
完備化の平坦性と剰余体拡大側との共通工程は、
[完備化の統合計画](adic-completion-integration.md)を正本とする。

対象とする版：Cai–Lee–Ma–Schwede–Tucker, *Perfectoid signature, perfectoid Hilbert–Kunz
multiplicity, and an application to local fundamental groups*, arXiv:2209.04046v4
（以下 CLMST）。準備として、Faltings の正規化長さ、perfectoid 塔、Bhatt–Scholze の perfectoid 化を含む。

## 0.2. Bhatt–Scholzeの別計画との統合（2026-10-14）

[BS計画](bhatt-scholze.md)を参照し、今後の順序を以下に改める。
BSの原典証明・δ環・prismの設計は同文書を正本とし、
本節はCLMSTから必要になる成果物、共通部品、接続の完了条件を扱う。
BS計画のB-I/B-S/B-Rはそれぞれ、普遍perfectoid化の存在、全射性、
mod p^Nのイデアル冪等性を指す。

### 作業の境界

| perfectoid化の全射性 | BS計画B4a〜B4c・B4 | CLMSTの具体的な商の正則性・完備性の証明を維持し、B-Sの証明へ接続する |

標準完備塔の具体的な証明は、BSのδ環・prism全体の完成を待たず進める。
一方、任意gのイデアル冪等性はBS側へ集約する。前回の三候補を
この側で全部順番に証明する方針は採らない。

### 現在のBS側の準備と設計上の確認事項

BS側には`DerivedTensor`、`CompletelyFlat`、`AbsolutelyIntegrallyClosed`と、
Thm 7.14の名前付き未証明入力`Inputs/AndreFlatness`が作業ツリーにある。
絶対整閉から両立する冪根を選ぶ部分は証明されているが、
André拡大そのものは未証明で、現在の主定理の証明には使われていない。
これは前回の引用台帳に追加された研究用の入力として別記し、
主定理の引用依存の削減と混同しない。

BS計画の「導来圏・∞圏は導入しない」は、そのままでは広すぎる。
既存CLMSTは実導来圏を使い、BS準備も導来テンソルを使う。
本統合での範囲は「導来prismatic cohomology・∞圏全体を新たに作らず、
必要なTor・導来完備性・複体の比較は共通基盤を使う」とする。
原典Prop 7.2はH⁰ of derived (p,d)-completionを実際に使う。
B3を古典的完備化だけで置き換えるには条件と比較の証明が必要であり、
pねじれのない場合の比較だけで一般の商を扱ったとはしない。

B5でも、完備導来テンソルの離散性からmod p^Nの冪等性へ移す工程を明示する。
通常のTor₁とK/K²の公式だけで、完備化・mod p^Nへの比較まで証明済みとしない。
原典：著者版[Prop 7.2、Thm 7.4、Lemma 10.3、Remark 10.7](https://people.mpim-bonn.mpg.de/scholze/prisms.pdf)。

### 並行作業の運用：共通準備・担当・待合せ

本表の担当は二つの作業の分担を表す。別チャットへの指示送信や新しい作業の起動は、
この計画書の更新だけでは行わない。BSの詳細計画はBS側で更新し、
本節は両側が合流するときの契約を正本とする。

#### P0：並行開始前の共通準備

共通準備は、すべての一般補題を先に証明する工程ではない。
対象・仮定・写像・担当ファイルを確定し、両側が独立に着手できるところまで行う。

1. `IsIntegralPerfectoid`と`IsPerfectoidization`を共通の定義として固定する。
   零環、素数p、宇宙、元環からの標準写像、環作用の量化を確認する。
   BS側で別定義が必要なら対応定理を設計し、既存定義を無断で置き換えない。
2. 共通APIを一覧にする。既存のFontaine核判定、Witt・tiltの自然性、pねじれ商、
   perfectoid化の一意性と核の一致、古典的完備化への普遍写像の延長は再利用する。
   Tor・p完全平坦性・導来完備性の比較で不足するものはこのチャットの共通基盤作業へ登録する。
3. B3の受渡し型を設計する。成果物は「明示したsemiperfectoid条件から、
   環Cと写像S→Cが存在し、`IsPerfectoidization p`を満たす」という証明である。
   その条件を、任意gのR/(g)またはその完備化にどう供給するかも接続側の作業として列挙する。
   pねじれのない商だけを証明して一般gへの移行が完了したとはしない。
4. 変更担当と検証対象を決める。既存の共通定義・公開入口の型は維持する。
   共通ファイルを両側が同時に編集しない。新しい一般補題は担当側が共通層へ追加し、
   相手はその公開宣言を適用する。欠けた補題を同じ内容で別実装しない。

P0の完了条件は、B3/B4/B5の受渡し型案、塔の証明に必要な既存API、
不足補題の担当が明記されていること。δ環・prism全体や導来完備化の完成は要求しない。
型案は設計であり、名前付きのsorryを先に増やして表現しない。

| B4 almost から λ へ | Prop 4.0.10 を `N = 0` にして、現在の `clmst_length_eq_zero_of_perfectoidIdeal_annihilates` を出す（`M^a ≃ 0` は「`(g)_perfd` で消える」こと） | 軽い。almost 同型の定義との整合だけ |
| B5 任意のパラメータ系での Koszul の almost 消滅 | Cor 4.0.4 の後半を `n = 0`（`A_0 ⊗_A R = R`）にして、現在の `clmst_exists_perfectoidIdeal_annihilates_koszul` を出す | 軽い（注意 2） |

B1〜B7 が揃えば、現在の `Inputs/CLMST.lean` の三つの定理は L2 の補題として直接の `sorry` なしで証明する。
移行中は旧ファイルに互換 wrapper を残せる。実際の定義と証明の正本は新しい層に一つだけ置く。
ファイル削除そのものを完了条件にはしない。

### 注意

1. **g の取り方（B1）。** CLMST は g に「`A[1/g] → R[1/g]` が有限エタール」を課す。
   現在の存在命題は `g ≠ 0` だけを主張している。標数 0 では分離性が自動なので、generic étaleness から g は取れる。
   これは CLMST ではなく古典的な可換環論の事実で、証明するか、
   別の引用ファイルに置くかを決める。原則は一般可換環論として証明する。
   Mathlib に有限 étale・分離拡大・局所化の API はあるが、必要な存在定理の接続は追加調査する。
   有限 étale 条件の意味を定義してから引用するのであり、未知の述語を仮定に追加するだけでは済ませない。
2. **B5 は軽い。** Cor 4.0.4 は局所コホモロジーの almost 消滅に加えて、
   `A_n ⊗_A R` の任意のパラメータ系の Koszul ホモロジーの almost 消滅まで主張している（原典で確認）。
   `n = 0` で R の任意のパラメータ系になるので、接続層に Čech と Koszul の比較は入らない。
   その比較は、Cor 4.0.4 自身を L1 の中で証明するとき（M4）に要る。
   以前この点を接続層の最大の危険としていたが、原典の確認でなくなった。
3. **B4 の一般性。** 現行の長さ零の引用は、任意の非零 g に対して述べている。
   原典の Notation 4.0.1 の形を保った Prop 4.0.10 からは、必要なら R=A として適用する。
   実際の D が g の外で étale であるという新しい仮定を、旧定理へ不用意に足さない。
4. **一般 n。** `A_n ⊗_A R` は原典で局所環として扱われる。
   Lean ではその局所性・次元・剰余体と、n=0 の代数同型を明示してからパラメータ系を扱う。
