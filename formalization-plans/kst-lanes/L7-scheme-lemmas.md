## 7. L7b：平坦化による支配

### 7.1 最初に固定する文言

S を Noether スキーム、f : X → S を固有射とする。
U ⊆ S は開集合とする。
f の U への基底変換は同型と仮定する。
このとき S 上の有限型イデアル層 J と射 g : Bl_J(S) → X が存在する。
J の U への制限は単位イデアルである。
g ≫ f は blowup の構造射に等しい。
S の Noether 性は準コンパクト性を含む Mathlib の定義で扱う。
U の準コンパクト性は Noether 性から導く。
f の有限型性は固有性から導く。
これらを追加の未証明仮定として束ねない。
これは Stacks 081T / Temkin 2008 Lemma 2.1.5 の特殊形である。

### 7.1a 実装前に固定した Lean の主文（2026-10-18 再確認）

原典：https://stacks.math.columbia.edu/tag/081T （Lemma 38.31.4）。
証明の分解の参照：https://stacks.math.columbia.edu/tag/081S と tag/080Y。
既存の §7.1 の Noether 特殊形を維持する。主文は次の形とする。
これは計画上の文言であり、未証明の宣言を Lean ソースに追加しない。

```lean
theorem noetherian_blowup_domination
    {S X : Scheme} [AlgebraicGeometry.IsNoetherian S]
    (f : X ⟶ S) [IsProper f] (U : S.Opens) [IsIso (f ∣_ U)] :
    ∃ J : S.IdealSheafData,
      (∀ V : S.affineOpens, (J.ideal V).FG) ∧
      U ≤ centerComplement J ∧
      ∃ g : blowup J ⟶ X, g ≫ f = blowupπ J
```

U の準コンパクト性、S の準分離性、f の有限型性は既存の仮定から導く。
支配とは上記の実際の因子化を意味し、X 全体への全射性は追加しない。
最初の中心は U の閉補集合の消滅イデアル層から取る。
その blowup の例外因子の有効 Cartier 性は L7a の実証明を使う。
strict transform の構成と、平坦性から実際の支配射を得る段階は証明済み。
固有な開部分スキームとスキーム論的稠密性から全体との一致も証明済み。
二回の admissible blowup の合成を一つで支配する段階は一般 Noether 基底上で証明済み。
残る本体は strict transform を平坦にする中心の存在であり、仮定フィールドにしない。
この文言と方針をチャットへ報告した後、承認待ちを挟まず実装を進める。

### 7.1b 次の環論的中間目標：Cartier 境界上の加群の平坦化

原典：Stacks 0815, Theorem 38.30.7、および 081R, Lemma 38.31.1。
Noether アフィン基底と Cartier 境界に限った次の文言を固定する。
A は Noether 可換環、B は有限型 A 代数、M は有限 B 加群とする。
f は A の非零因子で、M[1/f] は A[1/f] 上平坦と仮定する。
目標は J[1/f] が単位イデアルになる有限生成 J ⊆ A を構成し、
各 a ∈ J に対する blowup チャート C 上で、
(C ⊗_A M) を f の冪で消える元の部分加群で割った純変換が C 上平坦となること。
これは計画上の文言であり、未証明の Lean 宣言・型クラス・構造体フィールドにしない。

まず純変換を局所化写像の核による商として定義し、核の冪消滅判定、
商上の f の正則性、有限性、平坦な加群での核の消滅を証明する。
次に実際の平坦化中心の存在を扱う。
有限 A 加群に制限した証明と、一般の有限 B 加群の証明は区別する。
前者だけで有限型スキームの平坦化を完了したとは扱わない。
Noether 条件下では純変換の有限表示性は有限 B 加群性から導くが、
A 上の平坦性の存在証明は依然として必要である。
最初の Cartier 化と有限アフィン被覆の共通細分、二段合成の支配は既証明部分を使う。

#### イデアル加群の場合の先行する具体例

A のイデアル I と非零因子 f について fᴺ ∈ I を仮定する。
Bl_I の各標準チャート C 上で C ⊗_A I の f に沿う純変換を構成し、
C との実際の線形同型を作ることを次の中間目標とする。
乗法写像 C ⊗_A I → C の像は拡大イデアルで、その核はチャート元 a の像で消える。
fᴺ の像は a の像の倍なので、核は f の冪で消える。
チャート環で f が非零因子であることは A[1/a] への既存の埋め込みから導く。
従って純変換は拡大イデアルと同型であり、既証明の正則単項生成から自由になる。
この例は一般の有限 B 加群について平坦化中心を与える定理を置換しない。
原典は Stacks 0815 の純変換と KST §5 の通常 blowup の可逆イデアルの計算。

#### 階数一の場合への次の還元

有限表示 A 加群 M と N の f による局所化が同型なら、
分母を払って実際の写像 g : M → N と h : N → M、および指数 n を作り、
hg = fⁿ id と gh = fⁿ id を同時に満たすことを次の補題とする。
有限表示性で局所化された写像を持ち上げ、有限生成性で二つの合成の誤差を一様な冪で消す。
N = A の場合、g の像をイデアル I とすると fⁿ ∈ I で、核も fⁿ で消える。
基底変更でも合成の関係式を保つことにより、この場合の純変換を I の純変換に比較する。
これは境界外で階数一自由な有限 A 加群の特殊形であり、一般有限 B 加群の平坦化は別に残る。
原典の位置付けは Stacks 0815 の Noether 特殊形に向けた有限加群の分母消去。

#### 有限階数自由な場合の行列式による中心

次の中間目標は M[1/f] が A[1/f] 上階数 r 自由な有限表示 A 加群の場合。
分母倍同型 g : M → Aʳ、h : Aʳ → M を作り、
全 r 個組 m の像 g(m) を列に持つ行列の行列式が生成するイデアル J を取る。
gh = fᴺ id より f^(N r) ∈ J となり、中心は D(f) を避ける。
J の行列式生成元 d のチャートでは、列を一つ置換した行列式も J に入るので、
その d による比を使って Cramer の公式から像の各ベクトルを選んだ r 列で表せる。
d の正則性からこの r 列は線形独立で、像加群が自由になる。
元の加群から像への写像の核は分母倍の合成式で f の冪により消えるので、
純変換も同じ自由加群に同定する。
まず行列式生成元のチャートについて示し、一般チャート上の平坦性は開被覆と局所化で移す。
Noether 条件は中心の有限生成性にも使える。
これは有限 A 加群の特殊形であり、有限型 B 上有限な M の一般平坦化とは同一視しない。
原典の位置付けは Stacks 0815 の平坦化に向けた有限加群の行列式計算。

#### 既に平坦な純変換の追加基底変更

次の補題は Noether 環 A 上有限な M とその f に沿う純変換 Q に対するもの。
Q が A 上平坦で、A 代数 C における f の像が非零因子なら、
C ⊗_A M の純変換と C ⊗_A Q の実際の C 線形同型を構成する。
境界ねじれは有限生成なので fᴺ で消える。
fᴺ id_M は Q から M への写像に降り、商写像との合成は fᴺ id になる。
基底変更後もこの合成式を保つので商写像の核は f の冪で消える。
標的 C ⊗_A Q は平坦で f の像が正則に作用し、純変換の核と一致する。
商写像の基底変更が全射であることから実際の同型と平坦性が得られる。
この補題は、局所平坦化中心の共通細分・追加 blowup による平坦性の保存に使う。
原典の位置付けは Stacks 0815 の純変換の平坦性と KST §5 の admissible blowup。

#### 境界外で平坦な有限 A 加群への還元

Noether 環 A 上有限な M と非零因子 f について M[1/f] が A[1/f] 上平坦と仮定する。
既証明の自由な基本開の有限被覆を A[1/f] 上で選ぶ。
各係数 sᵢ の分子 aᵢ ∈ A を取り、aᵢ で生成する中心 I を選ぶ。
aᵢ の像は sᵢ と単元倍なので I[1/f] は単位イデアルとなり、ある fᴺ が I に入る。
Bl_I の aᵢ チャートでは I の像が (aᵢ) なので、f を可逆化すると aᵢ も可逆になる。
従って sᵢ も可逆となり、このチャートの境界外の加群は自由な部分からの基底変更になる。
各チャート上で有限階数自由の場合の平坦化を適用する。
その中心を延長して共通細分し、既証明の追加基底変更の安定性で平坦性を保つ。
最後に二段の admissible blowup の支配を使って元の A 上の一つの中心へ戻す。
まず有限被覆の係数の分子と中心、冪の所属を実際に構成する。
これは有限 A 加群の段階であり、有限型 B 上有限の場合の一般定理とは区別する。
原典の位置付けは Stacks 0815 の Noether 特殊形の準備。

#### 局所中心の大域化に用いる平坦性の局所性

S → Spec(A) に対し、任意の Spec(B) → S への引き戻しで、
f の像が B で正則なら B ⊗_A M の純変換が B 上平坦となる性質を明示的な命題として定義する。
M は有限 A 加群とし、Noether なアフィンモデルで既に純変換が平坦なら、
追加基底変更の安定性からこの性質を証明する。
さらにこの性質が始域の開被覆に関して局所的であることを、
試験対象 Spec(B) の基本開被覆と純変換の係数局所化の可換性から証明する。
中心の存在をこの性質の仮定フィールドとして移すことはしない。
チャート上の実際の局所中心、中心の延長と共通細分、二段合成の支配から得た実際の射に、
この性質の合成に関する安定性を適用する。
最後に得られた基礎環上の blowup の標準チャートで境界の正則性を使い、実際の平坦性を得る。
原典は Stacks 0815 の局所的な平坦化と KST §5 の admissible な支配。

#### 有限型代数上の有限加群へ進むための一様な境界ねじれ

一般形では M は有限 B 加群であり、A 上有限とは限らない。
追加基底変更の安定性の証明では、実際に必要なのは境界ねじれを消す一様な f の冪である。
その条件だけを仮定する比較同型を分離し、Noether 条件による有限生成性と切り離す。
A → B、B が Noether、M が有限 B 加群、スカラー作用が両立する場合、
A 上の f に沿う境界ねじれと B 上の f の像に沿う境界ねじれは所属が一致する。
従って B 上の有限性から一様な指数を得て、A 上の純変換にも同じ指数を使える。
Noether な A の有限型代数 B は Noether なので、この比較は目標の一般形にも適用できる。
平坦化中心の存在そのものは別に証明し、この一様性の補題に移さない。
原典は Stacks 0815, Theorem 38.30.7 の純変換の比較。

#### 基底変更代数の加群構造

C ⊗_A M への B の右因子からの作用を、
B → End_A(M) → End_C(C ⊗_A M) により定義する。
C の左作用と可換することを証明し、Mathlib の TensorProduct.Algebra.module を使って
C ⊗_A B 上の加群構造を明示的なデータとして構成する。
この作用は (c ⊗ b)·(c′ ⊗ m) = cc′ ⊗ bm を満たす。
Mathlib と同じくこの加群構造を大域インスタンスにはせず、必要な箇所で選ぶ。
有限 B 生成元の 1 ⊗ m を使って、この基底変更加群が C ⊗_A B 上有限であることを証明する。
A が Noether、B が A 上有限型、C が Noether なら C ⊗_A B も Noether なので、
追加基底変更先の境界ねじれの一様性へ接続できる。
原典は Stacks 0815, Theorem 38.30.7 の純変換の有限型条件。

#### 一般有限型加群に向けた係数イデアル

原典：Stacks 0810, Lemma 38.30.2（0811, Lemma 38.30.3 の環論的段階）。
有限 A 加群の行列式中心の構成だけでは、一般の有限 B 加群を扱えない。
次は A 線形写像 e : B → A^(ι)、p : A^(ι) → B と p e = id を明示的に与えた場合、
B のイデアル J の e による全係数が生成する A のイデアルを定義する。
A^(ι) は有限台の直和であり、添字集合の有限性は仮定しない。
任意の直和の線形自己写像は係数イデアルへの所属を保つことを有限台の展開で証明する。
乗法写像 e ∘ (b·) ∘ p にこれを適用すると、J が有限個の g で生成されれば、
係数イデアルはそれらの e(g) の有限個の非零係数で生成される。
この段階では直和因子としての B の存在も Fitting イデアルの性質も仮定フィールドに隠さない。
分裂写像を入力とする係数計算を先に証明し、直和因子の存在と自由化・次元帰納は別の実在定理として残す。
この実装前の文言と方針はチャットで報告済み。

#### 表示行列の小行列式によるイデアル

原典：Stacks 0810, Lemma 38.30.2 の Fit_r(M) の計算。
次は有限表示行列 P の k 次小行列式が生成するイデアルを定義する。
行と列の選択を Fin(k) からの写像で指定し、重複による零行列式も許す。
有限行列の有限生成性、任意の環準同型による基底変更との交換、
零次では単位イデアル、行数・列数を越えれば零イデアルとなること、
次数を一つ増すとイデアルが小さくなることを有限行列式の展開で証明する。
これは選んだ表示行列についての実在するイデアルの計算であり、
表示の選択から独立な Fitting イデアルの定義と生成元数・自由性の判定は次の別の段階に残す。
係数イデアルに未証明の Fitting の性質を仮定として含めない。
次に有限行列の積で行・列を線形結合しても小行列式イデアルが大きくならないことを、
行列式の多重線形性による有限和の展開で証明する。
左逆元を持つ行基本変換と右逆元を持つ列基本変換では、逆方向の包含から等式を得る。
これは同じ生成元数での表示変換の計算であり、生成元数を変える安定化は別に扱う。

#### 可逆な関係式の小行列による生成元の除去

原典：Stacks 0810, Lemma 38.30.2 とそこで用いる More on Algebra, Lemma 15.8.9。
生成元側を P × Q と書き、全射 q : P × Q → M と関係式 t : P → P × Q を与える。
q t = 0、かつ t の P 成分が自己同型 e : P ≃ P なら、
任意の (x,y) から t(e⁻¹ x) を引いて P 成分を除去できる。
従って Q から M への写像は全射である。
さらに ker(q) = range(t) なら同写像は単射でもあり、実際の線形同型 Q ≃ M を得る。
まず任意の加群でこの消去を証明し、有限自由加群・単元行列式からの自己同型を代入する。
この段階は単元小行列式を持つときの生成元除去であり、
小行列式イデアルが正則単項である場合の純変換の生成元数判定は引き続き別に残す。
同じ消去は、q t の像の各元が境界元の冪で消える場合、q を純変換の商へ合成すれば適用できる。
この接続では冪の指数の一様性を仮定する必要はなく、各元の境界ねじれへの所属を明示する。
080Z, Lemma 15.8.9 の随伴行列の計算が与える擬関係式にこの形を使う。
その随伴行列の段階では、関係式を上成分 A・下成分 B とし、det(A) = f u（u は単元）、
B adj(A) = f C を明示的な等式として入力する。
A adj(A) = det(A) id より、上成分 u id・下成分 C の像は q で送ると f により消える。
従って純変換は下成分の自由加群からの実際の全射を持つ。
さらに B adj(A) の各係数を行置換行列式として表し、小行列式の f による可除性から C を選ぶ。
ピボットの選択は、まず局所環 R の正則元 f に限った次の形で行う。
集合 E が (f) を生成するなら、ある e ∈ E は f の単元倍である。
各 e = f c_e と書き、c_e の生成イデアル J について (f) ≤ (f)J を導く。
f の正則性で一が J に入るため、局所環の極大イデアルへの包含判定から c_e の一つが単元となる。
これは原典の Algebra, Lemma 10.20.1 の必要な正則単項特殊形である。
選んだ単射な行写像 r : Fin(k) → m に対し、m と Fin(k) ⊕ (m ∖ range(r)) の実際の同型を作る。
関数加群の変数変換と直和・直積の同型を合成して、生成元加群をピボットと残りに分解する。
この同型は元の行列の選んだ列の写像を、上成分と下成分の行列の積写像に移す。
小行列への制限による小行列式イデアルの包含と合わせ、既存の随伴行列の消去に接続する。

#### 自由な直和因子となる関係式の小行列式

原典：Stacks 0810, Lemma 38.30.2 の自由加群の Fitting 条件の利用。
有限行列 T : m × Fin(k) と S : Fin(k) × m が S T = id を満たす場合、
単位行列の k 次小行列式イデアルと左乗法の包含から T の k 次は単位イデアルとなる。
k を越える次数では、列数による消滅から零となる。
別の関係式行列 H の列が T と同じ部分加群を生成するなら、
既証明の列部分加群による不変性を使って同じ結論を得る。
これは明示的な分裂した自由関係式についての計算であり、
任意の局所自由対象の表示から分裂と自由な核を構成する段階は別に証明する。
その存在の段階では、全射 q : P → M と M の射影性から実際の右逆元 s を選ぶ。
id_P - s q を ker(q) に制限した射影を構成し、包含との合成が恒等であることを証明する。
P が有限射影なら ker(q) も有限射影となり、局所環上では既存の有限平坦加群の自由性を適用する。
この証明には環の Noether 性を加える必要がない。
さらに ker(q) × M と P の実際の線形同型を、(x,m) ↦ x + s(m)、
逆写像 y ↦ (y - s(q(y)), q(y)) によって構成する。
有限自由な場合の階数の和の等式をこの同型から導き、
分裂行列の列数を表示の生成元数から対象の自由階数を引いた数として特定する。

#### 小行列式条件からの自由性の逆方向

原典：Stacks 0810, Lemma 38.30.2 の Fitting による自由性判定。
まず可逆な正方行列 A に一列 x と一行 b、一係数 y を加えた境界行列を定義する。
Mathlib の Schur 補元の行列式公式から、その行列式が det(A) (y - b A⁻¹ x) となることを証明する。
境界行列式が零なら det(A) の単元性によって y = b A⁻¹ x となる。
ピボットに関係式の各列と残りの各行を追加した境界行列を使えば、
一つ高い次数の小行列式の消滅から、残りの成分の関係式がピボットの像に入ることを得る。
その結果、核全体をピボットが生成するため、既存の補成分の実同型を適用できる。
この段階でも表示独立性を未証明の仮定フィールドとして使わない。

#### 境界外の局所自由階数から具体的な係数中心を選ぶ

原典：Stacks 0810, Lemma 38.30.2 の中心 I = f coeff(Fit_r(M)) の admissible 性。
元の有限表示 H と生成全射 q を固定し、J を N-r 次小行列式イデアルとする。

従って J は P の拡大に含まれず、明示的な分裂表示の係数イデアルの議論から、

拡大素性や境界外の局所自由性を、この中心の存在に置き換える仮定にはしない。
それらを幾何学的整ファイバー等から導く段階は別に残す。
拡大素性は、Noether 基礎環と平坦・有限表示・幾何学的整な Spec の射に限り先に証明する。
基礎環を素イデアル P で割った整 Noether スキームへの基底変更は整となる。
既存の商の Spec とファイバー積の実同型により、代数の拡大イデアルによる商が整域となり、
P の拡大が素イデアルであることを得る。
幾何学的整な有限表示平坦代数の基礎環上での射影性とは別の主張として扱う。

#### 閉ファイバーが体となる局所環での自由性への準備

原典：Stacks 0810, Lemma 38.30.2 の境界外の特別な局所環での局所自由性。
R → S と、両者のスカラー作用が両立する M に対し、任意の R のイデアル I について
I ⊗_R M → IS ⊗_S M、i ⊗ m ↦ φ(i) ⊗ m の実際の全射を構成する。
IS の生成元の span の帰納法で、S の係数を M 側に移して全射性を示す。
この写像はそれぞれのテンソル積から M への作用写像と可換。
M が R 上平坦なら左側の作用写像は単射なので、全射性を介して右側の作用写像も単射となる。
局所環で S の極大イデアルが R の極大イデアルの拡大なら、
この単射性と既存の有限表示加群の局所自由性判定から M の S 上の自由性を導く。
特別な局所化におけるスカラー塔・平坦性の保存と極大イデアルの等式は別に照合する。

実装済み：`ExtendedIdealTensor.lean` で比較全射・作用の可換性・
拡大イデアルのテンソル包含の単射性と、上記の有限表示加群の自由性を証明した。
一般の有限型代数の特別な局所化へ適用するための平坦性保存は引き続き必要。

次の補題は R → S、S 上の加群 M と平坦な S-加群 N に対して、
M が R 上平坦なら N ⊗_S M も R 上平坦となるというもの。
混合テンソル結合同型により、包含のテンソル化を
N ⊗_S (M ⊗_R -) と同定し、二つの平坦性を順に使う。
N が S の局所化環の場合に適用して、基礎環上の平坦性を保持する。
極大イデアルの単射性だけを使うため、基礎環 R が局所環である必要はない。
S が局所環で、その極大イデアルが R のあるイデアルの拡大であれば十分。
特別な素点 PS による局所化では、極大イデアルは P の拡大に等しいので、
R 自身の素点局所化を経由せずに自由性判定を適用する。

#### 設計変更案：生成全射の核による自由性への別経路

対象箇所：Stacks 0810, Lemma 38.30.2 の最後の自由性判定。
原典では高次の Fitting イデアルの消滅を検出するため、
Stacks 05DH, Lemma 38.7.4 の普遍単射性を用いる。
現行の計画ではこの一般的な普遍単射性の特殊化を未証明の幾何学的入力として残している。
次の核による経路に置き換えることを提案する。採用前に実装しない。

最初に独立して証明する文言：

- A → S、S は Noether、N は有限表示 S-加群で A 上平坦。
- 各 P ∈ Spec A について S ⊗_A κ(P) は整域または零環。
- q : S^r → N は実際の全射。
- 非零な各ファイバーの一般点で、q の局所化は同型。
- このとき q は同型である。

証明方針：

1. K = ker(q) とする。Noether S と有限自由な定義域により K は有限生成。
2. N が A 上平坦なので、0 → K → S^r → N → 0 は
   任意の A-加群とのテンソル後も左端で単射となる。
   必要な「平坦な余核を持つ完全列のテンソル単射性」は実際に証明する。
3. 従って K ⊗_A κ(P) は (S ⊗_A κ(P))^r の部分加群。
   ファイバーの一般点で q が同型なので、この部分加群を分数体へ移すと零。
   整域上の自由加群は分数体への写像が単射なので、この部分加群自身も零。
   零環のファイバーでは結論は自明。
4. S の任意の素点 Q とその縮約 P に対し、
   K_Q / P K_Q = 0 となる。K_Q は有限生成で P S_Q は極大イデアルに含まれるので、
   Nakayama により K_Q = 0。
5. 全素点で局所化が零なので K = 0。q の単射性と全射性から実線形同型を得る。

係数 blowup の純変換 G に適用する手順：

- 既証の正則な一元小行列式による補題で、各特別な素点の近傍に
  q : S_g^r → G_g という実際の生成全射を取る。
- 境界 f を可逆化すると G は元の加群の基底変更に一致し、基礎環上平坦となる。
  代数の g による局所化後の相対平坦性は `relativeFlat_localization` で扱う。
- 非空ファイバーの一般点での階数が r であることを、境界外の一定階数と
  幾何学的整な基底変更の比較から証明する。この階数の比較は依然必要。
- 自由階数 r の加群への r 個の生成元の全射は同型なので、上の独立補題により q_f は同型。
- ker(q) の各元は f の冪で消える。一方、S_g^r 上の f の作用は単射なので ker(q) = 0。
  従って G_g は階数 r の自由加群となる。

この変更で省ける候補は、当該自由性判定に限った
S → 特別な局所化の積の単射性と高次小行列式の消滅検出である。
Stacks 05DH の一般命題を証明したとは扱わない。
幾何学的整な有限表示平坦代数の基礎環上の射影性、
境界外での分裂表示の基底変更、有限支持次元による帰納法は引き続き必要。
L7a、担当境界 §14、K 非依存、追加公理なしという設計は変えない。

#### 特殊な局所化への準備：剰余体による単射性の検出

原典：Stacks 05DH, Lemma 38.7.4 の単射性の特殊形の準備。

## 14. 担当境界（採用済み、正本 §13-13）

原典確認先：KST arXiv:1611.08466v4 §5.3、Table 1、Lemma 5.5 とその証明。

### 14.2 二種類の古典的スキームを区別する

- `Bl_(a)(Spec A)` は本レーンの Rees 代数の Proj。
- KST §5.3 の `X̃` は導来 blowup の underlying scheme。

- その射は中心の外では同型だが、一般には大域同型ではない。
- したがって `X̃ := affineBlowup I` という定義で接続してはならない。
- K-L5 から underlying scheme の定義を受け取り、別の対象として比較する。
- 正則な普遍基底上の通常 blowup と、任意の基底変更後の通常 blowupも区別する。

### 14.4 §10-9 の量化子と証明方針（実装前記録）

Lemma 5.5(ii)(iii) 自体は一つの blowup と厚み指数 n の pro 系について述べる。
Lemma 5.6 の証明で blowup の指数 m を追加し、各固定 m に Lemma 5.5 を適用する。
その後、二重添字の pro 系から対角 n = m への移行が必要になる。
各段階で遷移写像が可換することを先に用意し、有限個の既指定段階の上界を取る。
全 m に共通の厚み指数が存在するという主張を、固定 m の結論から推論しない。
π_i の消滅・同型に必要な指数の i への依存も別に扱う。
この再構成が原文の Lemma 4.7 の利用を完全に置換できるかは未検証。
この K/pro の再構成と Lean 実装は K-L6 の担当とし、L7 は古典的幾何の入力を提供する。
本節の記録と設計上の問題はチャットに報告済み。
