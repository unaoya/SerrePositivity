#### W9-I-01 の反例と修正の内容

素数 p を固定し、`A = ℤ_p`、`d = p` とする。これは有界結晶 prism である（原典 pp.28–29 Def 3.2・Example 3.3）。
まず空列を許せば `B = A` とするだけでよい。原典の条件の射は

`K := Kos(A; p,p) → Kos(A; p,p) = K`

という恒等射なので平坦である。一方、ホモロジー次数で K は

`0 → A → A² → A → 0`

であり、微分を `c ↦ (-pc,pc)`、`(a,b) ↦ p(a+b)` と取れる。
A の p ねじれがないので `ker(d₁) = {(-b,b) : b ∈ A}`、`im(d₂) = {(-pc,pc) : c ∈ A}`。
したがって `H₁(K) = A/pA = 𝔽_p ≠ 0`、`H₀(K) = 𝔽_p`、`H₂(K) = 0`。
D20 の条件はこの恒等射さえ排除する。

空列に依存しない例は `B = ℤ_p⟨X⟩`、列 `(X)` である。
X は非零因子で `B/XB = A` だから、`Kos(B;X) ≃ A`。
従って自然な射

`Kos(A;p,p) → Kos(B;p,p,X)`

も同値であり、Def 2.42 の意味で平坦である。標的の `H₁ ≅ 𝔽_p` は依然として消えない。
B は導来 p 完備であり、この例は設計が対象とする離散完備代数の範囲内にある。

誤りの原因は、**相対的な平坦性と絶対的な離散性を同一視したこと**にある。
`K → L` という connective な単体的可換環の平坦性をホモロジーで書くなら、
`H₀(L)` の `H₀(K)` 上の平坦性に加え、各 i について自然な射

`Hᵢ(K) ⊗_{H₀(K)} H₀(L) → Hᵢ(L)`

が同型であることを要求する。基底 K 自身に高次ホモロジーがある場合、それを消してはいけない。
原典 p.26 Def 2.42 の射の平坦性をそのまま定義にする案が最も直接的であり、上の条件を同値な特徴づけとして証明する案もある。
`p,d` を正則列と仮定すれば消滅型の条件に簡約できるが、結晶 prism `(ℤ_p,(p))` を除くため、この追加仮定を一般定義の修復には使えない。

これは `IsPrismaticEnvelope` の普遍性や、変数の場合に `Z=dY` で作る具体的模型を否定する反例ではない。
しかし原典 pp.33–35 Prop 3.13・Example 3.14 が参照する Def 2.42 と設計上の述語が異なる以上、D20 を「同値」として後続の証明に使用することはできない。
停止判定の理由はこの数学的誤りであり、「D 番号がない」という指摘ではない。
