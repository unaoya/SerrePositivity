#### W9-I-01 の反例と修正の内容

素数 p を固定し、`A = ℤ_p`、`d = p` とする。これは有界結晶 prism である（原典 pp.28–29 Def 3.2・Example 3.3）。
まず空列を許せば `B = A` とするだけでよい。原典の条件の射は

`K := Kos(A; p,p) → Kos(A; p,p) = K`

という恒等射なので平坦である。一方、ホモロジー次数で K は

`0 → A → A² → A → 0`

であり、微分を `c ↦ (-pc,pc)`、`(a,b) ↦ p(a+b)` と取れる。
A の p ねじれがないので `ker(d₁) = {(-b,b) : b ∈ A}`、`im(d₂) = {(-pc,pc) : c ∈ A}`。
したがって `H₁(K) = A/pA = 𝔽_p ≠ 0`、`H₀(K) = 𝔽_p`、`H₂(K) = 0`。
D20 の条件はこの恒等射さえ排除する。

空列に依存しない例は `B = ℤ_p⟨X⟩`、列 `(X)` である。
X は非零因子で `B/XB = A` だから、`Kos(B;X) ≃ A`。
従って自然な射

`Kos(A;p,p) → Kos(B;p,p,X)`

も同値であり、Def 2.42 の意味で平坦である。標的の `H₁ ≅ 𝔽_p` は依然として消えない。
B は導来 p 完備であり、この例は設計が対象とする離散完備代数の範囲内にある。

誤りの原因は、**相対的な平坦性と絶対的な離散性を同一視したこと**にある。
`K → L` という connective な単体的可換環の平坦性をホモロジーで書くなら、
`H₀(L)` の `H₀(K)` 上の平坦性に加え、各 i について自然な射

`Hᵢ(K) ⊗_{H₀(K)} H₀(L) → Hᵢ(L)`

が同型であることを要求する。基底 K 自身に高次ホモロジーがある場合、それを消してはいけない。
原典 p.26 Def 2.42 の射の平坦性をそのまま定義にする案が最も直接的であり、上の条件を同値な特徴づけとして証明する案もある。
`p,d` を正則列と仮定すれば消滅型の条件に簡約できるが、結晶 prism `(ℤ_p,(p))` を除くため、この追加仮定を一般定義の修復には使えない。

これは `IsPrismaticEnvelope` の普遍性や、変数の場合に `Z=dY` で作る具体的模型を否定する反例ではない。
しかし原典 pp.33–35 Prop 3.13・Example 3.14 が参照する Def 2.42 と設計上の述語が異なる以上、D20 を「同値」として後続の証明に使用することはできない。
停止判定の理由はこの数学的誤りであり、「D 番号がない」という指摘ではない。

#### W9-I-13：PD Čech 脈体が切断つきでないことの直接計算

一変数の `B₀=ℤ_p⟨X⟩ → 𝔽_p[X]` を取り、D₀^• をその PD Čech 模型とする。
`D₀⁰/p=𝔽_p[X]`、`D₀¹/p=𝔽_p[X₀]⟨z⟩_PD`、`z=X₁−X₀`。
分冪多項式環では `z^p=p!γ_p(z)` なので、mod p では `z^p=0`。
従って Čech 微分 `δf=f(X₁)−f(X₀)` に対して `δ(X^p)=0 mod p`。
H⁰ には既に非定数の X^p が残り、基底 𝔽_p の定数に収縮する Čech 複体ではない。

さらに、どの次数0の対象への収縮でもないことは H¹ から分かる。
p ねじれのない PD 多項式環 D₀¹ で

`y = (X₁^p−X₀^p)/p`

は実際に元として存在する。具体的には

`y = Σ_(1≤k<p) (binom(p,k)/p) X₀^(p−k) z^k + (p−1)! γ_p(z)`。

3点上では差が望遠鏡和で消えるので、`p·δy=0`。D₀² も p ねじれがないため `δy=0`。
よって y mod p は1-cocycle。一方、任意の0-cochain f∈𝔽_p[X] の coboundary
`f(X₀+z)−f(X₀)` は z の通常の冪で書ける。mod p で z^k=0（k≥p）なので、その γ_p(z) の係数は零である。
y のその係数は `(p−1)!≠0 mod p`。分冪基底の独立性から y mod p は coboundary でない。
従って **H¹(D₀^•/p)≠0**。切断つき augmented Čech 脈体なら extra degeneracy が高次コホモロジーを消すので、設計書の説明と矛盾する。
この計算は、証明したい de Rham 比較や Cartier 同型を前提にしていない。

修正に使う文献では PD 微分を明示し、Ω¹ の余単体的加群に基底ごとの homotopy を作り、それを外冪等へ移している。D₀^• 自体の収縮ではない。
参照：[Bhatt–de Jong, *Crystalline cohomology and de Rham cohomology*](https://www.math.columbia.edu/~dejong/papers/crystalline-comparison.pdf)、p.1 規約、pp.5–6 Lemma 2.15・Example 2.16・Lemma 2.17。
これは BS 著者版 pp.45–47 Thm 5.2 を使う D25 β の補助比較に関する指摘である。

#### W9-I-18 の直接計算と修復案

一変数を取る。自由 δ 環の通常の多項式座標を `x_(i,k)=δ^k(X^(i))`（コピー i、k≥0）と書く。
BS pp.45–46 Thm 5.2 と設計 §2.3 によれば、PD を加える核は
`J₀¹ B¹=(p,x_(1,0)−x_(0,0))` であって、高い δ 座標の差を含むイデアルではない。
従って、`z=x_(1,0)−x_(0,0)` として通常の環の同型

`D¹/p ≅ 𝔽_p[x_(0,0), x_(0,k), x_(1,k) (k≥1)]⟨z⟩_PD`

がある。ここで `t=x_(1,1)−x_(0,1)` は通常の多項式変数として残る。
PD de Rham 微分について `d(t^p)=0` なので、t^p はこの列の H⁰ の元である。
複体は非負次数なので H⁰ に境界はなく、t^p は非零である。
コピー0からの `Ω^*_(B/p)→Ω^*_(D¹/p)` の H⁰ の像には t^p は入らない。
実際、右辺の通常の多項式座標の独立性により、t^p はコピー0の座標だけの多項式ではない。
従って **Ω^*_(D¹/p)≃Ω^*_(B/p) をコピー0の射で得る列の Poincaré 議論は成立しない**。
さらに n=0 でも `D⁰=B` であって B₀ ではなく、δ 座標の微分を足すだけでは目的の Ω^*_(B₀/p) にはならない。
これは無限変数・完備化の技術以前の問題で、一つの追加座標 t だけで検出される。

修復案は、**通常の環としての追加座標の Čech 因子だけ**を収縮することである。
`Q=ℤ_p[U_k | k≥1]` と置くと、p 完備化前の座標表示から、全次数について

`D^n ≅ (D₀^n ⊗_(ℤ_p) Q^{⊗(n+1)})^∧_p`

を得る。余面・余退化はコピーの挿入・同一視であり、この表示と両立する。
`E^n=Q^{⊗(n+1)}` は ℤ_p→Q の通常の Čech 余脈体で、`U_k↦0` という環の retraction がある。
その extra degeneracy が、増大射 `ℤ_p→E^•` を余単体的加群のホモトピー同値にする。
G-A1-3 の「テンソルでホモトピー同値を保つ」を D₀^• とテンソルして使えば、
`D₀^•→D^•` の非正規化複体が擬同型となる。各 mod p^a で同じ収縮を使い、Rlim_a で完備版へ移せる。
この方法は **D₀^• 自体を split と主張しない** ため、前回の W9-I-13 の誤りを含まない。

比較射として使うのは自然な包含 D₀^•→D^•。補助的な retraction の自然性や δ 射性を比較定理の仕様に要求する必要はない。
この包含は多項式写像に関して自然な余単体的環の射なので、同値性を示した後の逆は CAlg でも自然に取れる。
ただし Tot の CAlg 実現・PD de Rham 比較との乗法的な接続には G-A1-11 が依然として必要である。
原典の D₀、D、R、R′ の区別（BS p.45 Thm 5.2 の冒頭の図式）とも整合する。

| §8.1：自由 δ 環の平坦性と生の pushout | ○（数学的な多変数版） | 完備化前に `(X^(0),X^(i))↔(X^(0),z_i)` は自由 δ 環の変数変換。ℤ_(p){z}→ℤ_(p){z,X^(0)} は通常の多項式拡大で平坦。各変数の Frobenius は忠実平坦（BS pp.15–16 Lemma 2.11）、有限テンソルで多変数も忠実平坦となる。従って `ℤ_(p){y}→ℤ_(p){z}, y↦pz` と Frobenius の pushout は、p ねじれのない ℤ_(p){z} 上平坦で p ねじれなし。BS p.23 Lemma 2.36 の証明が多変数へ延び、PD 包との同定は各変数の分冪のテンソルで得る。ℤ_p への係数拡大と p 完備化後は p 完全平坦性として使う。完備環上の通常の自由加群性までは主張しない。 |

### 4. 指示書 §3 および A1 §9.4 への回答

**§3.4／D68：妥当（自然性の仕様を補うことを条件に、一つの黒箱を推奨）。**
HT と de Rham を二つの独立の黒箱にする必要はない。de Rham 比較の mod p と Cartier で Cor 5.5 を得る方針を維持する。
