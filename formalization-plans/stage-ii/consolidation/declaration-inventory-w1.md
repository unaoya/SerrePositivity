## 0. 目標と、IC-2 との関係

整理の目標（ユーザー、11-19）は次の三つ。

1. 全てのファイルの内容をブループリントで捕捉する。
2. その上で、内容に合わせたディレクトリ構成とファイルの分割に基づいて配置する。
3. 文献の形式化がどこまで進んだかを確認できる。

検討の単位は**ファイルではなく宣言**とする（ユーザー）。ファイルは細かく割れすぎている（11-19 の実測、Archive を除く：34,336 本・163,207 宣言・312 万行、1 ファイルの宣言の中央値 3・行の中央値 72、宣言 3 個以下が 17,542 本）。補助のファイルを減らすのも整理の目的に入る。

ブループリントは二つにする（ユーザー承認）：
- **文献のブループリント**（今のもの、`blueprint/`）：文献の項目ごとの主張・状態・結んだ宣言。進み具合を見る。
- **把握のブループリント**（新しく作る）：本体の側から見る。節点は宣言の**まとまり**（文献の項目の補助、または本体の構成の主題）で、宣言は節点の中の表にする。

**IC-2 は止める**（ユーザー承認）。今の組をコミットして止まる。残りの組への一括の承認は取り下げる。IC-2〜5 と BS の整理は、この目録の上で「まとめ直し＋移動」の束に組み直す（同じ宣言を二度動かさないため）。IC-2 の段 0 の資料（`research/infinity-consolidation-w2/`）は捨てずに、組み直しの入力にする。

## 2. 段 0 の出力

`formalization-plans/stage-ii/consolidation/report-declaration-inventory.md`（新設）と `research/declaration-inventory/`。

### 前半（ここで一度止まる）

1. **宣言の表**（`decls.csv.gz`）：本体（`SerrePositivity.*`、Archive を除く）のすべての宣言。列は、名前、モジュール、ファイル:行、種類、private か、自動生成か（`_proof_`・`match_`・等式の補題・`instance` の自動名など、親の宣言に寄せる）、docstring の有無、文献の属性（`@[cite]`・`@[kerodon]`）。
2. **依存の辺**（`edges.csv.gz`）：本体の宣言から本体の宣言への辺（型と本体の両方、自動生成の宣言は親に寄せる）。
3. **根**：(i) 論文の主定理と sorry の閉包の対象、(ii) 対応表（`research/*-coverage` のすべての review と items）が名指しする宣言と、その項目・状態、(iii) 全監査の期待の一覧。根ごとに件数。
4. **役割**：宣言ごとに一つ。
   - 主張：(ii) で名指しされている。
   - 補助：主張から依存をたどって届く。どの項目の補助かを付ける（最も近い項目。複数の文献の項目から届くものは、その一覧）。
   - 本体の構成：(i) から届くが (ii) からは届かない。
   - 監査だけ：(iii) からだけ届く。
   - 使われない：どこからも届かない。
   役割ごとの宣言数と行数を、ディレクトリごとに集計する。
5. **ファイルの所見**：ファイルごとに、宣言の役割と持ち主（項目か主題）の内訳。印を付けるもの：複数の文献にまたがる（分割の候補）、宣言 3 個以下（まとめる候補）、使われない宣言だけ（Archive の候補、提案だけ）。

前半の報告で止まる。まとまりの切り方（後半の 6）は、前半の数字を見て調整役とユーザーで決める。

### 後半（調整役の連絡の後）

6. **まとまりの案**：宣言を、文献の項目の補助、または本体の構成の主題ごとにまとめる。まとまりごとに、仮の題、宣言、今のファイル、置き場所の案（文献の節か主題のディレクトリ）を書く。把握のブループリントの節点の入力として、`groups.json` も出す（生成器は調整役が書く）。
7. **ファイルの案**：まとまりから決め直したファイルの数と行の分布（今との比較）。IC-2 の段 0 の `placement.csv` との食い違い。
8. **組み直しの案**：「まとめ直し＋移動」の束の順序と所要時間の見込み（適用・保存比較・調整役の検証）。束は IC-2〜5 と BS の整理の範囲を覆う。

## 3. 守ること

- 主張・証明・定義を変える提案はしない。宣言を動かす、まとめる、分けるだけ。
- 削除・Archive への移動は提案だけ。決めるのはユーザー。
- 報告の形は IC-W1 と同じく「一覧：済み n／全体 m（うち追加 k）」（単位は前半の 1〜5、後半の 6〜8）。
