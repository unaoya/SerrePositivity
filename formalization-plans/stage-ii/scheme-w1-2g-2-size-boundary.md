## 実測と、従来の見込みを更新する理由

基準 `56ea849a3` からの実測は次のとおり。

| 項目 | 実測 |
| --- | ---: |
| 新規157モジュールの本体 | 10,714行 |
| 既存ファイルへの追加（削除14行は相殺しない） | 25行 |
| 入口への追加（登録157行・空行21行） | 178行 |
| 外枠に対する計数 | **10,917行** |
| 新規モジュールの小監査の累計 | 1,026宣言、標準三公理のみ |
| 既存ファイルの対象監査（別計上） | 15宣言、標準三公理のみ |

9,054行時点の表では、相対 proper fppf の二重 Čech と実際の被覆比較を400〜1,000行と見ていた。実際の各写像の型を照合すると、アフィン始域の環の conerve の完全性だけでは、非アフィンな始域・基底の同じ二重 Čech の行の完全性にまだ渡せない。現在までに同じ余積・混合ファイバー積と Frobenius 係数の標準比較を検証したが、次の三つがなお必要である。

1. 同じ幾何的 nerve の Γ と混合ファイバー積の切断の積を、全次数・単体の射・増大を保つ同じ環図式で比較する。
2. 元の被覆の矩形タプルの開を、同じ混合ファイバー積の実際の開への射と同定し、同じ切断・Frobenius 係数の写像へ移す。
3. 非アフィンな中間基底 Y では有限アフィン被覆 U を選び、源の被覆を逆像に従属させ、増大項を同じ C(Y,U) とする相対二重 Čech へ渡す。

この三つは元のG4の残りで、範囲の追加ではない。非アフィン Y の Γ の忠実平坦性を仮定したり、独立な H の同型で写像の可換性を置き換えたりして省略しない。元のブローアップを保持する F8・Noether 帰納と、G2の実際の模型の代入も残る。
