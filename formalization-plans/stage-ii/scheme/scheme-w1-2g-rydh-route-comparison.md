# SC-W1 2g：Rydh 3.10 と 3.12 の経路比較

2026-11-14。G0 と並べて行う紙の比較。G1 以降の実装経路の承認を求める材料であり、未形式化の構造定理を仮定として本体に登録するものではない。停止点は、G1・G2 の幾何を **2g-1**、G3〜G5 の Čech 判定と移送を **2g-2** とする。

## 1. 結論：3.10 で同じ最終主張に届く

到達する主張は変更しない。任意の完全 F_p 環 A と完全 F_p 環の有限族 B_i への v 被覆について、通常の有限積への環準同型の増大 Čech conerve が `SerrePositivity.Cech.AugmentedRingCechExact` を満たす、という BS17 Thm 4.1(i) の同じ affine の主張を出す。有限表示・Noether・平坦性などの仮定を最終利用側へ追加しない。

[Rydh Thm 3.10](https://davidrydh.se/papers/submersion20100305.pdf#page=14) は、有限表示の universally subtrusive な射の細分を、有限表示の忠実平坦射と有限表示の固有全射の合成として与える。3.12 はここから準切断と 3.11 を使い、最初の射を開被覆に強める。その強化を省き、fppf 降下をそのまま使う。

[BS17 Thm 2.9 の証明](https://arxiv.org/pdf/1507.06490#page=8) が一般の被覆へ進む最後の段で使うのも、fppf と固有全射の合成による細分である。この部分の複体版は B1 の二重 Čech と合成からの消去を使って直接実装できる。3.10 の入力への v 判定と universally subtrusive 性の橋は依然必要で、構造定理を単なる全射性から適用しない。

## 2. 同じ結論へ至る複体の筋

一射 f:Spec B→Spec A とする。一般の有限族は G0 の `isAffineVCoverFamily_iff_pi` でこの入力にまとめる。

1. 有限表示の段で、3.10 の証人を実際のスキームの射の列として構成する：
   X'→T→Spec A、T→Spec A は固有全射・有限表示、X'→T は忠実平坦・有限表示、X'→Spec B を持ち、合成が一致する。
2. T は affine 基底上 proper なので qcqs。X'→T は有限表示なので X' も qcqs。X' の有限アフィン開被覆を取り、有限非交和を一つの affine スキーム X'' にまとめる。これで X''→T は引き続き fppf、X''→Spec B の細分の射も保持する。X' 自体を affine と仮定しない。開を選ぶために準切断は要らない。
3. 固有全射 T→Spec A を同じ有限型 F_p の段へ降ろし、2d の細分と G3 の帰納を使う。非被約の基底は nilimmersion と 2f の不変性で処理する。ブローアップの有限ファイバー冪には 2f の射影四角形の完全性を適用する。
4. X''→T の fppf 部分を有限アフィン被覆と各底変換で扱う。有限段の affine faithfully flat Amitsur 複体の完全性を使い、実際の Frobenius の順極限へ渡す。任意の環の Frobenius が flat という仮定は使わない。
5. B1 の `doubleCech_acyclic_iff` と `exact_zero_row_iff_zero_col_of_commute` で二つの方向の Čech を比較する。`isCechExact_of_comp` へは、合成の完全性だけでなく、正次数の各 Čech 項への底変換後の完全性も渡す。細分による消去で元の f の完全性を得る。
6. 一般の affine v 被覆は有限表示の環の段で表し、細分の模型を使って各段を v 被覆にする。B1 の `isCechExact_colimit` と 2f の自然な filtered 比較で戻す。2h で完全環の Frobenius 順極限の同型と有限テンソル冪を整合させ、元の型に戻す。

有限アフィン被覆を選んだだけで、スキームから複体への厳密な関手を得たとはしない。2f の共通細分・逆像の比較と鎖ホモトピーを、有限な二重・三重図式に組む作業は両経路に残る。

## 3. G1・G2 の変化

### G1：省けるのは 3.10 から 3.12 へ強める束

省ける候補は、fppf 射の準有限な準切断、3.11 の準有限な subtrusive 射の open–finite 細分、および有限射との合成で open–proper に強める組み立てである。Zariski Main の必要な部分や TIC 上の準有限な場合への接続の一部もここに属する。

一方、一般の affine v 被覆への 3.10 の適用そのものは残る。付値判定から subtrusive 性への橋、平坦化、非 Noether 基底での模型と降下は省けない。2d の固有全射の平坦化を、そのまま一般の有限表示の v 被覆の平坦化と同一視しない。

G1 は従来 **5,000〜10,000 行**から **3,500〜7,500 行**へ、約 **1,500〜2,500 行削減**を見込む。これは未実装部分の見積もりで、数学的な上限の保証ではない。

### G2：固有性と全射性のモデル構成は縮まない

3.10 の細分も T→Spec A の proper・finite presentation・surjectivity と、細分の有限個の射・可換式を同じ有限型 F_p の段へ降ろす必要がある。基底モデルから元の基底への射が faithfully flat とは限らないので、平坦降下の定理で代用できない。

3.12 の open-cover の証人をモデル化する部分の代わりに、3.10 では fppf の証人もモデル化する。有限表示の flatness の有限段への降下、全射性を同じ段にそろえること、有限アフィン被覆の貼り合わせが加わる。flatness は開 immersion の降下ほど即時ではない。したがって G2 が大幅に縮む根拠はない。

G2 は従来 **5,000〜9,500 行**に対し **5,500〜10,500 行**を見込む。約 **500〜1,000 行増**の余地を置く。既存の適切な flatness の極限 API が確認できれば従来の範囲へ戻すが、現時点でそれを前提に値引きしない。

## 4. G3〜G5 の変化

| 束 | 3.12 経路 | 3.10 経路で変わること |
| --- | --- | --- |
| G3 帰納的レベル・射影表示 | 2d の細分、nilimmersion、閉中心の次元低下、Rees・Segre 表示 | 同じ固有全射の帰納なので変更なし。2,000〜4,500 行。 |
| G4 Čech 判定 | open cover と proper の合成の消去、共通アフィン細分 | open-cover の入口を fppf に替える。各 affine 底変換での Amitsur・Frobenius・Čech の比較を明示する分、2,500〜5,000 → 2,700〜5,500 行。B1 は再利用。 |
| G5 filtered 移送 | 模型からの余極限と、環の conerve の構造写像の比較 | 最終型も環の図式も同じ。1,000〜2,500 行で変更なし。 |

2f の射影版から一般の固有射のコホモロジーへ範囲を広げる必要はない。固有全射を細分した後のブローアップとその有限ファイバー冪だけで帰納する点は両経路で同じ。

## 6. 型の差分案

3.12 の型案にある「proper な T の有限アフィン開被覆から元の X への射」を、3.10 では次へ替える。これは証明に供給する細分の証人の型案で、既存の最終 API の型変更ではない。

```lean
-- 未実装の案。f : X ⟶ Spec A は有限表示の v 被覆。
∃ (T X' : Scheme.{u}) (q : T ⟶ Spec (CommRingCat.of A))
  (a : X' ⟶ T) (k : X' ⟶ X),
  IsProper q ∧ Surjective q ∧ LocallyOfFinitePresentation q ∧
  Flat a ∧ Surjective a ∧ LocallyOfFinitePresentation a ∧ QuasiCompact a ∧
  k ≫ f = a ≫ q
```

q と a と k のモデルを同じ有限段でそろえる。任意の有限表示の flat 射に全射性を付け足したり、細分の存在を未証明の入力仮定として最終定理へ漏らしたりしない。

11-14 の新しい型つき一覧の規則に従い、既存の構成の自然性・係数移送・合成・貼り合わせと証明の分割に本数制限は置かない。型は各報告に載せ、200 行を超えるものは実測行数を記録する。今回の経路選択は新しい幾何学的供給の範囲と外枠に関わるので、G1 以降の判断をこの紙に残す。
