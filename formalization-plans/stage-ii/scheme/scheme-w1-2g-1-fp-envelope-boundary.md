## 止める理由と適用する規則

[lane-goals-2026-11-14.md の共通の規則](../lane-goals-2026-11-14.md) は「止まって報告するのは、新しい構成・新しい定理（既存の構成の法則でないもの）、まとまりの外のもの、外枠に届くとき」と指定する。下の C02 は既存の模型の射影・係数移送だけではなく、有限表示の新しい閉部分スキームの存在構成に当たると判断した。この構成の Lean へは入らず、型と原典・不足・代替案を報告し、既定の代わりの作業（2h の紙）へ移る。外枠 25,000 行には未到達。

## 未接続の箇所

一般平坦開を伴う Noether 模型を平坦化して元の基底へ引き戻すと、固有有限表示の周辺空間 Y と、その上の平坦・局所有限表示・準コンパクトな射 g:X'→Y が得られる。しかし、元の稠密開の逆像が Y 全体でも稠密であることは自動的には使えない。[整射近似のメモ](scheme-w1-2g-integral-colimit-note.md) の R[u]/(x(u−t)) のチャートの計算が、その推論の問題を示す。

必要なのは、元の基底へ全射な閉部分スキーム Z⊆Y を含み、g の像の開 V の中に入る、有限表示の閉部分スキーム Z₀ である。Z⊆Z₀⊆V なら、Z₀ は基底上固有・有限表示・全射で、g の Z₀ への引き戻しは fppf になる。Z 自体を有限表示と仮定したり、引き戻した Y 全体への g の全射性を未証明のまま入力したりはしない。

Z と V について残る既存構成の法則の接続もある。準コンパクト開の閉包上での特殊化と、v 被覆の特殊化の持ち上げを使って Z⊆V を示し、閉像の性質と元の稠密開から Z の基底上の全射性を得る。これらはまだ完成していない。C02 の前に無条件に成立したものとして扱わない。

## C02 候補の型

R は任意の可換環、p:Y→Spec R は固有かつ局所有限表示とする。K:Y.IdealSheafData、V:Y.Opens、K.support⊆V に対し、次を供給する。

```text
∃ J : Y.IdealSheafData,
  J ≤ K ∧ LocallyOfFinitePresentation J.subschemeι ∧
    (J.support : Set Y) ⊆ V
```

J≤K は K の閉部分スキーム Z が J の閉部分スキーム Z₀ に因子化することを表す。ここでの包絡 Z₀ は台を V の中で大きくしてよく、同じ台を持つ冪零の厚化は要求しない。元の基底を Noether と仮定しない。

紙の筋は、K を有限型な準連接部分イデアルの有向和として近似し、準コンパクトな閉集合 Y\V を有限個の局所切断で避けることで、一つの有限型な部分イデアル J≤K を選ぶもの。[Stacks 01PF](https://stacks.math.columbia.edu/tag/01PF)・[01PG](https://stacks.math.columbia.edu/tag/01PG) が有限型の準連接部分加群の延長・有向近似を与え、[01TV](https://stacks.math.columbia.edu/tag/01TV) が有限型イデアルと有限表示閉埋め込みを結ぶ。

最初に分ける小さい型の候補は、(i) 有限個のアフィン局所切断を含む有限型の部分イデアル J≤K、(ii) その各アフィン上の有限生成性から閉包含 J.subschemeι の局所有限表示性、(iii) 準コンパクトな補閉集合を避ける J の選択、である。これは承認前の候補であり、(i) の新しい大域存在構成を補助法則という名で実装しない。暫定の規模は **1,500〜4,000 行**。採用されても 2g-1 の外枠 25,000 行は変更しない。

## 既存 API と代わりの道

Mathlib の IdealSheafData と閉部分スキーム、LocallyOfFinitePresentation の Spec 判定、Algebra.FinitePresentation.quotient は使える。既存の OpenCenterExtension.idealSheaf_comap_map_openImmersion は準コンパクト開から中心を延長して戻す比較を与えるが、指定された K の内側の有限型部分イデアルを供給するものではない。Mathlib の IdealSheaf と有限表示のファイル、および既存の AG のイデアルの延長の API の調査では、C02 の存在構成をそのまま供給するものは見つかっていない。

代わりの道は、固定した有限生成中心について Noether な有限段の実際のブローアップの逆系と、その極限を構成し、平坦射の像の補閉集合がある段で消えることを Mathlib.exists_map_eq_top 等で示す経路である。Rees 次数成分・斉次局所化の比較は既存の 2e の材料を使えるが、Proj のスキームとしての実際の極限と各射影を供給する構成は未実装であり、こちらも単なる既存の射影の法則ではない。

BS17 の経路だけに絞る場合、C02 の Y を「Noether な模型のブローアップのアフィン基底への引き戻し」に限定する案はある。その範囲でも必要な包絡 Z⊆Z₀⊆V を得れば、同じ fppf–proper・有限表示の出口に届く。一般の固有射のコホモロジーや Stein 分解は不要。一方、固有射を有限型までに弱めるだけでは、現在の G2 の有限表示被覆模型の界面を満たしたことにはならない。最終の AugmentedRingCechExact の型は変更しない。

判断してほしい点は、C02 を G1 の一覧へ加えて上の型で進めるか、用途をブローアップ模型に限定するか、あるいは Proj の極限の経路を選ぶかである。C02 を採用する場合の主一覧は済み 7／全体 13（うち追加 4）になる。現在の正式な主一覧は 7／12（追加 3）のまま。
