# 有限 Koszul と標準完備化単位：検査待ちと残る出口

11-15 昼。以下のソースは未検証で、HT02 の完了数には含めない。

- `KoszulScalarNaturality`：本体のスカラー錐と単位のスカラー錐のテンソルの自然同型、および Mathlib の `tensorLeftTensor` を使う。二つのスカラー錐を自然に交換し、有限 Koszul とスカラー錐の自然な交換を関手の結合・whisker で帰納的に作る。以前の対象ごとの `koszulCochainTensorIso` の自然性を別途作る案を、この経路で置き換えた。
- `FiniteCompletionReduction`：末尾の単位の簡約を本体の主元の単位の一乗 Koszul の擬同型へ戻し、反復した単位の簡約が擬同型であることを帰納する。全座標の完備性と既存の点ごとの完備 Nakayama により、元の有限 Koszul の下界と同じ値で反復完備化の下界を得る証明を用意した。
- 同じファイルの `ScalarResolution.finiteCompletedTensor_lowerBound` は、元の `HasCochainCompleteTorAmplitude` から同じ定数 c の一様下界を得る型である。有限列を主元へ制限せず、列長を二重に引かない。

次の出口：

1. 対象ビルド・全依存を含む公理閉包の検査。型検査前のソースを完成扱いにしない。
2. `FiniteTensorInverse`・`FiniteTensorComparisonIso` に用意した、元の指定次数比較の両逆と、同じ標準鎖写像への移送を検査する。
3. 有限列の標準単位の Hom 同値で、全座標に完備な標的への一般の完備比較を指定する。有限頭部での完備比較、完備化を施した切断の完全三角形、両側の尾部の評価を接続する。
4. 固定係数模型の R 線形図式での比較を、元の S 上の標準の完備底変換へ同定する。K-flat 入力での比較だけから、一般入力の結論を出さない。係数模型に S 作用を仮定しない。
5. 固定次数ごとに深い有限頭部を取り、HT02 全体の型で標準比較の擬同型性を結論する。

反復完備化の模型・合成単位を保つ。任意の射や追加の Tor・平坦性の仮定へ置き換えない。
