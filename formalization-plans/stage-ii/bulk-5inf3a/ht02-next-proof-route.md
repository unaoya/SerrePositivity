# HT02 の残りの証明経路（11-15 午前、実装前の案）

このメモは未実装の数学の案を含む。型検査済みの範囲は各 checkpoint JSON と報告本文を参照する。
HT02 の対象は有限列の完全 Tor 振幅と、一様に下に有界な余鎖図式に対する標準比較の擬同型性である。

## 比較鎖写像と成分

既存の `ProductTotal.homTotalIso` と `tensorHomEquiv` の単位から比較鎖写像を作る。
非負横次数の模型では `extendRowHom` で単位を延長し、指定された `total` を始域・終域にする。
転置の評価の符号 `(-1)^(b*a)` と行での単位の符号 `(-1)^((b-n)*a)` の積は `(-1)^(a*n)` である。
この式を使って、最初に定義した `tensorComparisonDegree` との一致を証明する。
自然性・型検査の進捗は報告に記録し、このメモの式だけで完了扱いにしない。

## 有限切断

`StupidTruncation` の整数版には、行ごとに分裂する切断の短複体がある。
非負模型用には同じ構成を `CochainComplex.of` 上で作るか、既存の零延長と切断を同一視する。
頭部を `n < N`、尾部を `N ≤ n` とする。尾部の下界 `N+b-c` は `TailBounds` で検査済みである。
`BicomplexRowQuasiIso` の既存定理の入力は第一象限であり、今回の内部次数が非有界の入力へ適用するときは、必要な比較を別途証明する。

## 主元完備化の固定係数 Hom 表示の案

既存の主元完備化関手と単位を保つ自然同型を作る案である。以下の複体名は数学の記号であり、Lean の既存宣言名ではない。

- `P_m(a)` は次数 0・1 に R を置き、微分を `a^m` とする二項複体。
- 遷移 `P_m(a) → P_(m+1)(a)` は次数 0 で恒等、次数 1 で a 倍。
- 二項の線形 Hom の成分は、既存の `Cone(a^m : K → K)` に自然に同定できる。
  Hom の次数 q の二成分 `(u,v)` は、錐の二成分 `((-1)^(q+1) v,u)` に対応する。
  遷移は錐の既存の `(a,id)` の遷移へ対応し、`P_m(a) → R[0]` は次数 0 の恒等からなる増大射である。
- `P_∞(a)` を `1-shift : ⨁_m P_m(a) → ⨁_m P_m(a)` の写像錐とする。
  Hom が直和を直積へ移す同型と、始域の錐の Hom の既存の同型を組み合わせ、
  `homComplex R P_∞(a) K` と本体の `complexCompletionFunctor R a` の値を自然に同定する。
- 増大射 `P_∞(a) → R[0]` の前合成が、本体の `complexCompletionUnit` に対応することを確認する。
  この同定と単位の一致を証明してから、Hom–Tot 同型を完備化と Tot の比較に用いる。

調べる既存 API は `HomologicalAlgebra/HomComplexCone.lean`、`ProductTotalHomIso.lean`、
`DifferentialGraded/Complexes/HomLimits.lean`、`DerivedCompletion/ComplexCompletion/Basic.lean`、
`DerivedCompletion/Localization.lean` である。局所化からの Hom による完備性の判定は既に存在するが、
上の `P_∞(a)` による本体の完備化関手の表示は、このメモの時点では未実装である。

## 有限列と最後の下界

有限列の完備化は既存の主元完備化を反復した実際の模型で構成し、列の各元についての完備性と単位を確認する。
有限列の Koszul 下界を主元の下界へ渡す際には、残りの Koszul 関手と完備化の交換の法則を証明する。
`CompletionBounds` の主元の冪の一様評価を使う。`HasCochainCompleteTorAmplitude` に既に含まれる幅 c を再び列長だけ増やさない。

有限切断上の比較と、両側の尾部の `N+b-c` の評価を組み合わせ、固定したコホモロジー次数ごとに十分大きい N を選ぶ。
係数分解 L には R 作用を用いる。標準の S 線形底変換への接続は、既存の K-flat 入力での指定比較と、係数制限・完備化の比較を通して確認する。

一覧：済み 1／全体 6（うち追加 0）。このメモの未実装の案は完了数に含めない。

## 昼の経路の整理：標準単位だけを反転する比較（未検証）

上の固定係数 Hom 表示は、既存の完備化と無限 Tot を直接交換するための案だった。
残る擬同型性の証明には、有限切断だけで交換を確認し、両側の尾部を評価する経路もある。
こちらを先に検査する。固定係数 Hom 表示は実装必須の前提から外し、未実装の代案として残す。

`C` を本体の主元完備化、`F` を固定係数テンソルとすると、既存の鎖写像から
`F(Tot K) → Tot(F K) → Tot(C(F K))` が得られる。各行が完備なので最後の Tot も完備である。
この射に C を施した後、標的の標準単位の像だけを導来圏で反転する。
始域は `Q(C(F(Tot K)))`、標的は `Q(Tot(C(F K)))` のままで、模型を置き換えない。
標準単位との合成が元の射に一致する法則を `CompletedComparison.lean` に用意した。
この時点で定義も法則も型検査待ちであり、擬同型性は未証明である。

`NaturalTruncation.lean` には内部次数を保った横次数の頭部・尾部、射影・包含、
既存の尾部評価との接続を用意した。これも未検証である。
有限頭部での比較と切断の短完全列の法則、有限列の完備化の下界と単位の整合性が次の課題となる。

一覧：済み 1／全体 6（うち追加 0）。

## 有限列の経路の具体化（11-15 昼、未検証）

`FiniteCompletion` は本体の主元完備化を列の順に合成し、元の単位を合成する。
既存の `isComplete_Q_mappingCone` と holim の完備性から、主元完備化は他の元の完備性も保つ。
これを使って反復後の全座標の完備性を示す証明を用意した。
`FiniteCompletionReflection` は、本体の `derivedComplexCompletionHomEquiv` と比較同型を使い、
全座標に完備な標的への射の同値と、合成単位との前合成の公式を用意した。
これらはまだ型検査前である。

有限 Koszul の単位の簡約が擬同型になる法則を示せば、既存の点ごとの完備 Nakayama と
全座標の完備性により、同じ Koszul 下界を反復完備化の下界へ渡せる。
具体的な次の手順は `koszul-unit-next-proof.md` に記録した。
同じ原典の補題の証明の分割であり、新しい一般の導来関手や ∞ の構成へ範囲を広げない。

一覧：済み 1／全体 6（うち追加 0）。
