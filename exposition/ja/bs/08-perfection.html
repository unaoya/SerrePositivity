第 8 章　一般の perfection（§8）

基準コミット f970e69f1（2026-11-12）。原典 pp.63–70。E3 に必要な項目だけを載せる（判定は 原典の項目一覧、原典との差の評価は 末尾）。

§8 は perfectoid 環 \(R=A/I\) 上の任意の（導来 p 完備な単体的）代数 \(S\) の perfectoid 化 \(S_{\mathrm{perfd}}\) を導来対象として定義し（Def 8.2）、perfectoid 環への写像の極限として描き（Prop 8.5）、arc 位相での降下と excision（Cor 8.11・8.12）、テンソルとの両立（Prop 8.13）、離散な場合の普遍性（Cor 8.14）を示す。E3 の欄の大部分がここにある。現状は E3 の欄として引用していて、そこから環の帰結を証明している（界面の型は PerfectoidizationInterfaceE3（Derived/Interface:671）、その存在の引用は exists_perfectoidizationInterfaceE3（Inputs/PerfectoidizationInterface:54、perfectoid 側に残る唯一の sorry））。一方で、§8.2 の arc 位相のうち 1 圏で述べられる部分（arc 被覆と位相、Lemma 8.8 の affine 版、Prop 8.10 の BM18 の経路 B の部品）と、Prop 8.5 の証明で使う根添加は、E3 に依らずに本体で証明されている（BS-W11・W12）。

1. 定義と coconnective 性（Def 8.2・Lemma 8.4）

Def 8.2. \(\Delta_{S/A,\mathrm{perf}}=(\mathrm{colim}_\varphi\Delta_{S/A})^\wedge\)（導来 prismatic コホモロジーの Frobenius 余極限の \((p,I)\) 完備化）、\(S_{\mathrm{perfd}}=\Delta_{S/A,\mathrm{perf}}\otimes^L_AA/I\)。p 完備な \(E_\infty\)-S 代数。A に依存しないことは Prop 8.5 から出る。

Lemma 8.4. \(\Delta_{S/A,\mathrm{perf}}\)、\(S_{\mathrm{perfd}}\in D^{\ge0}\)。証明：\(\Delta_{S/A,\mathrm{perf}}/p\) は \(P^0\) 作用（\(E_\infty\)-\(\mathbb F_p\) 代数の Steenrod 型の作用）が可逆な \(E_\infty\)-\(\mathbb F_p\) 代数で、\(P^0\) は正次数のホモトピーを殺す（[Lur11, Rem 2.2.7]）ので \(D^{\ge0}\)。\(S_{\mathrm{perfd}}\) については \(H^0(\Delta_{S/A,\mathrm{perf}})\) が完全 p 完備 δ 環なので d が非零因子（Lemma 2.34）。

2. perfectoid 環への写像の極限（Prop 8.5・Lemma 8.6）

Prop 8.5. 完全 prismatic site 上の比較写像 \(\Delta_{S/A,\mathrm{perf}}\to R\Gamma((S/A)^{\mathrm{perf}}_\Delta,\mathcal O)\) は同値。特に \(S_{\mathrm{perfd}}\simeq\lim_{S\to R'}R'\)（S から perfectoid 環への写像全体の導来極限）で、A に依存しない。S が semiperfectoid なら Cor 7.3 の \(S_{\mathrm{perfd}}\) と一致。形式化（BS-D3、D3-01）：比較写像の第 0 脚は A3 の prismMapOfDiscrete ではなく、CAlg 値の RΓ の極限射影（A2 の prismaticCohomologyCAlg、discreteEvaluation）。完全 site への制限後の極限性は降下（A5-4）で示す。

証明の流れ. (1) 位相の取り方によらない：任意の元に「p 乗根を mod p で添加する」操作を超限的に繰り返すと、全ての perfectoid 環への写像が延びる semiperfectoid な \(\tilde S\) ができ、\(\tilde S_{\mathrm{perfd}}\) が弱終対象になる。Čech–Alexander の考え方で \((\tilde S^\bullet)_{\mathrm{perfd}}\) が計算する。(2) 有向余極限と両立するので、\(\pi_0S\) が位相的に有限生成としてよい。(3) \(R\langle X_1,\dots,X_r\rangle\to S\) から \(X_i\) の p 冪根を添加した \(\tilde S\) を作り、Lemma 8.6（強い降下）で semiperfectoid の場合に帰着。(4) semiperfectoid の場合：HT 比較で \(\Delta_{S/A}\) は連結、Lemma 8.4 と合わせて \(S_{\mathrm{perfd}}\) は perfectoid 環。\(S\to S_{\mathrm{perfd}}\to R'\)（\(R'\) は Cor 7.3 の普遍環）の合成は Thm 7.4 で全射なので、\(S\to S_{\mathrm{perfd}}\) の全射性を示せばよい。Thm 7.14 で核の生成元に根を持たせ、\(S'=R\langle X_j^{1/p^\infty}\rangle/(X_j)\) へ帰着し、Prop 7.10 で結論。

Lemma 8.6. \(T=R[X_1,\dots,X_n]^\wedge\to T_\infty=R[X_i^{1/p^\infty}]^\wedge\) について、\(\Delta_{T/A}\to\Delta_{T_\infty/A}\) とその完全化は descendable（[Mat16]）。証明：完全化への移行は [BS17, Lemma 11.22]。n=1 に帰着し、\(A/(p,\varphi^{-1}(d))\) へ底変換して R を標数 p の完全環とし、de Rham 比較と Cartier 同型で、二乗零拡大 \(T\oplus\Omega^1[-1]\) 上の RHom の計算に帰着する。形式化（D3-04、W9-II-13）：descendable は E∞ 代数 \(\Delta_T\) を底とする一般形 IsDescendableOver（\(\mathrm{Mod}_{\Delta_T}\) の thick ⊗-ideal）で述べ、離散環版はその特殊化。n = 1 の index ≤ 2 は RHom の計算（fiberSquareRHom、M15 待ち）、de Rham 側の入力は A1-5 の deRham_iso_rootAlgebra_modP（drafts/A1/DeRhamComparisonPoly:494）。

Lean の部品：根添加（BS-W11）. 証明の (1)・(3) で使う環の構成は本体にある（Derived/RootAdjunction）。(1) の \(\tilde S\)：一段 rootAdjunctionStep（:52）は S の全ての元 x に同時に \(X^p-x-pY\) の根を添加し、perfectoid 環への環射は一段ごとに延びる（rootAdjunctionStep_extends、:68）。完備な一段を ℕ で積み重ねた塔 completedRootTower（:116）の余極限の完備化が rootClosure（:121）で、完備性 rootClosure_isModuleComplete（:134）、perfectoid 環への射の延長 rootClosure_extends（:143）、関手性（rootClosureMap_id・rootClosureMap_comp、:426, :435）を持つ。原典の「超限的に繰り返す」は、各段で全ての元に根を添加するので可算の塔で足りる。完備化する前の関手版 algebraicRootFunctor（:316）は「S の全ての元の p 冪根を関手的に取る」に当たり、mod p の Frobenius の全射性 algebraicRootClosure_frobenius_surjective（:449）を持つ。(3) の \(\tilde S\)：\(R\langle X_1^{1/p^\infty},\dots,X_r^{1/p^\infty}\rangle\) が perfectoid であること polyRootAlgebra_isIntegralPerfectoid（:861、完全 δ 環上の単項式代数の distinguished 主イデアルによる商として示す）と、評価による完備な底変換 rootCover（:896）。根添加が filtered 余極限と可換であること、\(R\langle X\rangle\to R\langle X^{1/p^\infty}\rangle\) の p 完備忠実平坦性は drafts にある（drafts/A5/RootAdjunction:43, :52）。

E3 での扱い（界面の規約）

E3 の limitCone は、極限の添字を Type u の perfectoid 標的に制限し、指定した錐と単位・\(H^0\) の乗法の整合を含めて述べる（原典の「全ての perfectoid 環への写像」の圏は大きい）。原典の (1) の \(\tilde S\) は u-small に取れるので、この制限でも同じ極限になる。Lemma 8.6 の入力は Thm 6.4 の多項式・mod p の特別な場合（A1-5）で、普遍向き付き prism 上で証明して完全 prism へ底変換する（D69）。結晶側は黒箱として引用せず、使う対象ごとの Hodge–Tate の命題を直接証明する形に改めた（D68 の改訂、11-05）。一般の Thm 6.4 は要らない。

原典との差

(1) の \(\tilde S\) を、原典は「一つの元に根を添加する操作の超限的な繰り返し」で作るが、Lean では各段で全ての元に同時に根を添加する ω 段の塔で作る（rootClosure）。できる対象の役割（弱始対象）は同じで、用途は弱始対象と濃度の管理に限る。完備化を挟むので filtered 余極限は保たず、filtered 余極限との可換性は完備化前の algebraicRootFunctor で扱う（D51）。

3. arc 降下と excision（§8.2）

Def 8.7・Lemma 8.8. arc 被覆：p 完備な階数 1 の付値環への写像が、忠実平坦な拡大の後で持ち上がる写像。perfectoid は arc 位相の基底をなす（semiperfectoid な p 完備忠実平坦被覆 \(\tilde R\) と \(\tilde R\to\tilde R_{\mathrm{perfd}}\) の合成。形式化では先に \(R\to R_0:=\) completionRing\((R\otimes_{\mathbb Z_p}\mathbb Z_p[p^{1/p^\infty}]^\wedge)\) で perfectoid 基底の上へ移してから A5 の根添加を施す。基底なしの根添加は semiperfectoid にならない（\(\mathbb Z_p\) への retraction、W9-II-16）。試験付値環 V は先に perfectoid な W（絶対整閉包の p 完備化）に替える）。Prop 8.10. 構造層 \(\mathcal O\) は perfectoid の圏 Perfd 上の arc 層で、高次コホモロジーが消える。証明：tilt して \(R^\flat\to S^\flat\) の d 進完備な Čech 複体の完全性に帰着し、完全スキームの v 降下（[BS17, Thm 4.1]）と arc 降下の判定（[BM18, Thm 1.6]、[BS17, Lemma 6.3]）を使う。Cor 8.11. \(S_{\mathrm{perfd}}=R\Gamma_{\mathrm{arc}}(\mathrm{Spf}S,\mathcal O)\)（Prop 8.5 と Prop 8.10 を合わせる）。Cor 8.12（E3 の excision）. \(S\to S'\) が I の外で arc 層の同型（付値環への写像が一意に延びる）なら、\(S_{\mathrm{perfd}},S'_{\mathrm{perfd}},(S/I)_{\mathrm{perfd}},(S'/I)_{\mathrm{perfd}}\) の四角形は \(E_\infty\)-S 代数の引き戻し。証明：\(S'\) を \(S'\times S/I\) に替えて arc 被覆とし、[BS17, Thm 2.9] にならって Perfd 上の層の押し出しとして計算する。形式化では、集合の層の等式 \(F(S)=F(S')\times_{F(S'/I)}F(S/I)\) を 1 圏の層（Mathlib）で証明し、空間値の層への持ち上げと \(E\) 値の層 \(\mathcal O\) の局所性（S8、∞ 側の一般論）で引き戻しに移す（a6-design §3.2、D57）。
