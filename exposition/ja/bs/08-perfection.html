第 8 章　一般の perfection（§8）

基準コミット a0ccccb09（2026-10-25）。原典 pp.63–70。E3 に必要な項目だけを載せる（判定は 原典の項目一覧、原典との差の評価は 末尾）。

§8 は perfectoid 環 \(R=A/I\) 上の任意の（導来 p 完備な単体的）代数 \(S\) の perfectoid 化 \(S_{\mathrm{perfd}}\) を導来対象として定義し（Def 8.2）、perfectoid 環への写像の極限として描き（Prop 8.5）、arc 位相での降下と excision（Cor 8.11・8.12）、テンソルとの両立（Prop 8.13）、離散な場合の普遍性（Cor 8.14）を示す。E3 の欄の大部分がここにある。現状は E3 の欄として引用していて、そこから環の帰結を証明している（界面の型は PerfectoidizationInterface/Interface:21）。

1. 定義と coconnective 性（Def 8.2・Lemma 8.4）

Def 8.2. \(\Delta_{S/A,\mathrm{perf}}=(\mathrm{colim}_\varphi\Delta_{S/A})^\wedge\)（導来 prismatic コホモロジーの Frobenius 余極限の \((p,I)\) 完備化）、\(S_{\mathrm{perfd}}=\Delta_{S/A,\mathrm{perf}}\otimes^L_AA/I\)。p 完備な \(E_\infty\)-S 代数。A に依存しないことは Prop 8.5 から出る。

Lemma 8.4. \(\Delta_{S/A,\mathrm{perf}}\)、\(S_{\mathrm{perfd}}\in D^{\ge0}\)。証明：\(\Delta_{S/A,\mathrm{perf}}/p\) は \(P^0\) 作用（\(E_\infty\)-\(\mathbb F_p\) 代数の Steenrod 型の作用）が可逆な \(E_\infty\)-\(\mathbb F_p\) 代数で、\(P^0\) は正次数のホモトピーを殺す（[Lur11, Rem 2.2.7]）ので \(D^{\ge0}\)。\(S_{\mathrm{perfd}}\) については \(H^0(\Delta_{S/A,\mathrm{perf}})\) が完全 p 完備 δ 環なので d が非零因子（Lemma 2.34）。

2. perfectoid 環への写像の極限（Prop 8.5・Lemma 8.6）

Prop 8.5. 完全 prismatic site 上の比較写像 \(\Delta_{S/A,\mathrm{perf}}\to R\Gamma((S/A)^{\mathrm{perf}}_\Delta,\mathcal O)\) は同値。特に \(S_{\mathrm{perfd}}\simeq\lim_{S\to R'}R'\)（S から perfectoid 環への写像全体の導来極限）で、A に依存しない。S が semiperfectoid なら Cor 7.3 の \(S_{\mathrm{perfd}}\) と一致。

証明の流れ. (1) 位相の取り方によらない：任意の元に「p 乗根を mod p で添加する」操作を超限的に繰り返すと、全ての perfectoid 環への写像が延びる semiperfectoid な \(\tilde S\) ができ、\(\tilde S_{\mathrm{perfd}}\) が弱終対象になる。Čech–Alexander の考え方で \((\tilde S^\bullet)_{\mathrm{perfd}}\) が計算する。(2) 有向余極限と両立するので、\(\pi_0S\) が位相的に有限生成としてよい。(3) \(R\langle X_1,\dots,X_r\rangle\to S\) から \(X_i\) の p 冪根を添加した \(\tilde S\) を作り、Lemma 8.6（強い降下）で semiperfectoid の場合に帰着。(4) semiperfectoid の場合：HT 比較で \(\Delta_{S/A}\) は連結、Lemma 8.4 と合わせて \(S_{\mathrm{perfd}}\) は perfectoid 環。\(S\to S_{\mathrm{perfd}}\to R'\)（\(R'\) は Cor 7.3 の普遍環）の合成は Thm 7.4 で全射なので、\(S\to S_{\mathrm{perfd}}\) の全射性を示せばよい。Thm 7.14 で核の生成元に根を持たせ、\(S'=R\langle X_j^{1/p^\infty}\rangle/(X_j)\) へ帰着し、Prop 7.10 で結論。

Lemma 8.6. \(T=R[X_1,\dots,X_n]^\wedge\to T_\infty=R[X_i^{1/p^\infty}]^\wedge\) について、\(\Delta_{T/A}\to\Delta_{T_\infty/A}\) とその完全化は descendable（[Mat16]）。証明：完全化への移行は [BS17, Lemma 11.22]。n=1 に帰着し、\(A/(p,\varphi^{-1}(d))\) へ底変換して R を標数 p の完全環とし、de Rham 比較と Cartier 同型で、二乗零拡大 \(T\oplus\Omega^1[-1]\) 上の RHom の計算に帰着する。

E3 での扱い（界面の規約）

E3 の limitCone は、極限の添字を Type u の perfectoid 標的に制限し、指定した錐と単位・\(H^0\) の乗法の整合を含めて述べる（原典の「全ての perfectoid 環への写像」の圏は大きい）。原典の (1) の \(\tilde S\) は u-small に取れるので、この制限でも同じ極限になる。Lemma 8.6 の標数 p の de Rham 比較は Thm 5.2（結晶比較、A1）から出るので、Thm 6.4（一般の de Rham 比較）は要らない。

3. arc 降下と excision（§8.2）

Def 8.7・Lemma 8.8. arc 被覆：p 完備な階数 1 の付値環への写像が、忠実平坦な拡大の後で持ち上がる写像。perfectoid は arc 位相の基底をなす（semiperfectoid な被覆 \(\tilde R\) と \(\tilde R\to\tilde R_{\mathrm{perfd}}\) の合成）。Prop 8.10. 構造層 \(\mathcal O\) は perfectoid の圏 Perfd 上の arc 層で、高次コホモロジーが消える。証明：tilt して \(R^\flat\to S^\flat\) の d 進完備な Čech 複体の完全性に帰着し、完全スキームの v 降下（[BS17, Thm 4.1]）と arc 降下の判定（[BM18, Thm 1.6]、[BS17, Lemma 6.3]）を使う。Cor 8.11. \(S_{\mathrm{perfd}}=R\Gamma_{\mathrm{arc}}(\mathrm{Spf}S,\mathcal O)\)（Prop 8.5 と Prop 8.10 を合わせる）。Cor 8.12（E3 の excision）. \(S\to S'\) が I の外で arc 層の同型（付値環への写像が一意に延びる）なら、\(S_{\mathrm{perfd}},S'_{\mathrm{perfd}},(S/I)_{\mathrm{perfd}},(S'/I)_{\mathrm{perfd}}\) の四角形は \(E_\infty\)-S 代数の引き戻し。証明：\(S'\) を \(S'\times S/I\) に替えて arc 被覆とし、[BS17, Thm 2.9] にならって Perfd 上の層の押し出しとして計算する。形式化では、集合の層の等式 \(F(S)=F(S')\times_{F(S'/I)}F(S/I)\) を 1 圏の層（Mathlib）で証明し、空間値の層への持ち上げと \(E\) 値の層 \(\mathcal O\) の局所性（S8、∞ 側の一般論）で引き戻しに移す（a6-design §3.2、D57）。

Lean での扱い. 環としての帰結を界面から証明している：四つの環の普遍 perfectoid 化を指定すると、それぞれが標的圏の始対象になり、導来対象が指定環の離散像と同値になる。D(R) の指定四辺の長完全列で \(H^{-1}\)・\(H^1\) の両端が消え、環の引き戻しと差写像の全射性が出る（perfectoidization_excision_isPullback・perfectoidization_excision_difference_surjective、PerfectoidizationInterface/Excision:59,70）。CLMST が使う形は klCanonicalExcisionSquare_of_excision（Perfectoidization/PerfectoidizationExcision:48）。脚注 14（整写像で \(V(I)\) の外で同型なら条件を満たす）も証明済み。

4. テンソルとの両立と離散な場合の普遍性（Prop 8.13・Cor 8.14）

Prop 8.13. \(S\mapsto S_{\mathrm{perfd}}\) は対称モノイダル：\(S_{1,\mathrm{perfd}}\widehat\otimes^L_{S_{3,\mathrm{perfd}}}S_{2,\mathrm{perfd}}\simeq(S_1\widehat\otimes^L_{S_3}S_2)_{\mathrm{perfd}}\)。証明：\(\Delta_{-/A}\) が HT 比較で対称モノイダル（Construction 7.6 (5)）で、それが完全化と mod I に移る。Cor 8.14（E3 の universal）. \(S_{\mathrm{perfd}}\) が連結（⇔ 離散）なら perfectoid 環で、\(S\to S_{\mathrm{perfd}}\) は普遍。証明：導来 Nakayama で \(\Delta_{S/A,\mathrm{perf}}\) も離散で完全 δ 環（Lemma 7.7 の議論）なので完全 prism。普遍性は Prop 8.13 で \((S_{\mathrm{perfd}}\widehat\otimes_SS_{\mathrm{perfd}})_{\mathrm{perfd}}\simeq S_{\mathrm{perfd}}\) から。

Lean での組み立て（Prop 8.13 環版）. 図式 \(S_1\leftarrow S_3\to S_2\) の各環に環としての perfectoid 化が指定されているとき、完備テンソルの \(H^0\) が \(S_1\otimes_{S_3}S_2\) の perfectoid 化であることを、環の普遍性・\(H^0\) の主元完備化の比較・perfectoid 環の完備テンソルの離散性（Lemma 10.3 の一般形）を合わせて示す（prop813CompletedTensorMap_isPerfectoidization、Perfectoidization/PerfectoidizationCompletedTensorCompatibility:102）。perfectoid な底変換の版 prop813BaseChange_exists_algEquiv（Prop813PerfectoidBaseChange:112）。

原典との差

Prop 8.13 の環版は HT 比較を使わずに示せるが、環として perfectoid 化が存在する場合（semiperfectoid の商など）に限る。A7 で導来版（原典どおり Δ の対称モノイダル性から）ができると、環版はその系になる（D15、BR31）。

BR31　Prop 8.13 の環版を導来版の系に置き換える（A7 の後）

Prop 8.13 の環版（Perfectoidization/ の 4 本、約 600 行）は、HT 比較なしで示すために普遍性を手で組み立てている。原典の導来版は Δ の対称モノイダル性から一行で出て、A7 で形式化する。そのときは、環版を導来版と Cor 8.14 の系として述べ直し、今の証明を外す（主張と型は保つ）。

2026-10-25 の調査（コードの読解と、import グラフからの到達性の計算）による。「root から到達しない」は、既定のビルドでは一度もコンパイルされず、監査スクリプトだけが読むことを意味する。

BR20　有限直積の perfectoid 性が E3 に依存している

isIntegralPerfectoid_finPi（Perfectoidization/PerfectoidFiniteProduct:21、「perfectoid 環の有限直積は perfectoid」）は、E3 から得た perfectoid 化の存在 Inputs.exists_perfectoidization_of_integral を使って証明されている（確認済み）。CLMST の 3 ファイル（PerfectoidFiniteProductTor、Prop247ConstantRankExcision、KLAicTorFromExcision）が使う。主定理はもともと E3 に依存するので新しい sorry ではないが、BS-0 の消費経路の一覧（stage2 §1）に載っていない E3 の使用箇所。四条件（Fontaine 核の単項性、p 完備性、Frobenius の全射性）は成分ごとに確かめられるので、E3 なしで直接示せるはず。E3 の使用箇所を本当に必要な二つ（存在と excision）に絞るために優先度が高い。

BR22　底変換・三角図式・Prop 8.13 底変換の共通化と、二つのテンソルのモデル

PerfectoidizationBaseChange:28 と PerfectoidizationTensorCompatibility:55 は、係数テンソルの持ち上げとテンソル積の帰納法による同じ型の証明（各 70 行ほど）。そのままでは特殊化にならないので、「C⊗_P D からの射は左右の制限で決まる」外延性補題と持ち上げの補題を共通にする。prop813BaseChangeMap も三角図式版の特殊化に見える（推測）。また perfectoid 環のテンソルの perfectoid 化に、Witt 余積のモデル（Perfectoidization/WittPresentation/ ほか約 720 行）と完備テンソル H⁰ のモデルが並んでいる。Witt モデルの用途は mod p 全単射性と根付き拡大の 2 つだけで、前者は完備テンソル側の普遍性から直接出る見込み。後者が Witt モデル固有の性質を使っていないかの調査が要る。
