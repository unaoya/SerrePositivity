第 10 章　almost purity（§10）

基準コミット a0ccccb09（2026-10-25）。原典 pp.78–83。E3 に必要な項目だけを載せる（判定は 原典の項目一覧、原典との差の評価は 末尾）。

§10 は二つに分かれる。§10.1 は perfectoid 環 \(R\) と導来 p 完備なイデアル \(J\) について、\(J_{\mathrm{perfd}}=\ker(R\to(R/J)_{\mathrm{perfd}})\) に関する almost 数学を作る（Thm 7.4 で \(R\to(R/J)_{\mathrm{perfd}}\) が全射なので意味を持つ）。§10.2 は almost purity（Thm 10.9）と、その帰結の整代数の perfectoid 化の離散性（Thm 10.11 ＝ Thm 1.17(1)、E3 の integral 欄）。§10.1 は形式化済み（B5）、§10.2 は未形式化（A8）。

1. 任意のイデアルに関する almost 数学（§10.1）

Def 10.1. 導来 p 完備な R 加群 M が J-almost zero ⇔ \(J_{\mathrm{perfd}}M=0\)。\(J=(p)\) なら \(J_{\mathrm{perfd}}=\sqrt{pR}\) で、通常の almost zero。基底変換（a8-design §3.1、D2-02）：\(f:R\to R'\) について \((JR')_{\mathrm{perfd}}\) は完備テンソル \(J_{\mathrm{perfd}}\widehat\otimes_RR'\to R'\) の像で、有限生成 J でもイデアルの式には \(J_{\mathrm{perfd}}R'\) の p 進閉包が付く（Fayolle, Prop 2.9。通常の Ideal.map との一致は一般には成り立たない：p ねじれなしの perfectoid 付値環 V 上で \(R=V\langle x_1^{1/p^\infty},x_2^{1/p^\infty},\dots\rangle\)、\(J=\ker(R\to V)\)、\(R'=R\langle t^{1/p^\infty}\rangle\) が反例）。almost 零性の反映には \(K'\simeq K\widehat\otimes_RR'\) だけを使う。

Prop 10.2. J-almost zero な導来 p 完備加群の部分圏は核・余核・拡大で閉じた ⊗ イデアルで、導来 p 完備な \((R/J)_{\mathrm{perfd}}\) 加群の圏と同値。証明：忘却関手が RHom を保つことを示せばよく、それは \(M\to M\widehat\otimes^L_R(R/J)_{\mathrm{perfd}}\) が同型であることに帰着し、\(M=(R/J)_{\mathrm{perfd}}\) の場合が Lemma 10.3。

Lemma 10.3. \(J_{\mathrm{perfd}}\widehat\otimes^LJ_{\mathrm{perfd}}\to J_{\mathrm{perfd}}\)、\((R/J)_{\mathrm{perfd}}\widehat\otimes^L(R/J)_{\mathrm{perfd}}\to(R/J)_{\mathrm{perfd}}\) は擬同型で、\(J_{\mathrm{perfd}}\widehat\otimes^L(R/J)_{\mathrm{perfd}}=0\)。証明：より一般に、perfectoid 環の図式 \(S\leftarrow R\to T\) について \(S\widehat\otimes^L_RT\) は次数 0 に集中し perfectoid。対応する完全 prism の \(B\widehat\otimes^L_AC\) は、mod p で完全環の Tor 独立性（[BS17, Lemma 3.16]）により離散な完全 δ 環で、その商が \(S\widehat\otimes^L_RT\)。

Prop 10.4・Lemma 10.5. 複体 M が J-almost zero ⇔ \(J_{\mathrm{perfd}}\widehat\otimes^LM=0\)。M が連結 ⇔ \(M\widehat\otimes^LR/J_{\mathrm{perfd}}\) が連結かつ M が J-almost 連結（Thm 10.11 の帰納法で使う）。Rem 10.7. \(J_{\mathrm{perfd}}\) の \(R/p^n\) での像は冪等なイデアル（almost の基本設定になる）。

Lean での組み立て. (1) 一般の主張「perfectoid 環の完備導来テンソルは離散で perfectoid」lemma103_perfectoidTensor（Almost/Lemma103PerfectoidTensor:46）。これは完全 δ 環の完備テンソルの離散性（Prism/Tensor）→ 表示による移送 → Fontaine 版 → perfectoid 版の鎖で、完全環の Tor 独立性は共通基盤の CommutativeAlgebra/PerfectTorIndependence の代数的な証明を使う。(2) そこから Lemma 10.3 の三つの主張（Almost/Lemma103KernelTensor）。(3) Prop 10.2 のうち必要な拡大閉性を、「J-almost zero ⇔ 完備テンソルが消える」という判定（perfectoidIdeal_isAlmostZero_of_completedTensor_isZero、PerfectoidAlmostExtension:103）を経て示す（perfectoidIdeal_isAlmostZero_extension、:127）。(4) Rem 10.7 の冪等性 perfectoidIdealMod_idempotent（PerfectoidIdealIdempotent:99）は、\(K=J_{\mathrm{perfd}}\) について \(K/K^2\) の導来完備化が零になることから。

2. almost purity と整代数の離散性（§10.2）

Thm 10.9. R perfectoid、J 有限生成、S を V(J) の外で有限エタールな有限表示有限 R 代数とすると、\(S_{\mathrm{perfd}}\) は離散で perfectoid、\(S\to S_{\mathrm{perfd}}\) は V(J) の外で同型、\(R/p^n\to S_{\mathrm{perfd}}/p^n\) は almost 有限射影・almost 不分岐。

J-almost 版の証明. (1) Cor 8.12 により、S を V(J) の外で同型な整 S 代数で置き換えても \(S_{\mathrm{perfd}}\) は J-almost に変わらない。(2) Galois の場合：André の補題（Thm 7.14）で R を絶対整閉としてよい。すると局所化上の有限エタール被覆は Zariski 局所的に分裂するので、J の生成元 \(f_i\) ごとに \(R[1/f_i]\) 上で分裂し、(1) で自明な torsor に置き換えられる。(3) 定次数の場合は \(\Sigma_r\) Galois 閉包（[And18b, Lemma 1.9.2]）と Prop 10.8（[And18b]）で Galois の場合に帰着。(4) 一般には次数一定の開閉分解 \(\bigsqcup U_i\) と Cor 8.12 で定次数に帰着。

Thm 10.11（E3 の integral）. R perfectoid、S を整写像の p 完備化とすると \(\Delta_{S/A,\mathrm{perf}}\) は離散で、\(S_{\mathrm{perfd}}\) は離散な perfectoid 環。証明：有向余極限で有限表示有限に帰着し、Cor 8.14 で \(S_{\mathrm{perfd}}\) の連結性を示せばよい。Lemma 10.12 の層別 \(g_1,\dots,g_n\) の長さ n に関する帰納法：n=1 なら \(S_{\mathrm{red}}\) は有限エタールで perfectoid、Cor 8.11 で \(S_{\mathrm{perfd}}=S_{\mathrm{red}}\)。n>1 なら帰納法の仮定と Prop 8.13 で \((S/g_1)_{\mathrm{perfd}}\) は連結、Lemma 10.5 で \(g_1\)-almost 連結性に帰着し、\(R[1/g_1]\to S_{\mathrm{red}}[1/g_1]\) が有限エタールであることと Cor 8.12・Thm 10.9（J-almost 版）で示す。形式化では、R の \(S_{\mathrm{red}}[1/g_1]\) における整閉包 T は導来 p 完備とは限らない（収束列環の反例、W9-III-04）ので、Cor 8.12 は \(S\to\) completionRing\((T)\) に当て（原典の暗黙の完備化を明示、D70）、Thm 10.9 は T への写像を備えた有限表示有限代数の有向系に当てる（a8-design §3.3 の 5）。Lemma 10.12：有限表示有限射は、構成可能な層別の上で（普遍同相を除いて）有限エタールになる。普遍同相の判定に現れる「核が冪零」は各元が冪零（nil）の意味で、イデアルの冪零性ではない（G-A8-4、BS-D1）。ArcOutside の条件には整性を含める（G-A8-3″、W9-III-02）。

E3 に要る範囲

E3 の integral に要るのは Thm 10.11 で、そのために Thm 10.9 の J-almost 連結性の部分だけが要る（almost 有限射影性・不分岐性は不要）。BS-0 の案（A8）では、(3) の \(\Sigma_r\) Galois 閉包と [And18b] を使わず、CLMST の Prop 2.4.7 の形式化と同じく「絶対整閉な基底上で開被覆ごとに \(R^r\) と比べる」方法で連結性だけを示す。これは原典の (2) の議論を定次数に直接使うもので、原典の証明の簡略化になる見込み（A8 の設計で確かめる）。
