第 4 章　prismatic site と HT 比較の定式化（§4）

基準コミット a0ccccb09（2026-10-25）。方針と差の評価は 2026-11-02 に追記。原典 pp.36–45。E3 に必要な項目だけを載せる（判定は 原典の項目一覧、原典との差の評価は 末尾）。

固定した有界 prism \((A,I)\) と p 完全 smooth な \(A/I\) 代数 \(R\) について、prismatic site \((R/A)_\Delta\) とその構造層のコホモロジー \(\Delta_{R/A}\) を定義し（§4.1）、HT 比較を定式化し（§4.2）、Čech–Alexander 複体で \(\Delta_{R/A}\) を具体的に計算する（§4.3）。この章の内容は全て未形式化で、A0 の範囲。

方針（2026-10-25 決定、2026-11-02 追記）

HT 比較は迂回せず、原論文の経路に沿って形式化する。

2026-11-02：定義は原典のまま入れ、定理だけ E3 に要る特別な場合に絞る。すなわち Def 4.1 の site（圏・平坦位相・構造層）と Not 4.16 の \(\Delta_{R/A}=R\Gamma((R/A)_\Delta,\mathcal O_\Delta)\) をそのまま定義にし、Čech–Alexander 複体（Construction 4.17・4.18）が \(\Delta_{R/A}\) を計算することは定理（脚注 10 と Cor 3.12）にする。\(R\Gamma\) は ∞ 圏的に、D(A) 値前層の層化 \(F\mapsto F^\sharp\) と大域切断 \(\Gamma(F^\sharp)=\lim F^\sharp\) で定義する（設計書 infinity-sheaves-design.md）。層は HTT 6.2.2.6 の意味（Čech 層）で、hypersheaf との差は D17 に記す。大きい site は濃度 \(\le\kappa\) で切り落とす（D16）。向き付き・有界な基底 prism に限り（ノート D5）、完備化は導来完備化の \(H^0\) で、離散性は Lemma 3.7(2) の定理とする。

2026-11-03（Codex レビュー W9 の後）：κ には既定値以上であることに加えて \(\kappa^{\aleph_0}=\kappa\) を課す（IsAdmissibleCutoff、W9-I-11）。Construction 4.17 の \(J_0\) の閉包は「\(B\to H^0\) の一変数導来 p 完備化 \((B/J_0B)\) の核」で取り、変数変換後の対の等式はこの閉包で結ぶ（W9-I-09）。Def 2.42（prism の射の \((p,I)\) 完全平坦性）は「\(H^0\) の平坦性と全次数の底変換同型」であって高次ホモロジーの消滅ではない（W9-I-01、D20。基底 \((\mathbb Z_p,(p))\) で \(H_1=\mathbb F_p\)）。完全 prismatic site（Rem 4.6）は A5 で Lemma 4.8 の圏同値により \(\mathrm{Perfd}_{S/}\) と同一視し、その余積は \((T_1\widehat\otimes_S T_2)_{\mathrm{perfd}}\)（Cor 7.3 の普遍性。\(A\) 上の完備テンソル \(B\widehat\otimes_A B'\) では \(S\) の二つの構造射が一致しない、W9-II-06）。κ 不変性は二つの site の間の包含に沿う制限で \(R\Gamma\) を結ぶ可逆な辺として述べ、頂点の等号は主張しない（W9-I-03）。

1. prismatic site（§4.1）

Def 4.1. \((X/A)_\Delta\)：有界 prism の射 \((A,I)\to(B,IB)\) と \(\mathrm{Spf}(B/IB)\to X\) の組の圏。被覆は忠実平坦な prism の射。構造層 \(\mathcal O_\Delta(B)=B\)、\(\overline{\mathcal O}_\Delta(B)=B/IB\)。Cor 3.12 で site で、\(\mathcal O_\Delta\) は層。Rem 4.3・4.5：位相（flat・étale・Zariski）によらず同じコホモロジー。Rem 4.6：完全 prismatic site は perfectoid 環への写像の圏と同じ（§8 で使う）。Lemma 4.8：完全 prism \((A,I)\) と任意の prism \((B,J)\) について、環準同型 \(A/I\to B/J\) は prism の射に一意に持ち上がる。証明：\(A=W(\text{完全})\) は p 完全に \(L_{A/\mathbb Z_p}=0\) なので変形理論で \(A\to B\) に一意に持ち上がる。δ 射であることは、\(A\to B\) が逆極限の完全化 \(B^{\mathrm{perf}}=\lim_\varphi B\)（p ねじれなしの完全 δ 環）を経由することから。

A0 で要る範囲

E3 で使うのは affine な R、特に多項式代数だけ。定義は原典どおり site の \(R\Gamma\)（2026-11-02 の方針。それ以前の「Čech–Alexander 複体を定義に使い、site は避ける」見込みは取り下げた）。site の圏・平坦位相・\(\mathcal O_\Delta\) は定義し、Cor 3.12（\(\mathcal O_\Delta\) が層で、忠実平坦な Čech 脈体に沿って導来降下する）は一般の形で証明する。étale 層との関係（Construction 4.4、Rem 4.3・4.5）は要らない。Lemma 7.7(3)・Prop 8.5 と Construction 4.18 が使う「弱終対象の Čech 脈体の totalization が圏上の極限を計算する」という一般論（脚注 10）は、∞ 層の設計書の S3。Lemma 4.8 は、標的が完全 prism なら Thm 3.10 の射の一意持ち上げ（existsUnique_perfectPrismHomLift）で足りる。一般の標的（Prop 7.10 で使う）には変形理論（\(W\)(完全) の p 完全な形式エタール性）と逆極限の完全化が要る（A3）。

2. HT 比較の定式化（§4.2）

Construction 4.9. \(\overline\Delta_{X/A}=\Delta_{X/A}\otimes^L_AA/I\)。三角形 \(\overline\Delta\{i+1\}\to\Delta\otimes^LI^i/I^{i+2}\to\overline\Delta\{i\}\) の Bockstein \(\beta_I\) で \(H^*(\overline\Delta_{X/A})\{*\}\) は可換 dg 代数になる。\(\eta^0:\mathcal O_X\to H^0\) と \(\eta^1:\Omega^1\to H^1\{1\}\)（\(f\,dg\mapsto f\beta_I(g)\)）から、Lemma 4.10（\(\beta_I(f)^2=0\)、p=2 でだけ非自明、Prop 6.2 から出る）を使って de Rham 複体からの写像 \(\eta^*:\Omega^*_{X/(A/I)}\to H^*(\overline\Delta_{X/A})\{*\}\) に延ばす。向き付きなら捻り \(\{i\}\) は外せる。

Thm 4.11（HT 比較）. \(\eta^*\) は dg 代数の同型。特に \(H^i(\overline\Delta_{X/A})\cong\Omega^i\{-i\}\)。証明は第 5 章（§5・§6）。Cor 4.12：\(\Delta_{X/A}\) の形成は有界 prism の任意の底変換と可換（導来 Nakayama で mod I に帰着し、微分形式の底変換から）。

3. Čech–Alexander 複体（§4.3）— A0 の中心

Construction 4.17（弱始対象）. \(B_0\to R\) を A 上の p 完備多項式代数からの全射、\(B=\mathrm{Free}_{\delta,A}(B_0)^\wedge\)（自由 δ-A 代数の完備化）、\(J_0=\ker(B_0\to R)\)。\((B,\ker(B\to(B/J_0B)^\wedge))\) に Prop 3.13 を当てた envelope \(C=B\{J_0B/I\}^\wedge\) が \((R/A)_\Delta\) の弱始対象。証明：任意の対象 D について、\(B_0\to D\) を R→D/ID の持ち上げとして選び（多項式なので選べる）、δ 構造で \(B\to D\) に一意に延ばし、envelope の普遍性で \(C\to D\)。構成は \(B_0\) のテンソル積を \((R/A)_\Delta\) の余積に送る。

Construction 4.18（Čech–Alexander 複体）. \(A\to B_0\) の（完備化した）Čech 脈体 \(B_0^\bullet\) に 4.17 を当てると、\(C^0\) の Čech 脈体 \(C^\bullet\) ができ、\(C^\bullet\) が \(\Delta_{R/A}\)、\(C^\bullet/IC^\bullet\) が \(\overline\Delta_{R/A}\) を計算する（弱始対象の Čech 脈体と層の高次コホモロジーの消滅、脚注 10）。Rem 4.19：\(R=A/I\langle X\rangle\) なら \(B_0=A\langle X\rangle\) と取れ、\(C^\bullet\) は prism の底変換と可換。

Lemma 4.20（底変換）. \(A\to A'\) が有限 \((p,I)\) 完全 Tor 振幅なら \(\Delta_{R/A}\widehat\otimes^L_AA'\cong\Delta_{R'/A'}\)（Čech–Alexander 複体の項ごとの底変換と Lemma 4.22）。Lemma 4.22：有限 J 完全 Tor 振幅の写像に沿う J 完備底変換は、\(D^{\ge0}\) の totalization と可換（n 骨格で示し、Koszul 複体で振幅を評価して極限を取る）。Lemma 4.21（étale 局所化）は多項式代数で済ませるなら不要。

A0 の設計で決めること（読んで分かったこと）

  • 向き付きで足りるか：Construction 4.17 の対象 C・D は、固定した向き付き基底 \((A,(d))\) 上では剛性（Lemma 3.5）により \(IC=dC\) で単項。向き付き prism のまま進められる。
  • 離散版で足りるか：多項式代数の \(J_0\) は正則列で生成されるので、Prop 3.13 の envelope は離散で平坦（Cor 2.44 の離散版、T2-3）。Čech 脈体の各項も同じ形なので、単体的環は要らない見込み。
  • 要る部品：自由 δ-A 代数の完備化（既存の相対自由 δ 環 + Lemma 2.17）、δ 環の完備テンソル積（T2-0、Čech 脈体と余積）、Prop 3.13（定義は普遍性、存在は Ex 3.14 の場合の定理。T3-4）、Lemma 4.22（導来完備化と Koszul 複体の一般論、共通基盤の DerivedCompletion にある部品を確認）、弱終対象の Čech 脈体が圏上の極限を計算するという一般論（∞ 層の設計書 S3。∞ 圏側の極限として述べる）。
  • \(\Delta_{R/A}\) の定義（2026-11-02）：Not 4.16 どおり \(R\Gamma((R/A)_\Delta,\mathcal O_\Delta)\)。∞ 層の設計書の derivedGlobalSections（層化してから site 上の極限）で、値は D(A)。Čech–Alexander 複体がこれを計算することは、Cor 3.12（\(\mathcal O_\Delta\) は層なので層化で変わらない）と脚注 10 から出る定理。乗法構造（Construction 7.6 の可換代数対象）は A2・A4 で CAlg 値の同じ構成を作って結ぶ（D18）。
