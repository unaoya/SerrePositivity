1. E3 とは何か

\(R\) を perfectoid 環とする。原典 Def 8.2 は、\(R\) 代数 \(S\) に \(p\) 完備な \(E_\infty\)-\(S\) 代数 \(S_{\mathrm{perfd}}\) を対応させる（導来 prismatic コホモロジーの Frobenius 余極限を完備化し、\(\bmod d\) したもの）。\(S\) が perfectoid 環の商（semiperfectoid）なら離散で、\(S\) から perfectoid 環への普遍写像になる。一般の \(S\) では離散とは限らない。

E3 はこの関手の性質のうち主定理が使うものを束ねた構造で、その存在が現在の唯一の文献入力である。

原典との差（界面の規約）

六点ある（perfectoidization-interface.md §7）。excision は底の \(D(R)\) で述べる。universal は離散時の環の普遍性に限る。極限は Type u の標的に制限し、指定錐と単位・\(H^0\) の乗法の整合を含める。始域は導来 \(p\) 完備化の \(H^0\) を介して非完備な代数まで延ばす。差写像の全射性は欄に入れず、証明済みの帰結とする。

2. 主定理での使われ方

E3 は二つの入口を通って主定理に入る。

  1. 存在：E3 の integral と universal から Inputs.exists_perfectoidization_of_integral（任意の整代数の環としての perfectoid 化）→ 有限代数版 exists_perfectoidization_of_finite → CLMST の \(R_{\mathrm{perfd}}\)（Section2.MixedPerfectoid）。使われる \(S=R\otimes_A D\) は有限だが、\(R\) の全射商でも有限エタールでもない。
  2. excision：E3 の excision から Inputs.perfectoidization_excision_isPullback（環の引き戻し）→ klCanonicalExcisionSquare_of_excision → CLMST Prop 2.4.7 の有限比較と rank 四角形、Cor 4.0.4。

詳しい経路は bhatt-scholze-stage2.md §1。同 §2 の結論として、既証の部品だけでこの二つを迂回する道（案 B）は閉じない。どちらも Cor 8.12／Thm 10.9 の「almost 比較」そのものを要する。
