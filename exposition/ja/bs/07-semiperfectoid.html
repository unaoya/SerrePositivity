第 7 章　semiperfectoid 環と perfection（§7）

基準コミット a0ccccb09（2026-10-25、W2 後。W3 は f4dcf1d1a・7b82e02aa で完了）。原典 pp.55–62。E3 に必要な項目だけを載せる（判定は 原典の項目一覧、原典との差の評価は 末尾）。

§7 は三つの小節からなる。§7.1 は semiperfectoid 環 \(S\)（perfectoid 環の商）について、全ての prism の中での始対象（Prop 7.2）と普遍 perfectoid 環 \(S_{\mathrm{perfd}}\)（Cor 7.3）を作り、主定理「\(S\to S_{\mathrm{perfd}}\) は全射」（Thm 7.4）を述べる。§7.2 は導来 prismatic コホモロジー（Construction 7.6）と、それが離散な場合の性質（Lemma 7.7、Ex 7.9、Prop 7.10）。§7.3 は prismatic site の被覆の持ち上げ（Prop 7.11）から André の補題（Thm 7.14）を出し、Thm 7.4 を証明する。

形式化は §7.1 と §7.3 の環の結果（Cor 7.3、Thm 7.4、Thm 7.14）を、§7.2 を使わずに証明している。§7.2 は E3 の Def 8.2 の土台で、未形式化（A2・A3）。

1. semiperfectoid 環の perfectoid 化（Prop 7.2・Cor 7.3）

原典の証明. 全射 \(R\to S\)（\(R\) perfectoid）を取り、\(J=\ker(A_{\inf}(R)\to S)\)。prism \((C,K)\) と \(S\to C/K\) が与えられると、\((A_{\inf}(R),(d))\to(C,K)\) が一意に決まり（Lemma 4.8）、\(K=dC\)（Lemma 3.5）、\(f\in J\) ごとに \(f/d\in C\) が一意に決まる。そこで \(B=A_{\inf}(R)\{x_f\}/(dx_f-f)_\delta\) から、\(d\) ねじれの δ 閉包での商と導来 \((p,d)\) 完備化を超限的に繰り返して、全 prism の中の始対象 \(\Delta^{\mathrm{init}}_S\) を作る（Prop 7.2）。Cor 7.3：perfectoid な \(S\) 代数の圏は「\(J\) を \(d\) で割り切る完全 prism」の圏と同値なので、Lemma 3.9 で \(S_{\mathrm{perfd}}=(\Delta^{\mathrm{init}}_S)_{\mathrm{perf}}/I\) の p 進完備化。

Lean での組み立て（exists_perfectoidization_of_perfectoid_surjective_quotient、Semiperfectoid/SemiperfectoidPerfectoidization:21）。整 perfectoid 環 \(R\) を完全 prism の商で表し（exists_perfectoidTrialPrism、Thm 3.10）、完全試験 prism の商への全射について exists_perfectoidization_of_perfectPrism_quotient（Prism/Perfectoid/PerfectPrismQuotientPerfectoidization:163）を当てる。後者は δ 除算 \(A\{J/d\}\)（Delta/Division）→ \(d\) ねじれの除去 → δ 完全化 → 導来 \((p,d)\) 完備化で、完全試験 prism への写像の始対象を直接作り、Thm 3.10 で perfectoid 環の普遍性に読み替える。

原典との差

Prop 7.2（全 prism の中での始対象、超限帰納）を経由しない。標的が完全 prism なら、完全化の後では \(d\) が非零因子になる（Lemma 2.34）ので、ねじれ除去と完備化を一回ずつ行えば足り、超限帰納が要らない。主張（Cor 7.3 の存在と普遍性）は原典と同じ一般性。\(S\) の導来 p 完備性を仮定しない入口も別にある。

3. André の補題と Thm 7.4（§7.3）

原典の証明（Thm 7.14）. \(R=A/I\)（完全 prism）とし、全てのモニック多項式の根を形式的に添加した \(\tilde R\)（quasisyntomic 被覆）を取る。Prop 7.11(2)（導来 prismatic コホモロジーと HT 比較による prismatic site の被覆の持ち上げ）で、完全 prism \((B,IB)\) と \(\tilde R\to B/IB=R_1\) を得る。\(R\to R_1\) は p 完全忠実平坦で、R のモニック多項式は \(R_1\) で根を持つ。これを超限的に反復すると絶対整閉な perfectoid 環に達する。Thm 7.4：有向余極限で単項 \(J=(f)\) に帰着し、André の補題で \(f\) が両立する p 冪根を持つと仮定してよい。perfectoid 環は被約なので \(S_{\mathrm{perfd}}\) は \(R/(f^{1/p^\infty})\) の p 完備化で、全射。

Lean での組み立て（Thm 7.14）（Andre.exists_completelyFaithfullyFlat_absolutelyIntegrallyClosed、Andre/Transfinite/Theorem714:32）。四段：(a) 完全 prism の商の上で、正次数モニック多項式 \(f\) の根の割り算包（\(f/d\) の δ 除算）の完備化が p 完全忠実平坦な perfectoid 拡大になる（Andre/ 直下の 46 本）。(b) それを一般の perfectoid 基底へ移す（Transfinite.exists_monicRootPerfectoidExtension、SingleRoot:50）。(c) 固定した族を後続基数で一元ずつ飽和させる（FamilySaturation・FamilyExtension）。(d) ω₁ まで反復する。可算共終の極限段では p 進完備化を取り、ω₁ では自動的に p 完備、終段で全モニック多項式が根を持つ（OmegaOne・Existence・CountableDescent・RootClosure）。

Lean での組み立て（Thm 7.4）. W3 で原典どおりに替える：André の補題で絶対整閉な perfectoid 環 \(T\) へ p 完全忠実平坦に拡大し（核の全元が \(T\) で両立する p 冪根を持つ）、\(T\) 上の全射性を降下する（surjective_of_isPerfectoidization_of_andre、W3 後は Semiperfectoid/AndreSurjectivity）。原典の「有限生成・単項への帰着」は、任意の元の族を直接扱うので不要。

いまの B4 の証明. perfectoid 環 \(R\) と全射 \(R\to S=R/J\) について、完全 prism 上で「\(J\) の元に両立する p 冪根を添加する割り算包」を作り、その完備化が p 完全忠実平坦な perfectoid 拡大 \(R\to T\) になることを示す（PerfectPrismRootedPerfectoidExtension）。\(T\) 上では \(J\) の生成元が根を持つので全射性が出て、それを \(R\) へ降下する（RootedFamilyPerfectoidSurjectivityDescent）。André の補題を使わない。

原典の証明. Thm 7.4 の原典の証明は、André の補題（Thm 7.14）で絶対整閉な perfectoid 環 \(T\) へ p 完全忠実平坦に拡大し（絶対整閉なら全ての元が両立する p 冪根を持つ）、\(T\) 上の全射性を降下する。

なぜ二つあるのか. B4 を証明した時点（10-16 18:05、ca7121e79）では André の補題が未証明の引用だったので、引用を避けるために André を使わない経路を新しく作った。翌日 10-17 13:18（f9b959e61）に André の補題が別経路で証明されたので、この理由はもう成り立っていない。原典どおりの André 経由版 surjective_of_isPerfectoidization_of_andre（Semiperfectoid/RootedExtension/AndreSurjectivityConditional:18）は B4 本体と同じ主張で、今は無条件に成り立つ（docstring の「sorryAx に依存」は古い）。

差し替えると何が起きるか（import の到達性で計算、10-25）：

  • Thm 7.14 の証明は B4 も B3 も使わないので、循環は起きない。主定理はすでに CLMST 経由で Thm 7.14 に依存しているので、主定理の依存は増えない。公理は どちらも標準三公理。
  • 既定のビルドから外れるのは 33 本・3,395 行：PerfectPrismRoot* と PerfectPrismRootedPerfectoidExtension など直下 12 本、DeltaRoot/ の 19 本（有界台の余極限、源の離散性、perfectoid 候補）、DeltaDivisionBoundedSupportTor、TensorBaseChangeKernel。代わりに降下の 3 本（RootedKernel・RootedTensorBaseChange・RootedPerfectoidSurjectivityDescent）と André 経由版が入る。

判断の材料.

  • 差し替える利点：証明が原典と同じ形になり、Thm 7.4 の証明が一本になる。B4 固有の 33 本（と未使用の残り）を保守しなくてよい。
