§2.1 定義と基本性質

この節では δ 環の言葉を用意する。以下、\(p\) は素数、環はすべて可換環とする（原典は \(\mathbb Z_{(p)}\) 代数に限るが、形式化はこの仮定を置かない）。番号「命題 2.1.n」はこのノートの番号で、括弧内が原典の番号。

定義と言い換え

環 \(A\) の長さ 2 の Witt 環 \(W_2(A)\) は、集合 \(A\times A\) に \[(x_0,x_1)+(y_0,y_1)=\Big(x_0+y_0,\ x_1+y_1+\tfrac{x_0^p+y_0^p-(x_0+y_0)^p}{p}\Big),\qquad (x_0,x_1)(y_0,y_1)=(x_0y_0,\ x_0^py_1+x_1y_0^p+p\,x_1y_1)\] で環構造を入れたもの（分数は \(\mathbb Z[x_0,y_0]\) の多項式なので任意の環で意味を持つ）。第 0 成分 \(\epsilon\colon W_2(A)\to A\) と第 1 ghost 成分 \(g_1(x_0,x_1)=x_0^p+px_1\) はどちらも環準同型。

定義 2.1.1（δ 構造。原典 Rem 2.4 の形）

環 \(A\) 上の δ 構造とは、環準同型 \(w\colon A\to W_2(A)\) で \(\epsilon\circ w=\mathrm{id}_A\) を満たすもの。\(w(x)=(x,\delta(x))\) と書いて写像 \(\delta\colon A\to A\) を定め、\(\varphi=g_1\circ w\)、すなわち \(\varphi(x)=x^p+p\,\delta(x)\) を Frobenius 持ち上げと呼ぶ。δ 構造を持つ環を δ 環という。

Lean. DeltaStructure（DeltaRing:58）（sectionHom と coeff_zero の二つの欄）、\(\delta\) は delta（:66）、\(\varphi\) は frobeniusLift（:116）。\(W_2\) は Mathlib の TruncatedWittVector p 2 A。型クラスではなくデータなので、同じ環に複数の δ 構造を持てる。

命題 2.1.2（原典 Def 2.1 との同値）

写像 \(\delta\colon A\to A\) について、次は同値：(i) \(\delta\) はある δ 構造 \(w\) から定まる；(ii) \(\delta(0)=\delta(1)=0\) かつ任意の \(x,y\) で \[\delta(xy)=x^p\delta(y)+y^p\delta(x)+p\,\delta(x)\delta(y),\qquad \delta(x+y)=\delta(x)+\delta(y)+\tfrac{x^p+y^p-(x+y)^p}{p}.\] さらに δ 構造は \(\delta\) で決まる。

証明. \(w(x)=(x,\delta x)\) が環準同型であることを第 1 座標で書けば、上の \(W_2\) の和・積の式から (ii) の恒等式そのものになる（第 0 座標は自明）。\(W_2\) の和・積の第 1 座標の式自体は、変数 \(X_{(i,n)}\) の整数係数多項式環（p ねじれなし）で \(g_1\) の加法性・乗法性を書いて \(p\) を消去し、任意の環へ評価して得る。加法の補正項は \(p\) で割る式ではなく、\(p\) 倍すると \(X^p+Y^p-(X+Y)^p\) になる整数係数多項式として扱う。

Lean. (i)⇒(ii)：delta_zero（DeltaRing:75）・delta_one（:79）・delta_mul（:87）・delta_add（:98）。(ii)⇒(i)：ofFunction（DeltaRing:342）、往復 ofFunction_deltaStructure（:72）、一意性 ext（DeltaRing:125）。\(W_2\) の式は共通基盤 witt_mul_coeff_one（WittCoefficientOne:24）・witt_add_coeff_one（WittAdditionCarry:18）、補正項の多項式 wittAdditionCarry（WittAdditionCarry:53）。加法公式の補正項は Lean では「Teichmüller 元の和の第 1 Witt 座標」の形で書かれる。

命題 2.1.3（原典 Rem 2.2）

(1) \(\varphi\colon A\to A\) は環準同型で、\(A/p\) の Frobenius を持ち上げる：\(f(p)=0\) となる任意の環準同型 \(f\colon A\to B\) で \(f(\varphi(x))=f(x)^p\)。
(2) \(A\) が p ねじれなしなら、\(\psi(x)\equiv x^p \bmod pA\) を満たす環自己準同型 \(\psi\) に対し、\(\varphi=\psi\) となる δ 構造がただ一つ存在する。特に Frobenius 持ち上げが一致する δ 構造は一致する。

証明. (1) \(\varphi=g_1\circ w\) は環準同型の合成。(2) \(\delta(x)\) を \(p\,\delta(x)=\psi(x)-x^p\) の解として選び、\(\psi\) の加法性・乗法性を書いて \(p\) を消去すると命題 2.1.2 の恒等式が出る。一意性も \(p\) の消去から。

Lean. (1) frobeniusLift_apply（DeltaRing:120）、map_frobeniusLift_of_map_p_eq_zero（DeltaRing:186）。(2) existsUnique_of_frobeniusLift（DeltaRing:456）、mod p の形 existsUnique_of_mod_p（:63）、一意性 eq_of_frobeniusLift_eq（DeltaRing:193）。

定義 2.1.4（δ 射）

δ 環の間の環準同型 \(f\colon A\to B\) が δ 射であるとは、任意の \(x\in A\) で \(f(\delta(x))=\delta(f(x))\) となること。δ 環と δ 射は圏をなす。

Lean. IsDeltaHom（DeltaRing:143）。恒等射 isDeltaHom_id（:161）、合成 IsDeltaHom.comp（:165）、環同型の逆 IsDeltaHom.symm（:174）。

命題 2.1.5（δ 射の言い換え）

(1) 環準同型 \(f\) が δ 射 ⇔ \(W_2(f)\circ w_A=w_B\circ f\)。
(2) δ 射は Frobenius 持ち上げと可換：\(f\circ\varphi_A=\varphi_B\circ f\)。
(3) \(B\) が p ねじれなしなら、逆に \(f\circ\varphi_A=\varphi_B\circ f\) を満たす環準同型は δ 射。
(4) 任意の δ 環で \(\varphi\) と \(\delta\) は可換で、\(\varphi\colon A\to A\) は δ 射。

証明. (1) 両辺の第 0 座標は常に一致し、第 1 座標の一致が δ 射の条件。(2) \(\varphi(x)=x^p+p\delta(x)\) に \(f\) を当てる。(3) \(p\) の消去。(4) 自由 δ 環（p ねじれなし）で (3) を使って確かめ、普遍性で任意の δ 環へ送る。

Lean. (1) isDeltaHom_iff_sectionHom_comp（DeltaRing:418）、(2) IsDeltaHom.map_frobeniusLift（DeltaRing:147）、(3) isDeltaHom_of_map_frobeniusLift（DeltaRing:204）、(4) isDeltaHom_frobeniusLift_general（FreeDeltaRing:274）。

極限と余極限

命題 2.1.6（原典 Rem 2.7）

δ 環の圏はすべての極限と余極限を持ち、それらは下の環で計算される（忘却関手 \(U\colon\delta\text{-Ring}\to\text{Ring}\) は極限と余極限を保つ）。したがって \(U\) は左随伴（自由 δ 環、命題 2.1.11）と右随伴（Witt 環 \(W\)）を持ち、自然な δ 射 \(w_R\colon R\to W(R)\) がある（その最初の二成分は \(x\mapsto(x,\delta(x))\)）。

証明の方針. 極限は成分ごとの \(W_2\) の切断を貼ればよい。余極限は自然な写像 \(\mathrm{colim}_iW_2(A_i)\to W_2(\mathrm{colim}_iA_i)\) を使って切断を作る。随伴は随伴関手定理から。論理の向き：随伴があることから出るのは「存在すれば下の環で計算できる」（右随伴があれば余極限を、左随伴があれば極限を保つ）までで、存在そのものは上の直接の構成（あるいはモナドの代数の圏としての一般論）による。

Lean. 有向余極限だけ：deltaDirectLimitStructure（DeltaColimit:76）（各段の切断を Ring.DirectLimit.lift で貼る）、普遍射も δ 射（:79）。テンソル積は完全かつ p 正則な場合だけ perfectDeltaTensorStructure（PerfectDeltaTensor:135）。一般のテンソル積・積・引き戻しは未：A0（prism の余積）で要る。作り方は直接でよく、テンソル積 \(A\otimes_CB\) は \(A\to W_2(A)\to W_2(A\otimes_CB)\) と \(B\to W_2(A\otimes_CB)\) が \(C\) 上で一致するので環のテンソル積の普遍性（Algebra.TensorProduct.lift）で切断が決まる（100 行程度の見込み）。随伴は形式化していない。\(w_R\) は ghost 写像が単射の場合だけ deltaWittGhostRingHom（DeltaWitt:287）（長さ 2 に切ると \(w\) に戻る、:58）。

元の添加と消去

命題 2.1.7（元の添加。原典 Not 2.8 の \(\{\ \}\)）

δ 環 \(R\) と集合 \(\sigma\) に対し、δ 環 \(R\{x_s\}_{s\in\sigma}\)、δ 射 \(R\to R\{x_s\}\)、元 \(x_s\) の組で次を満たすものがある：任意の δ 環 \(A\)、δ 射 \(f\colon R\to A\)、元 \(a_s\in A\) に対し、\(f\) を延長し \(x_s\mapsto a_s\) となる δ 射がただ一つある。具体的には \(R\{x_s\}=R[x_{(s,n)}]_{s\in\sigma,\,n\ge0}\) で、\(\delta(x_{(s,n)})=x_{(s,n+1)}\)、係数上は \(R\) の δ。

証明. 一般に、多項式環 \(R[X_v]\) と任意の多項式 \(v_v\) に対し、係数上で \(R\) の δ に一致し \(\delta(X_v)=v_v\) となる δ 構造がただ一つある：係数の切断 \(R\to W_2(R)\to W_2(R[X])\) と \(X_v\mapsto(X_v,v_v)\) から、多項式環の普遍性で \(W_2\) への環準同型が一つ決まる（p ねじれなしは不要）。また多項式環からの環準同型は、係数と変数で δ と可換なら δ 射。これを \(v_{(s,n)}=x_{(s,n+1)}\) に使い、普遍性は \(x_{(s,n)}\mapsto\delta^n(a_s)\) の評価写像で与える。

Lean. 多項式 δ 構造 polynomialDeltaStructure（RelativeFreeDelta:77）、δ 射の判定 isDeltaHom_mvPolynomial（:106）。相対自由 δ 環 relativeFreeDeltaStructure（RelativeFreeDelta:32）、普遍性 existsUnique_relativeFreeDeltaHom（RelativeFreeDelta:319）。原典は自由 δ 環を作ってから pushout を取るが、Lean は基底 \(R\) 上で直接作る（一般の pushout が無くても済む）。

命題 2.1.8（原典 Lemma 2.9）

δ 環 \(A\) のイデアル \(I\) について、次は同値：(i) \(I\) は δ 安定（\(\delta(I)\subset I\)）；(ii) \(A/I\) 上の δ 構造で \(A\to A/I\) が δ 射になるものが存在する。このとき (ii) の δ 構造は一意で、\(I\) を零に送る δ 射 \(A\to B\) は \(A/I\) からの δ 射に一意に分解する。また δ 射の核は δ 安定。

証明. (i)⇒(ii)：\(A\to W_2(A)\to W_2(A/I)\) は \(I\) を零に送る（第 0 座標は \(x\in I\)、第 1 座標は \(\delta(x)\in I\)）ので、商の普遍性で切断が降りる。(ii)⇒(i)：\(x\in I\) なら \(\delta(x)\bmod I=\delta(0)=0\)。原典は加法公式から \(\delta(a)\equiv\delta(a+f)\bmod I\) を示すが、\(W_2\) への環準同型が降りることで済む。

Lean. 商 quotient（DeltaQuotient:38）、同値と一意性 isStable_iff_existsUnique_quotient（:71）、分解 existsUnique_quotient_lift（:84）、核 IsDeltaHom.isStable_ker（DeltaRing:218）。

命題 2.1.9（元の消去。原典 Ex 2.10）

δ 環 \(A\) のイデアル \(I\) に対し、\(I\) を含む最小の δ 安定イデアル \(I_\delta\)（δ 閉包）があり、\(I_\delta\) は \(\bigcup_{n\ge0}\delta^n(I)\) で（\(I=(S)\) なら \(\bigcup_n\delta^n(S)\) で）生成される。\(A\to A/I_\delta\) は「\(I\) を零に送る δ 射」の普遍対象である。

証明. \(I_\delta\) は \(I\) を含む δ 安定イデアル全部の交わり。生成元の表示には「生成元の δ が生成イデアルに入れば、イデアルは δ 安定」を使う：和は加法公式の補正項が \(I\) に入ること（Teichmüller 元を \(A/I\) へ送ると 0）、積は積公式の三項がそれぞれ \(I\) に入ることから、生成元についての帰納法。普遍性は、δ 射の核が \(I\) を含む δ 安定イデアルなので \(I_\delta\) も含むことと命題 2.1.8 から。

命題 2.1.10（生成元と関係式。原典 Not 2.8 の \(\{\ \}\) と \((\ )_\delta\) を合わせた形）

δ 環 \(R\)、集合 \(\sigma\)、イデアル \(I\subset R\{x_s\}\) に対し、\(R\{x_s\}/I_\delta\) は次の普遍性を持つ：δ 射 \(f\colon R\to A\) と元 \(a_s\in A\) で、評価写像 \(x_s\mapsto a_s\) が \(I\) を零に送るものに対し、\(f\) を延長し \(x_s\mapsto a_s\) となる δ 射 \(R\{x_s\}/I_\delta\to A\) がただ一つある。例：\(\mathbb Z_{(p)}\{x,y\}/(f)_\delta\)、\(d\) で割る包 \(A\{a_s/d\}=A\{x_s\}/(dx_s-a_s)_\delta\)（Delta/Division）。

自由 δ 環

命題 2.1.11（原典 Lemma 2.11）

(1) 集合 \(\sigma\) 上の自由 δ 環 \(\mathbb Z_{(p)}\{x_s\}\) は多項式環 \(\mathbb Z_{(p)}[x_{(s,n)}]\) で、\(x_{(s,n)}=\delta^n(x_s)\)。
(2) その Frobenius \(\varphi\) は忠実平坦。
