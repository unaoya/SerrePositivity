第 2 章　δ 環（§2）

基準コミット 7c56bbf72（2026-10-25）。原典 pp.13–27。E3 に必要な項目だけを載せる（不要な項目と判定の根拠は 項目一覧）。Lean のパスは BS-W2 の再配置後のもの（W2 の完了まではリンク先が古い場所にある）。名前空間は SerrePositivity.BhattScholze、δ 構造の API は DeltaStructure.（DS. と略す）。

§2 は prism を定義するための言葉を用意する節である。E3 への道で後に効くのは、δ 構造の基本（§2.1・§2.2）、distinguished 元（§2.3）、完全 δ 環（§2.4、第 3 章の Thm 3.10 の土台）、pd 包との関係と envelope の平坦性（§2.5・§2.6、第 4・5 章の Čech 計算と結晶比較の土台）である。

原典との差（全体）

原典は「すべての環は \(\mathbb Z_{(p)}\) 代数」と仮定するが、Lean は任意の可換環で述べる（零環も含む）。δ 構造は型クラスではなくデータ DeltaStructure p A で、仮定は [Fact p.Prime] だけ。

§2.1 定義と基本性質

定義. δ 環とは可換環 \(R\) と写像 \(\delta\colon R\to R\) で \(\delta(0)=\delta(1)=0\)、 \[\delta(xy)=x^p\delta(y)+y^p\delta(x)+p\,\delta(x)\delta(y),\qquad \delta(x+y)=\delta(x)+\delta(y)+\frac{x^p+y^p-(x+y)^p}{p}\] を満たすもの。同じことだが（Rem 2.4）、長さ 2 の Witt 環の第 0 成分 \(W_2(R)\to R\) の環準同型切断 \(x\mapsto (x,\delta(x))\) のこと。\(\varphi(x)=x^p+p\delta(x)\) は \(R/p\) の Frobenius の持ち上げになる（Rem 2.2）。

Lean は Rem 2.4 の形を定義に採り、Def 2.1 の恒等式を定理として導く。

§2.2 δ 構造の延長

§2.5 pd 包との関係

\(p\) ねじれなしの環で \(\gamma_n(x)=x^n/n!\)。Lemma 2.36：δ 環として \(\varphi(x)/p\) を添加した \(\mathbb Z_{(p)}\{x,\varphi(x)/p\}\) は \((x)\) に沿う pd 包。Lemma 2.38・Cor 2.39：\(f_1,\dots,f_r\) が \(A/p\) で正則列なら \(A\{\varphi(f_i)/p\}\) は離散・p ねじれなしで pd 包 \(D_{(f)}(A)\) に一致する。鍵は \(\bmod p\) で pd 包が \(\mathrm{Kos}(B/p;f^p)\) 上の自由加群になること。

形式化の課題

どれも「導来 pushout が離散」という主張を含むので、離散な環と Koszul 正則性で言い直した形で足りるかを A0 の紙上設計で決める。その判断の前には Codex に渡さない。

  1. T2-0　一般のテンソル積への δ 構造（Rem 2.7）：δ 射 \(A\to B\)、\(A\to C\) について \(B\otimes_A C\) に両立する δ 構造（W₂ 切断のテンソル積）。A0 の prism の余積の土台。
  2. T2-1　Lemma 2.38 の離散版：\(B/p\) 上 Koszul 正則な有限列について pd 包が p ねじれなしで、\(\bmod p\) で \(\mathrm{Kos}(B/p;f^p)\) 上自由。
  3. T2-2　Cor 2.39 の一般形：\(A\{\varphi(f_i)/p\}\cong D_{(f)}(A)\)（T2-1 と Lemma 2.36 の多変数化から）。
  4. T2-3　Def 2.42・Lemma 2.43・Cor 2.44 の離散版（IsCompletelyFlat を使う）。Prop 3.13 の一般形の入力。
  5. T2-4　Ex 2.21：普遍 distinguished δ 環（Lemma 2.15 の局所化と自由 δ 環から）。

リファクタの候補

BR4　自由 δ 環の二重構成

FreeDeltaRing（\(\mathbb Z\) 上）と RelativeFreeDelta（任意の δ 環上）が、普遍性と表示まで二系統ある。一致は relativeFreeDeltaStructure_int_eq（Delta/Free/RelativeFreeIntegerComparison:19）で証明済みで、\(\mathbb Z\) 版を相対版の特殊化にできる。Lemma 2.11 の Frobenius 平坦性が \(\mathbb Z\) 版の上にあるので、規模を測ってから判断する。

BR5　Frobenius が δ 射であることの二つの版

DS.isDeltaHom_frobeniusLift（Delta/Perfect/PerfectDeltaFrobenius:19、p 正則を仮定）は、仮定なしの DS.isDeltaHom_frobeniusLift_general（Delta/Basic/DeltaFrobeniusNaturality:31）に含まれる。前者の証明を後者に置き換える（名前と型は残す）。

BR6　pd 包の同型の三角形と分冪構造の三重構成

raw 包 ≅ 階乗部分環、raw 包 ≅ 主 pd 表示、表示 ≅ 階乗部分環の三本は一本が残りの合成。分冪構造を局所化への引き戻しで作る構成も三回現れる。T2-1・T2-2 で多変数化するときに一本化する。

BR7　根の関係とモニック関係の平行するファイル群

DeltaRootFamilyRawCompletelyFlat（\(X^p-b\)）と Andre/Variants/MonicRawCompletelyFlat（モニック）は同じ主元判定による同じ経路。統合の利益と危険を第 7 章で測る。

この章で押さえること

  1. Lean の δ 構造は W₂ への切断（Rem 2.4）で、Def 2.1 の恒等式は定理。\(\mathbb Z_{(p)}\) 代数を仮定しない。
  2. §2.1〜§2.4 の必要な項目は、一般のテンソル積と Ex 2.21 を除いて形式化済み。
  3. \(\varphi(x)/p\) の添加 ＝ pd 包（Lemma 2.36・Cor 2.39）は特殊形だけ。一般形と envelope の平坦性（§2.6）が A0 の入力として残る。
