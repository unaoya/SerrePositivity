§2.1 定義と基本性質

定義. δ 環とは可換環 \(R\) と写像 \(\delta\colon R\to R\) で \(\delta(0)=\delta(1)=0\)、 \[\delta(xy)=x^p\delta(y)+y^p\delta(x)+p\,\delta(x)\delta(y),\qquad \delta(x+y)=\delta(x)+\delta(y)+\frac{x^p+y^p-(x+y)^p}{p}\] を満たすもの。同じことだが（Rem 2.4）、長さ 2 の Witt 環の第 0 成分 \(W_2(R)\to R\) の環準同型切断 \(x\mapsto (x,\delta(x))\) のこと。\(\varphi(x)=x^p+p\delta(x)\) は \(R/p\) の Frobenius の持ち上げになる（Rem 2.2）。

Lean は Rem 2.4 の形を定義に採り、Def 2.1 の恒等式を定理として導く。

§2.5 pd 包との関係

2026-10-25 精読（原典 pp.22–25、Lean は Delta/DividedPower/ の 74 本を全部）。

\(p\) ねじれなしの \(\mathbb Z_{(p)}\) 代数で \(\gamma_n(x)=x^n/n!\in A[1/p]\) とおく。この節の主張は「δ 環で \(\varphi(x)/p\) を添加すること」と「\((x)\) に沿う pd 包を取ること」が同じだ、ということに尽きる。

原典の流れ

  1. Lemma 2.35. \(p\) ねじれなしの δ 環 \(A\) で \(\gamma_p(z)\in A\) なら全 \(\gamma_n(z)\in A\)。証明は二段：(i) \(\delta(z^p/p)\) を \(\varphi\) の定義で展開して \(z^{p^2}/p^{p+1}\in A\)、つまり \(\gamma_{p^2}(z)\in A\)。(ii) \(\gamma_{kp}=u\cdot\gamma_k\circ\gamma_p\)（\(u\) は \(\mathbb Z_{(p)}\) の単元）と \(n\) に関する帰納法。
  2. Lemma 2.36. \(C=\mathbb Z_{(p)}\{x,\varphi(x)/p\}\)（δ 環の pushout）は pd 包 \(D=D_{(x)}(\mathbb Z_{(p)}\{x\})\) に等しい。証明：(a) \(\varphi\) の忠実平坦性（Lemma 2.11）から \(C\) は \(p\) ねじれなしで、\(C[1/p]=\mathbb Z_{(p)}\{x\}[1/p]\)。よって \(C\) は「\(\varphi(x)/p\)（同じことだが \(x^p/p\)）を含む最小の δ 部分環」。(b) \(D\) は「全 \(\gamma_n(x)\) を含む最小の部分環」。(c) \(D\subset C\) は Lemma 2.35。\(C\subset D\) は \(D\) が δ 安定であることで、\(\varphi(\gamma_n(x))\) の展開係数 \(\binom ni(pi)!\,p^{n-i}/n!\) の \(p\) 整性と \(\gamma_n(x)^p\equiv0\bmod pD\) から出る。
  3. Rem 2.37. 同じ証明で、単体的可換環の pushout としても離散。
  4. Lemma 2.38. \(B\) が \(p\) ねじれなしで \(f_1,\dots,f_r\) が \(B/p\) で Koszul 正則なら、\(D'=B\otimes^L_{\mathbb Z_{(p)}[x]}D_{(x)}(\mathbb Z_{(p)}[x])\) は離散・\(p\) ねじれなしで \(D_{(f)}(B)\) に等しく、作り方は（同じ条件を満たす）底変換と可換。鍵は \(\mathbb F_p[x]\to D_{(x)}(\mathbb F_p[x])\) が \(\mathbb F_p[x]/(x^p)\) 上の自由加群であることで、\(D'\otimes^L\mathbb F_p\) が \(\mathrm{Kos}(B/p;f^p)\) 上自由になり、\(f^p\) も正則なので離散。同一視は普遍性による二つの射 \(a,b\) が互いに逆になることで示す。
  5. Cor 2.39. \(A\) が \(p\) ねじれなしの δ 環で \(f\) が \(A/p\) で正則列なら、\(A\{\varphi(f_i)/p\}\) は離散・\(p\) ねじれなしで \(D_{(f)}(A)\) に等しい。pushout を二段に分け、上段を Lemma 2.36（多変数）、下段を Lemma 2.38 で処理する。
  6. Rem 2.40・Warn 2.41. \(A[1/p]\) の中の \(A\{\varphi(f)/p\}\) は δ 構造によらない（\(\varphi\) で捻ることが本質で、\(A\{f/p\}\) ではそうならない）。

BR4　自由 δ 環の二重構成
