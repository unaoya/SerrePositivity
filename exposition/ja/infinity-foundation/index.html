整備後の ∞ 圏基盤

自分用の解説の新しいシリーズ（2026-10-28 開始）。 ∞ 圏基盤の整備計画が目指す層の構成に沿って、∞ 圏基盤の数学と Lean の配置を説明する。

このシリーズの書き方

  • 整備後の構成で書く。章立ては計画 §3 の層の順序（Simplicial < Core < Kan < … < Stable < F2）に従う。
  • 宣言ごとに、いまの所在と状態を添える。
    • いまの所在 → 移し先、の形で書く。
    • 状態は次の三つで示す。
      • 済：もう目標の場所にある。
      • 移動予定：計画の候補番号（R…）を付ける。
      • 未着手：まだない数学。段 G の M…。
    作業が進むたびに更新する。
  • 各章の冒頭に、基準コミットと計画の版を書く。
  • 旧シリーズ ∞ 圏基盤の解説（旧ディレクトリ単位、第 0〜8 章）は残す。 straightening・Yoneda・presentable などの詳しい説明は旧シリーズを参照する。
