∞-圏と六関手形式の形式化：概要ノート

2026-10-16 作成の Claude Doc（claude.ai/artifact/327aiEDtadrsWT7inCRUDi、37 版）を 2026-10-28 に HTML に書き出したもの。正本は Claude Doc 側。

目標と全体像

最終目標はエタールコホモロジーの六関手形式を Lean で形式化することで、独立リポジトリで進める。必要な仕事は三系統に分かれる。

  • A. ∞-圏論の道具：straightening、局所化、安定 ∞-圏、presentability、∞-オペラド、∞-層。
  • B. 六関手形式そのもの：対応の ∞-圏 Corr(C, E)、定義、拡張定理。幾何から独立した純粋な ∞-圏論。
  • C. 代数幾何の入力：永田コンパクト化、固有基底変換、𝔸¹ / ℙ¹ のコホモロジー。三角圏・アーベル層のレベルで証明できる。

B が受け取る入力は「ある自然変換が同値である」という命題（Prop）なので、C は B とインターフェースを決めて並行に進められる。

C の定理は自然変換が同値であるという性質として B に渡るので、∞-圏側と幾何側は独立に進められる。

なぜ ∞-圏が要るのか

三角圏でも f ↦ f_! を擬関手にまとめるところまでは手で済む（SGA4 XVII）。破綻するのは貼り合わせと整合性の爆発である。

  • 貼り合わせ：錐が関手的でないので、被覆に沿って対象を貼れず、D(X) が被覆上の D の極限にならない。
  • 整合性の爆発：基底変換・射影公式・Künneth の間の可換図式が増え続け、個別の検証が要る。

要点は「データを持つこと」より、「選択の曖昧さが可縮な空間になる形でデータを持つこと」。安定 ∞-圏では錐の選び方の空間が可縮なので、錐が関手的になる。降下は Cat_∞ での極限 D(X) ≃ lim D(U_•) として文字通り成り立ち、整合性はすべて「Corr(C, E) から出る一つの関手」に押し込まれる。

∞ 圏論の基礎（移動済み）

この位置にあった三節「straightening/unstraightening と、極限・余極限・随伴」「∞-オペラドと対称モノイダル構造」「局所化」は、2026-10-28 に「∞ 圏基盤の解説」の補章 10（六関手ノートから移した基礎）へ移した。

三関手部分 D^* の構成

拡張定理の入力 D^*: C^op → CAlg(Pr^L)、X ↦ Shv(X_ét; D(Λ)) は、厳密に関手的な向き（f_* と前層）で全空間を作り、性質を点ごとに確認し、f^* を逆読みで取り出して作る。

  1. 係数：D(Λ)（Λ は n を可逆とする捩れ環）を、presentable な対称モノイダル安定 ∞-圏として固定する。
  2. サイトの族：U ↦ U ×_X Y は擬関手だが、unstraighten すると (X, U → X エタール) の1-圏 Et と、引き戻しによるデカルトファイブレーション Et → Sch になる。整合性の問題は消える。
  3. 前層と f_*：PShv(X) = Fun(X_ét^op, D(Λ))、f_* は f^{-1} による制限。制限は厳密に関手的で、点ごとの ⊗ に関して厳密に対称モノイダル。ファイバーごとの関手圏は相対関手圏の構成（HTT 3.2.2）で書ける。X ↦ (PShv(X), ⊗, f_*) は CAlg(Cat_∞) 値の関手。
  4. 層と層化：Shv(X) は降下条件（Prop）を満たす充満部分圏。f^{-1} が被覆を保つので f_* は層を保ち、X ↦ Shv(X) は Pr^R 値。包含の左随伴 L（層化）は accessible で左完全な局所化で、存在は presentability から。
  5. f^* を逆読みで得る：各 f_* は左随伴を持ち、族の随伴で Sch → Pr^R ≃ (Pr^L)^op を逆に読むと f ↦ f^*。具体的には f^* = L ∘ f^*_pre（f^{-1} に沿った左 Kan 拡張）。
  6. 対称モノイダル性：層化が ⊗ と両立（L(F ⊗ G) ≅ L(LF ⊗ G)）すれば Shv(X) に ⊗ = L(⊗_pre) が入る（HA 2.2.1）。f^*_pre の余極限の添字圏は余フィルター的なので余極限はフィルター的で ⊗ と交換し、f^* は対称モノイダル。層の上の f_* は lax にすぎず左随伴は一般に oplax だが、比較写像が点ごとに同型なので関手全体が CAlg(Pr^L) 値になる（相対随伴の一般論 HA 7.3.2 を Fin_* 上のファイブレーションの性質として使う）。
  7. 超層と古典との比較：古典的な非有界導来圏 D(Sh(X_ét, Λ)) は超層の圏と一致する。C 側の定理を渡すには超層で定義すると比較が楽。有限コホモロジー次元のもとでは層と超層の差は消える（Clausen–Mathew など）。どちらで定義するかは f^* との相性も含めて Phase 0 で決める。

段2：サイトの族（詳細）

  • 一般論：擬関手 C^op → Cat のグロタンディーク構成は1-圏のデカルトファイブレーション。鍵の補題：1-圏のグロタンディークファイブレーションの脈体は ∞ の意味でデカルトファイブレーション。1-圏のデータがそのまま ∞ の入力になる（小さく独立で、最初の形式化の候補）。
  • 層の場合：1-圏 Et の対象は (X, U → X エタール)、射は f: Y → X と h: V → U の可換正方形。p: Et → Sch のファイバーは X_ét、デカルト射は引き戻しの正方形 (Y, U ×_X Y) → (X, U)。U ↦ U ×_X Y の擬関手性の管理は不要で、引き戻しの選択も要らない。被覆族はファイバーごとに与えられ、デカルト射で保たれる。
  • サイズ：X_ét は有限表示のアフィンエタールなどに制限して本質的に小さくする。
  • サイトは1-圏のまま：段2では脈体をとって ∞-圏として見るだけで、∞ 的なサイトは作らない。∞ 性は係数 D(Λ) だけから入る。∞-圏的なサイトが必要なのは導来代数幾何のように空間側も ∞ 的な場合で、エタールの六関手には不要。

段3：前層と f_*（詳細）

  • 一般論（相対関手圏、HTT 3.2.2）：E' → B とD に対し、T → B を {K → T（B 上）} ≅ {K ×_B E' → D} で定義する（n-単体は σ: Δⁿ → B と Δⁿ ×_B E' → D の組で、SSet の言葉だけで書ける）。E' → B が余デカルトなら T → B はデカルトで、ファイバーは Fun(E'_b, D)。関手圏が反変なので向きが一回ひっくり返る。要は余デカルトファイブレーションが平坦（exponentiable）であることで、重さは中〜重。
  • 層の場合：Et^op → Sch^op（余デカルト、ファイバー X_ét^op）に適用すると、T → Sch^op はデカルトで、ファイバーは PShv(X) = Fun(X_ét^op, D(Λ))、分類する関手は共変な X ↦ PShv(X)。
  • T の射の具体形：f: Y → X の上の射は前層の射 F → f_* G（f_* G(U) = G(U ×_X Y)）。デカルト持ち上げは G ↦ (f_*G, 恒等射)。straighten すると f ↦ 普通の押し出し f_* で、(gf)_* ≅ g_* f_* とその高次の整合性はすべて T の合成則に入っている。
  • 個々の PShv(X) は易しい：quasicategory への関手の空間（内部 Hom）は Mathlib にある。段3で新しいのは族としてまとめる部分だけ。
  • Rf_* が自動的に出る：段4で層に制限すると、係数が D(Λ) なので G(U ×_X Y) は導来大域切断を表し、f_* は自動的に Rf_* になる。入射分解は「係数を D(Λ) にして極限をとる」ことに吸収される。
  • モノイダル構造：D を D^⊗ → Fin_* に替えて同じ構成をすると点ごとの ⊗ が族として入る（HA 2.1.3）。f_* は制限なので厳密に保つ（段6）。

古典論が高次の整合性を気にしなくて済んだ理由

  1. アーベル層のレベル：X ↦ Sh(X) は2-圏 Cat への擬関手で、整合性は有限個。しかも (gf)_* ≅ g_* f_* はファイバー積の普遍性から来る標準的な同型で、一意的なので図式は自動的に可換になる。これが ∞ の「選択の空間が可縮」の1-圏的な影。
  2. 導来圏のレベル：三角圏は関手の間の同型までしか保持しないので、高次の整合性は表現できない。代償が、降下ができないことと錐が関手的でないこと。
  3. 整合性が本当に効く場面：古典的にも気にしていて苦労している。SGA4 XVII・XVIII の両立性の検証、コヒーレント双対性での Conrad の Grothendieck Duality and Base Change。

∞ の枠組みは、古典論が2-圏のレベルで「標準的な同型の一意性」で暗黙に処理していたことを、全レベルで「可縮性」として処理できるようにした。

段4：層と層化（詳細）

部分圏をとるだけの易しい部分（層の条件、f_* が層を保つこと）と、presentability が効く重い部分（層化の存在）に分かれる。

  • 4a 層の条件：各被覆 {U_i → U} の Čech 脈体 U_• について F(U) → lim_Δ F(U_•) が同値（有限直和 → 積も要求）。Prop なので Shv ⊂ PShv は充満部分圏。右辺は D の一般の極限で、錐の圏の終対象による定義を使う。超被覆に替えると超層（段7）。エタールでは被覆はエタールで全射な族（qcqs なら有限族）で、F(U) は RΓ(U, F) を表す複体、条件は Čech 降下そのもの。
  • 4b f_* は層を保つ：デカルトファイブレーションの中で、ファイバーの充満部分圏の族が推移関手で保たれれば、それらを集めたものもデカルトファイブレーション（軽い補題）。U の被覆を引き戻すと U ×_X Y の被覆になり Čech 脈体も保たれるので、f_*G は層。T を T_sh に制限すると X ↦ Shv(X)、f ↦ f_*（= Rf_*）。
  • 4c 層化の存在：PShv(X) は presentable で、Shv(X) は小さな射の集合 S（篩の包含 y(R) → y(U) と D の生成元のテンソル）に関する S-局所対象の圏。presentable な圏の小集合に関する局所対象の圏は反射的（HTT 5.5.4.15）。presentability が本格的に効く重い部品。
  • 安定係数の恩恵：一般の ∞-トポスでは L の左完全性が実質的な仕事（HTT 6.2.2）だが、係数が安定なら左随伴は有限余極限 = 有限極限を保つので L の完全性は自動。

古典的な層化との関係

  1. レシピは同じ：古典的にも f^{-1}F = a(f^{-1}_pre F)、F ⊗ G = a(F ⊗_pre G) と前層で作って層化した。∞ でも f^* = L ∘ f^*_pre、⊗ = L(⊗_pre) で、違いは係数が D(Λ) であることだけ。
  2. コホモロジーをとると一致：D(Λ) 値の前層 F について H^n(LF) ≅ a(U ↦ H^n(F(U)))。F → LF はコホモロジー層の上で同型になる局所同値。F が前層の複体 C^• のとき、項ごとに古典的層化 a をかけた複体は ∞ の超層化を表す（完全関手 a が誘導する D(PSh) → D(Sh) が超層化）。有限コホモロジー次元のもとでは層化と超層化の差は消える。
  3. 本質的な違いは分解が要らないこと：古典的には層化と導来関手は別の段階で、⊗^L には平坦分解、Rf_* には入射分解が要った（層の複体 C について C(U ×_X Y) は C が K-入射的でなければ RΓ を計算しない）。∞ では降下条件 F(U) ≃ lim F(U_•) がホモトピー極限を要求するので層の値は自動的に RΓ で、f_* はそのまま Rf_*。∞ の降下条件は古典論の「K-入射的（fibrant）であること」の役割を内蔵している。

段7の比較定理 Shv^hyp(X; D(Λ)) ≃ D(Sh(X_ét, Λ)) の証明の中心は、2（項ごとの層化が超層化を表す）と3（降下条件を満たす対象が K-入射的複体の役割を果たす）。

段5：f^* を逆読みで得る（詳細）

  • 5a 点ごとの左随伴：随伴関手定理（HTT 5.5.2.9）は使わず、明示的に作る。前層では制限 f_*^pre の左随伴 f^*_pre は左 Kan 拡張（HTT 4.3）、層化 L は包含の左随伴、層の f_* は f_*^pre の制限なので、随伴の合成で f^* = L ∘ f^*_pre ⊣ f_*。
  • 層の場合の公式：f^*_pre F(V) = colim_{(U, V → U ×_X Y)} F(U)（古典的な f^{-1}_pre の公式）。茎は (f^*F)_ȳ = F_{f(ȳ)}。
  • f がエタールの場合：Y_ét は X_ét のスライスなので f^* は単なる制限で層化不要。さらに左随伴 f_♯ を持ち、開埋め込みでは j_♯ = j_!（零拡張）。これが拡張定理の条件1の j_!。
  • 5b 族として組む（HTT 5.2.2 の相対版）：デカルトファイブレーションの推移関手がすべて左随伴を持てば余デカルトでもある。点ごとの判定は「f の上の射 F → f_* G が余デカルト ⇔ 随伴で移した f^* F → G が同値」で、余デカルト持ち上げは単位射 F → f_* f^* F。T_sh → Sch^op を余デカルトとして straighten すると X ↦ Shv(X)、f ↦ f^*（Pr^L 値）。

段6：対称モノイダル性（詳細）

  • 6a 前層の点ごとの ⊗（HA 2.1.3）：Fun(K, D)^⊗ := Fun(K, D^⊗) ×_{Fun(K, Fin_*)} Fin_*。制限は厳密に対称モノイダル。段3の構成を D^⊗ で Sch^op × Fin_* 上で行うと、Sch^op 方向にデカルト、Fin_* 方向に余デカルトな2変数ファイブレーション T^⊗。(F ⊗_pre G)(U) = F(U) ⊗^L G(U)。
  • 6b f^*_pre がモノイダル：モノイダル関手の左随伴は自動的に oplax。f^* が強モノイダル ⇔ Fin_* 方向の余デカルト射が Sch^op 方向の輸送で保たれる。B2 の「基底変換 ⇔ 余デカルト射が引き戻しで保たれる」と同じ型に統一される。層の場合、比較写像は対角 I → I × I から来て、I（U ∈ X_ét と V → U ×_X Y の組）はファイバー積を持つので余フィルター的、余極限の添字は sifted で対角は共終、よって同型。
  • 6c 層化で降ろす（HA 2.2.1）：L-同値 f と任意の Z で f ⊗ Z も L-同値なら、C' に ⊗' = L(⊗) が入り L は対称モノイダル。族としては推移関手が局所同値を保てばよい。層の場合、y(R) → y(U) と y(V) のテンソルは y(R ×_X V) → y(U ×_X V)、f^*_pre(y(R) → y(U)) = y(R ×_X Y) → y(U ×_X Y) で、どちらも被覆の引き戻し。Shv(X) の ⊗ = L(⊗_pre) は層の導来テンソル積で、平坦分解は不要。
  • 内部 Hom：Hom(F, G)(U) = Map(F|_U, G|_U) と明示的に書け、随伴関手定理は避けられる。

対応の ∞-圏と六関手形式の定義

六関手形式とは lax 対称モノイダル関手 D: Corr(C, E) → Cat_∞ のこと（Mann/Scholze）。基底変換・射影公式・Künneth とその高次整合性は、すべて「D が関手である」に含まれる。

Corr(C, E)

  • 設定：C は引き戻しを持つ（∞-）圏、E は同型を含み引き戻しと合成で閉じた射のクラス。エタールの場合は C = qcqs スキーム、E = 分離的有限型射。
  • 射：X ←g− W −f→ Y（f ∈ E）。合成は引き戻し W ×_Y V。
  • 単体：対角線に X₀, …, X_n、その上に W_{i,i+1}、さらに上に合成が並ぶ三角形の格子状図式で、すべての正方形が引き戻し、一方向の射が E に入るもの。純粋に組合せ的な SSet。
  • C が 1-圏の場合：写像空間は対応の同型の亜群なので、Corr は実質 (2,1)-圏。quasicategory であることは「引き戻しが同型を除いて一意」に帰着する。
  • モノイダル構造：X ⊗ Y := X × Y。Fin_* 上のファイブレーション Corr^⊗ として組む。

実装上は D を Corr^⊗ 上の余デカルトファイブレーションとして持つ。

拡張定理

三関手部分 D^* と「開埋め込みと固有射の随伴の条件」から、六関手形式が一意的に延びる。スキームは主張に出てこない純粋な ∞-圏論の定理で、リジッド解析・凝縮・モチーフの設定にもそのまま使える。

入力

  • D^*: C^op → CAlg(Cat_∞)（f^* と ⊗）
  • E の部分クラス I（開埋め込み）と P（固有射）。どちらも引き戻しと合成で閉じ、E の射はすべて p ∘ j（j ∈ I, p ∈ P）と分解でき、I ∩ P の射は切断的（スキームなら開かつ閉な埋め込みで単射）

条件

  1. j ∈ I に対し j^* は左随伴 j_! を持ち、基底変換と射影公式を満たす。
  2. p ∈ P に対し p^* は右随伴 p_* を持ち、基底変換と射影公式を満たす。
  3. 混合基底変換：引き戻しの正方形で j ∈ I、p ∈ P のとき、自然な写像 j'_! p'_* → p_* j_! が同型である（I ∩ P での一致 j_! ≅ j_* はその特殊な場合。Scholze の定式化に合わせた形で、正確な形は原典で要確認）。

結論：D^* は Corr(C, E) 上の六関手形式に一意的に延び、f = p ∘ j に対し f_! = p_* j_!。

証明の考え方

  1. I だけ、P だけについて Corr(C, I)、Corr(C, P) への延長を作る。D^* のデカルトファイブレーションが I の射の上でも余デカルトになること（左随伴の存在と基底変換）を使い、対応の圏の上のファイブレーションに組み直す（族の随伴）。
  2. 二つを貼り合わせる。鍵は「f の分解 p ∘ j のなす ∞-圏が弱可縮」で、これは分解の存在と I ∩ P の切断性という抽象的公理から ∞-圏論の中で示される。三角圏で Deligne が手で検証していた「コンパクト化によらない」の ∞ 版。

文献は Liu–Zheng（多重単体集合）、Mann の学位論文、Scholze の講義ノートの付録。形式化では Scholze/Mann 版を追う。

拡張定理の証明の仕組みと部品表

核心は「基底変換という条件を、余デカルト射が引き戻しで閉じるという性質に翻訳する」ことと、「コンパクト化によらない」を Fact(f) の可縮性と局所化の普遍性に置き換えること。

一つのクラスの延長

  1. D^* を C 上のデカルトファイブレーション E → C として持つ（対象 (X, F)、g の上の射 G → g^*F）。
  2. j^* が左随伴を持つ ⇔ j の上に余デカルト射がある。余デカルト持ち上げ (W, H) → (Y, j_! H) が j_! を与える。
  3. Beck–Chevalley ⇔ j の上の余デカルト射を g でデカルト的に引き戻すと j' の上の余デカルト射になる。基底変換の同型の族と高次整合性が、一つの Prop になる。
  4. 「C の対応の上にある E の対応」の ∞-圏 Corr(E) を作る。射は (X, F) ← (W, H) → (Y, G) で、左足は g の上のデカルト射、右足は j ∈ I の上の任意の射。
  5. Corr(E) → Corr(C, I) は余デカルトファイブレーションで、straighten すると X ← W → Y ↦ j_! g^*。Barwick の unfurling と同じ発想。射影公式も Fin_* 上の同じ型の条件になり、lax モノイダル性まで出る。

P については右随伴 p_* を使う双対版で同様。

二つのクラスの貼り合わせ

  1. 分解つきの対応 Corr^fact：X ← W −j→ W̄ −p→ Y を射とする ∞-圏。一つのクラスの延長を I 方向、P 方向の二回適用して (g, j, p) ↦ p_* j_! g^* を作る。両立の条件が混合基底変換。
  2. 分解を忘れる：π: Corr^fact → Corr(C, E) の f の上のファイバーは分解の圏 Fact(f)。D は分解を取り替える射をすべて同値に送る（混合基底変換から）。
  3. 可縮性：Fact(f) は空でなく（永田）、余フィルター的（二つの分解は X → W̄₁ ×_Y W̄₂ の分解で支配される）なので弱可縮。I ∩ P の切断性は分解の間の射の空間の制御に使う。C が1-圏なら Fact(f) も1-圏で古典的事実で済む。
  4. 降ろす：ファイバーが弱可縮なので π は局所化 Corr^fact[W⁻¹] ≃ Corr(C, E)。D は W を同値に送るので、局所化の普遍性で Corr(C, E) 上に一意的に降りる。Deligne が手で検証した無限の整合条件が、可縮性と局所化の普遍性の二つに置き換わる。

掘り下げ：Legendre 結び目の層理論的不変量

  • 設定と特異台：Legendre 結び目 Λ ⊂ T^∞ℝ² は前面射影で ℝ² 上の曲線として描ける。特異台 SS(F) ⊂ T^*M（Kashiwara–Schapira）は F が伝播しない余方向の集合で、構成可能層ではラグランジュ的、無限遠部分は Legendre 的。
  • 不変量：Sh_Λ(ℝ²) = 無限遠での特異台が Λ に含まれる層の安定 ∞-圏（Shende–Treumann–Zaslow）。接触同位で Sh_Λ ≃ Sh_{Λ'}（Guillermou–Kashiwara–Schapira）。証明は接触同位を M × M × I 上の核として量子化し、核の合成 p_{13!}(p_{12}^* K ⊗ p_{23}^* L) で作用させるもので、位相空間の六関手形式（f_!、f^*、⊗）をそのまま使う。
  • 計算 = exodromy + マイクロ局所条件：前面射影の成層（領域・弧・カスプ・交点）について構成可能なので、「領域にベクトル空間、弧をまたぐ写像、カスプと交点での条件」という箙の表現で書ける（STZ の組合せ的モデル）。マイクロ局所階数1の対象は Chekanov–Eliashberg DGA のオーグメンテーションと対応（Ng–Rutherford–Shende–Sivek–Zaslow）。有限体上の数え上げでルーリング多項式などが出る。階数1のモジュライにクラスター構造（Shende–Treumann–Williams–Zaslow、Casals–Zaslow の weave）。
  • ∞-圏が本質的な理由：特異台は錐と導来 Hom で定義される。マイクロ局所層は Λ 上の圏の層（Kashiwara–Schapira のスタック μsh）で、大域的な対象は Cat_∞ での極限 = 余デカルト切断。不変性の証明に六関手形式を使う。
  • Fukaya 圏との関係：余接束の Fukaya 圏 ≃ 構成可能層の圏（Nadler–Zaslow）、Λ で止めた wrapped Fukaya 圏 ≃ Sh_Λ のコンパクト対象（Ganatra–Pardon–Shende）。
  • 数論的な対応物：マイクロ局所層理論のエタール版は Beilinson のエタール層の特異台と斎藤毅の特性サイクル。接触同位の量子化（GKS）にはっきりした対応物は（知る限り）ない。
  • 形式化：一般論は重いが、前面射影の成層についての STZ の組合せ的モデルは有限的な箙の表現で扱いやすい。

Legendre 不変量：基礎からの説明

Legendre 結び目 Λ に「特異台が Λ に入る層」の安定 ∞-圏 Sh_Λ を対応させる。Legendre 同位で不変で、前面射影の図から組合せ的に計算できる。

  1. 接触幾何の準備：ℝ³ の接触構造 ξ = ker(dz − y dx)。Legendre 結び目はどこでも ξ に接する結び目。前面射影 (x, y, z) ↦ (x, z) で y = dz/dx は傾きとして復元され、垂直な接線の代わりにカスプが現れ、交点では傾きの小さい方が手前。前面の図だけで Legendre 結び目が決まる。古典的不変量（Thurston–Bennequin 数・回転数）では区別できない例がある（Chekanov）。ℝ³ = J¹(ℝ) は T^∞ℝ² の開部分と同一視でき、Legendre 結び目は「前面の曲線と各点での余法方向の選択」。
  2. 特異台（Kashiwara–Schapira）：(x, ξ) ∉ SS(F) ⇔ x の近くで φ(x) = 0、dφ(x) = ξ となる関数の等位線を ξ の方向にまたいでも切断が変わらない（{φ ≥ 0} に台をもつ局所コホモロジー = i^! 型の操作が消える）。「その方向をまたぐと切断が跳ぶ余方向の集合」。例：定数層は零切断、開半平面の零延長と閉半平面の定数層は境界の反対の余法方向。SS^∞(F) は零切断を除いて T^∞ に射影したもので、構成可能層では Legendre 的。
  3. Sh_Λ の定義（Shende–Treumann–Zaslow）：SS^∞(F) ⊂ Λ で z ≪ 0 で 0 となる層の充満部分圏（安定 ∞-圏）。マイクロ局所茎 μ_p(F) は p の余方向をまたぐ跳びの錐、その次元がマイクロ局所階数。階数1の対象のモジュライ 𝓜₁(Λ) は代数的スタック。
  4. 不変性（Guillermou–Kashiwara–Schapira）：同位を接触同位 φ_t に延長し、M × M × I 上の核 K（特異台が φ_t のグラフ）を作り（層量子化）、畳み込み K ∘ F = p_{2!}(K ⊗ p_1^* F) で作用させる。特異台の評価で SS^∞ が Λ₀ から Λ₁ に動く。Sh_Λ、𝓜₁(Λ)、その 𝔽_q 点の数、Hochschild ホモロジーなどが不変量。
  5. 組合せ的な計算（exodromy の応用、STZ の組合せ的モデルのおおよその形）：前面の成層について構成可能なので exit-path 圏の表現。領域に複体（非有界な下の領域は 0）、弧をはさむ領域の間に余向き付けで向きの決まる写像、カスプでは内外の写像の合成が恒等、交点では4領域の正方形が可換で全複体が非輪状、階数1では各弧の写像の錐が1次元。例：標準的な非結び目（二つのカスプの「空飛ぶ円盤」）では内側が1次元に決まり、𝓜₁ は一点を G_m で割ったもの。
  6. 他の理論との関係：Chekanov–Eliashberg DGA（Reeb コードで生成、正則円板を数える微分）のオーグメンテーションの圏 ≃ マイクロ局所階数1の部分（Ng–Rutherford–Shende–Sivek–Zaslow）。ルーリング多項式（前面を目の対に分解する仕方の数え上げ）は 𝓜₁(Λ) の 𝔽_q 点の数と q のべきを除いて一致。Λ で止めた wrapped Fukaya 圏 ≃ Sh_Λ のコンパクト対象（Ganatra–Pardon–Shende）。
  7. 局所から大域へ：Λ 上の圏の層 μsh_Λ（大域切断は Cat_∞ での極限 = 余デカルト切断）。マイクロ局所化 Sh_Λ → μsh(Λ)、Λ が円周なら μsh(Λ) は（Maslov 指数などで捻られた）局所系の圏で、𝓜₁(Λ) → Loc₁(Λ)。フィリング L 上の階数1の局所系から 𝓜₁(Λ) のトーラス・チャート (G_m)^{b₁(L)} が得られ、チャートの間の座標変換がクラスター変換（Casals–Gao）。

レベル2：六関手で定義される不変量

不変量を六関手の演算（j_*、i^*、i^!、近接サイクル、双対性）と双対化対象だけで定義すれば、位相とエタールの六関手形式で同じ定義の二つの値になり、辞書の各項目が一つの定理の二つの例になる。

  • 絡み数 ↔ Legendre 記号：recollement の境界写像と双対性ペアリングの合成（森下のカップ積の抽象化）。
  • Alexander 加群 ↔ 岩澤加群：補空間上の普遍的なアーベル局所系を係数とするコホモロジー。
  • Milnor 不変量 ↔ 多重剰余記号：Massey 積。

レベル3：(∞,2)-圏（マイクロ局所・トレース・場の理論）

  • ULA と特異台：普遍局所非輪状性は、六関手形式から作ったコホモロジー的対応の2-圏での双対化可能性と同値（Lu–Zheng）。Beilinson の特異台は ULA で定義されるので、特異台は六関手形式から抽象的に定義できる。Kashiwara–Schapira の特異台もテスト関数に沿った伝播で特徴づけられ、同じ抽象的定義の位相版と見られる可能性がある。成り立てば Sh_Λ の数論版が定義でき、欠けているのは接触同位の不変性（GKS 量子化）の対応物。
  • トレース：Grothendieck–Lefschetz は圏論的トレース（Lu–Zheng）の例で、Lefschetz 数とフロベニウスのトレースは同じ構成の二つの値（確立）。
  • 場の理論：Ben-Zvi–Sakellaridis–Venkatesh の数論的な場の理論。現時点では指導原理の段階。

結び目の場合に「点を動かす」とは

「点を動かす」には三つの意味があり、それぞれ別の数学に関係する。

  1. 結び目そのものが動く点の軌跡：円板の中の n 点を時間とともに動かし元の配置に戻すと組紐（配置空間 Conf_n(円板) のループ、組紐群は配置空間の基本群）。両端を貼ると閉じた組紐で結び目・絡み目（Alexander の定理：すべての結び目は組紐の閉包）。ファイバー付き3次元多様体では写像トーラスの中の自己同相の周期軌道が結び目。関数体では次数 d の閉点は d 点が Frobenius で巡回的に置換されるもので、Frobenius の写像トーラスの中の閉じた組紐（𝔽_q[t] の d 次既約多項式は Conf_d(𝔸¹) の 𝔽_q-点）。
  2. 結び目を動かす（イソトピー）：結び目の同値は周囲の空間の中での連続変形で、不変量はこの動きで変わらない量。Markov の定理：二つの組紐の閉包が同じ結び目 ⇔ 共役と安定化（Markov 移動）で移り合う。関数体では多項式の係数を族として動かすことが配置空間の中で点を動かすことに当たり、配置空間のエタール基本群（副有限組紐群）が現れる。
  3. 点を動かすことから生まれる代数構造：平面で二点を入れ替えるとき右回りと左回りで異なる動きになることが組紐構造（E₂-構造の影）の起源。Reshetikhin–Turaev 型の不変量は組紐群の表現（R-行列）と Markov トレースから作られ、Jones 多項式も Temperley–Lieb（Hecke）代数の表現とトレースから見つかった。Chern–Simons 理論では結び目は Wilson 線で、時刻の断面の中で点として動き、その交換が組紐構造。「点を動かせる → 組紐群の表現 → 量子不変量」の連鎖。

移らないものを移すための手

移らない理由は「素点を動かせない」の一点なので、移すアイディアは「動きをどこから調達するか」に整理できる。

  1. 動ける場所を借りる：関数体の配置空間 Conf_d(𝔸¹)（基本群は組紐群）、FF 曲線（Fargues–Scholze で点は Div¹ の上を動き、Hecke 作用素の融合積が Div^d 上に現れる）、p 進族（Hida・Coleman 族、固有値曲線）。
  2. イソトピーをホモトピー的な影に置き換える：組紐構造は E₂-構造の影。絶対ガロア群は GT 群を通じて副有限組紐群に作用する（伊原、Drinfeld）。組紐モノイダル圏や Drinfeld アソシエーターにもガロア群が作用。
  3. 1の冪根で評価して有限・副有限にする：有限な像の量子表現は副有限組紐群に延び、数論的基本群と比べられる。
  4. 量子パラメータ q を Frobenius から作る（類似 B）。
  5. 接触同位を分岐を保つ変形に置き換える（方向 C）。
  6. 形式的な変形で動かす（下記）。

スケッチ：Frobenius 組紐の量子不変量（推測的）

  1. 𝔽_q 上の平方因子のない d 次多項式 f は Conf_d(𝔸¹)(𝔽_q) の点で、その Frobenius 元は数論的基本群（幾何的部分が副有限組紐群）の捻れた共役類を与える。f の「閉じた組紐 = 結び目・絡み目」（点の数え上げとの関係は Church–Ellenberg–Farb など）。
  2. 1の冪根 ζ で有限な像をもつ量子表現は副有限組紐群に延びる。
  3. Frobenius 方向への延長には量子パラメータとの両立が要り、円分指標と GT 作用から「Frobenius が ζ を ζ^q に送る」形が期待される。類似 A（点 = 閉じた組紐）と類似 B（q = |𝔽_q|）が一つの式で出会う。
  4. 各 f に Jones の1の冪根での値の類似を対応させる不変量の候補。数体へは EVW 流に関数体の統計から予想として移す。
  5. 要確認：有限な像の量子表現のレベル、Frobenius 方向への延長の障害、ガロア作用と量子不変量の既存研究との重なり。

形式的な変形で動かす

素点は自由には動かせなくても、形式的（冪単）な変形なら動かせる。位相側でも組紐構造の本質の多くは形式的な変形で捉えられる。

  • 位相側の形式的な影：無限小組紐リー代数（Drinfeld–河野）、KZ 接続、Drinfeld アソシエーターが組紐群の冪単完備化を記述。Kontsevich 積分はアソシエーターから作る普遍的な有限型不変量で、量子不変量の摂動部分をすべて含み、係数に多重ゼータ値。
  • ガロア群の作用：GT 群を通じた組紐への作用（伊原、Drinfeld）、Brown の定理（ℤ 上の混合 Tate 動機の動機的ガロア群が ℙ¹ ∖ {0, 1, ∞} の冪単基本群に忠実に作用）。形式的には組紐構造と量子不変量の摂動部分はすでに数論的な対称性を持つ。

Scholze のゲシュタルテン（Gestalten）

六関手形式を幾何の側から受け止める普遍的な受け皿として設計された新しい幾何的対象。出典は Scholze, Geometry and Higher Category Theory（ボン 2025/26 冬学期の講義ノート、Germán Stefanich との共同研究、序文 2026-02）。

  • 動機：Gelfand・Stone・Hilbert・Grothendieck・Tannaka の「幾何 ↔ 代数」の双対の系譜を完成させる。可換環を超えて概環・関数解析的な圏・安定 ∞-圏を扱い、B²G_m・B³G_m のような高次スタックに乗る高次線形圏の層まで、すべての次数の線形高次圏を追跡する。
  • 定義：Stefanich 環は列 (A₁, A₂, …)、各 A_n は κ-presentable な (∞,n)-圏の圏 nPr の中の可換代数で A_n ≃ End_{A_{n+1}}(1)（足し算と掛け算の完全な脱ループ）。ゲシュタルテンは Stefanich 環の圏の反対圏。
  • 主定理（Scholze–Stefanich）：実用上ゲシュタルテンの圏は ∞-トポスで、標準位相は有効エピ射、層化は不要。
  • サイズ：NBG 集合論で κ = ℵ₁ の Pr^L_κ を使い、それ自身 presentable な「自分自身を含む圏の圏」を作って宇宙の扱いのほとんどを避ける。
  • 他の枠組み：代数的スタック（qcqs、アフィン対角）はゲシュタルテンに写り、十分大きな部分圏で充満忠実（一般にはそうでない）。解析的スタックからの関手は ℵ₁-コンパクトな対象上で保守的。
  • 六関手：Spec A ↦ nPr_A がアフィン上の六関手形式。n ≥ 1 で可算表示の射は両側随伴的、fpqc 降下。ゲシュタルテン上にも !-可能な射の六関手形式。
  • 変換（transmutation）：圏 C 上の任意の presentable な六関手形式 D から C → Gest、X ↦ [X]_D が得られ、有限極限と !-位相の貼り合わせを保つ。ゲシュタルテンはすべての六関手形式の共通の受け皿（ノートでは普遍性でなく分解の結果として述べている）。
  • 例：Morel–Voevodsky の SH から [Spec ℤ]_SH。青木の定理で「1-アフィン、コホモロジー的に滑らか、ホモロジー的に可縮で、零切断と単数による成層をもつ環ゲシュタルト」として特徴づけ。最終講は Berkovich 動機のゲシュタルト、第X〜XII講は Cartier 双対（中身は未確認）。

これまでの議論との関係

  1. 素数と結び目を同じ圏の対象にする場所：(S³, K) は Betti（位相）の六関手から、(Spec O_K, S) はエタールの六関手から、変換でどちらも Gest の対象になる。比較が「六関手が見る幾何」のレベルで行われ、「局所系の圏 + 六関手 + 双対性が類似の正しいレベル」という原理と一致。
  2. 抽象的な3次元多様体・結び目の公理化（推測）：青木の定理のように、ゲシュタルテンの中で「構造射が次元3のコホモロジー的滑らかさ（Poincaré 双対）、閉ストラタが次元1、絡みが次元2」といった公理でレベル1の定義を書ける言語になっている可能性。
  3. 形式化の設計への示唆：宇宙レベルの問題に対する「ℵ₁-presentable な自分自身を含む圏の圏」は Lean での実装方針の参考になる。幾何を六関手から作る発想は「六関手のライブラリを先に作り幾何をその上に載せる」設計と相性がよい。ただしゲシュタルテン自体はすべての n の (∞,n)-圏を使い今の Mathlib から遠いので、直接の目標ではなく設計思想として取り入れるのが現実的。

形式化の設計方針とフェーズ案

中核はファイブレーションの理論で、Cat_∞ を明示的に登場させない設計を第一候補にする。

設計方針

  • ファイブレーション路線：Cat_∞ に値をとる関手は、すべて底の上の余デカルト（デカルト）ファイブレーションとして実装する。性質は Prop になり、宇宙レベルも上がらない。
  • straightening は後回し：使うのは (a) ファイブレーションの定義と基底変換、(b) ファイバー間の輸送が可縮な選択で決まること、(c) 極限 = 切断、の三つ。straightening 定理は「Cat_∞ の極限・関手と一致する」という正当化として独立に示す。
  • D(Λ) の構成：Dwyer–Kan 局所化よりも、K-入射的複体の dg-nerve（HA 1.3.5）を有力候補にする。
  • 最大の実装上の難所：presentability と随伴関手定理のサイズ・宇宙レベルの扱い。
  • 既存資産との接続：Mathlib の QCat.strictBicategory と Bicategory.Adjunction を使い、「双デカルトファイブレーション ⇔ homotopy 2-category の随伴」を早い段階のマイルストーンにする。

フェーズ案

  1. Phase 0：Mathlib と InfinityCosmos に依存するリポジトリを立て、最終目標から逆算した依存グラフを blueprint にする。
  2. Phase 1：余デカルトファイブレーションの基本理論、切断としての極限、降下の定式化。
  3. Phase 2：随伴（双デカルトファイブレーション）、族の随伴、homotopy 2-category の随伴との一致。
  4. Phase 3：安定 ∞-圏・D(Λ)・presentability・∞-オペラド・∞-層。Mathlib の DerivedCategory との比較。
  5. Phase 4：Corr(C, E)、六関手形式の定義、拡張定理。
  6. 並行（C 側）：永田コンパクト化、固有基底変換、𝔸¹ / ℙ¹ のコホモロジー。三角圏・アーベル層のレベルで進め、Phase 4 の条件にインターフェースで渡す。
