0. 左 fibration と cocartesian fibration の意義

厳密さより位置づけ。

0.1 関手を書く代わりのもの

∞ 圏論の根本的な困難は、\(\mathcal S\) や \(\mathrm{Cat}_\infty\) に値を取る関手を手で書けないこと（各射に写像を割り当てるだけでなく、合成のずれを埋めるホモトピーとその高次の整合性を無限に与える必要がある、補章 3）。fibration はこれを回避する：関手 \(B\to\mathcal S\) の代わりに一つの単体的集合 \(E\) と射影 \(E\to B\) を与え、条件はホーンの持ち上げという局所的な性質だけ。fiber \(E_b\) が \(F(b)\) の、持ち上げによる輸送が \(F(u)\) の役を果たし、高次の整合性は \(E\) が単体的集合であることに含まれる。fibration は整合性を持ち上げ性質に置き換えた関手の別表現で、分類定理（straightening）はこの二つが同じものだと保証する橋。

0.4 極限・余極限、cofinality

関手の極限は対応する fibration の（cocartesian）切断の空間、余極限は全空間を（cocartesian 辺で）局所化したもの（左 fibration なら全空間の空間化）。cofinality の判定（Quillen の定理 A の ∞ 版）も fibration の言葉で述べられる。

0.5 理論の組み立ての中での位置

HTT の順：準圏の基礎（第 1 章）→ fibration の理論（第 2 章）→ straightening（第 2〜3 章）→ 前層・米田・Kan 拡張（第 4〜5 章）。fibration は「関手圏 \(\mathrm{Fun}(B,\mathcal S)\)・\(\mathrm{Fun}(B,\mathrm{Cat}_\infty)\) がまだ使えない段階での代用品」として土台に置かれ、straightening を越えた後は「関手として考え、必要なときに fibration として作る」（補章 6 §5）。

1. 目標と道筋

定理 I（\(\mathcal S\) は左 fibration を分類する）：\(\mathrm{Map}(B,\mathcal S)\simeq\mathrm{LFib}(B)^{\simeq}\)（\(B\) について自然、写像から族へは \(\mathcal S_*\to\mathcal S\) の引き戻し）。強い形は \(\mathrm{Fun}(B,\mathcal S)\simeq\mathrm{LFib}(B)\)。

定理 II（\(\mathrm{Cat}_\infty\) は cocartesian fibration を分類する）：\(\mathrm{Map}(B,\mathrm{Cat}_\infty)\simeq\mathrm{coCart}(B)^{\simeq}\)。強い形は \(\mathrm{Fun}(B,\mathrm{Cat}_\infty)\simeq\mathrm{coCart}(B)\)。

どちらも三つに分かれる：(1) 普遍な族を作り \(\mathrm{Un}(\chi):=\chi^*(\text{普遍な族})\)、(2) 充満忠実性（核心は \(B=\Delta^1\) での univalence）、(3) 本質的全射性（分類写像の構成、最も重い）。

2.3（0.2 補足）普遍性をホーン型の拡張条件として述べる

鍵は二点：(1) 全ての普遍性は、ある ∞ 圏の始対象（終対象）として述べられる。(2) 始対象の条件は頂点 0 を固定した境界 \(\partial\Delta^n\) からの拡張。

2.4（0.3）Kan 複体と準圏

Kan 複体は準圏（1 圏の「亜群は圏」）。

例 1：圏のナーブ。\(N(\mathcal C)\) の内ホーンは一意に埋まる（\(n=2\) は \(f_{02}=f_{12}\circ f_{01}\) しかない、\(n=3\) は結合律で自動、\(n\ge4\) は単体が辺で決まり自動）。逆に内ホーンが一意に埋まる単体的集合は圏のナーブと同型（HTT Prop. 1.1.2.2）。準圏は「内ホーンが埋まるが一意とは限らない」ものとして圏を一般化したもの。\(N(\mathcal C)\) が Kan ⇔ \(\mathcal C\) は亜群。\(\Delta^n=N([n])\) は準圏だが Kan でない。モノイドのナーブ \(BM\) は準圏で、Kan ⇔ \(M\) は群。

例 2：特異単体集合。\(\mathrm{Sing}(T)\) は Kan：\(|\Lambda^n_i|\subset|\Delta^n|\) はレトラクトなので \(|\Lambda^n_i|\to T\) はレトラクションとの合成で延びる。Kan 複体のホモトピー論と位相空間のホモトピー論は同値（Quillen 同値）。

2.5（0.4）持ち上げ性質と fibration の言葉

持ち上げ性質：\(i\colon A\to B\)、\(p\colon X\to Y\) について、全ての可換正方形（\(A\to X\)、\(B\to Y\)）に対角線 \(B\to X\) があるとき、\(i\) は \(p\) に対して左持ち上げ性質、\(p\) は \(i\) に対して右持ち上げ性質を持つ。\(Y=\Delta^0\) が 0.3 の「ホーンが埋まる」。底が一点の場合を、底を一般にして相対化したもの。

相対的なホーンの持ち上げ：\(E\) の中のホーンと、それを延ばす \(B\) の \(n\) 単体が与えられ、ホーンを延ばし \(B\) の単体の上にある \(E\) の \(n\) 単体を求める（底の単体を固定したまま上で埋める）。

2.6（0.5）アノダイン写像

なぜ必要か：実際の議論ではホーン以外の包含（\(\{0\}\hookrightarrow\Delta^n\)、\(\{0\}\times K\hookrightarrow\Delta^1\times K\) など）に対する持ち上げが要る。一つずつ確かめる代わりに、ホーンから形式的に作れる包含のクラスを考える。

弱飽和クラス：押し出し・超限合成・レトラクトで閉じたクラス。基本補題：任意のクラス \(P\) について「全ての \(p\in P\) に対して左持ち上げ性質を持つ写像」の全体は弱飽和（持ち上げ問題を一段ずつ解けば解が運べる）。よって生成元に対する持ち上げ性質から、その弱飽和閉包全体に対する持ち上げ性質が自動的に従う。

内アノダイン ⊂ 左アノダイン ⊂ アノダイン。ある写像 \(i\) に対する \(p\) の持ち上げ性質を示すには、(1) \(i\) がアノダイン（\(i\) だけの性質で一度示せば済む）、(2) \(p\) が生成元に対して持ち上げ性質を持つ（定義そのもの）、の二つを確かめればよい。

例：

  • \(\{0\}\hookrightarrow\Delta^2\) は左アノダイン：\(\{0\}\hookrightarrow\Delta^{\{0,1\}}\)（\(\Lambda^1_0\)）、\(\Delta^{\{0,1\}}\hookrightarrow\Lambda^2_0\)（辺 \(\{0,2\}\) を \(\Lambda^1_0\) の押し出しで付け足す）、\(\Lambda^2_0\hookrightarrow\Delta^2\)。一般に \(\{0\}\hookrightarrow\Delta^n\) も左アノダイン（始対象の包含）。したがって Kan・左 fibration は「底の 2 単体と頂点 0 の上の点から、頂点 0 がその点の 2 単体」を持ち上げる。右 fibration が持ち上げるのは \(\{2\}\hookrightarrow\Delta^2\)。内アノダイン写像は頂点の上で全単射（内ホーンは全頂点を含む）なので \(\{0\}\hookrightarrow\Delta^2\) は内アノダインでない。
  • spine \(\mathrm{Sp}^n\hookrightarrow\Delta^n\) は内アノダイン（Joyal）：\(n=2\) は \(\Lambda^2_1\)、\(n=3\) は \(\Lambda^2_1\) で \(\{0,2\},\{1,3\}\) と面を足し、\(\{0,3\}\) と面 \(\{0,1,3\}\) を足して \(\Lambda^3_2\)、最後に埋める。準圏では射の列から \(n\) 単体が本質的に一意に決まる（最短路 §8 の「\(\mathrm{Corr}\) の単体は spine で決まる」と同じ現象）。
  • 非例：\(\partial\Delta^1\hookrightarrow\Delta^1\) はアノダインでない（アノダインは弱同値）。\(\Lambda^2_0\hookrightarrow\Delta^2\) は左アノダインだが内アノダインでない。

Joyal の積の補題（HTT Cor. 2.3.2.4、Prop. 2.1.2.7）：\(A\hookrightarrow B\) が内（左）アノダイン、\(K\hookrightarrow L\) が単射なら \((A\times L)\sqcup_{A\times K}(B\times K)\hookrightarrow B\times L\) も内（左）アノダイン。最小の例：\(\{0\}\hookrightarrow\Delta^1\) と \(\partial\Delta^1\hookrightarrow\Delta^1\) で「正方形から一辺を除いた三辺 ⊂ 正方形」（二つの 2 単体に分けてホーンを二回埋める）。

3.1（1.1）関手の ∞ 圏 \(\mathrm{Fun}(K,\mathcal C)\) の中身

3.2（1.2）同値な辺と Joyal の定理

定義：辺 \(f\colon x\to y\) が同値 ⟺ \([f]\) が \(h\mathcal C\) で同型 ⟺ \(g\colon y\to x\) と、境界 \((f,g,\mathrm{id}_x)\)、\((g,f,\mathrm{id}_y)\) の 2 単体が存在する。

定義についての質問：同じ境界の 2 単体が複数あったら、それらをつなぐ中身は要るか。要らない。境界 \((f,g,\mathrm{id}_x)\) の 2 単体は \(\mathrm{Map}(x,x)\) の中の \(gf\) から \(\mathrm{id}_x\) への道で、\(\pi_1\) が非自明なら 3 単体でつなげない別々のものがある（枕の例 2.4 で \(\mathrm{Map}(0,2)\simeq S^1\)）。それでも同値は \(f\) の性質で、\(h\mathcal C\) だけで決まり、どの証拠を選んでも結論は同じ。ただし証拠をデータとして持ち運ぶと話が変わる：

証拠の形空間
同じ \(g\) と二つのホモトピー（quasi-inverse）一般に可縮でない（二つの 2 単体の間を埋めていないため。ホモトピー型理論で qinv が命題でないのと同じ）
左逆元と右逆元を別々に持つ可縮
同じ \(g\) と三角等式の高次セル（随伴同値）可縮
自由な同型の圏のナーブ \(J\) からの延長可縮（全ての整合性込み）

定理（Joyal）：\(\mathcal C\) 準圏、\(n\ge2\)。\(\sigma_0\colon\Lambda^n_0\to\mathcal C\) の最初の辺が同値なら \(\Delta^n\) に延びる。双対に \(\Lambda^n_n\) で最後の辺が同値なら延びる。最初（最後）の辺が可逆なら外ホーンの延長問題は内ホーンと同様に解ける、という主張。

\(n=2\)（手で）：\(\Lambda^2_0\) は \(f\colon x\to y\) と \(h\colon x\to z\)。頂点 \(x,y,x,z\) の 3 単体を考え、\(d_3=\{0,1,2\}\) に左逆の 2 単体 \((f,f',\mathrm{id}_x)\)、\(d_0=\{1,2,3\}\) に \(\Lambda^2_1\) で作る合成 \(g:=hf'\)、\(d_1=\{0,2,3\}\) に退化 \(s_0h\) を置く。欠けているのは \(d_2\) だけなので内ホーン \(\Lambda^3_2\)。埋めた \(d_2\) が \((f,g,h)\)。逆元を一つ挟んで外ホーンを内ホーンに変えた。

\(n=3\)（意味）：\(\Lambda^3_0\) は「\(f\) を右から合成した後の関係から \(f\) を外す」右キャンセル。全次元まとめると、\(f\) を前から合成する操作が選択の空間ごと可逆。

join・スライス・制限写像（ここで初めて正式に定義）：

  • join：\((K\star L)_n=K_n\sqcup L_n\sqcup\bigsqcup_{i+j+1=n}K_i\times L_j\)。\(\Delta^m\star\Delta^n=\Delta^{m+n+1}\)、\(\Delta^0\star K\) は始点を足した錐（2.3 の \(\Delta^0\star\partial\Delta^n=\Lambda^{n+1}_0\)）。ナーブでは圏の join。
  • 下のスライス \(\mathcal C_{p/}\)（\(p\colon K\to\mathcal C\)）：\(n\) 単体は \(K\star\Delta^n\to\mathcal C\) で \(K\) 上 \(p\) のもの。\(\mathrm{Hom}(A,\mathcal C_{p/})=\{K\star A\to\mathcal C,\ K\text{ 上 }p\}\)。\(\mathcal C_{x/}\) の頂点は射 \(x\to y\)、\(\mathcal C_{f/}\) の頂点は \(f\) を通る分解 \((g,h,gf\simeq h)\)（コンマ圏の ∞ 版）。
  • 上のスライス \(\mathcal C_{/p}\)：\(\Delta^n\star K\to\mathcal C\) で \(K\) 上 \(p\) のもの。
  • 制限写像：\(K'\subseteq K\) から \(\mathcal C_{p/}\to\mathcal C_{p|_{K'}/}\)（\(\mathcal C_{/p}\) も同様）。例：\(q\colon\mathcal C_{f/}\to\mathcal C_{x/}\) は分解を忘れて \(h\) だけ見る、\(\mathcal C_{x/}\to\mathcal C\) は終点を取る。

join とホーンの計算：\(\Delta^m\star\Delta^n\) の面は \(j\le m\) で \((d_j\Delta^m)\star\Delta^n\)、\(j\gt m\) で \(\Delta^m\star(d_{j-m-1}\Delta^n)\)。よって

\[ (\partial\Delta^m\star\Delta^n)\cup(\Delta^m\star\Lambda^n_i)=\Lambda^{m+n+1}_{m+1+i},\qquad(\Lambda^m_i\star\Delta^n)\cup(\Delta^m\star\partial\Delta^n)=\Lambda^{m+n+1}_i . \]

前者は \(i\lt n\) なら、後者は \(i\gt0\) なら内ホーン。弱飽和性で片側を一般の単射に広げ：任意の単射 \(A\subseteq A'\) と \(i\lt n\) に対し \((A\star\Delta^n)\cup(A'\star\Lambda^n_i)\subseteq A'\star\Delta^n\) は内アノダイン（右側も同様）。積の補題（2.6）と違い生成元の計算がホーンそのものになるので直接終わる。帰結：下のスライスの制限は左 fibration、上のスライスの制限は右 fibration（\(\mathcal C_{x/}\to\mathcal C\) が左 fibration なのは 0.3 の表の正確な形）。

最初の方針（下のスライス）：\(\Delta^n=\Delta^{\{0,1\}}\star\Delta^{n-2}\) とすると \(\Lambda^n_0=(\Delta^{\{0,1\}}\star\partial\Delta^{n-2})\cup(\{0\}\star\Delta^{n-2})\) で、さらに \((\Delta^1\star\partial\Delta^m)\cup(\{0\}\star\Delta^m)=\Lambda^{m+2}_0\)。よって定理は「\(q\colon\mathcal C_{f/}\to\mathcal C_{x/}\) が自明 Kan fibration」の言い換えそのもの。\(q\) が左 fibration であることは上の計算で \(f\) の可逆性なしに出るが、残りの \(\partial\Delta^m\) に対する持ち上げを「左 fibration は fiber が可縮なら自明」で示そうとすると、fiber が Kan であること（それ自体 Joyal の定理の帰結）を使って循環する。

証明（循環しない形、Kerodon Prop. 4.4.2.13 の双対）：反対側の上のスライスを取ると、問題が辺一本の持ち上げになる。

  1. 右 fibration は同値を反映する：\(\theta\colon E\to B\) 右 fibration、\(\theta(u)\) が同値。底で右逆元の 2 単体 \((\bar w,\theta u,\mathrm{id})\) を取り、\(E\) で \(\{1,2\}=u\)、\(\{0,2\}=\mathrm{id}_Y\) として \(\Lambda^2_2\) を持ち上げると \(uv\simeq\mathrm{id}\) の \(v\)。\(\theta(v)\) も同値なので繰り返して \(vw\simeq\mathrm{id}\)。\(hE\) で \(u=u(vw)=(uv)w=w\) なので \(u\) は同値。
  2. 右 fibration は始点を指定して同値を持ち上げる：\(\bar v\colon\rho(Y)\to\bar Z\) 同値。逆元 \(\bar w\) を終点 \(Y\) 指定で持ち上げ（\(\Lambda^1_1\)）\(w\colon Z\to Y\)、1 より同値。その逆元 \(w'\colon Y\to Z\) について \([\rho w']=[\bar v]\) なので境界 \((\rho w',\mathrm{id},\bar v)\) の 2 単体があり、\(\{0,1\}=w'\)、\(\{1,2\}=\mathrm{id}_Z\) として内ホーン \(\Lambda^2_1\) を持ち上げると \(\{0,2\}\) が求める \(v\)。

3.4（1.4）写像空間 \(\mathrm{Map}_{\mathcal C}(x,y)\)

目標：「\(x\) から \(y\) への射の空間」を Kan 複体として作り、\(\pi_0=h\mathcal C(x,y)\)、高次の \(\pi_n\) がホモトピーのホモトピーを表すようにする。

模型 1：\(\mathrm{Hom}^R(x,y)\)。\(n\) 単体は前の面 \(\Delta^{\{0,\dots,n\}}\) が \(x\) で定値、最後の頂点が \(y\) の \((n+1)\) 単体。右 fibration \(\mathcal C_{/y}\to\mathcal C\) の \(x\) 上の fiber。頂点は辺 \(x\to y\)、辺は境界 \((\mathrm{id}_x,f',f)\) の 2 単体（ホモトピー）、2 単体はホモトピーのホモトピー。

  • Kan：点上の右 fibration なので \(\Lambda^n_i\)（\(0\lt i\le n\)）が埋まり準圏。\(\Lambda^2_2\) を \(\{1,2\}=u\)、\(\{0,2\}=\mathrm{id}\) で埋めると全ての辺に右逆元があり、亜群。3.2 の系で Kan。
  • \(\pi_0\)：辺 \(x\to y\) をホモトピーで割ったもの ＝ \(h\mathcal C(x,y)\)（Boardman–Vogt）。\(\pi_1\)：枕の例で \(S^1\)。

模型 2：\(\mathrm{Hom}^L(x,y)\)。双対（最初の頂点が \(x\)、後ろの面が \(y\) で定値）。\(\mathcal C_{x/}\to\mathcal C\) の fiber、\(\Lambda^2_0\) で左逆元。

模型 3：\(\mathrm{Fun}(\Delta^1,\mathcal C)\) の fiber。\((\mathrm{ev}_0,\mathrm{ev}_1)\colon\mathrm{Fun}(\Delta^1,\mathcal C)\to\mathcal C\times\mathcal C\) の \((x,y)\) 上の fiber。\(n\) 単体は \(\Delta^n\times\Delta^1\to\mathcal C\) で両端が定値。辺は二辺が恒等の正方形。準圏であることは 2.6、Kan であることは 1.5 の後（辺が \(\mathrm{Fun}(\Delta^1,\mathcal C)\) で同値なことを各点判定で見て、相対版 Joyal で fiber の外ホーンを埋める）。

比較：\(\Delta^n\times\Delta^1\to\Delta^{n+1}\)、\((i,0)\mapsto i\)、\((i,1)\mapsto n+1\) で引き戻して \(\mathrm{Hom}^R\to\mathrm{Map}\)（\(\mathrm{Hom}^L\) も同様）。これらはホモトピー同値（HTT Cor. 4.2.1.8、Kerodon §4.6）。証明は「\(\mathcal C_{/y}\) と \(\mathrm{Fun}(\Delta^1,\mathcal C)\times_{\mathcal C}\{y\}\) という \(\mathcal C\) 上の右 fibration の間の写像が fiber ごとに同値」で、段 2 の判定法で回収する。

合成：厳密な合成はない。\(\mathrm{Fun}(\Delta^2,\mathcal C)\to\mathrm{Fun}(\Lambda^2_1,\mathcal C)\) の \((x,y,z)\) 上の fiber が自明 Kan fibration \(\to\mathrm{Map}(x,y)\times\mathrm{Map}(y,z)\) になり、切断を選んで \(\{0,2\}\) に制限すると合成。可縮な選択を除いて一意。

使われ方：充満忠実（1.6）、段 3 の \(\mathcal S\) の写像空間の比較、段 6 の充満忠実性。

模型の比較（質問への答え）：模型 3 が一番すっきりするという感覚は正しく、現代的な扱いもその方向。ただし計算には \(\mathrm{Hom}^R\)、\(N^{hc}\) との比較には \(\mathfrak C[-]\) が要り、「定義は一つ、計算用の模型は別」という使い分けになる。

3.5（1.5）自然同値は各点で判定できる

成分の定義：\(\mathrm{Fun}(K,\mathcal C)\) の辺は \(\alpha\colon\Delta^1\times K\to\mathcal C\)、頂点 \(k\colon\Delta^0\to K\) での成分は \(\Delta^1\times\{k\}\) への制限 \(\alpha_k:=\alpha\circ(\mathrm{id}\times k)\colon\Delta^1\to\mathcal C\)、両端は \(F(k)=\alpha|_{\{0\}\times\{k\}}\)、\(G(k)=\alpha|_{\{1\}\times\{k\}}\)。関手として言えば制限 \(\mathrm{ev}_k\colon\mathrm{Fun}(K,\mathcal C)\to\mathcal C\) で \(\alpha_k=\mathrm{ev}_k(\alpha)\)。単体 \(\Delta^m\to K\) で制限すれば自然性の角柱。

条件中身
\(\alpha\) が \(\mathrm{Fun}(K,\mathcal C)\) で同値逆向きの辺 \(\beta\colon\Delta^1\times K\to\mathcal C\) と、境界 \((\alpha,\beta,\mathrm{id}_F)\)、\((\beta,\alpha,\mathrm{id}_G)\) の 2 単体 \(\Delta^2\times K\to\mathcal C\)（\(K\) 全体の形をした図式で間を埋める）。\(\mathrm{id}_F\) は射影 \(\Delta^1\times K\to K\) と \(F\) の合成
各成分 \(\alpha_k\) が \(\mathcal C\) で同値頂点ごとにばらばらな逆元と 2 単体 \(\Delta^2\to\mathcal C\)

定理：\(\alpha\) が同値 ⟺ 全ての頂点 \(k\) で \(\alpha_k\) が同値。後者のばらばらなデータから前者の整合した逆元と間を埋めるものが出る、という主張。

3.6（1.6）∞ 圏の同値

定義：\(F\colon\mathcal C\to\mathcal D\) が同値 ⟺ \(G\colon\mathcal D\to\mathcal C\) と自然同値 \(GF\simeq\mathrm{id}\)、\(FG\simeq\mathrm{id}\)（関手の ∞ 圏の同値な辺）が存在。自然同値は各点で判定できる（1.5）。Kan 複体同士では \(\mathrm{Fun}(K,L)\) が Kan なので単体的ホモトピー同値と一致。

定理：同値 ⟺ 充満忠実（全ての \(\mathrm{Map}(x,y)\to\mathrm{Map}(Fx,Fy)\) がホモトピー同値）かつ本質的全射（全ての \(d\) にある \(x\) と同値 \(Fx\simeq d\)）。

4.5（2.5）fiber ごとの同値の判定

定理：\(B\) 上の左 fibration の間の \(B\) 上の写像 \(f\colon E\to E'\) について、(1) \(\mathrm{LFib}(B)\) で同値（\(B\) 上の逆写像とホモトピー）、(2) 全ての \(b\) で \(f_b\colon E_b\to E'_b\) がホモトピー同値、(3)（\(B\) 準圏）全空間の圏同値、は同値（(3) は Kerodon Theorem 5.1.6.1 の左 fibration の場合、HTT Prop. 3.3.1.5 も同種）。

(1)⇒(2)：\(B\) 上の逆写像とホモトピーを fiber に制限する。

(2)⇒(1)：\(\mathrm{LFib}(B)\) での米田の議論に帰着：全ての左 fibration \(X\) で \(f_*\colon\mathrm{Fun}_B(X,E)\to\mathrm{Fun}_B(X,E')\) がホモトピー同値なら、\(X=E'\) の \(\pi_0\) 全射で \(fg\simeq\mathrm{id}\)、\(X=E\) の \(\pi_0\) 単射で \(gf\simeq\mathrm{id}\)。\(f_*\) がホモトピー同値なことは：

  1. 単体一つ：\(\{0\}\subset\Delta^n\) が左アノダインなので \(\mathrm{Fun}_B(\Delta^n,E)\to E_{\sigma(0)}\) は自明 Kan fibration、よって \(f_*\) は \(f_{\sigma(0)}\) と同一視できる。単体の上の切断は始点の fiber だけで決まる、というのが fiber で判定できる理由の核心。
  2. 境界：制限 \(\mathrm{Fun}_B(\Delta^n,E)\to\mathrm{Fun}_B(\partial\Delta^n,E)\) は Kan 複体の間の左 fibration。補題：Kan 複体の間の左 fibration は Kan fibration（最後の辺は同値なので相対版 Joyal で \(\Lambda^n_n\) が持ち上がる）。

5.1（3.1）\(N^{hc}\) の復習と、準圏であること

復習：\(\mathfrak C[\Delta^n](i,j)=N(\{S\subseteq[i,j]\mid i,j\in S\},\subseteq)\cong(\Delta^1)^{j-i-1}\)（座標 \(t_k\)、\(k\in S\) なら 1、合成は和集合）。\(N^{hc}(D)_n\) は単体的関手 \(\mathfrak C[\Delta^n]\to D\)。

Hom\((0,n)\) は蓋のない箱：\(t_k=0\) の面は面 \(d_k\) から（\(k\ne i\) だけある）、\(t_k=1\) の面は合成 \(\mathfrak C(0,k)\times\mathfrak C(k,n)\) から（\(\mathfrak C(0,k)\subset d_n\)、\(\mathfrak C(k,n)\subset d_0\) なので \(0\lt i\lt n\) なら全てある）。よって \(\mathfrak C[\Lambda^n_i](0,n)=\sqcap^{n-1}_i\)（\(t_i=0\) の開面を除いた立方体の境界）。

5.3（3.3）写像空間の比較定理

主張（Kerodon Theorem 4.6.7.5）：局所 Kan な \(\mathcal C\) について比較写像 \(\theta\colon\mathcal C(X,Y)\to\mathrm{Hom}^L_{N^{hc}\mathcal C}(X,Y)\) はホモトピー同値（\(\mathrm{Hom}^R\) とは向きの反転を除いて同じ）。一般形（Theorem 4.6.7.8）：\(\mathcal C(X,Y)\) が準圏なら \(\mathrm{Hom}^L\) も準圏で \(\theta\) は圏同値。Kan 性はこの準圏性にだけ使う。

  1. \(\mathrm{Hom}^L\) は \(\mathcal C(X,Y)\) だけで決まる：\(n\) 単体は懸垂 \(\Sigma(K)=(\{x\}\star K)\sqcup_K\{y\}\)（\(K=\Delta^n\)）からの写像。\(\Phi(K):=\mathfrak C[\Sigma K](x,y)\) と置くと \(\mathrm{Hom}(K,\mathrm{Hom}^L)\cong\mathrm{Hom}(\Phi(K),\mathcal C(X,Y))\)、つまり \(\mathrm{Hom}^L\) は \(\Phi\) の右随伴。
  2. \(\Phi(\Delta^n)\) は太らせた \(\Delta^n\)：\(\Phi(\Delta^0)=\Delta^0\)、\(\Phi(\Delta^1)=\Delta^1\)（向き反転、データは \(f_{01},f_{02}\) と \(f_{02}\to f_{01}\) の辺）、\(\Phi(\Delta^2)\) は \(t_1=1\) の辺を潰した正方形。一般に単体は最大元を共有する部分集合の減少列（旗、Kerodon Ex. 4.6.7.27）で、\(\Phi(\Delta^n)\cong\Delta^0\diamond\Phi(\Delta^{n-1})\)（鈍い join）。頂点を \([n]\) の元に送る \(\rho_K\colon\Phi(K)\to K\) が \(\theta\) に対応。
  3. 鍵の補題（Prop. 4.6.7.23）：\(\rho_K\) は圏同値。有限な \(K\) に帰着（フィルター余極限）、\(\Phi\) が余極限と単射を保つので単体ごとの帰納法で \(\Delta^n\) に帰着、\(\rho_{\Delta^n}\) は \(\mathrm{id}\diamond\rho_{\Delta^{n-1}}\)（帰納法）と鈍い join から join への比較（Prop. 4.6.2.12）の合成。
  4. 結論：内アノダインな \(A\to B\) で \(\Phi(A)\to\Phi(B)\) は単射かつ圏同値なので \(\mathrm{Hom}^L\) は準圏。\(\pi_0\mathrm{Fun}(K,M)^{\simeq}\to\pi_0\mathrm{Fun}(K,\mathrm{Hom}^L)^{\simeq}=\pi_0\mathrm{Fun}(\Phi(K),M)^{\simeq}\)（Cor. 4.6.7.26）は \(\rho_K\) の前合成で全単射、よって \(\theta\) は圏同値。\(M\) が Kan ならホモトピー同値。

直観：\(N^{hc}\mathcal C\) の写像空間の単体は \(\mathcal C(X,Y)\) の単体を太らせた形 \(\Phi(\Delta^n)\) で見たもので、太らせても圏同値なのでホモトピー型は変わらない。\(\mathfrak C\) の一般論は要らず、懸垂の場合だけを直接計算する。
