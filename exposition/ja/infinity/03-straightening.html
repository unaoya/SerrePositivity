第 3 章　cocartesian fibration と straightening

基準コミット cf0ddf537（2026-10-23）。対象は F1/ の fibration・transport・straightening の部分と Core/Cocartesian*。パスは SerrePositivity/InfinityCategories/ からの相対パス。

F1 は約 18 万行あり、この層で最大の部分である。この章では、その中心にある straightening 定理の主経路をたどる。

目標（Kerodon Cor. 5.6.0.6）. 小さい quasicategory \(B\) について、\(B\) 上の左 fibration の ∞ 圏と、関手 ∞ 圏 \(\mathrm{Fun}(B,\mathcal S)\) は同値。

Cat∞ 値版（Kerodon Thm. 5.6.0.2）. \(B\) 上の cocartesian fibration の ∞ 圏と \(\mathrm{Fun}(B,\mathrm{Cat}_\infty)\) は同値。

状態：空間値版は任意の小さい quasicategory の底で完成している。Cat∞ 値版は、分類写像を通常の圏の nerve の底で構成し、同値性は有限単体 \(\Delta^n\) の底でだけ示したところで止まっている（第 II 段へ送られた）。

1. cocartesian 辺と cocartesian fibration

定義

\(p\colon X\to B\) の辺 \(e\) が \(p\)-cocartesian とは、最初の辺が \(e\) であるような外側ホーン \(\Lambda^{n+2}_0\to X\) の、\(p\) に関する持ち上げ問題がすべて解けることをいう（Kerodon Def. 5.1.1.1）。

def IsCocartesianEdge {X B : SSet.{u}} (p : X ⟶ B) (e : X _⦋1⦌) : Prop :=
  ∀ (n : ℕ) (a : (horn (n + 2) 0 : SSet.{u}) ⟶ X)
    (b : (Δ[n + 2] : SSet.{u}) ⟶ B),
    a.app (Opposite.op ⦋1⦌) (initialHornEdge n) = e →
    ∀ sq : CommSq a (horn (n + 2) 0).ι p b, sq.HasLift

\(p\) が cocartesian fibration とは、inner fibration であって、底の任意の辺に対し、始点を指定した cocartesian な持ち上げが存在することをいう（Kerodon Def. 5.1.4.1）。Lean では cocartesianFibrations（MorphismProperty）とそれを包む型クラス CocartesianFibration の二段で持つ。cartesian 側も同じ形で並んでいる（F1/CartesianFibration）。

第 1 章の Joyal の定理は、「\(B=\Delta^0\) のとき、cocartesian 辺は可逆な辺に一致する」という特殊な場合だと読める。実際、証明の道具も同じで、外側ホーンを join で書き直す議論が相対版に一般化されている（Core/Cocartesian*、Core/RelativeOuterHorn）。

transport

cocartesian fibration では、底の辺 \(e\colon b\to b'\) に沿って fiber の間の関手 \(e_!\colon X_b\to X_{b'}\) が「ほぼ一意に」決まる。

「選択空間が可縮」という形で一意性を述べるのが、以後の構成の基本の型である。選び方の任意性を、可縮な Kan 複体の点を選ぶことに閉じ込めておく。

2. ∞ 圏を作る ∞ 圏：coherent nerve

straightening の両辺に現れる ∞ 圏（\(\mathcal S\)、Cat∞、左 fibration の ∞ 圏）は、すべて同じ方法で作られる。Hom が Kan 複体であるような単体的圏を作り、その coherent nerve を取る。

定理（HTT Prop. 1.1.5.10、Kerodon Thm. 2.4.5.1）. 各 Hom が Kan 複体である単体的圏 \(\mathcal C\) について、coherent nerve \(N^{hc}(\mathcal C)\) は quasicategory。

Lean：simplicialNerve_quasicategory（instance、Coherent/Quasicategory）。coherent nerve 自体は Mathlib の SimplicialNerve をそのまま使っている。

宇宙の扱い

対象が宇宙 \(u\) の単体的集合なので、それらを集めた ∞ 圏は宇宙 \(u+1\) に入る。関手 ∞ 圏 \(\mathrm{Fun}(B,\mathcal S)\) を作るには、底 \(B\) も同じ宇宙に持ち上げる必要がある。そのため主定理には (SSet.uliftFunctor.{u + 1, u}).obj B が現れる。宇宙の持ち上げと、その逆向きの「反映」（F1/Universe*、26 ファイル）は、この層の目立たないが避けられない作業になっている。

原典との違い：写像の向き

HTT は straightening \(\mathrm{St}\)（左随伴）を単体的圏の側で作り、covariant モデル構造の Quillen 同値として示す（HTT §2.2.1、Thm. 2.2.1.2）。Kerodon は unstraightening を主に扱う。ここでは「fibration → 関手」の向きの写像を直接 ∞ 圏の射として作り、それが同値であることを示している。モデル構造は使わない。逆向き（unstraightening）は、本質的全射性の証明の中で対象ごとに現れるだけである。

4. 証明の経路

二段に分かれる。まず通常の圏の nerve \(N(C)\) を底とする場合を示し、次に一般の \(B\) をそれに帰着させる。

第一段：底が通常の圏の nerve の場合

strict transport。\(N(C)\) 上の左 fibration \(X\) と対象 \(c\) に対し、under 圏の nerve \(N(C_{c/})\to N(C)\) 上の \(X\) の切断の空間 \(\mathrm{Fun}_{/N(C)}(N(C_{c/}),X)\) を考える。\(C_{c/}\) は始対象 \(\mathrm{id}_c\) を持ち、その包含 \(\{c\}\hookrightarrow N(C_{c/})\) は left anodyne なので、切断を始対象に制限する写像は trivial Kan fibration になる（relativeFunctorOverPre_trivialKanFibration_of_leftAnodyne、F1/RelativeSectionInitialRestriction）。よってこの空間は fiber \(X_c\) と同値である。さらに \(c\mapsto C_{c/}\) は厳密に反変なので、\(c\mapsto\mathrm{Fun}_{/N(C)}(N(C_{c/}),X)\) は厳密な関手 \(C\to\mathrm{Kan}\) になる。fiber のままでは transport の選択があいまいで厳密な関手にならないが、切断の空間に置き換えることでそのあいまいさが消える。

def strictTransportDomains (C : Type u) [Category.{u} C] : Cᵒᵖ ⥤ Over (nerve C)
-- under 圏の忘却を、nerve C 上の反変図式に束ねたもの

lemma strictTransportDomains_realization (C : Type u) [Category.{u} C] :
    (relativeSectionEnrichedDiagram (strictTransportDomains C)).realization
      = leftStraighteningCoherentMap C

この構成は fibration \(X\) についても単体的に関手的なので、二変数の単体的関手「左 fibration の単体的圏 × \(C\) → Kan」が得られる。その coherent nerve を取って curry したものが分類写像 leftStraighteningCoherentMap C である（F1/StrictTransport*）。

  • 充満忠実性（leftStraighteningCoherentMap_isFullyFaithful）：Hom への作用を strict transport の像の Hom と比較する。単体的関手の Hom が同値なら coherent nerve の写像は充満忠実、という判定を使う（F1/StrictTransportEnrichedFunctor など）。
  • 本質的全射性（leftStraighteningCoherentMap_isEssentiallySurjective）：与えられた coherent 図式 \(F\) に対し、小さい unstraightening（全空間）\(\mathrm{Un}(F)\) を作り、その straightening が \(F\) と同型であること（余単位 leftStraighteningInfinityCounit）を示す。この部分は実は一般の底 \(B\) で直接示されていて（leftStraighteningInfinityMap_isEssentiallySurjective、F1/LeftStraighteningEssentialSurjectivity）、nerve の場合はその特殊化である。unstraightening の構成には、strict な図式なら weighted nerve（Kerodon Def. 5.3.3.1、F1/WeightedNerve）、一般の coherent 図式なら F1/Coherent* の表現の議論を使う。

結論：leftStraighteningCoherentMap_isQCatEquivalence（F1/LeftStraighteningCoherentEquivalence）。

第二段：一般の底への帰着

任意の単体的集合 \(B\) に対し、単体の圏 \(\Delta_{/B}\)（Lean では TransportSimplexCategory B）と、各単体をその最初の頂点に送る写像

\[ \mathrm{fv}\colon N(\Delta_{/B})\longrightarrow B \]

を考える。鍵になるのは次の事実である。

命題. \(\mathrm{fv}\) は、「始点を保つ辺」の集合 \(W\) に関する局所化である。すなわち \(W\) を反転する関手 \(N(\Delta_{/B})\to\mathcal E\) は、\(B\) からの関手に（同型を除いて一意に）降りる。

Lean：transportSimplexFirstVertexMap_isLocalization（F1/TransportLocalizationAllBases）。証明は \(B\) の骨格に沿った帰納法で、境界の次元、小さい余積、骨格の pushout、可算の逐次余極限の各段で局所化が保たれることを示す（F1/TransportLocalization*）。\(B\) に quasicategory であることは仮定しない。

\(N(\Delta_{/B})\) は通常の圏の nerve なので、第一段が使える。\(B\) 上の左 fibration を \(\mathrm{fv}\) で引き戻して straightening すると、\(W\) を反転する関手 \(N(\Delta_{/B})\to\mathcal S\) が得られる。これを局所化の普遍性で \(B\) へ降ろしたもの（transportUliftFunctorDescent）が、一般の底の分類写像 leftStraighteningInfinityMap B である。

本質的全射性は上で見たとおり一般の底で示されているので、残るのは充満忠実性である。同値性は次の判定に帰着する（F1/LeftStraighteningFirstVertexCriterion）。

lemma leftStraighteningInfinityMap_isQCatEquivalence_iff_firstVertexBaseChange (B : SSet.{u}) :
    IsQCatEquivalence (leftStraighteningInfinityMap B) ↔
      IsFullyFaithful (leftFibrationInfinityBaseChange (transportSimplexFirstVertexMap B))

つまり、「左 fibration を \(\mathrm{fv}\) で引き戻す操作が充満忠実」であればよい。これは相対関手空間への引き戻しの作用の同値性として示され（F1/LeftFibrationBaseChangeFullyFaithful）、宇宙を持ち上げた側で示したものを元の宇宙へ反映して閉じる（F1/LeftFibrationFirstVertexUlift、F1/UniverseRelativePullbackReflection）。

Lean の構造：主経路の入口ファイル

  1. F1/CatInfinity、F1/LeftFibrationInfinity：両辺の ∞ 圏
  2. F1/StrictTransportDomains → StrictTransportJointEvaluation：nerve 上の分類写像
  3. F1/LeftStraighteningCoherentFullyFaithful、LeftStraighteningEssentialSurjectivity → LeftStraighteningCoherentEquivalence：nerve 上の同値

この章で押さえること

  1. cocartesian 辺は外側ホーン \(\Lambda^{n+2}_0\) の相対的な持ち上げで定義され、Joyal の定理の相対版になっている。transport の一意性は「選択空間が可縮」という形で述べる。
  2. \(\mathcal S\)、Cat∞、\(\mathrm{LFib}(B)\) はすべて、Kan 豊穣な単体的圏の coherent nerve（Mathlib の SimplicialNerve）。宇宙が一つ上がる。
  3. straightening は「fibration → 関手」の向きで直接作り、充満忠実かつ本質的全射で同値を示す。モデル構造は使わない。
  4. 通常の圏の nerve の底では、under 圏上の切断の空間で厳密な関手（strict transport）を作る。一般の底は、単体の圏からの first vertex 写像が局所化であることで帰着させる。
  5. 空間値版は完成。Cat∞ 値版は有限単体の底まで（3.7 万行が休止中）。
