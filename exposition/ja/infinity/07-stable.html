安定性（HA Def. 1.1.1.9）

class IsStable (X : SSet.{u}) [Quasicategory X] : Prop extends HasZeroVertex X where
  fiber_exists {x y : X _⦋0⦌}
    (f : SSet.Truncated.Edge (X := (truncation 2).obj X) x y) : Nonempty (FiberSquare f)
  cofiber_exists {x y : X _⦋0⦌}
    (f : SSet.Truncated.Edge (X := (truncation 2).obj X) x y) : Nonempty (CofiberSquare f)
  fiber_iff_cofiber (t : ZeroTriangle X) : IsFiberSequence t ↔ IsCofiberSequence t

零対象を持ち、すべての射が fiber と cofiber を持ち、零角の四角形について fiber 列と cofiber 列が一致すること。三条件をそのまま書いている。三角圏の構造や \(\Sigma\) の可逆性は定義に含めず、定理として導く（Stable/Definition）。

2. ホモトピー圏の三角構造

安定 ∞ 圏 \(X\) のホモトピー圏 \(hX\) に、Mathlib の三角圏の構造が instance として入っている。

構造Lean場所
加法圏preadditive_hoStable/HomotopyPreadditive
suspension 関手 \(\Sigma\colon hX\to hX\)suspensionFunctor XStable/Suspension
\(\mathbb Z\) によるシフトhasShift_hoStable/Shift
前三角圏（distinguished = cofiber 三角形と同型なもの）pretriangulated_hoStable/PretriangulatedInstance
三角圏（八面体公理 TR4）isTriangulated_hoStable/TriangulatedInstance

Σ の作り方：零対象の間に \(x\) を置いた四角形 \(x\to0\), \(0\to\Sigma x\) を「suspension の四角形」とする。こうした四角形の ∞ 圏から始点を取り出す評価写像は、安定性から trivial Kan fibration になる。その逆（切断）を選び、反対の角を評価したものが \(\Sigma\) である。逆の選び方の違いは可逆な 2-胞体で比較する（suspensionFunctorChoiceIso）。第 2 章で見た「性質を持ち上げ性に変えてから切断を選ぶ」型の構成である。

distinguished な三角形：cofiber の四角形から作った三角形 \(x\to y\to z\to\Sigma x\) と同型な三角形の全体（cofiberDistinguishedTriangles）。八面体公理は、二つの cofiber 四角形を貼り合わせた図式（Stable/CofiberOctahedron*）から導く。

長完全列

fiber 列 \(x\to y\to z\) に \(\mathrm{Hom}_{hX}(w,-)\) を適用すると、全整数次数の長完全列が得られる（fiberHomSequence_exact、反変版も、Stable/LongExactSequence）。接続準同型は fiberHomConnecting で、評価式も公開されている。

3. 完全関手

class IsExactFunctor {X Y : SSet.{u}} (F : X ⟶ Y) : Prop
  -- 零対象と cofiber 列を保つ
  • 安定な \(X\) からの完全関手は fiber 列も保つ（IsExactFunctor.preservesFiber）。逆に fiber 列を保てば完全（isExactFunctor_of_preservesFiber）。
  • 一般の押し出し・引き戻しの四角形を保つ（preservesPushoutSquare、preservesPullbackSquare）。零角の長方形への貼り合わせで、零角の場合に帰着させる。
  • ホモトピー圏の三角関手になる（exactFunctor_isTriangulated。CommShift ℤ つき）。完全関手の間の自然変換はシフトと両立する。

このほか、部分集合の「安定閉包」（cofiber・fiber・シフトで閉じた充満部分圏、stableHoClosure、Stable/StableHoClosure）とその三角圏の構造がある。Verdier 列や局所化不変量（K 理論側）で使われる。

4. 作業中：Ω による安定性の判定（D-7）

目標（HA Cor. 1.4.2.27 (3) ⇒ (1)）. 有限極限を持つ pointed ∞ 圏で、loop 関手 \(\Omega\) が同値なら安定。

用途：スペクトラム Sp（Kan 複体の Ω スペクトラムの模型）が安定 ∞ 圏であることを示す入力（Sp-5 d3）。Sp は局所化不変量の値域になる。

状態：Σ と Ω の随伴、有限余極限の存在までは証明済み。最後の段階（IsStable の結論）として、HA Lemma 1.4.2.15・Prop. 1.4.2.13 の「切除」の議論を格子状の図式で形式化している（Stable/Excision*、116 ファイル）。

格子（ExcisionSquareGrid、ExcisionGridExtension）は、元の四角形と suspension の四角形を組み合わせた比較の格子である。各面が押し出しであることを一つずつ示し、貼り合わせによって元の四角形が引き戻しであることを回収する（計画文書の記述による）。

  4. 作業中なのは Ω による安定性の判定（HA 1.4.2.27）だけで、スペクトラムのために必要。
