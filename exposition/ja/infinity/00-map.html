1. 基本の語彙：∞ 圏の符号化

Kerodon・HTT と同じく quasicategory 模型を使う。束ねた型は作らず、単体的集合 X : SSet.{u} に Mathlib の型クラス [Quasicategory X]（内ホーン充填）を添える。以下の対応が全体の前提になる。

極限の定義

図式 \(p\colon K\to\mathcal C\) 上の錐は join からの射 \(\Delta^0\star K\to\mathcal C\) で \(K\) 上 \(p\) に一致するもの。極限とは slice \(\mathcal C_{/p}\) の終対象である（HTT Def. 1.2.13.4）。Lean ではこれがそのまま定義になっている。

abbrev JoinCone {K X : SSet.{u}} (p : K ⟶ X) :=
  {F : join (Δ[0] : SSet.{u}) K ⟶ X // joinInr Δ[0] K ≫ F = p}

def IsLimitCone {K X : SSet.{u}} {p : K ⟶ X} (c : JoinCone p) : Prop :=
  IsTerminalVertex (X := sliceOver p) c

終対象は「境界からの拡張がいつでもできる」という充填条件で定義され、写像空間の可縮性との同値は定理として別に証明されている。定義そのものには Quasicategory の仮定が要らない点に注意する。

写像空間

写像空間には右 pinched Hom を使う。その \(n\) 単体は \(\mathcal C\) の \((n+1)\) 単体で、最初の \(n+1\) 個の頂点が張る面が \(x\) で定値になり、最後の頂点が \(y\) になるもの。

structure Simplex (n : ℕ) where
  val : X _⦋n + 1⦌
  source : X.map (front n).op val = constant x n
  target : X.map (lastVertex n).op val = y

dg nerve の写像空間と比べやすいように、この模型が選ばれている（第 8 章）。名前に pinchedHomMap を含む補題は、F2 以降でも「写像空間の上の同値」を述べるときの共通の言葉になっている。

同値

同値は「逆向きの関手と、二つの合成から恒等への自然同値がある」と定義する（Kerodon Def. 4.5.1.10）。Joyal のモデル構造は使わない。

方針上の制約

主経路では [ModelCategory SSet] のような仮定を置かない。こうした仮定は公理監査を通ってしまうが、実際には満たせない。モデル圏は、古典的な対象を ∞ 圏化する γ 層（coherent nerve、ホモトピー極限、Quillen 随伴）でだけ使う。
