第 4 章　Yoneda・随伴・局所化・cofinality・Kan 拡張

基準コミット 5af94602c（2026-10-23）。対象は F1/ の前層・Yoneda・twisted arrow と F1B/。パスは SerrePositivity/InfinityCategories/ からの相対パス。

この章の内容は二つの系統に分かれる。

  • F1 側（straightening を使う）：前層 ∞ 圏と Yoneda 埋め込み。Hom 関手は twisted arrow の straightening として作る。
  • F1B 側（straightening を使わない）：随伴、局所化と反射的部分圏、cofinality、Kan 拡張、通常の圏論との比較。

F1B は「推移的にも straightening に依存しない」という規則のもとで書かれている。その副作用がコードの複製である（記録）。

1. 前層 ∞ 圏

def PresheafInfinity (C : SSet.{u}) : SSet.{u + 1}
-- = Fun((ULift C)ᵒᵖ, 𝒮)、内部 Hom で定義
instance presheafInfinity_quasicategory (C : SSet.{u}) : Quasicategory (PresheafInfinity C)

\(\mathcal S\) が quasicategory なので、底 \(C\) に充填条件がなくても \(\mathcal P(C)\) は quasicategory になる。基本的な操作は、制限 \(f^*\)（presheafInfinityRestriction。合成を逆順の合成に厳密に写す）、評価（presheafInfinityEvaluation）、定値前層（constantPresheafInfinity）である（F1/PresheafInfinity）。

前層 ∞ 圏は小さい極限・余極限を無条件に持ち、それらは評価で保存・検出される（presheafInfinity_hasLimit、presheafInfinity_hasColimit）。証明は、第 2 章の「関手 ∞ 圏の極限は各点で計算できる」と、\(\mathcal S\) の極限・余極限（straightening 経由。第 5 章 §3）を組み合わせたもの。

2. Hom 関手と Yoneda 埋め込み

構成

Kerodon 第 8 章と同じく、Hom 関手は twisted arrow ∞ 圏から作る。\(\mathrm{Tw}(C)\to C^{\mathrm{op}}\times C\) は左 fibration で、その fiber は写像空間 \(\mathrm{Map}_C(x,y)\) である。これを第 3 章の straightening で分類すると、関手

\[ \mathrm{Hom}\colon C^{\mathrm{op}}\times C\longrightarrow\mathcal S \]

が得られる。第二変数で curry すると Yoneda 写像 \(C\to\mathcal P(C)\) になる。

def twistedArrowHomInfinity (C : SSet.{u}) [Quasicategory C] :
    (SSet.uliftFunctor.{u + 1, u}).obj (C.op ⊗ C) ⟶ SpaceInfinity.{u}
def yonedaInfinityMap (C : SSet.{u}) [Quasicategory C] :
    (SSet.uliftFunctor.{u + 1, u}).obj C ⟶ PresheafInfinity C
def representablePresheafInfinity {C : SSet.{u}} [Quasicategory C] (c : C _⦋0⦌) :
    (SSet.uliftFunctor.{u + 1, u}).obj C.op ⟶ SpaceInfinity.{u}

場所：F1/YonedaInfinityConstruction。twisted arrow の性質（fiber の計算、表現可能な場合の比較）は F1/TwistedArrow*（27 ファイル）にある。

原典との違い

HTT §5.1.3 は Yoneda 埋め込みを単体的圏の側で作り、モデル構造を通して ∞ 圏の関手にする。ここでは Kerodon §8.2〜8.3 と同様に、twisted arrow と straightening で ∞ 関手として直接作っている。ただし Yoneda が使うのは、straightening の分類写像の構成（F1/LeftStraighteningAllBases）、対象ごとの表現、unstraightening の写像空間比較であって、第 3 章の同値定理 leftStraighteningInfinityMap_isQCatEquivalence そのものには依存していない（import の閉包で確認）。

3. 随伴

定義

随伴は Kerodon Def. 6.2.1.1 と Remark 6.2.1.4 に従い、ホモトピー 2-圏での随伴として定義する。すなわち、単位・余単位が \(h\,\mathrm{Fun}\) の射で、三角恒等式が \(h\,\mathrm{Fun}\) で成り立つものである。Mathlib の quasicategory の strict bicategory（SSet.QCat.strictBicategory）の Bicategory.Adjunction をそのまま使っている。

abbrev QCatAdjunction {X Y : SSet.{u}} [Quasicategory X] [Quasicategory Y]
    (F : X ⟶ Y) (G : Y ⟶ X) := Bicategory.Adjunction (qcatMap F) (qcatMap G)

ホモトピー 2-圏での定義は扱いやすい一方で、「関手 ∞ 圏の中の随伴」や「随伴の空間」のような高次の情報は含まない。必要になるのは写像空間の同値までであり、それは上の表のように定理として得られる。

4. 局所化と反射的部分圏

局所化

def IsLocalization {X D : SSet.{u}} (F : X ⟶ D) (W : Set (X _⦋1⦌)) : Prop :=
  ∃ hF : InvertsEdges F W, ∀ (E : SSet.{u}) [Quasicategory E],
    IsQCatEquivalence (localizationPrecomposition F W hF E)

\(F\) が \(W\) を反転し、任意の quasicategory \(E\) について、前合成 \(\mathrm{Fun}(D,E)\to\mathrm{Fun}_W(X,E)\)（\(W\) を反転する関手の充満部分 ∞ 圏）が同値であること（Kerodon Prop. 6.3.1.13(2) の普遍性）。この定義は第 3 章の一般の底への帰着（first vertex 写像が局所化）で決定的に使われている。

反射的部分圏

structure ReflectiveSubcategory (X : SSet.{u}) [Quasicategory X] (P : X _⦋0⦌ → Prop) where
  reflector : X ⟶ (fullSubcomplexOnVertices X P : SSet.{u})
  adjunction : QCatAdjunction reflector (fullSubcomplexOnVertices X P).ι

頂点の条件 \(P\) が張る充満部分 ∞ 圏への、包含の左随伴を指定したもの。ここから次が導かれる（F1B/Reflective*）。

  • 余単位は可逆で、\(L\circ L\simeq L\)（counitIso、idempotentIso）
  • 局所対象（単位が可逆な対象）は本質的像と一致する（isLocal_iff_essentialImage）
  • 反射は、自身が反転する辺についての局所化（ReflectiveSubcategory.isLocalization）

一般の局所化の存在（Bousfield 局所化）は含まれていない。これは presentable の理論（第 6 章、P レーン）の範囲である。

5. cofinality

def IsLeftCofinal {A B : SSet.{u}} (i : A ⟶ B) : Prop :=
  ∀ (E : SSet.{u}) (p : E ⟶ B) [LeftFibration p],
    IsSimplicialHomotopyEquivalence (cofinalFunctorPre p (𝟙 B) i)

任意の左 fibration \(E\to B\) について、切断の空間の制限 \(\mathrm{Fun}_{/B}(B,E)\to\mathrm{Fun}_{/B}(A,E)\) がホモトピー同値であること（Kerodon Def. 7.2.1.1）。極限を計算する向きが left、余極限の向きが right である。

6. Kan 拡張

定義：各点の条件

\(\delta\colon K\to C\)、\(F_0\colon K\to D\) と、\(F\colon C\to D\) および変換 \(\beta\colon F_0\Rightarrow F\delta\) について、\(F\) が左 Kan 拡張であるとは、各 \(c\in C\) で、局所図式

\[ K\times_C C_{/c}\longrightarrow K\xrightarrow{F_0}D \]

の上の誘導された余錐（頂点 \(F(c)\)）が余極限であることをいう（Kerodon Variant 7.3.1.5）。

def IsLeftKanExtension {K C D : SSet.{u}} (δ : K ⟶ C) (F₀ : K ⟶ D) (F : C ⟶ D)
    (β : SSet.Homotopy F₀ (δ ≫ F)) : Prop :=
  ∀ c : C _⦋0⦌, ∃ t : LeftKanCoconeTransport δ F₀ F β c, IsColimitCone t.cocone

変換 \(\beta\) は単体的ホモトピー（\(K\times\Delta^1\to D\)）として厳密に持つ。\(h\,\mathrm{Fun}\) の射として持つ版が IsLeftKanExtensionHom である（F1B/KanExtensionHom）。

証明の方針（存在）

各点で余極限を選ぶだけでは、それらを一つの関手 \(F\) に束ねられない。そこで「相対 join」による表示を使う。拡張の問題を \(C\) の単体に沿った相対的な延長の問題に書き直し（LeftKanRelativeJoinRealization）、各単体で局所余極限の普遍性から延長を作る。そのうえで厳密化（Strictification）して、元の \(\beta\) を保ったまま関手に組み立てる（F1B/KanGlobal*、KanRelative*）。第 2 章の「関手 ∞ 圏の極限の各点計算」と同じ型の議論で、各点の選択を骨格に沿って自然な族へ延ばしていく。

7. 通常の圏論との整合（B5）

F1B では、∞ 圏の概念を通常の圏の nerve に制限すると Mathlib の概念に一致することを確かめている（F1B/KanNerve*、71 ファイル）。

  • 随伴：kanNonempty_adjunction_iff_nerveAdjunction
  • 左右の Kan 拡張（pointwise）：kanNerve_isLeftKanExtensionHom_iff_pointwise、kanNerve_isRightKanExtensionHom_iff_pointwise
  • 局所的な Kan 錐の双方向の移送：kanNerveLeftCoconeTransport_cocone、kanNerveRightConeTransport_cone

定義が意図どおりであることを確かめる検算の役目を果たしている。第 2 章で見たとおり、一般の極限についての同種の比較は、Core にはまだ小さな例しかない。

この章で押さえること

  1. Hom 関手は twisted arrow の straightening で作り、Yoneda はそれを curry したもの。充満忠実性は「Yoneda 写像そのものの Hom 作用」として示している。
  2. 随伴は Mathlib のホモトピー 2-圏の随伴で、写像空間の同値は定理として得る。
  3. 局所化は「前合成が反転関手の ∞ 圏への同値」という普遍性で定義し、第 3 章の first vertex の議論で使われる。反射的部分圏は局所化になる。一般の局所化の存在はまだない。
  4. cofinality は左 fibration の切断空間で定義し、anodyne と trivial Kan fibration の分解や Quillen A 型の判定で扱う。
  5. Kan 拡張は各点の余極限条件で定義し、存在 ⇔ 局所余極限、一意性、充満忠実な場合の単位の可逆性、nerve での古典との一致が揃っている。
