第 1 章　単体的集合と Kan 複体

基準コミット 91d8dc9cd（2026-10-28）。計画は infinity-foundation-plan.md（10-28 版）。 ファイルの場所は SerrePositivity/ からの相対パス。Mathlib のものは「Mathlib」と書く。

この章は、整備後の最下層 Simplicial と、Core の上の Kan・Kan/Pointed を扱う。 内容は次の三つに分かれる。

  • 単体的集合の組合せ論：horn、anodyne、置き換え
  • 空間の理論：ホモトピー群、長完全列、Whitehead、塔

いま、これらの多くは KST/Spectra・KST/Comparison・HomotopicalAlgebra に散らばっている（第 0 章 §5）。各節の末尾に、いまの所在と移し先を書く。

1. 単体的集合の組合せ論（Simplicial）

1.1 標準単体・境界・horn

基本の対象は Mathlib にある（open Simplicial で記法が使える）。

数学Lean（Mathlib）
標準 \(n\) 単体 \(\Delta^n\)Δ[n]（SSet.stdSimplex）
境界 \(\partial\Delta^n\)∂Δ[n]（SSet.boundary n、Δ[n] の部分複体）
horn \(\Lambda^n_i\)：\(\Delta^n\) から \(i\) 番目の面と内部を除いたものΛ[n, i]（SSet.horn n i）

horn \(\Lambda^n_i\) は、\(0 < i < n\) のとき内 horn、\(i = 0, n\) のとき外 horn という。

1.2 Kan 複体と quasicategory

どちらも「horn の充填」で定義される。

\[ \begin{array}{ll} \text{Kan 複体：} & \text{すべての horn } \Lambda^n_i \to X \text{ が } \Delta^n \to X \text{ に延びる} \\ \text{quasicategory：} & \text{内 horn } \Lambda^n_i \to X\ (0 < i < n) \text{ が延びる} \end{array} \]
  • class Quasicategory (S)（Mathlib）。Kan 複体は quasicategory である（インスタンスがある）。
  • KanComplex S（Mathlib）は HomotopicalAlgebra.IsFibrant S の別名として定義されている。fibration の族は「すべての horn の包含 J に対する右持ち上げ性質」J.rlp で与えられ、Kan fibration は Fibration f と書く。

Mathlib の Kan 複体は「モデル圏の言葉」で書かれているが、モデル圏は仮定していない

Mathlib は単体的集合に「fibration の族」「cofibration の族」（CategoryWithFibrations など）を与えている。具体的には、fibration = horn に対する右持ち上げ性質、cofibration = 単射である。 これは射の族を指定しているだけで、Quillen のモデル構造（ModelCategory SSet）の存在は使っていない。中核は、この語彙を自由に使ってよい。 避けるのは、モデル圏の公理を仮定する [ModelCategory SSet] の方である（第 2 章）。

1.3 anodyne 射と inner anodyne 射

Kan fibration に対して左持ち上げ性質を持つ射を anodyne といい、inner fibration に対して左持ち上げ性質を持つ射を inner anodyne という。

\[ \text{anodyne} = {}^{\text{⧄}}(\text{Kan fibration}),\qquad \text{inner anodyne} = {}^{\text{⧄}}(\text{inner fibration}) \]
  • anodyneExtensions := (fibrations _).llp、innerAnodyneExtensions := innerFibrations.llp（Mathlib）。
  • small object argument により、anodyne 射は「horn の包含の pushout の超限合成の retract」と一致する（anodyneExtensions_eq_retracts_transfiniteCompositions、Mathlib）。
  • pushout-product：anodyne と単射の pushout-product は anodyne、inner anodyne と単射の pushout-product は inner anodyne（anodyneExtensions_unionProd_ι・innerAnodyneExtensions_pushoutObjObjι、Mathlib）。 ここから、Kan 複体や quasicategory への写像の空間 \(\mathrm{Fun}(A, X)\) が再び Kan 複体・quasicategory になることが従う。

1.4 分解と置き換え

small object argument から、どんな射も「anodyne の後に fibration」に分解できる。これを使って、任意の単体的集合を Kan 複体や quasicategory に置き換える。

置き換え主張宣言（いまの所在）
inner anodyne と inner fibration への分解任意の \(f : X \to Y\) は \(X \xrightarrow{i} Z \xrightarrow{p} Y\)（\(i\) は inner anodyne、\(p\) は inner fibration）と分解するexists_innerAnodyne_innerFibration_factorization（InfinityCategories/F1/Simplicial/InnerAnodyneReplacement.lean:37）
quasicategory への置き換え上で \(Y\) が quasicategory なら \(Z\) も quasicategory にできる。第 3 章の「局所化の存在」の証明で使うexists_quasicategory_resolution_over（同 :47）
Kan 置換（関手的）関手 \(R\) と自然変換 \(X \to RX\) で、\(X \to RX\) は anodyne、\(RX\) は Kan 複体AnodyneKanReplacement.functor・unit_anodyne・terminal_rlp（HomotopicalAlgebra/Simplicial/AnodyneKanReplacement.lean:53〜68）
Kan の Ex∞\(\mathrm{Ex}^\infty X = \operatorname{colim}_n \mathrm{Ex}^n X\) は Kan 複体で、\(X \to \mathrm{Ex}^\infty X\) は anodyne。Ex∞ は有限極限を保ち、Kan fibration を保つexInfinity_kanComplex・exInfinityUnit_anodyne・exInfinity_preservesFiniteLimits・exInfinity_map_rlp（KST/Comparison/ExInfinity*）。Ex（一回分）は Mathlib の SSet.ex

二つの Kan 置換の違いは次のとおり。small object argument による置換は作り方が抽象的で、Ex∞ は具体的（細分を使う）。Ex∞ は有限極限を保つので、fiber や pullback と相性がよい。

1.5 prism とホモトピー

写像 \(f, g : X \to Y\) の間のホモトピーは、\(\Delta^1 \times X \to Y\) で、両端が \(f, g\) になるものである（Mathlib の SSet.Homotopy）。 ホモトピー同値 IsSimplicialHomotopyEquivalence f（InfinityCategories/Core/SimplicialHomotopyEquivalence.lean:50）は、逆向きの写像と両側のホモトピーがあることをいう。 prism \(\Delta^1 \times \Delta^n\) の shuffle による分割は Mathlib にあり、端の包含 prismEndpoint は Core/PrismContraction.lean にある。

1.6 宇宙の持ち上げ

Lean では単体的集合が宇宙 u ごとに別の型になるので、宇宙を上げる関手 SSet.uliftFunctor を使う場面がある（例：大きな ∞ 圏 \(\mathcal S\) と小さい対象の比較）。この関手について、次のことが分かっている。

  • 充満忠実で、余極限を保つ。単体・境界・horn を単体・境界・horn に送る（HomotopicalAlgebra/Simplicial/UniverseLift.lean）。
  • horn・境界に対する持ち上げ性質を保ち、かつ反映する（UniverseLiftLifting）。anodyne 射を保つ（UniverseLiftAnodyne の anodyne_map）。
  • Kan 複体・quasicategory・inner fibration・inner anodyne を保つ（InfinityCategories/F1/Universe）。π₀ を変えない（UniverseLiftPiZero）。

注意：UniverseLiftModel・UniverseLiftWeakEquivalence は [ModelCategory SSet] を仮定しており、中核には入れない（計画の R72 で ModelBridge へ）。

3. ホモトピー群（Kan）

3.1 定義

Kan 複体 \(X\) と頂点 \(x\) について、\(\pi_n(X, x)\) は、境界を \(x\) に送る \(n\) 単体 \(\Delta^n \to X\) のホモトピー類である。Mathlib はその材料（基点付きの単体 PtSimplex、関係 RelStruct、積の構造 MulStruct、π₀ SSet.π₀）を持つが、群そのものは持っていない。群は KST/Spectra で作られている。

宣言意味場所
KanHomotopyGroup X n x\(\pi_{n+1}(X, x)\)（添字が一つずれている）。群で、\(n \ge 1\)（\(\pi_{\ge 2}\)）なら可換群KST/Spectra/HomotopyGroups.lean:94、Commutativity.lean:447
KanHomotopyZero X x\(\pi_0\) を基点付き集合とみたものKST/Spectra/HomotopyDegreeZero.lean:26
KanHomotopy X n x本来の添字の \(\pi_n\)：\(0 \mapsto\) KanHomotopyZero、\(n+1 \mapsto\) KanHomotopyGroup X nKST/Spectra/HomotopyIndexing.lean:25

3.2 写像、不変性、π_* 同型

  • Kan 複体の写像は、ホモトピー群の準同型を誘導する。基点付きホモトピーで移り合う写像は、同じ準同型を誘導する（KanHomotopyGroup.map_eq_of_basedHomotopy）。
  • KanPiIsomorphism f：すべての基点とすべての \(n\) で \(\pi_n(f)\) が全単射であること（KST/Spectra/HomotopyIsomorphism.lean:27）。
  • 基点のないホモトピーで移り合う二つの写像は、同時に π_* 同型になるか、同時にならないか、のどちらか（kanPiIsomorphism_iff_of_homotopy）。

3.3 Kan fibration の長完全列

Kan fibration \(p : E \to B\)（\(E, B\) は Kan 複体）と、\(E\) の頂点 \(e\) について、fiber を \(F = p^{-1}(p(e))\) とすると、次の長完全列がある。

\[ \cdots \to \pi_{n+1}(B) \xrightarrow{\ \partial\ } \pi_n(F) \to \pi_n(E) \to \pi_n(B) \to \cdots \to \pi_0(E) \to \pi_0(B) \]
  • fiberLongExact p e（KST/Spectra/FibrationSequence.lean:28）：fiber・全空間・底空間の各所での完全性を、すべての \(n\) についてまとめた主張。fiber は KanFiber p b、包含は fiberι、連結準同型は connecting。
  • 連結準同型は群準同型である：connectingHom p e n : π_{n+2}(B) →* π_{n+1}(F)（添字は KanHomotopyGroup の流儀。FibrationMultiplication.lean:198）。

3.4 Whitehead の定理

Kan 複体の間の写像が π_* 同型なら、ホモトピー同値である。

  • 基点付き版：exists_pointedHomotopyInverse（KST/Spectra/PointedKanWhitehead.lean:80）。π_* 同型な基点付き写像は、基点付きのホモトピー逆を持つ。
  • 基点なし版：homotopyEquivalence_of_kanPiIsomorphism_of_piZero_surjective（InfinityCategories/HomotopyLimits/KanWhiteheadComparison.lean:82）。π_* 同型（すべての基点で）かつ π₀ で全射なら、ホモトピー同値。逆も成り立つ（kanPiIsomorphism_of_homotopyEquivalence）。

§2 の結果と合わせると、Kan 複体の間の写像について、次の四つが同値になる。「π_* 同型」「ホモトピー同値」「∞ 圏としての同値」「（Kan fibration なら）自明 fibration」。

3.5 弱同値の三つの見方

単体的集合（Kan とは限らない）の間の写像 \(f : A \to B\) が「弱同値」であることには、このリポジトリでは三つの言い方がある。

言い方定義宣言
Kan 複体への写像で見るすべての Kan 複体 \(Z\) について、\(\pi_0\mathrm{Fun}(B, Z) \to \pi_0\mathrm{Fun}(A, Z)\) が全単射IsWeakHomotopyEquivalence（InfinityCategories/F1B/Homotopy/WeakHomotopy.lean:38）
anodyne 局所化で見る単体的集合の圏を anodyne 射で局所化した 1 圏（空間のホモトピー圏）で、\(f\) が同型になるanodyneQ（HomotopicalAlgebra/Simplicial/AnodyneHomotopyLocalization.lean:101）

関係を示す結果として、Kan 複体の間の anodyne 射は π_* 同型である（kanPiIsomorphism_of_anodyne、KST/Spectra/AnodyneHomotopyEquivalence.lean:98）。三つが一致することは、第 2 章で「モデル圏を使わない基礎」としてまとめる。

4. 塔と lim¹（Kan）

Kan fibration の塔 \(\cdots \to X_2 \to X_1 \to X_0\) の極限を考える。スペクトラムのホモトピー群の計算や、filtered な状況の比較で使う。

  • 極限は Kan 複体：各 \(X_{n+1} \to X_n\) が Kan fibration で、\(X_0\) が Kan 複体なら、\(\lim X_n\) は Kan 複体で、射影 \(\lim X_n \to X_0\) は Kan fibration（FibrationTower.limit_kanComplex・projection_zero_fibration、KST/Spectra/FibrationTower.lean。HomotopyLimits/KanLimits.lean にも towerLimit_kanComplex がある）。
  • 非可換な lim¹：群の塔 \(G_n\) と準同型 \(q_n : G_{n+1} \to G_n\) について、\(\prod_n G_n\) に「ねじれた共役」で作用させた軌道の集合（TowerLimOne.limOne、KST/Spectra/TowerLimOne.lean:51）。可換群なら、通常の \(\lim^1\) と一致する。
  • Milnor の完全列（KST/Spectra/TowerMilnorExactness.lean・TowerGroupLimitComparison.lean）： \[ 1 \to {\lim_n}^1 \pi_{r+2}(X_n) \xrightarrow{\ \delta\ } \pi_{r+1}(\lim_n X_n) \to \lim_n \pi_{r+1}(X_n) \to 1 \] 右の写像の全射性は limitGroupComparison_surjective、\(\delta\) の単射性と「像 = 核」は limOneBoundary と exists_limOneBoundary_iff による。
  • Mittag–Leffler：塔が Mittag–Leffler 条件を満たせば、\(\lim^1\) は自明になり、ホモトピー群は極限と交換する（subsingleton_of_mittagLeffler・limitGroupEquivOfMittagLeffler）。

6. 基本亜群と necklace

  • 基本亜群：単体的集合 \(A\) の基本亜群を、ホモトピー圏の自由亜群として定義する（simplicialFundamentalGroupoid、KST/SConstruction/FundamentalGroupoidComparison.lean:21）。 anodyne 射 \(A \to B\)（\(B\) は Kan）があれば、\(A\) の基本亜群は \(\mathrm{h}B\) と圏同値になる（fundamentalGroupoidEquivalence、FundamentalGroupoidEquivalence.lean:50）。これで \(\pi_1\) が自由亜群で表示できる。
  • necklace（Dugger–Spivak）：単体を頂点で貼り合わせた「数珠」の形の単体的集合。coherent nerve の写像空間を組合せ的に計算するのに使う（KST/SConstruction/Necklace*）。第 3 章以降の coherent nerve の話で再び出てくる。

  1. Kan 複体と quasicategory は、どちらも horn の充填で定義される（すべての horn か、内 horn だけか）。Mathlib の KanComplex は fibration の族の言葉で書かれているが、モデル圏は仮定していない。
