第 4 章　安定 ∞ 圏と Verdier 列

基準コミット 91d8dc9cd（2026-10-28）。計画は infinity-foundation-plan.md（10-28 版）。整備の計画と状態の正本は形式化の側（infinity-foundation-plan.md、台帳 refactor-ledger.md）にある。表の「今の所在」は 2026-11-12（KL-W1 の後）に引き直した。 ファイルの場所は SerrePositivity/ からの相対パス。LI は KST/LocalizingInvariants の略。

この章では、安定 ∞ 圏の基本と、その中でのVerdier 列を扱う。Verdier 列は「部分圏 \(A\) で割った商 \(B/A\)」を特徴づけるもので、第 5 章の商の構成の目標になる。 このリポジトリには Verdier 列の定義が二つある。その関係もここで説明する。

1. 安定 ∞ 圏の基本

1.1 定義

quasicategory \(X\) が安定であるとは、次の三つが成り立つことをいう（HA 1.1.1.9）。

  1. 零対象を持つ（始対象かつ終対象である対象）。
  2. すべての射が fiber と cofiber を持つ。
  3. 零対象を角に持つ四角形 \[ \begin{array}{ccc} x & \to & y \\ \downarrow & & \downarrow \\ 0 & \to & z \end{array} \] について、「fiber 列（pullback）であること」と「cofiber 列（pushout）であること」が同値。
class IsStable (X : SSet.{u}) [Quasicategory X] : Prop extends HasZeroVertex X where
  fiber_exists   (f : Edge x y) : Nonempty (FiberSquare f)
  cofiber_exists (f : Edge x y) : Nonempty (CofiberSquare f)
  fiber_iff_cofiber (t : ZeroTriangle X) : IsFiberSequence t ↔ IsCofiberSequence t

InfinityCategories/Stable/Definition.lean:24。

関手 \(F : X \to Y\) が完全であるとは、零対象を保ち、cofiber 列を cofiber 列に送ることをいう（IsExactFunctor、Stable/ExactFunctor.lean:37）。 安定 ∞ 圏の間では、これは「有限極限を保つ」「有限余極限を保つ」とも同値である（HA 1.1.4.1）。

1.3 完全関手の ∞ 圏

Verdier 列の普遍性を述べるために、関手 ∞ 圏の中の部分を用意しておく（InfinityCategories/HA/StableInfinityCategories/Exact/ExactFunctorCategory.lean）。

  • exactFunctors X Y：完全関手のなす \(\mathrm{Fun}(X, Y)\) の充満部分 ∞ 圏 \(\mathrm{Fun}^{\mathrm{ex}}(X, Y)\)。
  • zeroingExactFunctors X Y P：頂点の集合 \(P\) を零に送る完全関手のなす部分。
  • zeroingExactPrecomposition q P … Y：\(q : X \to Q\) との前合成 \(\mathrm{Fun}^{\mathrm{ex}}(Q, Y) \to \mathrm{Fun}^{\mathrm{ex}}_{P \mapsto 0}(X, Y)\)。

2. 部分圏を零にすることと、cofiber 辺を可逆にすること

安定 ∞ 圏 \(B\) と頂点の集合 \(P\)（部分圏 \(A\) の対象）について、cofiber が \(P\) に入る射の集合を考える。

\[ W_P \;=\; \{\, f : x \to y \mid \mathrm{cofib}(f) \in P \text{（同型を除いて）}\,\} \]

（cofiberLocalizingEdges P、Stable/CofiberLocalizingEdges.lean:21）。安定 ∞ 圏では、次の同値が基本になる。

命題

関手 \(F : B \to E\)（\(B\) は安定）について、次は同値（inverts_cofiberLocalizingEdges_iff_kills、同 :58）。

  • \(F\) は \(W_P\) の射をすべて可逆にする。
  • \(F\) は \(P\) の対象をすべて零に送る。

理由：\(z \in P\) について、\(0 \to z\) の cofiber は \(z\) なので、\(W_P\) を可逆にするなら \(F(0) \to F(z)\) が可逆になり、\(F(z)\) は零になる。 逆に \(P\) を零に送る完全関手なら、cofiber 列 \(x \to y \to z\) が \(F(x) \to F(y) \to 0\) に移るので、\(F(f)\) は可逆になる。 したがって「\(A\) で割る」とは、「cofiber が \(A\) に入る射を可逆にする局所化」のことである。

3. Verdier 列

3.1 定義（9 人論文による特徴づけ）

安定 ∞ 圏と完全関手の列 \(A \xrightarrow{i} B \xrightarrow{q} C\) が Verdier 列であるとは、次の三つが成り立つことをいう（Calmès ほか 9 名『Hermitian K-theory for stable ∞-categories』II、付録 A.1）。

  1. \(i\) は充満忠実。
  2. \(q\) の核（零に送られる対象）は、ちょうど \(i\) の本質像。
  3. \(q\) は、cofiber が \(i\) の本質像に入る射での局所化（第 3 章の Dwyer–Kan 局所化）。

このとき \(C\) を Verdier 商 \(B/A\) と書く。条件 2 から、\(A\) の像は「retract で閉じた安定部分圏」（厚い部分圏）でなければならない。

structure IsVerdierSequence {A B C : StableCategory.{u}} (i : ExactMap A B) (q : ExactMap B C) : Prop where
  fullyFaithful : IsFullyFaithful i.hom
  kernel (b : B.obj _⦋0⦌) : IsZeroVertex (q.hom.app _ b) ↔ b ∈ essentialImage i
  quotient : IsLocalization q.hom (cofiberLocalizingEdges (essentialImage i))

LI/VerdierSequence.lean:30。StableCategory は「単体的集合・quasicategory であること・安定性」を束ねた構造体、ExactMap は「射・完全性」を束ねた構造体（LI/StableCategories.lean）。

定義から出る基本の補題：

  • kills_inclusion：\(q \circ i\) は \(A\) のすべての対象を零に送る。
  • inverts：\(q\) は cofiber が \(A\) に入る射を可逆にする（§2 の命題から）。
  • universal：どの quasicategory \(E\) についても、前合成 \(\mathrm{Fun}(C, E) \to \mathrm{Fun}_{W}(B, E)\) は同値。

3.2 もう一つの定義：完全関手として普遍的な商

structure IsStableVerdierSequence (i : B ⟶ X) (q : X ⟶ Q) [安定・quasicategory のインスタンス] : Prop where
  fullyFaithful : IsFullyFaithful i
  inclusionExact : IsExactFunctor i
  quotientExact : IsExactFunctor q
  kills (z : B _⦋0⦌) : IsZeroVertex ((i ≫ q).app _ z)
  universal (Y) [Quasicategory Y] [IsStable Y] :
    IsQCatEquivalence (zeroingExactPrecomposition q (像) … Y)

InfinityCategories/HA/StableInfinityCategories/Verdier/StableVerdierSequence.lean:15。

関係：

  • IsVerdierSequence ⇒ IsStableVerdierSequence は成り立つはずで、計画の M1。証明の筋は次のとおり。局所化の普遍性を、安定な行き先と完全関手に制限する。延長した関手が完全であることは、商の射を分数で表して確かめる（第 5 章）。
  • 逆向きには、像が厚いこと（核 = 像）と、完全関手に限らない普遍性（局所化が安定で、Dwyer–Kan 局所化でもあること。M2）が必要である。

3.3 二つの形の関係

束ねた定義の三つの条件は、どれも \(i\) と \(q\) の下の単体的集合の射（i.hom・q.hom）しか使わない。essentialImage i も「i.hom の像と同型な頂点」である。 つまり、束ねた形と束ねない形は、包み方が違うだけで中身は同じである。束ねない形の定義と、束ねた定義との同値補題は、まだコードにない（扱いは形式化の側）。

4. 厚い部分圏

安定 ∞ 圏 \(B\) の充満部分圏 \(A\) が厚いとは、零対象・fiber・cofiber で閉じていて（安定部分圏）、さらに retract で閉じていることをいう。

  • 完全関手の核は、いつも厚い部分圏である。したがって Verdier 列の \(A\)（の像）は厚い。
  • 任意の部分圏 \(A\) で割ると、核は \(A\) の厚い閉包（\(A\) を含む最小の厚い部分圏）になる。これが第 5 章の M7 の「一般の場合」である。

いまの状態：一般の述語はなく、dg 版 dgThickClosureProperty（Derived/DGQuotientThickKernelCriterion.lean、triaRepresentable の retract 閉包）だけがある。 材料として、安定な閉包 StableVertexClosure（InfinityCategories/HA/StableInfinityCategories/StableVertexClosure、零・同型・fiber・cofiber で閉じた最小の集合）と retract 閉包 retractClosure（InfinityCategories/HTT/RetractsAndIdempotentCompletion/RetractClosure.lean:24）がある。

一般の安定 ∞ 圏での厚い部分圏・厚い閉包の定義は、まだコードにない。dg 版との一致は M9（第 5 章）。

5. 随伴による判定と半直交分解

定理（随伴による判定）

\(A \xrightarrow{i} B \xrightarrow{q} C\) について、\(i\) が充満忠実で、\(q\) の核が \(i\) の本質像で、\(q\) が右随伴 \(j\) を持ち、その余単位 \(q j \Rightarrow \mathrm{id}\) が同型（\(j\) が充満忠実）なら、Verdier 列である。

isVerdierSequence_of_adjoint（LI/AdjointVerdier.lean）。条件 3（局所化）は、第 3 章 §5 の「反射による判定」（AdjointLocalization.isLocalization）から出る。

この状況は半直交分解 \(B = \langle A, C \rangle\) に対応する。\(C\) は \(B\) の中に \(j(C) = A^{\perp}\) として実現され、商は Bousfield 型（第 3 章 §6）になる。 このリポジトリでは、次の形で使われている（InfinityCategories/HA/StableInfinityCategories/Semiorthogonal・Lax と KST/LocalizingInvariants）。

  • SemiorthogonalDecomposition.isVerdier：半直交分解から Verdier 列を作る。
  • lax pullback（Tamme）：二つの完全関手 \(f : X \to Z \leftarrow Y : g\) の lax pullback は、\(X\) と \(Y\) の半直交分解を持つ。そこから Verdier 列が得られる（laxDifference_isVerdier・tammeVerdierSequence）。これは Land–Tamme の定理の基礎で、K 理論の excision に使われる。

右随伴が存在しない一般の場合（小さい安定 ∞ 圏の商など）は、この判定は使えない。第 5 章の方法（局所化の存在と分数）が必要になる。

6. 安定 ∞ 圏の ∞ 圏と局所化不変量

  • \(\mathrm{Cat}^{\mathrm{ex}}_\infty\)：安定 ∞ 圏を対象とし、完全関手の ∞ 圏の core を Hom とする単体的圏の coherent nerve（StableInfinity := SimplicialNerve StableQCat、InfinityCategories/HA/StableInfinityCategories/Infinity/StableInfinity.lean）。
  • Verdier 図式：Verdier 列 \(A \to B \to C\) を、\(\mathrm{Cat}^{\mathrm{ex}}_\infty\) の中の四角形 \(A \to B,\ 0 \to C\) として表したもの（VerdierDiagram、InfinityCategories/HA/StableInfinityCategories/Infinity/VerdierDiagrams.lean）。
  • 局所化不変量（Blumberg–Gepner–Tabuada）：\(\mathrm{Cat}^{\mathrm{ex}}_\infty\) からスペクトラムの ∞ 圏への関手 \(E\) で、零を零に送り、Verdier 図式を pullback に送るもの（IsLocalizingInvariant、LI/Invariant.lean）。非連結 K 理論がその代表例。 これはスペクトラムの ∞ 圏 Sp を使うので、KST に残す。

この章で押さえること

  1. 安定 ∞ 圏は「零対象を持ち、fiber・cofiber があり、fiber 列 = cofiber 列」で定義され、ホモトピー圏は三角圏になる。
  2. 安定 ∞ 圏では「部分圏 \(A\) を零にする」ことと「cofiber が \(A\) に入る射を可逆にする」ことが同じなので、商 \(B/A\) は局所化として定義できる。
  3. Verdier 列は「\(i\) が充満忠実、\(q\) の核 = \(i\) の像、\(q\) は cofiber 辺での局所化」の三条件。完全関手だけで普遍な商（IsStableVerdierSequence）はこれより弱い。両者をつなぐのが M1。
  4. \(q\) が充満忠実な右随伴を持てば Verdier 列になる（半直交分解、lax pullback）。一般には右随伴がないので、第 5 章の方法が要る。
