補章　unstraightening

基準コミット 65f9185c1（2026-10-23）。第 3 章の補足で、「Yoneda への道」の段 6 を詳しくしたもの。対象は F1/LeftUnstraightening*、F1/PointedSpace*、F1/SmallLeftUnstraightening* など。パスは SerrePositivity/InfinityCategories/ からの相対パス。

unstraightening は straightening の逆向きの構成で、空間値の関手 \(F\colon B\to\mathcal S\) から、\(B\) 上の左 fibration \(\mathrm{Un}(F)\to B\) で fiber が \(F(b)\) になるものを作る。直観的には「各 \(b\) の上に空間 \(F(b)\) を置き、辺 \(b\to b'\) に沿って \(F\) の写像で貼り合わせた全空間」（Grothendieck 構成の ∞ 版）である。

1. 普遍左 fibration \(\mathcal S_*\to\mathcal S\)

すべての unstraightening の元になるのは、一点空間 \(\ast\in\mathcal S\) の下の coslice、つまり「点つき空間の ∞ 圏」である。

noncomputable def PointedSpaceInfinity : SSet.{u + 1} :=
  sliceUnder (SSet.yonedaEquiv.symm pointSpaceVertex.{u})
noncomputable def pointedSpaceProjection : PointedSpaceInfinity.{u} ⟶ SpaceInfinity.{u}
instance pointedSpaceProjection_leftFibration : LeftFibration pointedSpaceProjection.{u}

場所：F1/PointedSpaces（Kerodon Construction 5.5.2.1、Prop. 5.5.2.2）。\(\mathcal S_*=\mathcal S_{\ast/}\) の対象は「空間 \(K\) と点 \(\ast\to K\)」で、射影は点を忘れる写像である。左 fibration であることは、第 1 章の「quasicategory の coslice 射影は左 fibration」をそのまま使うだけで、新しい議論は要らない。

fiber は空間そのもの

noncomputable def pointedSpaceFiberValueEquivalence (s : SpaceInfinity.{u} _⦋0⦌) :
    QCatEquivalence (vertexFiber pointedSpaceProjection s)
      ((SSet.uliftFunctor.{u + 1, u}).obj (spaceInfinityObject s).obj)

\(\mathcal S\) の頂点 \(s\)（Kan 複体 \(K\) を表す）上の fiber は \(K\) と同値（F1/LeftUnstraighteningFiberValue）。証明の流れは次のとおり。

  1. coslice \(\mathcal S_{\ast/}\) の \(s\) 上の fiber は、左 pinched 写像空間 \(\mathrm{Map}^L_{\mathcal S}(\ast,s)\) と同型（Core の coslice の fiber の計算、F1/PointedSpaceMappingSpaces）。
  2. 左の写像空間を右の写像空間に移す（第 2 章の pinchedHomLeftRightEquivalence）。
  3. coherent nerve の写像空間は元の単体的圏の Hom と同値（coherentHomEquivalence）。\(\mathcal S\) の場合、それは Kan 複体の関手単体集合 \(\mathrm{Fun}(\Delta^0,K)=K\)。

つまり「\(\mathcal S_*\to\mathcal S\) の fiber が \(K\) になる」のは、「\(\ast\) から \(K\) への写像の空間は \(K\) そのもの」ということの言い換えである。

2. 定義：引き戻し

noncomputable def leftUnstraightening {C : SSet.{u + 1}} (F : C ⟶ SpaceInfinity.{u}) :
    SSet.{u + 1} := pullback pointedSpaceProjection F

instance leftUnstraighteningProjection_leftFibration {C : SSet.{u + 1}} (F : C ⟶ SpaceInfinity.{u}) :
    LeftFibration (leftUnstraighteningProjection F)
\[ \begin{array}{ccc} \mathrm{Un}(F) & \longrightarrow & \mathcal S_*\\ \downarrow & \lrcorner & \downarrow\\ C & \xrightarrow{\ F\ } & \mathcal S \end{array} \]

場所：F1/LeftUnstraightening（Kerodon Example 5.6.2.9）。単体的集合としての厳密な引き戻しなので、次のことがほぼ定義から従う。

  • 左 fibration：左 fibration は引き戻しで保たれる。底 \(C\) が quasicategory なら全空間も quasicategory。
  • fiber：\(\mathrm{Un}(F)_c\) は \(\mathcal S_*\) の \(F(c)\) 上の fiber そのものなので、§1 により \(F(c)\) と同値（leftUnstraighteningFiberValueEquivalence）。
  • 底変換：\(k\colon D\to C\) について \(\mathrm{Un}(F\circ k)\cong D\times_C\mathrm{Un}(F)\) は同型（同値ではない。leftUnstraighteningBaseChangeIso、F1/LeftUnstraighteningBaseChange、Kerodon Remark 5.6.2.5）。引き戻しの貼り合わせによる。
  • 底についての関手性：\(\alpha\colon C\to D\) が \(G\circ\alpha=F\) を満たせば、射 \(\mathrm{Un}(F)\to\mathrm{Un}(G)\) が決まり、恒等則・合成則が厳密に成り立ち、四角形は引き戻しになる（leftUnstraighteningMap、_id、_comp、_isPullback）。

この定義の利点

HTT §2.2.1 では unstraightening を、単体的圏の側の straightening の右随伴（モデル圏の右 Quillen 関手）として定義する。そのため、底変換との両立はホモトピーを除いてしか成り立たない。ここでは \(\mathcal S_*\to\mathcal S\) の引き戻しで定義しているので、底変換との両立が厳密な同型になり、それ以後の議論（局所化による一般の底への降下、strict な図式との比較）で「同型を除いて」の管理が一段減る。

3. 宇宙と小ささ

\(\mathcal S\) は宇宙 \(u+1\) にあるので、\(\mathrm{Un}(F)\) も SSet.{u+1} になる。しかし \(B\) 上の左 fibration の ∞ 圏 \(\mathrm{LFib}(B)\)（第 3 章）の対象は宇宙 \(u\) の単体的集合である。そこで二段の手当てをする。

  1. 小ささ：底が各次数で \(u\)-小さければ、引き戻しの単体も \(u\)-小さい（pullback_simplex_small_of_fibers、leftUnstraightening_obj_small、F1/LeftUnstraighteningSmallness）。fiber が \(u\)-小さい Kan 複体だからである。
  2. 縮小：各次数を Shrink して宇宙 \(u\) に戻したものが smallLeftUnstraightening F（F1/SmallLeftUnstraightening）。射影・左 fibration 性・fiber は縮小の同型で移す（smallLeftUnstraighteningFiberValueEquivalence）。相対関手空間も厳密に同型（smallLeftUnstraighteningRelativeFunctorIso。Yoneda の h₂）。

前層（\(C^{\mathrm{op}}\) 上の関手）の場合は、\(C^{\mathrm{op}}\) 上の左 unstraightening を反転して \(C\) 上の右 fibration にする（smallRightUnstraightening、F1/PresheafUnstraightening）。

4. 変換への作用

変換 \(H\colon F\Rightarrow G\)（\(\Delta^1\times B\to\mathcal S\) で両端が \(F\)、\(G\) のもの）から、\(B\) 上の射 \(\mathrm{Un}(F)\to\mathrm{Un}(G)\) を作る。次の持ち上げ問題を解く。

\[ \begin{array}{ccc} \{0\}\times\mathrm{Un}(F) & \xrightarrow{\ \text{標準の点}\ } & \mathcal S_*\\ \downarrow & \nearrow & \downarrow\\ \Delta^1\times\mathrm{Un}(F) & \xrightarrow{\ H\circ(\mathrm{id}\times p)\ } & \mathcal S \end{array} \]

上の辺は引き戻しの第一射影（\(\mathrm{Un}(F)\) の各点が持っている \(F(b)\) の点）。左の包含 \(\{0\}\times X\hookrightarrow\Delta^1\times X\) は left anodyne で、右は左 fibration なので、持ち上げが存在する。持ち上げを \(\{1\}\) で評価すると \(G\circ p\) の上の点つき空間、つまり \(\mathrm{Un}(G)\) への射になる。

5. 写像空間の比較（Yoneda の h₁）

定理. 任意の底 \(B\) と \(F,G\colon B\to\mathcal S\) について、比較写像

\[ M\colon\ \mathrm{Map}_{\mathrm{Fun}(B,\mathcal S)}(F,G)\longrightarrow\mathrm{Fun}_{/B}\bigl(\mathrm{Un}(F),\mathrm{Un}(G)\bigr) \]

は同値（leftUnstraighteningMappingSpaceMap_isQCatEquivalence、F1/CoherentUnstraighteningMappingEquivalence）。底や高次のパラメーターの小ささは要らない。

比較写像 \(M\) の作り方

§4 の持ち上げを、変換一本ずつではなく変換の空間 \(T\) 全体に対して一度に行う（F1/LeftUnstraighteningFamilyLifts）。\(\{0\}\times\mathrm{Un}(F)\times T\hookrightarrow\Delta^1\times\mathrm{Un}(F)\times T\) も left anodyne なので、族ごと持ち上げられる。終点で評価して相対的に curry したものが \(M\)（F1/LeftUnstraighteningMappingSpaceMap）。

同値性の証明：普遍的な族から逆を作る

lemma leftUnstraighteningMappingSpaceMap_isQCatEquivalence ... := by
  let Y := relativeFunctorSpace (leftUnstraighteningProjection G) (leftUnstraighteningProjection F)
  let T := leftUnstraighteningTransformationSpace F G
  let M := leftUnstraighteningMappingSpaceMap F G
  let f := relativeFunctorUncurry (𝟙 Y)                       -- Y 上の普遍的な族
  obtain ⟨t, W, hw₀, hw₁, hwp⟩ := exists_coherentFamily_recovery F G f hf   -- 族 → 変換の族
  ...
  have hleft : Nonempty (FunctorIso (M ≫ t) (𝟙 T)) := UnstraighteningFamilyWitness.unique ...
  have hright := unstraighteningFamilyComparisonIso F G t f hf W hw₀ hw₁ hwp  -- t ≫ M ≅ 𝟙 Y
  ...
  exact ⟨t, hleft, ⟨hright⟩⟩
  1. 普遍的な族：相対関手空間 \(Y\) の恒等射を uncurry すると、\(Y\) をパラメーターとする相対射の族 \(\mathrm{Un}(F)\times Y\to\mathrm{Un}(G)\) が得られる。「\(Y\) の各点が表す射そのもの」の族である。
  2. 族の復元：この族から、\(Y\) をパラメーターとする変換の族 \(t\colon Y\to T\) を作る（exists_coherentFamily_recovery、F1/SmallCoherentFamilyRecovery）。方法は、族の始域と終域を写像円柱（collage）で貼り合わせた fibration を作り、それを straightening の構成で分類する、というもの（docstring：「指定した標準表現を両端に保つ collage を分類し curry する」）。
  3. \(M\circ t\cong\mathrm{id}\)：「変換の族が相対射の族を実現する」という証拠（UnstraighteningFamilyWitness：持ち上げの prism と、始点・終点・射影の三条件）は、同型を除いて一意である（UnstraighteningFamilyWitness.unique）。\(M\) の定義に使った普遍的な持ち上げも、\(t\) から作った持ち上げも、どちらも同じ族の証拠なので一致する。
  4. \(t\circ M\cong\mathrm{id}\)：復元した族を \(M\) で戻すと元の普遍的な族と比較できる（unstraighteningFamilyComparisonIso）。普遍的な族は \(Y\) の恒等射なので、これは \(t\circ M\cong\mathrm{id}_Y\) を意味する。

Yoneda の議論と同じ「普遍元」の型の証明である。2 で straightening の構成（分類写像）を使っているので、この定理は straightening から独立ではないが、straightening の同値定理は使っていない。

可逆性の保存と反映

\(M\) が変換 \(\alpha\) に対応させる射 \(\mathrm{Un}(F)\to\mathrm{Un}(G)\) が同値であることと、\(\alpha\) が可逆であることは同値（leftUnstraighteningMappingVertexMap_isQCatEquivalence_iff、F1/LeftUnstraighteningReflectsEquivalences）。fiber に制限し、普遍射影の transport から各点での可逆性を回収して示す。

6. strict な図式との比較

通常の圏 \(C\) 上の strict な図式 \(F\colon C\to\mathrm{Kan}\) には、古典的な全空間 weighted nerve \(N_F(C)\to N(C)\) がある（Kerodon Def. 5.3.3.1、F1/WeightedNerve。単体は「底の合成可能な射の列」と「各段の標準単体からの自然変換の組」）。これと、coherent な図式とみなした kanDiagramCoherentNerve F の unstraightening を比較する。

  • F1/DirectKanUnstraightening：weighted nerve から、図式自身の coherent な復元への比較。edgewise 細分（F1/Edgewise*、47 ファイル）を経由する。
  • F1/OppositeKanUnstraightening：値を反転した coherent 図式の unstraightening との比較。
  • F1/LocalUnstraighteningStrictification：標準単体上の一般の coherent な図式の小さい unstraightening を、strict な図式の底変換で表す。

これらは主に、straightening の本質的全射性（「任意の coherent 図式は何かの straightening」）の証明で、局所的に strict な模型に帰着させるために使われる。

注意：Un は ∞ 関手としてはまとめられていない

straightening は ∞ 圏の射 leftStraighteningInfinityMap : LFib(B) → Fun(B, 𝒮) として作られ、同値定理もこの射について述べられている（第 3 章）。一方 unstraightening は、対象への作用（§2）、変換への作用（§4、同型を除く関手性）、写像空間への作用（§5）が個別に与えられているだけで、∞ 関手 \(\mathrm{Fun}(B,\mathcal S)\to\mathrm{LFib}(B)\) としては定義されていない。F1/PresheafUnstraightening の docstring にも「前層全体の unstraightening ∞ 関手は主張しない」とある。St が同値である以上、Un はその逆として（選択を通して）得られるので、理論上の欠落ではない。ただ、Un の自然性を直接使いたい場面が出てきたら、そこで初めて必要になる。

どこで使われるか

  • Yoneda の補題：h₁（§5）、h₂（§3）、h₄（§2 の fiber）。表現可能前層の unstraightening が slice になること（h₃）には §7 の再構成を使う。
  • \(\mathcal S\) の極限・余極限（第 5 章 §3）：極限 = \(\mathrm{Un}(F)\) の切断の空間、余極限 = \(\mathrm{Un}(F)\) の全空間。
  • straightening の同値定理：本質的全射性（§7 の余単位）。

この補章で押さえること

  1. \(\mathrm{Un}(F)\) は普遍左 fibration \(\mathcal S_*=\mathcal S_{\ast/}\to\mathcal S\) の \(F\) に沿う厳密な引き戻し。左 fibration 性・fiber・底変換はほぼ定義から従い、底変換とは厳密な同型で両立する。
  2. \(\mathcal S_*\to\mathcal S\) の fiber が \(K\) になるのは、「点からの写像の空間は \(K\)」の言い換え。
  3. 変換への作用は、left anodyne な包含 \(\{0\}\times X\hookrightarrow\Delta^1\times X\) に沿う持ち上げで作り、選択空間は可縮。
  4. 写像空間の比較 \(\mathrm{Map}(F,G)\simeq\mathrm{Fun}_{/B}(\mathrm{Un}F,\mathrm{Un}G)\) は、普遍的な族から逆を復元する議論で示す。復元には straightening の構成（collage の分類）を使う。
  5. Un は ∞ 関手としてはまとめられておらず、対象・変換・写像空間への作用が個別に与えられている。
