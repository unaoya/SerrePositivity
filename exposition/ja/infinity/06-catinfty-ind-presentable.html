1. Cat∞ の写像空間と極限

Cat∞ は coherent nerve として定義されていた（第 3 章）。その写像空間は関手 ∞ 圏の core と同値である。

def catInfinityMappingEquivalence (X Y : QCat.{u}) :
    QCatEquivalence ((SSet.uliftFunctor.{u + 1, u}).obj (catInfinityFunctorCore X Y))
      (catInfinityMappingSpace X Y)

場所：F2/CatMappingSpace。coherent nerve の写像空間が元の単体的圏の Hom と同値であることの一般論（coherentHomEquivalence）の特殊化である。

2. filtered ∞ 圏と交換定理

class IsKappaFiltered (κ : Cardinal.{u}) (C : SSet.{u}) [Quasicategory C] : Prop where
  cocone_nonempty {K : SSet.{u}} (hK : IsKappaSmall κ K) (f : K ⟶ C) :
    Nonempty (JoinCocone f)

κ-small な図式がすべて余錐を持つこと（HTT Def. 5.3.1.7 の形）。cofinality による特徴づけ、coslice の弱可縮性、filtered 余錐の普遍性は揃っている（F2/Filtered*）。

目標（HTT Prop. 5.3.3.3）. \(\mathcal S\) において、filtered 余極限は有限極限と可換。

状態：未完成。Lean では仮定の形 CoherentFilteredLimitExchangeShape K（「形 \(K\) の極限が filtered 余極限と交換する」）として述べられ、空の形と標準単体の形でだけ証明されている（coherentFilteredLimitExchangeShape_of_empty、coherentFilteredLimitExchangeShape_simplex）。一般の有限形への拡張（F2N-1 a7）が F1B レーンで進行中である。

この定理は、Ind の安定性（§3）、compact 対象の有限余極限での閉性（§4）、さらにその先の K 理論側の Indκ(Perf) の扱いの前提になっている。現在のファイル数で見ると、F2 最上位の CoherentColimit* だけで 330 ファイル・約 1.9 万行あり、その大半がこの交換定理の準備である。

4. κ-compact 対象

def IsKappaCompact (κ : Cardinal.{u}) {C : SSet.{max u v}} [Quasicategory C]
    (x : C _⦋0⦌) : Prop :=
  PreservesKappaFilteredColimits.{u, v} κ (C := C) (covariantRepresentableInfinity x)

\(\mathrm{Map}(x,-)\) が小さい κ-filtered 余極限を保つこと。

  • 表現可能前層は \(\mathcal P(C)\) の中でも Ind の中でも κ-compact（indYoneda_isKappaCompact、F2/Compact/IndCompact）
  • retract で閉じる。有限余極限で閉じることは、交換定理を仮定にとった形で証明されている（a7 待ち）
  • compact 生成：\(C\) が冪等完備なら \(C\simeq\mathrm{Ind}_\kappa(C)^\kappa\)（compactGenerationEquivalence、F2/Ind/CompactGeneration）

5. 冪等完備化

冪等射は、高次の整合性まで含めて「冪等図式」（Idem の nerve からの図式、CoherentIdempotent）として扱う（HTT §4.4.5）。

def IsIdempotentComplete (X : SSet.{u}) : Prop :=
  ∀ d : CoherentIdempotent X, Nonempty (StrongSplitting d)

def IsIdempotentCompletion {C D : SSet.{u}} (f : C ⟶ D) : Prop :=
  IsIdempotentComplete D ∧ IsFullyFaithful f ∧
    ∀ d : D _⦋0⦌, ∃ c : C _⦋0⦌, IsVertexRetractOf d (f.app (Opposite.op ⦋0⦌) c)

冪等完備化とは、冪等完備な \(D\) への充満忠実な \(f\) で、\(D\) の任意の対象が像の retract になるもの（HTT 5.1.4.2）。
