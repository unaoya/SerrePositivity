第 1 章　quasicategory の基本

基準コミット 9225a04b3（2026-10-23）。対象は Core/ の前半と Mathlib の該当部分。パスは SerrePositivity/InfinityCategories/ からの相対パス。

この章で読むのは、以後のすべての章が前提にする五つの部品である。

  1. quasicategory と各種 fibration（ほとんど Mathlib）
  2. ホモトピー圏：二つの構成とその比較
  3. 可逆な辺と Joyal の定理（Kan 複体 ⇔ ホモトピー圏が亜群）
  4. join と slice、slice が quasicategory になること

写像空間、極限の一般論、充満忠実性は第 2 章で扱う。

1. quasicategory と fibration

数学

単体的集合 \(X\) が quasicategory であるとは、すべての内ホーン \(\Lambda^n_i\hookrightarrow\Delta^n\)（\(0<i<n\)）に対して拡張を持つことをいう。射 \(p\colon X\to Y\) についても、どのホーンに対して右持ち上げ性を持つかで次のように分類する。

名前持ち上げるホーン \(\Lambda^n_i\)Lean定義の場所
inner fibration\(0<i<n\)InnerFibrationMathlib
右 fibration\(0<i\le n\)RightFibrationCore/RightFibration
左 fibration\(0\le i<n\)LeftFibrationCore/RightFibration

trivial Kan fibrationすべての単射（境界包含 \(\partial\Delta^n\hookrightarrow\Delta^n\) で十分）TrivialKanFibrationCore/Terminal

これらのホーン族が生成する「左側のクラス」（llp(rlp(·))）を、それぞれ inner／右／左 anodyne と呼ぶ。inner anodyne は Mathlib にあり（innerAnodyneExtensions）、右・左 anodyne はこのリポジトリで定義している（Core/JoinCells）。

inductive rightHornInclusions : MorphismProperty SSet.{u} where
  | intro {n : ℕ} (i : Fin (n + 2)) (h0 : 0 < i) : rightHornInclusions Λ[n + 1, i].ι

def rightAnodyneExtensions : MorphismProperty SSet.{u} := rightHornInclusions.rlp.llp

Lean の構造

右・左 fibration は MorphismProperty（rightFibrations）とそれを包んだ型クラス（RightFibration p）の二段で持つ。型クラスにしてあるのは、「slice 射影は右 fibration」のような事実を instance にして自動で見つけさせるためである。trivial Kan fibration ⇒ 右・左 fibration ⇒ inner fibration の包含も instance になっている。

原典との対応

右 fibration の向き（\(0<i\le n\)）は HTT §2.1.2 と Kerodon §4.2.1 に一致する。trivial Kan fibration は「すべての単射に対する右持ち上げ性」で定義し、境界包含だけで十分であることを trivialKanFibration_iff_boundary で示している。

2. ホモトピー圏

数学

quasicategory \(X\) のホモトピー圏 \(hX\) には、よく知られた構成が二つある。

  • (a) 道の商：頂点を対象とし、辺の道で生成した自由圏を 2 単体の関係（\(d_1\sigma\sim d_0\sigma\circ d_2\sigma\)）で割る。これは nerve の左随伴 \(h\dashv N\) そのもので、任意の単体的集合に対して定義できる。
  • (b) 辺のホモトピー類：射を、辺の「ホモトピー類」とする（Boardman–Vogt、HTT §1.2.3）。合成がうまく定義できるためには quasicategory であること（実際には 2 次元の内ホーン充填）が必要である。

quasicategory では二つが一致する（HTT §1.2.3、Kerodon §1.4.5）。

使い分け

公開されている命題の多くは (a) の hoFunctor で述べる（409 ファイルが使用）。Mathlib の関手性や随伴と直接つながるからである。(b) の HomotopyCategory₂ は「射が 1 本の辺で代表される」「合成の等式が実際の 2 単体で実現される」という具体的な議論が必要な証明の内部で使う（47 ファイル）。橋渡しは homotopyCategoryBridge と、次の二つの補題が担う。

  • homotopyCategory_homMk_surjective：\(hX\) の射は 1 本の辺で表せる。
  • compStruct_nonempty_of_homMk_fac：\(hX\) での合成の等式は実際の合成 2 単体で実現できる。

3. 可逆な辺と Joyal の定理

数学

辺 \(e\colon x\to y\) が可逆とは、\(hX\) で同型になることをいう。Joyal の定理（HTT Prop. 1.2.4.3、Kerodon Thm. 4.4.2.6）は、これを外側ホーンの充填で特徴づける。

定理. quasicategory \(X\) の辺 \(e\) について次は同値。

  1. \(e\) は可逆。
  2. 最後の辺が \(e\) であるような任意の \(\Lambda^{n}_{n}\to X\)（\(n\ge 2\)）は \(\Delta^n\) へ拡張できる。

最初の辺と \(\Lambda^n_0\) についても同様。系：quasicategory \(X\) が Kan 複体であることと、\(hX\) が亜群であることは同値（HTT Prop. 1.2.5.1）。

証明の方針（(1) ⇒ (2)）

鍵は、外側ホーンを join で書き直すことである（finalHornJoinIso、Core/OuterHornJoin）。

\[ \Lambda^{n+2}_{n+2}\;\cong\;(\partial\Delta^n\star\Delta^1)\;\cup_{\partial\Delta^n\star\Lambda^1_1}\;(\Delta^n\star\Lambda^1_1)\;\subset\;\Delta^n\star\Delta^1\cong\Delta^{n+2}. \]

ここで \(\Lambda^1_1=\{1\}\) であり、右因子 \(\Delta^1\) が問題の最後の辺 \(e\) に対応する。join と coslice の随伴（§4）によって、この拡張問題は次の持ち上げ問題に言い換えられる。

\[ \begin{array}{ccc} \{1\} & \longrightarrow & X_{\sigma/}\\ \downarrow & & \downarrow q\\ \Delta^1 & \longrightarrow & X_{\sigma|_{\partial\Delta^n}/} \end{array} \]

ここで \(\sigma\) は最初の \(n+1\) 頂点が張る単体である。§4 の結果から \(q\) は左 fibration で、左 fibration は「下の辺が可逆なら、終点を指定して持ち上げられる」（leftFibration_liftHorn_one_last）。下の辺の可逆性は、その \(X\) への像が \(e\) であることと、左 fibration \(X_{\sigma|_{\partial\Delta^n}/}\to X\) が可逆性を反映すること（leftFibration_reflects_invertibleEdge）から従う。Lean ではこれを joinUnion_extend_of_invertible_rightEdge として一般の部分複体 \(K_0\subset K\) について示し、\(K=\Delta^n\)、\(K_0=\partial\Delta^n\) に適用している。

(2) ⇒ (1) では、2 次元のホーンで片側の逆を作り、3 次元のホーンで同じ辺が反対側の逆にもなることを示す。最初の辺の版は反対圏 \(X^{\mathrm{op}}\)（Core/Opposite）を通して双対化している。

4. join と slice

join の構成

\(K\star L\) の \(n\) 単体は、「\(n+1\) 個の頂点を前後に切り、前半を \(K\) の単体、後半を \(L\) の単体とするもの」である。頂点が 0 個の部分は空単体として許す。Lean ではこれを、頂点数で添字を付けた拡張単体 augObj K r（\(r=0\) は一点）の直和として直接書く。

def Simplex (K L : SSet.{u}) (n : ℕ) : Type u :=
  Σ ℓ : Fin (n + 2), augObj K ℓ.val × augObj L (n + 1 - ℓ.val)

def join (K L : SSet.{u}) : SSet.{u} where
  obj n := Join.Simplex K L n.unop.len
  ...

面・退化写像は、順序写像に沿って切れ目の位置を引き戻すことで定義する。基本的な性質は次のとおり。

  • joinStdSimplexIso i j : join Δ[i] Δ[j] ≅ Δ[i + j + 1]
  • joinMap、joinInl、joinInr：関手性と二つの包含
  • joinUnion A₀ B₀：\(A_0\star B\cup A\star B_0\subset A\star B\)（pushout-join）

原典との違い

HTT §1.2.8 は拡張単体的集合の Day 畳み込みとして、Kerodon §4.3.3 は有限線形順序集合上の関手として join を定義する。ここではどちらも使わず、単体の型を直接書いた。Mathlib に join がないため、扱いやすい具体的な模型を選んだもので、代わりに Join.lean（1,051 行）は切れ目の算術でほぼ埋まっている。

slice と普遍性

図式 \(p\colon K\to X\) の slice \(X_{/p}\) の \(n\) 単体は、\(K\) 上で \(p\) に一致する \(\Delta^n\star K\to X\) である。これは Lean でも同じ形で書かれている。

def sliceOver {K X : SSet.{u}} (p : K ⟶ X) : SSet.{u} where
  obj n := {σ : join (stdSimplex.obj n.unop) K ⟶ X //
    joinInr (stdSimplex.obj n.unop) K ≫ σ = p}
  ...

def sliceOverEquiv {A K X : SSet.{u}} (p : K ⟶ X) :
    (A ⟶ sliceOver p) ≃ {F : join A K ⟶ X // joinInr A K ≫ F = p}

sliceOverEquiv が「\(A\to X_{/p}\) は \(A\star K\to X\) と同じ」という随伴で、以後の持ち上げ問題の言い換えはすべてこれによる。coslice（sliceUnder）も同様に定義されている。

slice は quasicategory（Joyal の補題）

命題（HTT Lemma 2.1.2.3、Kerodon Prop. 4.3.6.4）. \(A_0\hookrightarrow A\) が右 anodyne なら \(A_0\star B\cup A\star B_0\hookrightarrow A\star B\) は inner anodyne。左右を入れ替えた版も成り立つ。

系. \(X\) が quasicategory なら \(X_{/p}\to X\) は右 fibration で、とくに \(X_{/p}\) は quasicategory。

証明の方針：生成元 \(\Lambda^p_i\hookrightarrow\Delta^p\)（\(0<i\)）と \(\partial\Delta^q\hookrightarrow\Delta^q\) について、pushout-join が \(\Delta^{p+q+1}\) の内ホーンになることを、joinStdSimplexIso の下で頂点の集合を数えて確かめる（JoinCells）。一般の右 anodyne 射へは、llp の閉包性（pushout・合成・レトラクト）で広げる。その際、持ち上げ問題を slice への持ち上げ問題に移すのが JoinLifting の役目である。

5. 終対象

定義

頂点 \(x\) が終対象とは、最後の頂点が \(x\) である任意の \(\partial\Delta^{n+1}\to X\)（\(n\ge 0\)）が \(\Delta^{n+1}\) へ拡張できることとする。\(n=0\) は「任意の \(y\) から \(x\) への辺がある」、\(n=1\) は「その辺がホモトピーを除いて一意」、それより高い次元はより高次の一意性を表す。

def IsTerminalVertex {X : SSet.{u}} (x : X _⦋0⦌) : Prop :=
  ∀ (n : ℕ) (b : (boundary (n + 1) : SSet.{u}) ⟶ X),
    boundaryVertex n (Fin.last (n + 1)) ≫ b = SSet.yonedaEquiv.symm x →
      ∃ F : (Δ[n + 1] : SSet.{u}) ⟶ X, (boundary (n + 1)).ι ≫ F = b
内容Lean場所
\(x\) が終対象 ⇔ \(X_{/x}\to X\) が trivial Kan fibration（HTT Prop. 1.2.12.4）isTerminalVertex_iff_trivialKanFibrationCore/Terminal
終対象は \(hX\) で同型を除いて一意terminalVertexIsoCore/TerminalUniqueness
始対象とその一意性IsInitialVertex、initialVertexIsoCore/Terminal、Core/InitialUniqueness

第 0 章で見たように、極限 IsLimitCone は slice の終対象として定義されるので、この節の結果はそのまま極限の一意性になる。

原典との違い

HTT Def. 1.2.12.1 は「任意の \(y\) について \(\mathrm{Map}(y,x)\) が可縮」で終対象を定義し、境界充填は特徴づけ（Prop. 1.2.12.4）として出てくる。ここでは逆に境界充填を定義に採っている。写像空間を使わずに定義でき、Quasicategory の仮定も要らないからである。写像空間による特徴づけは第 2 章で扱う（Core/TerminalMappingSpace）。

6. ∞ 圏の同値

定義

Kerodon Def. 4.5.1.10 に従い、\(F\colon X\to Y\) が同値であるとは、\(G\colon Y\to X\) と、\(h\,\mathrm{Fun}(X,X)\) での同型 \(GF\cong\mathrm{id}\)、\(h\,\mathrm{Fun}(Y,Y)\) での同型 \(FG\cong\mathrm{id}\) が存在することとする。

abbrev FunctorIso {X Y : SSet.{u}} (f g : X ⟶ Y) :=
  (SSet.HomotopyCategory.mk (functorVertex f) : hoFunctor.obj ((ihom X).obj Y)) ≅
    SSet.HomotopyCategory.mk (functorVertex g)

structure QCatEquivalence (X Y : SSet.{u}) [Quasicategory X] [Quasicategory Y] where
  hom : X ⟶ Y
  inv : Y ⟶ X
  homInvIso : FunctorIso (hom ≫ inv) (𝟙 X)
  invHomIso : FunctorIso (inv ≫ hom) (𝟙 Y)

def IsQCatEquivalence ... (f : X ⟶ Y) : Prop :=
  ∃ g : Y ⟶ X, Nonempty (FunctorIso (f ≫ g) (𝟙 X)) ∧ Nonempty (FunctorIso (g ≫ f) (𝟙 Y))

注意：FunctorIso は頂点ごとの同型の族ではない

FunctorIso f g は関手 ∞ 圏 \(\mathrm{Fun}(X,Y)\) のホモトピー圏での同型であり、自然変換としての一貫性を含んでいる。「各点で可逆な自然変換は可逆」（Kerodon Thm. 4.4.4.4）はこれとは別の定理で、第 2 章で扱う（Core/FunctorEdgePointwise）。FunctorIso.toNatIso によってホモトピー圏の自然同型に落とせるが、逆は成り立たない。

最後の項目の方針：\(i\colon A\to B\) が inner anodyne なら、制限 \(\mathrm{Fun}(B,Y)\to\mathrm{Fun}(A,Y)\) は trivial Kan fibration になる（trivialKanFibration_pre_of_innerAnodyne）。\(Y=A\) とすると恒等射が持ち上がり、レトラクション \(r\) で \(ri=\mathrm{id}\) となるものが得られる。\(Y=B\) とすると、\(\mathrm{id}_B\) と \(ir\) が同じ fiber に入ることから、可縮な fiber の中で両者を結ぶ可逆辺が得られる。

方針上の要点

同値の定義にも証明にも Joyal のモデル構造は使っていない。「弱同値」ではなく、明示的な逆と自然同型で議論が閉じている。

この章で押さえること

  1. ホモトピー圏は二つあり、公開する命題は hoFunctor で述べ、証明の内部では辺の類 HomotopyCategory₂ を使う。両者の橋が homotopyCategoryBridge。

  4. 終対象は境界充填で定義し、slice 射影が trivial Kan fibration であることと同値。極限はその上に定義される。
  5. 同値は明示的な逆と \(h\,\mathrm{Fun}\) での同型で定義しており、モデル構造は使わない。FunctorIso は頂点ごとの同型の族より強い。
