Yoneda への道

基準コミット 1b32cd7a8（2026-10-23）。目標の定理から import の閉包と証明の本体を逆にたどって組み立てた読書ルート。パスは SerrePositivity/InfinityCategories/ からの相対パス。

1. 目標

Yoneda の補題（写像空間版）. 小さい quasicategory \(C\)、対象 \(y\)、前層 \(F\colon C^{\mathrm{op}}\to\mathcal S\) について

    QCatEquivalence
      (pinchedHom (functorVertex (representablePresheafInfinity y)) (functorVertex F))
      ((SSet.uliftFunctor.{u + 1, u}).obj
        (spaceInfinityObject (F.app (Opposite.op ⦋0⦌)
          (ULift.up (SSet.opObjEquiv.symm y)))).obj)

場所：F1/YonedaPresheafEvaluation（68 行）。

読み方の注意：左辺は第 2 章の右 pinched 写像空間、右辺は「空間 \(F(y)\) の台の単体的集合」を宇宙 \(u+1\) に持ち上げたもの。前層は \(C^{\mathrm{op}}\) 上の関手として、宇宙を持ち上げた底 ULift C.op 上で扱う（第 3 章「宇宙の扱い」）。

2. 証明の本体：四つの同値の合成

証明は短く、四つの同値を合成するだけである。

lemma yonedaPresheafEvaluation_isQCatEquivalence ... := by
  have h₁ := small_leftUnstraighteningPinchedMappingSpaceMap_isQCatEquivalence
    (representablePresheafInfinity y) F
  have h₂ := (qCatEquivalenceOfIso
    (smallLeftUnstraighteningRelativeFunctorIso (representablePresheafInfinity y) F).symm).isQCatEquivalence
  have h₃ := (representableUnstraighteningEvaluation_isQCatEquivalence
    (smallLeftUnstraighteningProjection F) y).ulift.{u, u + 1}
  have h₄ := (smallLeftUnstraighteningLiftedFiberValueEquivalence F
    (SSet.opObjEquiv.symm y)).isQCatEquivalence
  exact h₁.comp (h₂.comp (h₃.comp h₄))

数学として書くと次のようになる。\(\mathrm{Un}(G)\to C^{\mathrm{op}}\) は前層 \(G\) の unstraightening（左 fibration）、\(\mathrm{Fun}_{/C^{\mathrm{op}}}(-,-)\) は相対関手空間である。

\[ \mathrm{Map}(h_y,F)\;\xrightarrow[h_1]{\ \simeq\ }\;\mathrm{Fun}_{/C^{\mathrm{op}}}\bigl(\mathrm{Un}(h_y),\mathrm{Un}(F)\bigr)\;\xrightarrow[h_2]{\ \cong\ }\;(\text{小さい模型})\;\xrightarrow[h_3]{\ \simeq\ }\;\mathrm{Un}(F)_y\;\xrightarrow[h_4]{\ \simeq\ }\;F(y) \]
  1. h₁　写像空間の比較：前層の間の写像空間は、unstraightening の間の相対関手空間と同値（F1/CoherentUnstraighteningMappingEquivalence、SmallCoherentMappingEquivalence）。この証明全体で最も重い入力。
  2. h₂　宇宙の調整：大きい unstraightening と小さい模型の相対関手空間は厳密に同型（F1/SmallLeftUnstraighteningMappingSpace）。数学的な内容はない。
  3. h₃　表現可能前層での評価：任意の左 fibration \(p\colon E\to C^{\mathrm{op}}\) について、\(\mathrm{Fun}_{/C^{\mathrm{op}}}(\mathrm{Un}(h_y),E)\to E_y\)（恒等点での評価）は同値（F1/RepresentableUnstraighteningEvaluation）。Yoneda の補題の数学的な核心はここにある。
  4. h₄　fiber の値：\(\mathrm{Un}(F)\) の \(y\) での fiber は \(F(y)\) と同値（F1/SmallLeftUnstraighteningFiber）。

h₃ の中身

lemma representableUnstraighteningEvaluation_isQCatEquivalence
    {E C : SSet.{u}} [Quasicategory C] (p : E ⟶ C.op) [LeftFibration p]
    (y : C _⦋0⦌) : IsQCatEquivalence (representableUnstraighteningEvaluation p y) := by
  have h₁ := relativeFunctorOverPre_isQCatEquivalence p (...)
    (representableCosliceUnstraighteningComparison_isPrecompositionEquivalence y)
  have := leftFibration_cosliceIdentityEvaluation_trivialKanFibration p (SSet.opObjEquiv.symm y)
  have h₂ := isQCatEquivalence_of_trivialKanFibration (relativeFunctorEvaluate p ...)
  exact h₁.comp (h₂.comp ...)

二段に分かれる。

  1. 表現可能前層の unstraightening は coslice：比較写像 \(C^{\mathrm{op}}_{y/}\to\mathrm{Un}(h_y)\) は前合成同値（representableCosliceUnstraighteningComparison_isPrecompositionEquivalence）。前合成同値に沿った制限は、左 fibration への相対関手空間の同値を与える（relativeFunctorOverPre_isQCatEquivalence）。
  2. coslice は恒等点を始対象に持つ：\(\mathrm{Fun}_{/C^{\mathrm{op}}}(C^{\mathrm{op}}_{y/},E)\to E_y\)（恒等錐 \(\mathrm{id}_y\) での評価）は自明 Kan fibration（leftFibration_cosliceIdentityEvaluation_trivialKanFibration）。自明 Kan fibration は同値（第 2 章）。

古典的な Yoneda の補題の証明（「\(\mathrm{id}_y\) の行き先で自然変換が決まる」）が、2 の「始対象への制限は自明 Kan fibration」にそのまま対応している。

段 3　左 fibration と相対関手空間 第 1 章 §1、第 3 章 §4、第 4 章 §5

押さえること

  • 左 fibration の定義（LeftFibration）と、coslice 射影が左 fibration であること（sliceUnderProjection_leftFibration）

確認ポイント：最後の補題は「coslice は恒等錐を始対象に持ち、始対象の包含は left anodyne」の言い換えになっていること。

段 4　𝒮、関手 ∞ 圏、前層 第 3 章 §2、第 4 章 §1、第 5 章 §1

押さえること：SpaceInfinity（Kan 複体の単体的圏の coherent nerve）、spaceInfinityObject（\(\mathcal S\) の頂点から Kan 複体を取り出す）、PresheafInfinity、宇宙の持ち上げ SSet.uliftFunctor。coherent nerve が quasicategory であること（γ1）は結果だけ使えばよい。

段 5　straightening の構成 第 3 章 §4一回目は黒箱

使われ方：Hom 関手（したがって \(h_y\)）は、左 fibration \(\mathrm{Tw}(C)\to C^{\mathrm{op}}\times C\) の分類写像として定義される。そのため、分類写像 leftStraighteningInfinityDiagram（F1/LeftStraighteningRepresentation）と、対象ごとの再構成 \(\mathrm{Un}(\mathrm{St}(p))\simeq p\)（leftStraighteningInfinityReconstruction、F1/LeftStraighteningInfinityReconstruction）が必要になる。

一回目に信じておくこと：

  • 任意の左 fibration \(p\colon E\to B\) に分類写像 \(\mathrm{St}(p)\colon B\to\mathcal S\) が対応する。
  • \(\mathrm{Un}(\mathrm{St}(p))\) と \(E\) を \(B\) 上で比べる写像は前合成同値。

二回目に読むもの：strict transport（F1/StrictTransport*）、first vertex 写像が局所化であること（F1/TransportLocalizationAllBases）、局所化による降下（F1/TransportUliftFunctorDescent）、再構成（F1/LeftStraighteningInfinityReconstruction ← LeftStraighteningEssentialSurjectivity ← SmallUnstraighteningRepresentation ← CoherentRepresentationExtension ← …）。この再構成の鎖が、この道で最も深い部分である（§5 も参照）。

段 6　unstraightening 第 3 章、補章

定義：普遍左 fibration（pointed space の射影）\(\mathcal S_*\to\mathcal S\) の \(F\) に沿う引き戻し。

noncomputable def leftUnstraightening {C : SSet.{u + 1}} (F : C ⟶ SpaceInfinity.{u}) :
    SSet.{u + 1} := pullback pointedSpaceProjection F
instance pointedSpaceProjection_leftFibration : LeftFibration pointedSpaceProjection.{u}

引き戻しなので左 fibration になり、fiber は \(F(c)\) そのものになる（h₄）。小さい模型 smallLeftUnstraightening は宇宙を \(u\) に戻すための縮小版（h₂）。

h₁ の中身（F1/LeftUnstraighteningMappingSpaceMap、CoherentUnstraighteningMappingEquivalence）：前層の間の変換（\(\mathrm{Fun}(B,\mathcal S)\) の辺）を、引き戻しの普遍性で全空間の間の写像に持ち上げる。逆向きには、全空間の相対写像の「普遍的な族」から変換を復元する。docstring には「普遍的な相対射の族を復元しその証拠を制限して両側の関手同型を得る」とある。

段 7　twisted arrow と Hom 関手 第 4 章 §2

  • \(\mathrm{Tw}(C)\to C^{\mathrm{op}}\times C\) は左 fibration（twistedArrowProjection_leftFibration、F1/TwistedArrowLeftFibration）。ホーンを固定領域に貼り、inner anodyne な包含で延長して示す。
  • その分類写像が Hom 関手 twistedArrowHomInfinity。第二変数を固定したものが representablePresheafInfinity y（\(h_y\)）。
  • \(h_y\) は slice の分類写像と同型（representablePresheafInfinity_sliceIso、F1/RepresentablePresheafSliceComparison）。これと段 5 の再構成から \(\mathrm{Un}(h_y)\simeq C_{/y}^{\mathrm{op}}=C^{\mathrm{op}}_{y/}\)（F1/RepresentableUnstraighteningComparison）。

7. straightening を使わない Yoneda

Yoneda には、どの形で述べるかによって二つの段階がある。

形主張straightening
fibration 版（Riehl–Verity、Kerodon の fibration による扱い）左 fibration \(p\colon E\to B\) と対象 \(b\) について、\(\mathrm{Fun}_{/B}(B_{b/},E)\to E_b\)（恒等点での評価）は同値不要
関手版（このページの目標）\(\mathrm{Map}_{\mathcal P(C)}(h_y,F)\simeq F(y)\)、さらに \(C\to\mathcal P(C)\) が充満忠実Hom 関手 \(C^{\mathrm{op}}\times C\to\mathcal S\) を作るために必要

fibration 版では、前層を「\(C\) 上の右 fibration（\(C^{\mathrm{op}}\) 上の左 fibration）」として扱い、表現可能前層を slice \(C_{/y}\) で表す。すると、主張は h₃ の後半そのものになる。証明は「\(\{b\}\hookrightarrow B_{b/}\) は left anodyne なので、そこへの制限は自明 Kan fibration」の一行で、straightening は出てこない。

Lean では leftFibration_cosliceIdentityEvaluation_trivialKanFibration（F1/LeftFibrationInitialEvaluation）がこれにあたる。import の閉包は 256 モジュールで、関手版（約 1,750）よりはるかに小さい。閉包には CatInfinity と LeftUnstraightening が含まれるが、これは重複調査で特定した PullbackFiber → LeftUnstraightening の汚染の経路によるもので、数学的には使っていない。

関手版で straightening が要る理由

∞ 圏では、Hom 関手 \(C^{\mathrm{op}}\times C\to\mathcal S\) を「各 \((x,y)\) に \(\mathrm{Map}(x,y)\) を対応させる」だけでは定義にならない。射の合成と、それに伴うすべての高次の整合性を、一つの単体的集合の射として与える必要があるからである。その作り方は主に三つある。

  1. twisted arrow の straightening（Kerodon、このリポジトリ）：\(\mathrm{Tw}(C)\to C^{\mathrm{op}}\times C\) が左 fibration であることは straightening なしで示せる（F1/TwistedArrowLeftFibration の閉包には straightening 系のモジュールが一つもない）。それを関手に変える一歩で straightening が要る。
  2. 単体的圏による rigidification（HTT §5.1.3）：\(C\) を単体的圏 \(\mathfrak C[C]\) に置き換え、その Hom で strict な関手を作り、coherent nerve に戻す。\(\mathfrak C\dashv N^{hc}\) が Quillen 同値であること（Joyal のモデル構造）が必要になる。主経路ではモデル構造を使わない方針なので、採用されていない。
  3. 関手を作らない（∞-cosmos、Riehl–Verity）：前層を最初から右 fibration として扱い、\(\mathcal P(C)\) の代わりに右 fibration の ∞ 圏を使う。Yoneda は上の fibration 版で済む。ただしその場合、「前層 = 関手」との比較（＝ straightening の同値定理）が別に必要になる。

つまり、straightening（あるいはそれと同等の rigidification）は、「前層を関手として扱う」ことと「fibration として扱う」ことの橋の代価であって、Yoneda の数学的な核心（h₃）には要らない。

学習の順番への含意

最も早く Yoneda の核心に到達するには、段 1〜3 だけで fibration 版（leftFibration_cosliceIdentityEvaluation_trivialKanFibration）を読めばよい。そこから関手版へ進むときに初めて、段 4〜7（𝒮、unstraightening、Tw、straightening の構成）が必要になる。
