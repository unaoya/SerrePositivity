1. γ1：coherent nerve は quasicategory

定理（HTT Prop. 1.1.5.10、Kerodon Thm. 2.4.5.1）. 単体的圏 \(\mathcal C\) の各 Hom が Kan 複体なら、coherent nerve \(N^{hc}(\mathcal C)\) は quasicategory。

instance simplicialNerve_quasicategory (C : Type u) [Category.{v} C] [SimplicialCategory C]
    [∀ X Y : C, SSet.KanComplex (SimplicialCategory.sHom X Y)] :
    SSet.Quasicategory (SimplicialNerve C)

証明の方針：\(N^{hc}(\mathcal C)\) の \(n\) 単体は単体的関手 \(\mathfrak C[\Delta^n]\to\mathcal C\) である。\(\mathfrak C[\Delta^n](0,n)\) は立方体 \((\Delta^1)^{n-1}\) で、内ホーン \(\Lambda^n_i\) から決まるのは、この立方体から内部と一つの面を除いた部分（空洞の立方体）だけである。空洞の立方体の包含は anodyne なので、Hom が Kan 複体であれば延長できる。その延長を使って単体的関手を復元し、各面への制限が元のホーンと一致することを確かめる。Lean では Mathlib の SimplicialNerve の Path による記述に合わせて、Cube、Hollow*、Horn*、Path*、Filled* の各ファイル（Coherent/、40 ファイル・約 4,500 行）でこの手順を一つずつ形式化している。

この定理は γ 層の中で最も小さく、しかも第 3 章の \(\mathcal S\)、Cat∞、LFib のすべてがこれに依存している。

2. γ1.5：Dold–Kan 豊穣化と dg nerve

dg 圏 \(D\) から ∞ 圏を作る方法は二つある（HA §1.3.1）。

  • dg nerve \(N_{dg}(D)\)：dg 圏から直接作る（第 8 章、DGNerve/）。
  • Dold–Kan 豊穣化の coherent nerve：Hom 複体を \(\tau_{\ge0}\)（コードの規約では \(\tau^{\le0}\)）で切断し、Dold–Kan 対応 \(\Gamma\) で単体的加群、したがって Kan 複体にする。合成は Alexander–Whitney 写像で与える。こうして得た単体的圏の coherent nerve を取る。
def doldKanHomModule (x y : D) : SimplicialObject (ModuleCat.{u} R) :=
  (CategoryTheory.Abelian.DoldKan.Γ : ChainComplex (ModuleCat.{u} R) ℕ ⥤ _).obj
    (connectiveHomComplex (R := R) x y)
def doldKanCoherentNerve : SSet.{max u v} := SimplicialNerve (ClosedCategory R D)
def coherentComparison : doldKanCoherentNerve (R := R) (D := D) ⟶ dgNerve R D
lemma coherentComparison_isQCatEquivalence :
    IsQCatEquivalence (coherentComparison (R := R) (D := D))

場所：DoldKanComparison/ConnectiveHom、CoherentComparison、ComparisonEquivalence。任意の可換環上の任意の dg 圏について、比較写像が同値であることが示されている（HA Prop. 1.3.1.17）。Dold–Kan 対応は Mathlib の Abelian.DoldKan.Γ をそのまま使う。

証明の方針：比較写像は頂点の上で全単射なので、本質的全射性は自明である。充満忠実性は、写像空間の比較（coherent nerve 側の pinched Hom → dg nerve 側の pinched Hom）がホモトピー同値であることに帰着する。これを標準的な分解（Resolution*）を通して示し、第 2 章の判定（充満忠実かつ本質的全射）で結論する。比較写像の各単体は、降順の立方体の評価（Cube*、AW*）で具体的に作られている。

二つの模型を持つ理由

dg nerve は D(S) などの dg の対象を扱うのに直接的で、第 8 章ではこちらを主に使う。一方、coherent nerve の側は \(\mathcal S\)、Cat∞ と同じ枠組みにあり、単体的豊穣の議論（γ4 など）が使える。両者の同値によって、どちらの模型で示した性質も他方に移せる。

3. γ3：𝒮 の極限・余極限

空間の ∞ 圏 \(\mathcal S\) が完備かつ余完備であることは、二つの経路で示されている。

(a) 一般の coherent 図式：straightening 経由（無条件）

(b) strict な図式：Bousfield–Kan 経由

通常の小さい圏 \(I\) 上の strict な図式 \(F\colon I\to\mathrm{Kan}\) は、coherent な図式 kanDiagramCoherentNerve F : N(I) → 𝒮 とみなせる（F1/KanDiagramCoherentNerve）。古典的なホモトピー（余）極限（Bousfield–Kan の coend・end、重み付き切断）がその ∞ （余）極限になることを示すのが γ3 である。

4. γ4：Quillen 随伴 ⇒ ∞ 随伴

設定：simplicial モデル圏 \(\mathcal C,\mathcal D\)（SM7 を固定）と、豊穣 Hom の同型と合成の両立を明示した simplicial Quillen 随伴 \(F\dashv G\)。cofibrant かつ fibrant な対象（cf 対象）がなす単体的圏は SM7 により局所 Kan なので、γ1 によりその coherent nerve \(N^{hc}(\mathcal C^{cf})\) は quasicategory になる。

lemma quillenCfDerivedAdjunction_exists :
    ∃ H : SSet.Homotopy (𝟙 (SimplicialNerve (CofibrantFibrantObjects C)))
      (quillenCfLeftDerived R adj fibD e SC SD ≫ quillenCfRightDerived R adj SC SD cofC),
      ∃ a : QCatAdjunction (quillenCfLeftDerived ...) (quillenCfRightDerived ...),
        a.unitHom = SSet.Truncated.HomotopyCategory.homMk (functorEdgeOfSimplicialHomotopy H)

場所：HomotopyLimits/QuillenCfDerivedAdjunction。導来関手 \(\mathbb LF\)、\(\mathbb RG\) が cf nerve の間の ∞ 随伴（第 4 章の QCatAdjunction）をなし、その単位は指定したホモトピーから来る。系として、右導来関手は ∞ 極限を保つ（quillenCfRightDerived_hasLimit_postcomp、HomotopyLimits/QuillenCfDerivedLimits。一般の「右随伴は極限を保つ」hasLimit_postcomp_of_adjunction の適用）。

証明の方針（HTT 5.2.4.6）：\(\Delta^1\) 上の「cf 対応圏」を作る。両端の fiber が \(\mathcal C^{cf}\) と \(\mathcal D^{cf}\) で、二つをつなぐ混合 Hom は \(\mathrm{Map}(FX,Y)\cong\mathrm{Map}(X,GY)\) である。その coherent nerve \(\to\Delta^1\) が cocartesian かつ cartesian な fibration であることを示し（HomotopyLimits/QuillenCfBifibration）、cocartesian 辺に沿った transport と cartesian 辺に沿った transport を導来関手と比較する。そのうえで、写像空間の同値から随伴を組み立てる（Quillen*、34 ファイル）。
