1. dg nerve

定義（HA Construction 1.3.1.6）

dg 圏 \(D\) の dg nerve \(N_{dg}(D)\) の \(n\) 単体は、対象 \(x_0,\dots,x_n\) と、各部分集合 \(I=\{i_0<\dots<i_r\}\subset[n]\)（\(r\ge1\)）に対する次数 \(1-r\) の射 \(f_I\colon x_{i_0}\to x_{i_r}\) の族で、次を満たすものである。

\[ \delta f_I=\sum_{j\in I,\ i_0<j<i_r}\varepsilon(I,j)\,\bigl(f_{I\setminus\{j\}}-f_{I_{\ge j}}\circ f_{I_{\le j}}\bigr),\qquad \varepsilon(I,j)=(-1)^{\#\{k\in I\,:\,j<k\}}. \]

たとえば 2 単体では \(\delta f_{012}=f_{12}\circ f_{01}-f_{02}\)、つまり \(f_{012}\) は合成 \(f_{12}\circ f_{01}\) と \(f_{02}\) の間のホモトピーである。

def dgNerve : SSet.{max u v} where
  obj Δ := DGNerve.Simplex A D Δ.unop.len
  map f := ↾fun s => s.pullback f.unop.toOrderHom
instance instQuasicategory : SSet.Quasicategory (dgNerve A D)

場所：DGNerve/Basic、DGNerve/Quasicategory。係数環 \(A\) は任意の可換環で、有界性・平坦性・標数の仮定はない。

符号の規約（重要）

コードの微分は次数 +1（cochain）で、合成は通常順 compose A g f h \(=g\circ f\)、Leibniz 則は \(\delta(g\circ f)=\delta g\circ f+(-1)^{|g|}g\circ\delta f\)。HA の chain 次数を負に読み替え、HA の \(f_I\) は符号を変えずに使う。Kerodon Construction 2.5.3.1 とは括弧の順序が逆で、同じ Hom 複体の微分で比べると \(f_I^{\mathrm{Kerodon}}=(-1)^{|I|-2}f_I^{\mathrm{HA}}\) となる。原典の式をそのまま混在させないこと。詳細は InfinityCategories/README.md（実質的に dg nerve の規約文書）。

2. 導来 ∞ 圏 D(S) と Perf(S)

abbrev Semifree := DGFullSubcategory (Complex S) (complexSemifree S)

3. Verdier 商（β3）

dg 圏 \(D\) と対象の集合 \(P\) について、Drinfeld の dg 商 \(D/P\)（\(P\) の対象の恒等射を null-homotopic にする）を考える。

定理（Drinfeld 2004 Thm. 3.4 の ∞ 圏版、HA §1.1.4、Kerodon §6.3）. 平坦性の条件のもとで、\(N_{dg}(D)\to N_{dg}(D/P)\) は \(P\) を零にする局所化で、安定な Verdier 列を与える。

  • resolvedDGQuotientFunctor_isLocalization：平坦分解した後の商関手は局所化（第 4 章の IsLocalization）
  • resolvedDGQuotient_isStableVerdierSequence：安定 Verdier 列
  • dgQuotient_isStableVerdierSequence：局所 K-flat な場合は分解なしで成り立つ

注意：分解していない path 商がいつでも Verdier 商になるとは主張していない（計画文書の方針）。\(H^0\) の Verdier 商との一致だけでは ∞ 関手圏の普遍性にならない点も明記されている。K 理論側では、Thomason の局所化 Perf(X)/PerfZ(X) ≃ Perf(U) や fibration 定理に使われる。

4. 非可換 dg 代数の導来 ∞ 圏と Morita 不変性（β5）

abbrev dgModuleDerivedInfinityCategory := dgNerve R (SemifreeDGModules R D)

dg 圏（とくに非可換 dg 代数）\(D\) 上の semifree dg 加群の dg nerve として \(D(A)\) を定義する（HA §7.1.2 は比較の目標であり、引用はしていない）。

  • D(A)・Perf(A) の安定性。Perf(A) は冪等完備（第 6 章の強分裂を使う）。
  • 双加群による相対テンソル・Hom を dg 関手として作り、dg nerve に移して ∞ 関手にする。単位・合成・随伴の整合性。
  • Morita 不変性：Morita 同値な dg 代数の D・Perf は同値（dgMoritaPerfectKernelInfinity_isQCatEquivalence など、Derived/DGModule*）。
  • 単体環は正規化によって dg 代数になり、台の弱同値は D・Perf の同値を与える。

Land–Tamme の ⊙ 構成（K 理論側）では、環や導来環をこの形で扱う（B 案：dg による増強の経路）。

5. 作業中：dg gluing と lax pullback（β4）

二つの dg 圏 \(C,D\) と双加群 \(M\) から、貼り合わせの dg 圏（対象は \(C\) と \(D\) の対象を \(M\) を通る射でつないだ組。Hom 複体は比較差の mapping cocone）を作り、その dg nerve が安定 ∞ 圏の lax pullback（第 6 章）と同値であることを示すのが目標（Tamme 2018 §1、Kuznetsov–Lunts）。
