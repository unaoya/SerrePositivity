第 2 章　モデル圏を使わない基礎

基準コミット 91d8dc9cd（2026-10-28）。計画は infinity-foundation-plan.md（10-28 版）。整備の計画と状態の正本は形式化の側（infinity-foundation-plan.md、台帳 refactor-ledger.md）にある。表の「今の所在」は 2026-11-12（KL-W1 の後）に引き直した。 ファイルの場所は SerrePositivity/ からの相対パス。HA は HomotopicalAlgebra の略。

単体的集合のホモトピー論は、伝統的には Quillen のモデル構造（Kan–Quillen モデル構造）の上で語られる。 この章では、∞ 圏の基盤に必要な部分がモデル構造なしで展開できること、そして実際にこのリポジトリでそう証明されていることを説明する。 あわせて、本当にモデル圏が必要な結果（「モデル圏 → ∞」の比較）を ∞ 圏論の基盤の外に置く理由を述べる。

1. なぜモデル圏を避けるのか

  • 証明されていない入力がある。単体的集合の Kan–Quillen モデル構造の存在（Hovey 定理 3.6.5）は、このリポジトリでは引用（sorry）のままである（Inputs/Homotopy/KanQuillen.lean の kanQuillen_model_exists）。主定理の経路にはないが、これに頼ると基盤が未証明の入力に依存する。
  • 仮定の形で入り込むと消せない。[ModelCategory SSet] を仮定にした定理は、公理の監査には引っかからない。しかし、その仮定を満たすインスタンスがないので、使う場面では永久に仮定のまま残る（プロジェクトの方針で、主経路では禁止している）。
  • ∞ 圏論は、本来モデル構造なしで書ける。Kerodon は Kan–Quillen モデル構造を使わずに ∞ 圏論を展開している。必要なのは、持ち上げ性質、small object argument、Kan 複体への写像のホモトピー類だけである。

「モデル圏の言葉」と「モデル圏の仮定」の区別

Mathlib は単体的集合に、fibration の族（horn に対する右持ち上げ性質）と cofibration の族（単射）を与えている（第 1 章 §1.2）。 これは射の族を名前で呼んでいるだけで、使ってよい。 避けるのは、モデル圏の公理（2-out-of-3、分解、持ち上げ）が成り立つことを仮定する [ModelCategory SSet] と、その上の結果である。

2. 道具 1：small object argument と Kan 置換

持ち上げ性質で定まる射の族 \(I\) について、small object argument は、任意の射を「\(I\) の pushout の超限合成」と「\(I\) に対する右持ち上げ性質を持つ射」に、関手的に分解する。 \(I\) を horn の包含の集合 \(J\) にとれば、次が得られる。

\[ X \xrightarrow{\ \text{anodyne}\ } RX \xrightarrow{\ \text{Kan fibration}\ } \ast \]

つまり、関手的な Kan 置換 \(X \to RX\) である（AnodyneKanReplacement.factorization : FunctorialFactorizationData anodyneExtensions J.rlp、HomotopicalAlgebra/Simplicial/AnodyneKanReplacement.lean:44）。 これは small object argument（Mathlib）と anodyne の定義だけから作られており、モデル構造は使っていない。

関連する一般的な補題もある：generatedLeft_map（HomotopicalAlgebra/Generated/FunctorClosure.lean:70）。余極限を保つ関手 \(F\) が \(I\) を \(W\) に送るなら、\(I\) から生成される射（\({}^{\text{⧄}}(I^{\text{⧄}})\)）もすべて \(W\) に送る。 これは、宇宙の持ち上げが anodyne を保つこと、inner anodyne を保つことなどに使われる。

3. 道具 2：ホモトピーと anodyne 局所化

3.1 端点の包含は anodyne

単体的集合 \(X\) について、端点の包含 \(X \to \Delta^1 \times X\)（\(0\) 側・\(1\) 側）は anodyne である （endpoint_zero_anodyne・endpoint_one_anodyne、HomotopicalAlgebra/Simplicial/AnodyneIntervalEndpoints.lean:85・90）。 証明は、\(\Delta^0 \to \Delta^1\) が anodyne であることと、anodyne と単射の pushout-product が anodyne であること（Mathlib）から出る。

3.2 anodyne 局所化

単体的集合の圏を、anodyne 射を可逆にして局所化した 1 圏を考える（Gabriel–Zisman の局所化）。

\[ \texttt{anodyneQ} : \mathbf{sSet} \to \mathbf{sSet}[\text{anodyne}^{-1}] \]

（anodyneQ := SSet.anodyneExtensions.Q、HomotopicalAlgebra/Simplicial/AnodyneHomotopyLocalization.lean:101）。これは「空間のホモトピー圏」の一つの定義である。 §3.1 から、ホモトピックな写像は anodyneQ で同じ射になる（map_homotopy_eq、同 :82）。

4. 弱同値の三つの見方が一致すること

第 1 章 §3.5 で、単体的集合の写像 \(f : X \to Y\) が「弱同値」であることの三つの言い方を挙げた。ここで、それらがモデル構造なしで一致することを確かめる。

見方定義宣言
(a) anodyne 局所化\(\texttt{anodyneQ}(f)\) が同型IsIso (anodyneQ.map f)
(b) Kan 複体による判定すべての Kan 複体 \(K\) について、前合成 \([Y, K] \to [X, K]\)（ホモトピー類）が全単射KanTestDetection.Tests f（HomotopicalAlgebra/Simplicial/KanTestDetection.lean:47）。IsWeakHomotopyEquivalence（Kerodon/KanComplexes）（\(\pi_0\mathrm{Fun}(-, Z)\) で同じことを言う）もこの形
(c) Kan 置換と π_*\(Rf : RX \to RY\) が π_* 同型第 1 章 §3.2 の KanPiIsomorphism

(a) ⇔ (b)：anodyneQ_isIso_iff_tests（KanTestDetection.lean:111）。証明の流れは次のとおり。

  1. (a) ⇒ (b)：Kan 複体 \(K\) へのホモトピー類 \([-, K]\) は、anodyne 射を全単射に送る（Kan 複体への写像は anodyne に沿って延び、延長はホモトピーを除いて一意）。したがって \([-, K]\) は anodyneQ を経由し、\(\texttt{anodyneQ}(f)\) が同型なら全単射（tests_of_anodyneQ_isIso）。
  2. (b) ⇒ (a)：Kan 置換 \(X \to RX\) は anodyne なので、anodyneQ の中で \(f\) と \(Rf\) は同型の違いしかない。Kan 複体の間では、(b) は米田の議論により「ホモトピー同値」を意味する。ホモトピー同値は §3.2 により anodyneQ で同型になる（replacement_tests・map_isIso_of_tests）。

(b) ⇔ (c)：Kan 複体の間の写像については、(b) はホモトピー同値と同じで、ホモトピー同値は Whitehead の定理により π_* 同型と同値である（第 1 章 §3.4）。 一般の \(f\) については、Kan 置換を経由して (b) と (c) が比べられる。Kan 置換の単位 \(X \to RX\) は anodyne なので、(b) の判定を変えない。

ポイント

「弱同値」を、モデル構造の公理から出すのではなく、Kan 複体へのホモトピー類（(b)）で定義してしまう。そうすれば、局所化（(a)）や π_*（(c)）との一致は、持ち上げ性質と small object argument だけで示せる。 これが「モデル圏を使わない基礎」の中心である。

5. bisimplicial 集合の対角

bisimplicial 集合 \(A : \Delta^{\mathrm{op}} \to \mathbf{sSet}\) の対角は、\(n \mapsto A_n\) の \(n\) 単体である。次の定理は、ホモトピー余極限の計算（例：Ex∞ やスペクトラムの構成）で繰り返し使われる。

\[ f : A \to B,\quad \text{各 } n \text{ で } f_n : A_n \to B_n \text{ が弱同値} \ \Longrightarrow\ \mathrm{diag}(f) \text{ は弱同値} \]

（localized_diagonal_map、HomotopicalAlgebra/Simplicial/DiagonalLocalizedEquivalence.lean:55。弱同値は §4 の (a) の意味）。 docstring にあるとおり、モデル構造は置かずに、anodyne 局所化で可逆性を読んでいる。 証明は、Reedy 型の単射への分解（境界による分解系 BoundaryFactorization.reedy_wfs）と、§4 の Kan 複体による判定を組み合わせる。

ただし、補助のファイル（BisimplicialCofibrancy・QuillenStandardFrame・StandardCosimplicial）が、末尾に Model の節を持っていたり、HomotopyFunctionComplex という名前のディレクトリにあったりする。そのため import の閉包にはモデル圏が入っている（§7）。

6. 本当にモデル圏が要るもの

次の結果は、主張そのものがモデル圏についてのものなので、モデル圏を避けることはできない。これらは基盤の外（InfinityCategories/HTT/ModelCategoryAdjunctions・InfinityCategories/HA/ModelCategoryComparison・InfinityCategories/Project/ModelCategoryComparison、EInfinity/SimplicialLocalization）にある。
