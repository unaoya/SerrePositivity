非連結 K の設計：関手性をどこに置くか

基準コミット 63b823320（2026-10-27）。K-7（K-B3 レーン）の c4 で見つかった問題と、10-27 11:55 の設計変更の整理。このページのパスは SerrePositivity/ からの相対パス（∞ 圏の層と KST の両方にまたがるため）。正本は formalization-plans/kst-lanes/L10-nonconnective.md（K-7 計画、v6）と formalization-plans/refactoring-infinity-r2.md。

1. 作りたいもの

BGT の非連結 K 理論。小さい安定 ∞ 圏 \(\mathcal C\) に対し、Calkin 懸垂

\[ \Sigma\mathcal C=\mathrm{Ind}_\kappa(\mathcal C)^\kappa/\mathcal C \]

を使って

\[ K^{nc}(\mathcal C)=\operatorname{colim}_r\,\Omega^rK(\Sigma^r\mathcal C) \]

と定める。登場する関手は、それぞれ別の ∞ 圏の上にある。

関手どこからどこへ中身
\(\Sigma\)（Calkin 懸垂）StableInfinity → StableInfinity（または冪等完備な部分 Catperf）Ind、κ-compact 部分、Verdier 商
\(K\)（連結 K）StableInfinity → Sp∞-S• 構成
\(\Omega\)（ループ）Sp → Spスペクトラムのループ。安定 ∞ 圏ではなく値域 Sp の上の関手

なぜ ∞ 関手でなければならないか

Knc を局所化不変量として登録する先の型が、それを要求する。

structure IsRelativeLocalizingInvariant {S : SSet.{u + 1}}
    (ν : S ⟶ StableInfinity.{u}) (E : S ⟶ Spectra.Sp.{u}) : Prop where
  preservesZero : PreservesRelativeZeroCategories ν E
  -- Verdier 列の四角形を E で送ると Sp の引き戻しになる

（KST/LocalizingInvariants/RelativeInvariant）。Verdier 列 \(\mathcal A\to\mathcal B\to\mathcal B/\mathcal A\) の四角形を送るには、\(E\) が対象だけでなく射と 2 単体にも作用する単体的集合の射 S ⟶ Sp、つまり ∞ 関手でなければならない。対象ごとの値がいくら正しくても、それだけでは登録できない。

3. 何が起きたか：dg 側だけで組む設計の破綻

当初の設計

K の主経路は厳密な dg 入力に限っていた（Land–Tamme を dg で実現する B 案。経路正本 §13 の決定 16 と、K レーンの運用方針）。懸垂も dg 側で、Drinfeld 商によって作る。零にしたい対象 b ごとに縮約 \(\varepsilon_b\)（\(d\varepsilon_b=\mathrm{id}_b\)）を付け足すものである。

根本原因

厳密な dg 関手の圏の dg nerve は、正しい（導来の）写像空間ではない。

dg 圏の間の正しい写像空間は、準関手（右準表現可能な双加群）の空間である。厳密な dg 関手だけを見ると、ホモトピーで同一視されるべきものが別の点に分かれたり、逆に剛すぎたりする。Drinfeld 商は縮約 ε を選ぶ構成なので、厳密には関手的にならない。

c4 が難しかったのではなく、ホモトピー不変な関手性を、それを表現できない場所（S の剛な写像空間）に載せようとしていた、という設計の問題である。

4. 新しい設計（2026-10-27 11:55）

           ν
  S ─────────────→ StableInfinity ──Σ_∞──→ StableInfinity
(dg 入力)               │ K_∞
                        ↓
                        Sp ──Ω──→ Sp
  1. 関手性は ∞ 側で作る：\(\Sigma_\infty\)（Calkin 懸垂）を Ind・compact・Verdier 商の普遍性から ∞ 関手として作り、\(K_\infty\)、\(K^{nc}_\infty=\operatorname{colim}_r\Omega^rK_\infty(\Sigma_\infty^r)\) も ∞ 関手にする。登録するのは \(E:=K^{nc}_\infty\circ\nu\)。合成なので自動的に S ⟶ Sp の射になる。
  2. 値は dg 側で計算する：すでに無条件に作ってある dg 側の dgNonconnectiveK A（π の計算、余極限）が、各 A で \(K^{nc}_\infty(\nu A)\) と一致することを対象ごとの比較で示し、dg 側の計算を ∞ 側の値に移す。
  3. 関係のないレーンは継続（K-S•、Sp-2、Sp-3）。c4 に関係する D・D-S・K-B3 の作業は、凍結または診断として保持（扱いは台帳 formalization-plans/refactor-ledger.md の R32・R33）。

役割の線引き

dg 側は「計算できる模型」、∞ 側は「関手性の置き場所」で、ν と対象ごとの比較がその二つをつなぐ。関手性だけは dg 側では表現できないので ∞ 側に移し、対象の供給と計算は dg 側に残す。

これは Yoneda への道 §7 と同じ構図である。Yoneda では、関手性（Hom 関手）を「前層を関手として扱う」側に置くために straightening を代価として払った。ここでは関手性を ∞ 側に置き、dg との橋を代価として払う。

作り方（方法 (a)）

  1. S• 構成：\(S_n(\mathcal C)=\mathrm{Fun}^{\mathrm{gapped}}(\mathrm{Ar}[n],\mathcal C)\) の core。完全関手 \(f\) は後合成で作用し、関手の族（Hom の高次単体）の作用も内部 Hom の合成なので、厳密に合成と両立する。dg を経由する必要はない。
  2. 実現：\(|\iota S_\bullet\mathcal C|\)。S• を反復して前スペクトラムにする。
  3. Sp の模型への置き換え：Sp の対象（BF の Ω スペクトラム：各段が Kan 複体、構造写像が単射、随伴が π* 同型）に、関手的かつ単体的豊穣と両立する形で置き換える。
  4. これらを厳密な豊穣関手 StableQCat → OmegaSpectrum にまとめ、coherent nerve を取る。

難しいところ

  • 3 の置き換え：K-S• の計画（kst-lanes/L1-s-construction.md）には、「一般の完全関手について BF 模型上で高次面を手作業で貼る整流は、検証済みの区切りで保存して中断する」「K の主経路は厳密 dg 入力に限定（ユーザー指示）」とある。dg の場合は Perf の模型自体が厳密に関手的だったので通った。
    見立て：1 の S• の部分は一般でも厳密に関手的なので、障害は 3 の「Kan 化と Ω スペクトラム化を単体的豊穣と厳密に両立させる」部分に集中しているはずである。止めた作業のどの段で詰まったのかを、K-S• の記録で確認する価値がある。
  • 定理の再証明か移送か：Knc∞ を局所化不変量にするには、\(K_\infty\) の加法性・fibration 定理が要る（§11）。dg 側（K-S•、K-6）では証明済み、∞ 側では未証明。

10. \(\Sigma_\infty\colon\) StableInfinity → StableInfinity

作り方

BGT に従うと、Calkin 懸垂は Catperf の中の余極限として書ける。

\[ \Sigma\mathcal C=\operatorname{cofib}\bigl(\mathcal C\to\mathrm{Ind}_\kappa(\mathcal C)^\kappa\bigr)\qquad(\text{Verdier 商。必要なら冪等完備化を込める}) \]
  1. cone の関手 \(\mathcal C\mapsto\mathrm{Ind}_\kappa(\mathcal C)^\kappa\) と、Yoneda による自然変換 \(\mathcal C\to\mathrm{Ind}_\kappa(\mathcal C)^\kappa\)。
  2. Verdier 商の存在：考えられる道は、Ind の中で Bousfield 局所化を取り（bousfieldReflection・bousfieldLocalizationFunctor、F2/Presentable、10-26 構成）、compact 対象を取る（Thomason–Neeman 型）こと。Ind の安定性（ind_isStable_unconditional）と交換定理（coherentFilteredLimitExchangeShape_finite）は証明済み。
  3. 関手として束ねる：方法 (b) がこのリポジトリの流儀に合う。「\(\mathcal C\) と、その Calkin 商のデータ（cone、商、Verdier 列）」をまとめた ∞ 圏から StableInfinity への射が自明 Kan fibration であることを示し、切断を選ぶ。普遍性で定まるものは選択空間が可縮なので、原理的には成り立つ。余極限を関手的に選ぶ道具 coherentColimitFunctor（F2/FilteredExchange/CoherentColimitFunctor）もある。

難しいところ

  • 方法 (a) は使いにくい：\(\mathcal C\mapsto\mathrm{Ind}(\mathcal C)\) の共変な作用は左 Kan 拡張 \(f_!\) で、選択を伴い、合成とは同型を除いてしか両立しない（\(f_!g_!\cong(fg)_!\)）。c4 と同じ「厳密か coherent か」の問題である。ただし ∞ 側では写像空間が正しいので、§3 の円板の反例のような不可能性はない。問題は「不可能」から「手間がかかる」に変わる。
  • 方法 (b) の「データの ∞ 圏」：StableInfinity の上に Calkin データの ∞ 圏を作り、その射（完全関手に沿ったデータの写像）を正しく定め、選択空間の可縮性を示す必要がある。見立て：\(\Sigma_\infty\) の工数の大半はここ。
  • 宇宙：\(\mathrm{Ind}_\kappa(\mathcal C)\) は宇宙 \(u+1\) にある。κ-compact 部分は本質的には小さいが、StableInfinity.{u} に戻すには「本質的に小さい ∞ 圏を同値な小さい ∞ 圏に取り替える」操作を関手的に行う必要がある。unstraightening の Shrink（補章 §3）より難しい。
  • 冪等完備化：Verdier 商を Catperf で取るか（Idem を含める）どうかで K の π0 が変わる。dg 側の比較目標は Idem を含む形 \(\nu(\Sigma_{dg}A)\simeq\mathrm{Idem}(\cdots)\) なので、定義を揃える必要がある。

11. 共通の難しさ：Knc∞ が局所化不変量であること

BGT の議論には次の二つが要る。

  1. \(K(\mathrm{Ind}_\kappa(\mathcal C)^\kappa)=0\)：可算余積を使う Eilenberg の swindle。\(K_\infty\) の加法性が要る。
  2. Verdier 列 \(\mathcal C\to\mathrm{Ind}_\kappa(\mathcal C)^\kappa\to\Sigma\mathcal C\) への fibration 定理の適用。

どちらも \(K_\infty\) の側の定理である。dg 側で証明済みのものを使う場合の注意：

対象ごとの比較では足りない

局所化不変量の条件は「Verdier 列の四角形を送ると引き戻しになる」という四角形についての主張である。引き戻しであることは、四角形の間の自然な同値でしか移らない。したがって dg 側の fibration 定理を移すには、対象ごとの比較ではなく Fun(S, Sp) の中の自然同値 dgKInputK ≃ \(K_\infty\circ\nu\) が要る。設計の「対象ごとの比較で ∞ 側と一致させる」という言い方とずれている点で、注意が必要。

さらに \(\Sigma_\infty\nu A\) は ν の像に入るとは限らない（Idem を除いて \(\nu(\Sigma_{dg}A)\) と一致するだけ）ので、その分の比較も要る。
