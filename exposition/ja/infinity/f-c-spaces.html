補章 3　空間の ∞ 圏 S と Hom 関手：coherent nerve と twisted arrow

2026-10-28。Claude との議論を整理した数学の章。形式化の対応は SerrePositivity の Lean ソース（F1/Coherent、Coherent、Core）を 2026-10-28 に読んだもの。Kerodon の節番号は同日のオンライン版による。 入門テキストの最初の山として、空間の ∞ 圏 \(\mathcal S=N^{hc}(\mathcal Kan)\) を定義し、その写像空間を計算するまでをまとめる。

1. 流れ

  1. 単体的圏と \(\mathcal Kan\)（Hom が Kan 複体で、合成は厳密）。
  2. \(\mathfrak C[\Delta^n]\)：\(n\) 単体のホモトピー整合的な形（Hom が立方体）。
  3. \(N^{hc}(\mathcal C)_n=\mathrm{Hom}_{\mathrm{sCat}}(\mathfrak C[\Delta^n],\mathcal C)\)。
  4. 局所 Kan なら \(N^{hc}(\mathcal C)\) は quasicategory（開いた箱の充填）。
  5. \(\mathcal S:=N^{hc}(\mathcal Kan)\)、\(\mathrm{Cat}_\infty:=N^{hc}(\mathcal{QC}at^{\simeq})\)。
  6. 写像空間の比較定理 \(\mathcal C(X,Y)\simeq\mathrm{Hom}_{N^{hc}\mathcal C}(X,Y)\)。\(\mathcal S\) では \(\mathrm{Fun}(X,Y)\simeq\mathrm{Hom}_{\mathcal S}(X,Y)\)。

\(N^{hc}\) が作るのは quasicategory であって Kan 複体ではない。Kan 複体は \(\mathcal S\) の対象として入力の側にいて、\(N^{hc}\) は「Kan 複体を射の空間にもつ単体的圏」を ∞ 圏に翻訳する。

2. 単体的圏と \(\mathcal Kan\)

  • 単体的圏：単体的集合で豊穣化された圏。Hom \(\mathcal C(x,y)\) は単体的集合で、合成 \(\mathcal C(y,z)\times\mathcal C(x,y)\to\mathcal C(x,z)\) は厳密に結合的・単位的。
  • \(\mathcal Kan\)：対象は小さい Kan 複体（宇宙を一つ固定）、\(\mathcal Kan(X,Y)=\mathrm{Fun}(X,Y)=Y^X\)。\(Y\) が Kan なのでこれも Kan で、\(\mathcal Kan\) は局所 Kan。1 単体は \(\Delta^1\times X\to Y\)、つまり写像のホモトピー、2 単体はホモトピーの間のホモトピー。
  • 厳密な合成：合成は単体的集合の写像として一つに定まり、結合律は等号で成り立つ。quasicategory では合成は \(\Lambda^2_1\) の充填として「選択の空間が可縮」という形でしか定まらず、結合律もホモトピーを除いてしか成り立たない。

単体的圏も ∞ 圏の正当な模型（Bergner）で、厳密であることは欠点ではない。違うのはデータの形式で、単体的圏では「Hom ごとの空間と厳密な合成」に分かれ、quasicategory ではすべてが一つの単体的集合にあり 2 単体は「ホモトピーを指定して可換な三角形」になる。下にある 1 圏の脈体 \(N(\mathcal Kan_0)\) をとると 2 単体は厳密に可換な三角形だけになり、ホモトピーの情報が消える。\(N^{hc}\) は Hom 空間の高次の単体を \(\mathfrak C[\Delta^n]\) の立方体を通して quasicategory の高次の単体に組み込む。

4. \(N^{hc}\) と quasicategory 性

4.1 低次元の単体

  • 0 単体：対象。1 単体：\(\mathcal C(x,y)\) の頂点。
  • 2 単体：\(f\colon x_0\to x_1\)、\(g\colon x_1\to x_2\)、\(h\colon x_0\to x_2\) と \(\mathcal C(x_0,x_2)\) の辺 \(h\to gf\)。\(\mathcal Kan\) ではホモトピー \(h\simeq g\circ f\)。
  • 3 単体：四つの 2 単体と \(\mathcal C(x_0,x_3)\) の正方形（二通りの貼り合わせのホモトピーをつなぐ）。
  • 確かめ：Hom が離散な普通の圏なら立方体からの写像は定数で、\(N^{hc}(\mathcal C)=N(\mathcal C)\)。

4.3 局所 Kan でないと失敗する例

開いた箱の包含は anodyne だが inner anodyne ではないので、Hom が quasicategory なだけでは延長できない。\(n=3\)、\(i=1\)：\(\mathrm{Hom}(0,3)\) は頂点 \(\{0,3\},\{0,1,3\},\{0,2,3\},\{0,1,2,3\}\) の正方形で、与えられるのは三辺 \(\{0,3\}\to\{0,1,3\}\)、\(\{0,1,3\}\to\{0,1,2,3\}\)、\(\{0,2,3\}\to\{0,1,2,3\}\)。三角形 \((\{0,3\},\{0,1,3\},\{0,1,2,3\})\) は合成で埋まるが、残る三角形は辺 \(\{0,2,3\}\to\{0,1,2,3\}\) と合成 \(\{0,3\}\to\{0,1,2,3\}\) から欠けた辺 \(\{0,3\}\to\{0,2,3\}\) を作る外側の horn \(\Lambda^2_2\) で、その辺が可逆でないと埋まらない。Hom が ∞ 圏の単体的圏は (∞,2) 圏で、2 射の向きを忘れられないので coherent nerve は quasicategory にならない。

7. 写像空間の比較定理

7.1 主張と \(\mathrm{Hom}^L\) の具体形

\(\mathcal C\) が局所 Kan なら \(\mathcal C(x,y)\simeq\mathrm{Hom}^L_{N^{hc}\mathcal C}(x,y)\)。\(\mathrm{Hom}^L\) の \(n\) 単体は頂点 0 が \(x\)、面 \(\{1,\dots,n+1\}\) が \(y\) で退化した \((n+1)\) 単体、つまり \(\mathfrak C[\Delta^{n+1}]\to\mathcal C\) で頂点 \(1,\dots,n+1\) を \(y\) に、\(\mathrm{Hom}(j,k)\)（\(j\ge1\)）を \(\mathrm{id}_y\) に送るもの。\(\mathrm{Hom}(j,k)\) をつぶす合成の関係で立方体を割って

\[J^n:=(\Delta^1)^n\big/(S\sim S\cup T),\qquad\mathrm{Hom}^L(x,y)_n=\mathrm{Hom}_{\mathrm{sSet}}(J^n,\mathcal C(x,y)).\]

\(S\) の類は \(m(S)=\min(S\setminus\{0\})\) で決まり、\(J^n\) の頂点は \(n+1\) 個。\(S\subseteq S'\) なら \(m(S)\ge m(S')\) なので \(S\mapsto n+1-m(S)\) は \(J^n\) を経由し、余単体的な写像 \(r\colon J^\bullet\to\Delta^\bullet\) を与える。

\(n=2\)：正方形の頂点 \(\varnothing,\{1\},\{2\},\{1,2\}\) の \(m\) は \(3,1,2,1\)。\(\mathrm{Hom}(1,3)=\Delta^1\) との合成で辺 \(\{1\}\to\{1,2\}\) が一点につぶれ、三角形 \(\varnothing\subseteq\{2\}\subseteq\{1,2\}\) は \(\Delta^2\) のまま、三角形 \(\varnothing\subseteq\{1\}\subseteq\{1,2\}\) は一辺が退化した 2 単体になる。\(J^2=\Delta^2\cup_{\Delta^1}(\text{一辺が退化した 2 単体})\ne\Delta^2\)。\(J^n\) と \(\Delta^n\) はどちらも弱可縮だが同型ではない。

7.2 比較写像と素朴な方針の難点

\(\theta=r^*\colon\mathcal C(x,y)=\mathrm{Hom}(\Delta^\bullet,\mathcal C(x,y))\to\mathrm{Hom}(J^\bullet,\mathcal C(x,y))=\mathrm{Hom}^L(x,y)\) は選択を使わない明示的な単体的写像。定理は「Kan 複体 \(Z\) について \(r^*\colon\mathrm{Hom}(\Delta^\bullet,Z)\to\mathrm{Hom}(J^\bullet,Z)\) はホモトピー同値」に帰着する。各 \(r_n\) は弱ホモトピー同値で切断 \(s_n\colon k\mapsto\{0\}\cup[n+1-k,n+1]\) をもつが、\(s_n\) は \(n\) について自然でないので逆写像を単体ごとに作れない。\(r\) は単射でないので \(\theta\) は trivial fibration でもなく、持ち上げで直接は示せない。Reedy 型の議論や二重単体の対角補題でも書けるが、Kerodon と形式化は別の道をとる。

一般化するなら、Kerodon 4.6.7.8 の方式（写像柱で「同型の転置は同型」を処理）、転置の可逆性を直接示す（円筒の比較 \(\Phi(K\times\Delta^1)\to\Phi K\times\Delta^1\) が可逆な辺を保つことを示して差し替える）、Hom を \(\mathrm{Ex}^\infty\) で Kan 化する（2 射の向きは消える）のいずれか。\(\mathcal S\) と \(\mathrm{Cat}_\infty\) はどちらも局所 Kan なので今の形で足り、Hom が ∞ 圏の場合が要るのは \(\mathrm{Cat}_\infty\) の 2 圏構造や \(\mathrm{Corr}\) の 2 射のような (∞,2) 的な場面で、そこでは写像空間の比較より先に (∞,2) の模型を選ぶ問題になる。

11. \(\mathrm{Map}\) を関手にする：twisted arrow の straightening

11.1 方針

\(\mathrm{Hom}^R(x,y)\) は各点では定まるが、関手 \(C^{\mathrm{op}}\times C\to\mathcal S\) には射の作用（前合成と後合成）と高次の整合性を整合的に選ぶ必要があり、直接選ぶと horn の充填の選択が積み重なって破綻する。そこで写像空間をファイバーにもつ左 fibration を作り（transport と整合性は持ち上げ性質で、選択は可縮）、関手への翻訳を St に任せる。

  1. \(\mathrm{Tw}(C)\to C^{\mathrm{op}}\times C\) を作る。
  2. 左 fibration であること、ファイバーが \(\mathrm{Hom}(x,y)\) と同値であることを示す。
  3. \(\mathrm{Map}_C:=\mathrm{St}(\mathrm{Tw}(C)\to C^{\mathrm{op}}\times C)\)。

矢の圏 \(\mathrm{Fun}(\Delta^1,C)\to C\times C\) もファイバーは \(\mathrm{Hom}(x,y)\) だが、終点の方向には後合成で共変（cocartesian）、始点の方向には前合成で向きが逆（cartesian）の両側 fibration で、左 fibration にならない。始点側を \(C^{\mathrm{op}}\) に取り替えて両方向とも共変にしたのが twisted arrow。

11.2 単体的集合の反対

\(\Delta\) の自己同型 \(\mathrm{rev}\)（対象は固定、\(\theta\colon[m]\to[n]\) を \(i\mapsto n-\theta(m-i)\) に）を前合成して \(X^{\mathrm{op}}=X\circ\mathrm{rev}^{\mathrm{op}}\)。\(X^{\mathrm{op}}_n=X_n\)、\(d_i^{\mathrm{op}}=d_{n-i}\)、\(s_i^{\mathrm{op}}=s_{n-i}\)。単体の集合は同じで頂点の番号を逆にしたもの。

性質内容
脈体\(N(C)^{\mathrm{op}}=N(C^{\mathrm{op}})\)
標準単体\((\Delta^n)^{\mathrm{op}}\cong\Delta^n\)（\(i\mapsto n-i\)、恒等写像ではない）
join\((A\star B)^{\mathrm{op}}\cong B^{\mathrm{op}}\star A^{\mathrm{op}}\)
horn\((\Lambda^n_i)^{\mathrm{op}}\cong\Lambda^n_{n-i}\)。内部 horn は内部 horn に移るので quasicategory の反対は quasicategory

11.3 \(\mathrm{Tw}(C)\) の定義

  • 射影：左半分への制限 \((\Delta^n)^{\mathrm{op}}\to C\) は \(\mathrm{Hom}(X^{\mathrm{op}},C)=\mathrm{Hom}(X,C^{\mathrm{op}})\) により \(C^{\mathrm{op}}\) の \(n\) 単体 \(x_0\to\cdots\to x_n\)。右半分は \(C\) の単体 \(y_0\to\cdots\to y_n\)。
  • \(\mathrm{Tw}\) の頂点 \(i\) は辺 \(f_i=\sigma|_{\{\bar i,i\}}\colon x_i\to y_i\)。
  • \(d_i\) は \(\bar i\) と \(i\) を対にして同時に除き、\(s_i\) は対にして同時に繰り返す。
  • op を書く理由：\(\theta\) に対し \(\theta^{\mathrm{op}}\star\theta\) で関手的になり、\(\bar i\) と \(i\) が常に対になって辺 \((\bar i,i)\) が入れ子に並ぶ。\(\Delta^n\star\Delta^n\) では入れ子にならない。

11.4 \(n=0,1,2\) の計算

\(n=0\)：\(\Delta^1\)（\(\bar0\to0\)）。頂点は \(C\) の射 \(f\colon x\to y\)（退化した \(\mathrm{id}_x\) も含む）。

\(n=1\)：\(\Delta^3\)、\(x_1\xrightarrow{u}x_0\xrightarrow{f_0}y_0\xrightarrow{v}y_1\)。

辺意味
\((\bar1,\bar0)=u\)\(C^{\mathrm{op}}\) 成分（\(C^{\mathrm{op}}\) では \(x_0\to x_1\)）
\((0,1)=v\)\(C\) 成分
\((\bar0,0)=f_0\)\(\mathrm{Tw}\) の辺の始点（\(d_1\)）
\((\bar1,1)=f_1\)\(\mathrm{Tw}\) の辺の終点（\(d_0\)）

四つの三角形と 3 単体が \(f_1\simeq v\circ f_0\circ u\) をすべての括弧の付け方で整合的に与える。\(\mathrm{Tw}\) の辺 \(f_0\to f_1\) は \(f_0\) を内側、\(f_1\) を外側に置いた入れ子の矢。\(C\) が普通の圏なら \(N(\mathrm{Tw}\,C)\) は古典的な twisted arrow 圏（射 \(f_0\to f_1\) は \(f_1=vf_0u\) をみたす \((u,v)\)）。

\(n=2\)：\(\Delta^5\)、\(x_2\to x_1\to x_0\xrightarrow{f_0}y_0\to y_1\to y_2\)。頂点は入れ子の三本の矢 \(f_0=(\bar0,0)\)、\(f_1=(\bar1,1)\)、\(f_2=(\bar2,2)\)。辺は \(d_2\)（\(\bar1\bar0\,01\)）が \(f_0\to f_1\)、\(d_0\)（\(\bar2\bar1\,12\)）が \(f_1\to f_2\)、\(d_1\)（\(\bar2\bar0\,02\)）が \(f_0\to f_2\)。5 単体全体が「\(f_0\to f_1\to f_2\) の合成が \(f_0\to f_2\)」の整合性を運ぶ。

11.5 左 fibration であること：持ち上げの計算

左 horn \(\Lambda^n_i\)（\(0\le i

\[D=\bigcup_{\tau\subseteq\Lambda^n_i}(\tau^{\mathrm{op}}\star\tau)\cup(\Delta^n)^{\mathrm{op}}\cup\Delta^n\subseteq(\Delta^n)^{\mathrm{op}}\star\Delta^n\]

で、\(D\subseteq\Delta^{2n+1}\) が inner anodyne であることを示す（Kerodon 8.1、HA 5.2.1.3）。

  • \(n=1\)、\(i=0\)：\(D\) は三辺 \(u\)、\(f_0\)、\(v\)、つまり \(\Delta^3\) の背骨で、背骨の包含は inner anodyne。持ち上げは \(f_0\) を \((u,v)\) に沿って動かした \(v\circ f_0\circ u\) で、これが transport。
  • \(n=1\)、\(i=1\)（右 horn）：\(D\) は \(u\)、\(f_1\)、\(v\)。欠けた辺 \(x_0\to y_0\) には \(u\) か \(v\) の逆が要り、一般には延長できない。\(\mathrm{Tw}(C)\) は右 fibration ではない。
  • \(n=2\)、\(i=0\)：\(D\) は 3 単体 \(\bar1\bar0\,01\) と \(\bar2\bar0\,02\)、三角形 \(\bar2\bar1\bar0\) と \(012\) の和。ここから \(\Delta^5\) まで内部 horn の貼り付けで埋める。

11.6 ファイバーの計算

\((x,y)\) 上のファイバーの \(n\) 単体は、左半分がすべて \(x\)、右半分がすべて \(y\) の \(\Delta^{2n+1}\to C\)（TwistedArrow/HomSpace）。

  • 0 単体：射 \(f\colon x\to y\)。
  • 1 単体：3 単体 \(x\xrightarrow{\mathrm{id}}x\to y\xrightarrow{\mathrm{id}}y\)。辺 \(f_0=(\bar0,0)\)、\(f_1=(\bar1,1)\)、\(a=(\bar1,0)\)、\(b=(\bar0,1)\)。四つの三角形は一辺が恒等射で \(f_0\sim a\)、\(f_0\sim b\)、\(a\sim f_1\)、\(b\sim f_1\)、3 単体がそれらを整合させる。\(\mathrm{Hom}^L(x,y)\) の 1 単体（三角形 \((x;y,y)\) 一つ）よりデータは多いが同値。

比較写像（cosliceTwistedHomMap）：左半分を錐点につぶす崩壊 \((\Delta^n)^{\mathrm{op}}\star\Delta^n\to\Delta^0\star\Delta^n\) の前合成で、\(n\) について自然な \(\mathrm{Hom}^L(x,y)\to\mathrm{Tw}(C)_{(x,y)}\)。\(n=1\) では三角形 \(\tau\) を退化した 3 単体に送り、\(a=f_0\)、\(b=f_1\)。素朴な逆「\(\bar0\star\Delta^n\) に制限」は、\(d_0\) が \(\bar0\) と \(0\) を同時に除くので面写像と可換にならない（\(N^{hc}\) の \(s_n\) と同じ種類の難点）。

証明（TwistedHomRows、TwistedHomDiagonal、Joins/CosliceTwistedHomEquivalence）：前に候補として挙げた二重単体の対角の方式。

  1. 左の大きさ \(m\) と右の大きさ \(n\) を別々に動かした二重単体集合 \(R_{m,n}=\{(\Delta^m)^{\mathrm{op}}\star\Delta^n\to C\mid\text{左は }x\text{、右は }y\text{ で一定}\}\)。
  2. \(m\) を固定した行は、退化単体 \(\sigma\)（\(x\) の \(m\) 単体）の下のスライス \(C_{\sigma/}\) の \(y\) 上のファイバーそのもの。崩壊 \(\Delta^m\to\Delta^0\) による比較 \(\mathrm{Hom}^L(x,y)\to R_{m,\bullet}\) は同値（cosliceSimplexExpansion_isQCatEquivalence）。頂点への制限 \(C_{\sigma/}\to C_{x/}\) が trivial fibration で、join の持ち上げの補題で端の頂点の包含が anodyne であることに帰着する。
  3. 各行で同値なら対角でも同値（localized_diagonal_map）。
  4. \(R\) の対角 \(R_{n,n}\) は \(\mathrm{Tw}(C)_{(x,y)}\)、定数の側の対角は \(\mathrm{Hom}^L(x,y)\)。

自然性の問題は行ごとに \(m\) を固定して避け、対角補題が全体をまとめる。

11.7 straighten する

\[\mathrm{Map}_C:=\mathrm{St}\bigl(\mathrm{Tw}(C)\to C^{\mathrm{op}}\times C\bigr)\colon C^{\mathrm{op}}\times C\to\mathcal S\]

  • 値：\(\mathrm{Map}_C(x,y)\simeq\mathrm{Tw}(C)_{(x,y)}\simeq\mathrm{Hom}^L(x,y)\)（St の値はファイバーと同値。第一段は fibration 版 Yoneda、第二段は局所化）。
  • 射の作用：\(\mathrm{Tw}(C)\) の辺に沿った transport で、\((u,v)\) に沿って \(f\mapsto v\circ f\circ u\)、選択はすべて可縮。
  • 必要な St：底 \(C^{\mathrm{op}}\times C\) は一般の quasicategory なので、第一段だけでは足りず、\(\mathrm{fv}\) の局所化で降ろす第二段まで要る。
  • 宇宙：\(C\) が宇宙 \(u\) で小さく、\(\mathcal S\) は \(u+1\)。底は uliftFunctor で持ち上げる。
  • 形式化（Yoneda/YonedaInfinityConstruction）：twistedArrowHomInfinity C := leftStraighteningInfinityDiagram (twistedArrowProjection C)、curry した Yoneda 写像 yonedaInfinityMap C（\(C\to\mathcal P(C)\)）、\(h_c\) は representablePresheafInfinity c。
