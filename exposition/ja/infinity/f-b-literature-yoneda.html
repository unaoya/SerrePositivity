3. cofinality

\(e\colon C'\to C\) が cofinal とは、どんな \(F\colon C\to\mathcal D\) についても \(\operatorname{colim}_{C'}(F\circ e)\to\operatorname{colim}_C F\) が同値であること（極限には逆向きの coinitial、Kerodon の left cofinal を使う）。判定法は Quillen の定理 A：すべての \(c\) で \(C'\times_C C_{c/}\) が弱可縮。

  • 余極限を簡単にする：終対象 \(t\) があれば \(\operatorname{colim}_C F\simeq F(t)\)。filtered な図式は cofinal な部分で計算できる。図式の形を取り替える。
  • 他の一般論の土台：Kan 拡張の各点公式、極限の推移性、Ind とコンパクト対象（密度、単一の filtered 図式での表示）、局所化と余極限の整合。
  • 不変性：cofinal は「制限が余極限を変えない」という極限の理論の中での同値の概念。モデル圏での「ホモトピー余極限は添字の弱同値で不変」の ∞ 版。
  • 1 圏の final functor は「\(c\downarrow e\) が空でなく連結」。∞ 版では連結が弱可縮に強まる。
  • 単射が left anodyne ⇔ left cofinal。§6 の「始対象の包含は left anodyne」はこれから出る。

4. Kan 拡張の位置づけ

4.1 二つの役割

  • 極限の一般化：各点の右 Kan 拡張は \(\mathrm{Ran}_fF(d)=\lim(d\downarrow f\to C\to\mathcal E)\)、\(d\downarrow f=C\times_D D_{d/}\)。Kerodon が 7.1 → 7.2 → 7.3 と並べるのはこのため。
  • 整合的な関手を作る手段：\(C_0\subseteq C\) 上の関手を左 Kan 拡張した関手の全体は \(\mathrm{Fun}(C_0,\mathcal D)\) に trivial fibration で写る（Kerodon 7.3.6）。小さな部分で値を決めれば、全体への延長が可縮な選択の空間から一意に得られる。極限を関手にする構成（trivial fibration の切断）の一般化。

4.4 一点への Kan 拡張

大域的には、\(\mathrm{Ran}_f\) は制限 \(f^*\colon\mathrm{Fun}(D,\mathcal E)\to\mathrm{Fun}(C,\mathcal E)\) の右随伴。\(D=\ast\) なら \(\mathrm{Fun}(\ast,\mathcal E)=\mathcal E\)、\(f^*\) は対角 \(\delta\) なので \(\mathrm{Ran}_{C\to\ast}=\lim\)。各点の形でも \(d\downarrow f=C\) なので値は \(\lim_CF\)。Kerodon・HTT は Kan 拡張を各点の形（極限を使う形）で定義するので、極限が先で Kan 拡張が後。1 圏論の流儀で Kan 拡張を先に定義すれば、極限はその特別な場合として定義できる。

5. ホモトピー極限（Kerodon 7.5）

  • ∞ 圏論の中では極限そのものが最初からホモトピー不変で、別の概念としてのホモトピー極限は要らない（∞ 極限を慣習的にホモトピー極限と呼ぶ文献はある）。
  • ホモトピー極限が意味を持つのは厳密な図式 \(C\to\mathrm{Kan}\)（または quasicategory の圏）の側。Bousfield–Kan などで導来関手として定まる。
  • 7.5 は、それが \(N(C)\to\mathcal S\)（または \(\mathcal{QC}\)）と見たときの ∞ 極限と一致することを示す。後半のホモトピー極限図式と categorical な極限図式の比較は、局所化と極限の関係。
  • 扱うのは Kan 複体と ∞ 圏の場合だけで、モデル構造も使わない。一般のモデル圏との比較は ModelBridge 層の話。形式化の HomotopyLimits 層（bousfieldKanHolim）が 7.5 に対応する。

6.3 証明の部品

部品 A：\(\mathrm{id}_b\) は \(B_{b/}\) の始対象

\(\partial\Delta^n\to B_{b/}\)（頂点 0 が \(\mathrm{id}_b\)）の延長は、join で翻訳すると \(\Delta^0\star\partial\Delta^n\to B\) を \(\Delta^{n+1}\) に延ばすこと。\(\Delta^0\star\partial\Delta^n\) は \(d_0\) 以外の面をすべて含むので外側の horn \(\Lambda^{n+1}_0\) の充填で、最初の辺が恒等射（同値）なので Joyal の定理で埋まる。写像空間の立方体で言えば、\(f_1=\mathrm{id}\) なので whisker を割る必要がない。

部品 B：始対象の包含は left anodyne

始対象 \(x\) について \(\{x\}\hookrightarrow X\) は left anodyne。一般には「単射が left anodyne ⇔ left cofinal」（Kerodon 7.2）から出る（始対象への包含はスライスがすべて可縮なので left cofinal）。\(B_{b/}\) なら、\(\{\mathrm{id}_b\}\) から先頭が \(\mathrm{id}_b\) につながる left horn の充填で単体を一つずつ付け加えて全体が得られる。

部品 C：left anodyne に沿った相対関手空間の制限は trivial fibration

\(i\colon K\hookrightarrow L\) が \(B\) 上の left anodyne、\(E\to B\) が左 fibration なら \(i^*\colon\mathrm{Fun}_{/B}(L,E)\to\mathrm{Fun}_{/B}(K,E)\) は trivial Kan fibration。\(\partial\Delta^n\subseteq\Delta^n\) の持ち上げは \(\partial\Delta^n\times L\cup\Delta^n\times K\hookrightarrow\Delta^n\times L\) に沿った延長と同じで、単射と left anodyne の pushout-product は left anodyne（HTT 2.1.2.7、join の補題の直積版）。

組み立て：A で \(\mathrm{id}_b\) が始対象、B で \(\{\mathrm{id}_b\}\hookrightarrow B_{b/}\) が left anodyne、C で \(\mathrm{Fun}_{/B}(B_{b/},E)\to\mathrm{Fun}_{/B}(\{\mathrm{id}_b\},E)=E_b\) が trivial Kan fibration。straightening も \(\mathcal S\) も写像空間の関手性も使わない。Lean では leftFibration_cosliceIdentityEvaluation_trivialKanFibration（import の閉包は約 256 モジュール、関手版は約 1,750）。

逆写像の直観：切断が与える \(\sigma_e\colon B_{b/}\to E\) は \(f\colon b\to c\) を \(f_!e\) に送り、2 単体 \(b\to c\to d\) で \((gf)_!e\simeq g_!f_!e\) を与える。\(e\) から出るすべての transport を高次の整合性まで一度に選んだもので、部品 C の持ち上げがそれを引き受ける。St を「表現可能関手の Un（\(B_{b/}\)）からの写像」と見る見方はこれ。

6.4 関手版

Hom 関手 \(C^{\mathrm{op}}\times C\to\mathcal S\) の作り方は三つ：twisted arrow の straightening（Kerodon 第 8 章、いまの形式化）、\(\mathfrak C[C]\) による厳密化（HTT §5.1.3、モデル構造を使うので不採用）、関手を作らない（∞-cosmos。前層 = 関手の比較が別に要る）。形式化の証明は次の合成。

\[\mathrm{Map}(h_y,F)\xrightarrow[h_1]{\simeq}\mathrm{Fun}_{/C^{\mathrm{op}}}(\mathrm{Un}(h_y),\mathrm{Un}(F))\xrightarrow[h_2]{\cong}(\text{小さい模型})\xrightarrow[h_3]{\simeq}\mathrm{Un}(F)_y\xrightarrow[h_4]{\simeq}F(y)\]

7. 部品 A・B の詳しい証明

7.1 部品 A：\(\mathrm{id}_b\) は \(B_{b/}\) の始対象

始対象 \(x\) の持ち上げ条件：すべての \(n\ge 1\) について、頂点 0 が \(x\) の \(\partial\Delta^n\to X\) は \(\Delta^n\) に延長できる。これは HTT の定義（\(X_{x/}\to X\) が trivial fibration）を join で書き直したもので、「写像空間がすべて可縮」と同値。

  1. join で翻訳：\(u\colon\partial\Delta^n\to B_{b/}\)（頂点 0 が \(\mathrm{id}_b\)）は \(\tilde u\colon\Delta^0\star\partial\Delta^n\to B\)、延長は \(\Delta^{n+1}\to B\)。
  2. 同定：\(\Delta^{n+1}\) の頂点を 0（錐）と \(1,\dots,n+1\) とすると、面 \(S\) が \(\Delta^0\star\partial\Delta^n\) に入る ⇔ \(S\) が \(1,\dots,n+1\) のどれかを含まない ⇔ \(S\subseteq d_k\)（\(k\ge 1\)）。よって \(\Delta^0\star\partial\Delta^n=\Lambda^{n+1}_0\)（外側の horn）。
  3. 最初の辺：頂点 0 が \(\mathrm{id}_b\) なので、horn の辺 \(0\to 1\) は \(s_0(b)\)。
  4. Joyal の定理（HTT 1.2.4.3）：\(m\ge 2\) で \(\Lambda^m_0\to B\) の最初の辺が同値なら延長できる。\(m=n+1\ge 2\) なので埋まる。

7.2 部品 B：始対象の包含は left anodyne（retract による証明）

  1. 切断：\(X_{x/}\to X\) は trivial fibration なので、\(\{x\}\hookrightarrow X\) と \(\mathrm{id}_x\) の持ち上げ問題から切断 \(s\colon X\to X_{x/}\)、\(s(x)=\mathrm{id}_x\) が得られる。

  3. 直積へ：fat join から join へのつぶす写像 \(c\colon\Delta^1\times X\to\Delta^0\star X\)（\(\{0\}\times X\) を錐の頂点に）と合成して \(h=\tilde s\circ c\colon\Delta^1\times X\to X\)。\(h|_{\{1\}\times X}=\mathrm{id}\)、\(h|_{\{0\}\times X}\) と \(h|_{\Delta^1\times\{x\}}\) は \(x\) で定数（後者は \(s_0(x)\) の退化単体が退化単体に行くため）。定数関手 \(x\) から \(\mathrm{id}_X\) への自然変換。

7.4 持ち上げ性質による証明

単射が left anodyne ⇔ すべての左 fibration に対して左持ち上げ性質を持つ（small object argument と retract。モデル圏は使わない）。したがって、左 fibration \(p\colon E\to S\)、\(e\colon\{x\}\to E\)、\(g\colon X\to S\) に対して持ち上げ \(X\to E\) を作ればよい。

  1. 底の取り替え：\(E'=X\times_SE\to X\) は左 fibration。必要なのは切断 \(\tau\colon X\to E'\) で \(\tau(x)=e'\) のもの。fibration 版 Yoneda の逆写像の存在そのもの。
  2. 縮約：7.2 の \(h\)（\(B_{b/}\) なら \(s_0\) で具体的に）。
  3. 引き戻して持ち上げ：\(h^*E'\to\Delta^1\times X\) は左 fibration。\(A=(\{0\}\times X)\cup(\Delta^1\times\{x\})\) 上では \(h\) が \(x\) で定数なので、切断を \(e'\) で定数と定める。\(j\) は left anodyne なので \(\Delta^1\times X\) 全体に延びる。
  4. 制限：\(\{1\}\times X\) に制限すると \(E'\to X\) の切断で、\((1,x)\in A\) なので \(\tau(x)=e'\)。

直観：時刻 0 ではすべてが \(x\) に縮んでいるので \(e'\) を置くだけ。left fibration の持ち上げが時間の向き \(0\to 1\) に沿った輸送を保証し、時刻 1 で \(X\) 全体の切断が得られる。7.2 の retract は、この構成を「\(j\) の持ち上げを \(\iota_1\) で前合成する」と抽象化したもの。

部品 B と C をまとめて：\(\mathrm{ev}_x\colon\mathrm{Fun}_{/X}(X,E')\to E'_x\) の \(\partial\Delta^n\subseteq\Delta^n\) に対する持ち上げは \((\partial\Delta^n\times X)\cup(\Delta^n\times\{x\})\hookrightarrow\Delta^n\times X\) に沿った延長。\(\mathrm{id}_{\Delta^n}\times h\) を使い、\(\Delta^n\times A\cup\partial\Delta^n\times\Delta^1\times X\hookrightarrow\Delta^n\times\Delta^1\times X\) が left anodyne であること（pushout-product をもう一度）で持ち上げれば、left anodyne という中間命題を経由せずに fibration 版 Yoneda が直接出る。

9. straightening の構成と \(h_y\) の関手性

9.1 straightening のおさらい

quasicategory \(B\) について \(\mathrm{St}\colon\mathrm{LFib}(B)\xrightarrow{\simeq}\mathrm{Fun}(B,\mathcal S)\)。ファイバー \(X_b\) が値 \(F(b)\)、transport \(f_!\) が \(F(f)\)、2 単体に沿った \((gf)_!\simeq g_!f_!\) が合成のホモトピー、\(B\) 上の写像が自然変換に対応する。関手を直接与えるには値・射の作用・高次の整合性をすべて整合的に選ぶ必要があるが、左 fibration ではそれらが持ち上げ性質（Prop）として入っていて、選択の空間は可縮。Un（普遍左 fibration の引き戻し）は易しく厳密に関手的、St（fibration から関手を作る）が難しい側。\(h_y\) を関手にするには St の構成だけでよく、同値定理は要らない。

9.2 なぜ素朴には関手にならないか

∞ 関手 \(C^{\mathrm{op}}\to\mathcal S\) は単体的関手 \(\mathfrak C[C^{\mathrm{op}}]\to\mathcal Kan\) と同じで、値、射の作用 \(f^*\)、合成のホモトピー、高次のホモトピーを整合的に与える必要がある。\(\mathrm{Hom}^R(x,y)\) を使うと \(f^*\) は horn の充填の選択でしか定まらず、\(f^*g^*=(gf)^*\) は厳密に成り立たない。

9.3 St の第一段：底が普通の圏の脈体 \(N(C)\)

値を \(X_c\) の代わりに \(\mathrm{St}(X)(c):=\mathrm{Fun}_{/N(C)}(N(C_{c/}),X)\) とする。

  • 厳密に関手的：\(f\colon c\to c'\) に対し \(f^\sharp\colon C_{c'/}\to C_{c/}\)、\((c'\xrightarrow{u}d)\mapsto(c\xrightarrow{f}c'\xrightarrow{u}d)\) は前合成で厳密に定まり \((gf)^\sharp=f^\sharp g^\sharp\)。切断の制限も厳密に関手的で、\(X\) についても関手的。厳密な関手 \(C\to\mathcal Kan\) を \(\mathfrak C[N(C)]\to C\) と合成し、\(\mathfrak C\dashv N^{hc}\) で ∞ 関手 \(N(C)\to\mathcal S\) にする。
  • 値は正しい：\(\mathrm{id}_c\) は \(C_{c/}\) の始対象なので、\(\mathrm{id}_c\) での評価 \(\mathrm{St}(X)(c)\to X_c\) は trivial Kan fibration（fibration 版 Yoneda、§6）。
  • 射の作用：切断 \(\sigma\) を \(f^\sharp\) で制限して \(\mathrm{id}_{c'}\) で評価すると \(\sigma(f)\simeq f_!\sigma(\mathrm{id}_c)\)。transport の厳密な模型。

ファイバーを表現可能な fibration からの切断空間に置き換えることで、値を変えずに厳密な関手性を得る。選択は一つもしない。

9.4 相対関手空間 \(\mathrm{Fun}_{/S}(K,X)\)

  • 定義：\(\mathrm{Fun}_{/S}(K,X)=\mathrm{Fun}(K,X)\times_{\mathrm{Fun}(K,S)}\{K\to S\}\)。\(n\) 単体は \(S\) 上で可換な \(\Delta^n\times K\to X\)。\(\mathrm{Fun}_{/K}(K,K\times_SX)\)（切断の空間）とも同じ。
  • Kan 複体（\(X\to S\) が左 fibration のとき）：(1) \(\mathrm{Fun}(K,X)\to\mathrm{Fun}(K,S)\) は左 fibration（\(\Lambda^n_i\times K\subseteq\Delta^n\times K\) は left anodyne と単射 \(\emptyset\subseteq K\) の pushout-product、HTT 2.1.2.7）。(2) 点上のファイバーは \(\Delta^0\) 上の左 fibration で、すべての辺が可逆な quasicategory なので Kan 複体（Joyal、HTT 1.2.5.1）。\(K=N(C_{c/})\) なら \(X_c\) への trivial Kan fibration からも直接わかる。
  • 写像空間として：\(N(C_{c/})\to N(C)\) 自身が左 fibration なので \(\mathrm{Fun}_{/N(C)}(N(C_{c/}),X)=\mathrm{Map}_{\mathrm{LFib}(N(C))}(N(C_{c/}),X)\)。関手の言葉では Yoneda の左辺 \(\mathrm{Map}(h^c,F)\simeq F(c)\)。第一段は値 \(F(c)\) を Yoneda で同値な \(\mathrm{Map}(h^c,F)\) に置き換えて厳密な関手性を得ている。

10. fibration 版 Yoneda の証明の確認

10.1 設定

  • \(B\)：単体的集合（quasicategory でなくてよい）。\(p\colon E\to B\)：左 fibration（本質的な仮定）。
  • \(E_b=\{b\}\times_BE\)：厳密な引き戻し。\(p\) は isofibration なので ∞ 圏としての引き戻しでもある。
  • \(B_{b/}\)：join スライス（\(n\) 単体は頂点 0 が \(b\) の \(\Delta^{n+1}\to B\)、射影は \(d_0\)）。\(B_{b/}\) と \(E\) はどちらも \(B\) 上の単体的集合。
  • \(\mathrm{Fun}_{/B}(B_{b/},E)=\mathrm{Fun}(B_{b/},E)\times_{\mathrm{Fun}(B_{b/},B)}\{\text{射影}\}\)（厳密な引き戻し）。
  • 評価写像：\(\mathrm{id}_b=s_0(b)\) は \(b\) の上にあるので \(i\colon\{\mathrm{id}_b\}\hookrightarrow B_{b/}\) は \(B\) 上の写像。\(\mathrm{ev}=i^*\colon\mathrm{Fun}_{/B}(B_{b/},E)\to\mathrm{Fun}_{/B}(\{\mathrm{id}_b\},E)=E_b\)。

10.2 相対関手空間の普遍性による書き直し

内部 Hom の普遍性 \(\{K\to\mathrm{Fun}(L,E)\}\cong\{K\times L\to E\}\) から、\(\mathrm{Fun}_{/B}(L,E)\) が \(\mathrm{Fun}(L,E)\to\mathrm{Fun}(L,B)\) の点 \(p_L\) 上のファイバーであることにより

\[\{K\to\mathrm{Fun}_{/B}(L,E)\}\cong\{g\colon K\times L\to E\mid p\circ g=p_L\circ\mathrm{pr}_L\}\]

（\(K\times L\) を \(L\) 経由で \(B\) 上にあるとみたときの \(B\) 上の写像）。\(\mathrm{ev}\) の \(\partial\Delta^n\subseteq\Delta^n\) に対する持ち上げ問題の各部分を読み替える（\(L=B_{b/}\)、\(x=\mathrm{id}_b\)）。

持ち上げ問題読み替え後
上の写像 \(u\colon\partial\Delta^n\to\mathrm{Fun}_{/B}(L,E)\)\(B\) 上の \(\tilde u\colon\partial\Delta^n\times L\to E\)
下の写像 \(v\colon\Delta^n\to E_b\)\(B\) 上の \(\tilde v\colon\Delta^n\times\{x\}\to E\)
可換性\(\tilde u,\tilde v\) が \(\partial\Delta^n\times\{x\}\) で一致
持ち上げ \(w\)\(\tilde u,\tilde v\) を延長する \(B\) 上の \(\tilde w\colon\Delta^n\times L\to E\)

\(\tilde u,\tilde v\) は合併 \((\partial\Delta^n\times L)\cup(\Delta^n\times\{x\})\)（共通部分 \(\partial\Delta^n\times\{x\}\)、押し出しと同じ）からの写像に貼り合わさり、底の写像は \(\Delta^n\times L\to L\to B\)。したがって元の問題は、\(j_n\colon(\partial\Delta^n\times L)\cup(\Delta^n\times\{x\})\hookrightarrow\Delta^n\times L\) の \(p\) に対する持ち上げ問題と同じ。一般に「\(i\colon K\hookrightarrow L\) に沿った制限が trivial Kan fibration」⇔「すべての \(n\) で \(\partial\Delta^n\subseteq\Delta^n\) と \(i\) の pushout-product が \(p\) に対して左持ち上げ性質を持つ」。\(n=0\) では \(j_0=i\) で、\(E_b\) の点を通る切断の存在（逆写像）にあたる。

10.3 pushout-product で \(i\) に帰着

\(j_n\) は単射 \(\partial\Delta^n\subseteq\Delta^n\) と \(i\) の pushout-product。単射と left anodyne の pushout-product は left anodyne（HTT 2.1.2.7。生成元どうしの場合に角柱 \(\Delta^m\times\Delta^n\) を単体に分解する組合せ論で示される）。よって \(i\) が left anodyne なら \(j_n\) も left anodyne で、\(p\) は左 fibration なので持ち上がる。

10.4 \(i\) が left anodyne：縮約を式で書く

\(X=B_{b/}\)。\(\Delta^1\times X\) の \(n\) 単体 \((\alpha,\sigma)\)（\(\alpha\colon[n]\to[1]\)、\(\sigma\colon\Delta^{n+1}\to B\) で頂点 0 が \(b\)）について \(\alpha^{-1}(0)=\{0,\dots,k-1\}\) とし、

\[\rho_k\colon[n+1]\to[n+1],\quad\rho_k(j)=\begin{cases}0&(j\le k)\\ j&(j>k)\end{cases},\qquad h(\alpha,\sigma)=\sigma\circ\rho_k.\]

錐の頂点と最初の \(k\) 個の頂点をまとめて \(b\) につぶす操作。\(\rho_k\) は単調で 0 を 0 に送るので \(X\) の単体になり、単体的作用素とも整合する（\(\alpha\circ\theta\) の 0 の逆像が \(\theta\) で \(\alpha^{-1}(0)\) に移る）。§7.3 の方法 2（余分な退化写像 \(s_0\)）を fat join→join のつぶす写像と合成して書き下したもの。

\(\{0\}\times X\)（\(k=n+1\)）\(\mathrm{id}_b\) で定数\(\rho_{n+1}\) はすべてを 0 に送る
\(\Delta^1\times\{\mathrm{id}_b\}\)\(\mathrm{id}_b\) で定数\(\sigma\) が \(b\) で定数なので前合成で不変

\(j\colon(\{0\}\times X)\cup(\Delta^1\times\{\mathrm{id}_b\})\hookrightarrow\Delta^1\times X\) は \(\Lambda^1_0\subseteq\Delta^1\) と単射の pushout-product なので left anodyne。\(\iota_1\) と \(h\) で \(i\) は \(j\) の retract（\(h\circ\iota_1=\mathrm{id}\)、\(h\) は \(j\) の始域を \(\{\mathrm{id}_b\}\) に送る）なので left anodyne。

\[\text{縮約 }h\text{（式）}\Rightarrow i\text{ は left anodyne}\xRightarrow{\text{pushout-product}}j_n\text{ は left anodyne}\xRightarrow{p\text{ は左 fibration}}\mathrm{ev}\text{ は trivial Kan fibration}\]

使うのは相対関手空間の普遍性、pushout-product の補題、retract での閉性、\(h\) の式だけ。Joyal の定理も切断の選択も使わず、部品 A（\(\mathrm{id}_b\) が始対象）はむしろ系として出る。\(B\) は quasicategory でなくてよく、\(p\) が左 fibration であることは 10.2 の延長でだけ使う。

\(X\) が quasicategory で \(x\) が始対象なら \(\{x\}\hookrightarrow X\) は left anodyne（§7.2：\(X_{x/}\to X\) の切断を選び、縮約 \(h\) を作り、retract）。

\(G\) を固定すると左随伴 \((F,\eta)\) の空間は可縮（HTT 5.2.6、Riehl–Verity）で、「左随伴をもつ」は実質的に性質。Riehl–Verity はホモトピー 2 圏の随伴 (B) が homotopy coherent な随伴に一意に延びることを示し、∞-cosmos では (B) を定義に採る。

12.3 自然性はどこにあるか

  • (A)：自然性はデータ（\(F,G\) と自然変換 \(\eta\colon\Delta^1\times C\to C\)）にすべて入っている。\(\mathrm{Hom}_D(FX,Y)\to\mathrm{Hom}_C(X,GY)\) は本来 \(\mathrm{Map}_D(F-,-)\Rightarrow\mathrm{Map}_C(-,G-)\) の成分で、「関手圏で自然変換が同値 ⇔ 各成分が同値」（Joyal の定理の関手圏版）により条件は各点で足りる。(A) はこれを先取りして、\(\mathrm{Map}\) の関手性を経由せずに書いた形。
  • 注意：\(\eta\) を射の族 \(\eta_X\) にしてはいけない。1 圏でも、\(F\) が先に与えられていれば普遍射の族が自然かは自動でない（\(F\) の射への作用を \(FX\) の自己同型でねじると、各 \(\eta_X\) は普遍のまま自然性が壊れる）。
  • (E)：\(F\) は与えず、\(G\) だけが関手。始対象の空間が可縮であることが \(X\mapsto FX\) の関手性を強制し、整合性はすべて cocartesian 持ち上げの空間が可縮であることから出る。1 圏で普遍性により \(F\) の射への作用が一意に決まるのと同じで、「一意」が「選択の空間が可縮」に置き換わる。
  • (D)：関手 \(C^{\mathrm{op}}\times D\to\mathcal S\) の同値として自然性を明示的に要求する。

どれも整合性を条件にせず、データか普遍性に任せる作りで、極限を「スライスの終対象」と定義して錐の関手性を問わないのと同じ考え方。
