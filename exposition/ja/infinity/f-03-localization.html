2. 局所化の定義

単体的集合 \(X\)、辺の集合 \(W \subseteq X_1\)、写像 \(F : X \to D\) について、\(F\) が \(W\) での局所化であるとは、次の二つが成り立つことをいう。

  1. \(F\) は \(W\) の辺をすべて可逆な辺に送る。
  2. すべての quasicategory \(E\)（同じ宇宙）について、前合成 \[ F^* : \mathrm{Fun}(D, E) \longrightarrow \mathrm{Fun}_W(X, E) \] が ∞ 圏の同値である。ここで \(\mathrm{Fun}_W(X, E)\) は、\(W\) を可逆に送る関手のなす充満部分 ∞ 圏。
def IsLocalization {X D : SSet.{u}} (F : X ⟶ D) (W : Set (X _⦋1⦌)) : Prop :=
  ∃ hF : InvertsEdges F W, ∀ (E : SSet.{u}) [Quasicategory E],
    IsQCatEquivalence (localizationPrecomposition F W hF E)

InfinityCategories/Kerodon/AdjointFunctors/Localization/Localization.lean:79。\(\mathrm{Fun}_W(X, E)\) は invertingFunctors X E W。

定義の細かい点

  • \(D\) が quasicategory であることは要求しない。実際、§3 の証明の途中に出てくる「逆辺を貼り付けた単体的集合」は quasicategory ではないが、局所化の普遍性は満たす。
  • 普遍性を確かめる相手 \(E\) は同じ宇宙 u に限る。宇宙を変える補題（IsLocalization.ulift など、InfinityCategories/Kerodon/AdjointFunctors/Localization/Universe*）が別にある。
  • これは Dwyer–Kan 局所化（一般の局所化）の定義である。Bousfield 局所化（反射的局所化）は、その特別な場合として §6 で扱う。

3. 存在：任意の辺の集合で局所化できる

定理

任意の単体的集合 \(X\) と辺の集合 \(W\) について、quasicategory \(Q\) と、\(W\) での局所化 \(F : X \to Q\) が存在する。

theorem exists_quasicategory_localization (X : SSet.{u}) (W : Set (X _⦋1⦌)) :
    ∃ (Q : SSet.{u}) (F : X ⟶ Q), Quasicategory Q ∧ IsLocalization F W

InfinityCategories/Kerodon/AdjointFunctors/Localization/LocalizationResolution.lean:41。選択した局所化に名前を付けたものが edgeLocalization X W・edgeLocalizationMap（InfinityCategories/Kerodon/AdjointFunctors/Localization/GeneralLocalization.lean）。

証明は三段で、どれも第 1・2 章の道具でできている。

3.1 段 1：可逆な辺の「歩く版」を作る

\(\Delta^1\)（一本の辺）を Kan 置換したものを \(J\) とする（walkingEquivalence := AnodyneKanReplacement.functor.obj Δ[1]、InfinityCategories/Kerodon/AdjointFunctors/Localization/WalkingEquivalence.lean:25）。

  • \(J\) は Kan 複体なので、すべての辺が可逆である。
  • 包含 \(\Delta^1 \to J\) は anodyne である。

つまり \(J\) は「可逆な辺が一本ある、可縮な空間」で、\(J\) から \(Y\) への関手は「\(Y\) の可逆な辺」と（ホモトピーを除いて）同じものになる。

3.2 段 2：W の辺ごとに J を貼り付ける

\(W\) の各辺 \(w\) について、\(\Delta^1 \xrightarrow{w} X\) と \(\Delta^1 \to J\) の pushout をとる（全部まとめて）。

\[ P \;=\; X \sqcup_{\coprod_{w \in W} \Delta^1} \coprod_{w \in W} J \]

（inverseAttachment X W、InfinityCategories/Kerodon/AdjointFunctors/Localization/InverseAttachment.lean:47）。\(X \to P\) は \(W\) の辺を可逆な辺に送る。

主張：どの quasicategory \(Y\) についても、制限写像 \(\mathrm{Fun}(P, Y) \to \mathrm{Fun}_W(X, Y)\) は自明 Kan fibration である（inverseAttachmentRestriction_trivialKanFibration、InfinityCategories/Kerodon/AdjointFunctors/Localization/InverseAttachmentUniversal.lean）。

理由は次のとおり。\(P\) への関手は「\(X\) への関手」と「各 \(J\) への延長」の組である。 \(W\) を可逆に送る関手なら、各 \(w\) の像は \(Y\) の可逆な辺で、可逆な辺は \(Y\) の core（Kan 複体）に入る。 \(\Delta^1 \to J\) は anodyne なので、Kan 複体への写像は延び、延長の空間は可縮になる。 境界からの延長の問題に直すと、ちょうど自明 Kan fibration の持ち上げ条件になる。

自明 Kan fibration は同値なので（§1）、\(X \to P\) は局所化である（inverseAttachment_isLocalization）。ただし \(P\) は quasicategory とは限らない。

3.3 段 3：quasicategory に置き換える

\(P \to \ast\) を「inner anodyne の後に inner fibration」に分解する（第 1 章 §1.4 の exists_quasicategory_resolution_over）。

\[ P \xrightarrow{\ j\ (\text{inner anodyne})\ } Q \to \ast,\qquad Q \text{ は quasicategory} \]

inner anodyne \(j\) について、どの quasicategory \(Y\) でも前合成 \(j^* : \mathrm{Fun}(Q, Y) \to \mathrm{Fun}(P, Y)\) は同値である（isPrecompositionEquivalence_of_innerAnodyne）。 局所化に前合成同値を後ろから合成しても局所化なので（localization_postcomp_precompositionEquivalence）、\(X \to P \to Q\) が求める局所化になる。

この証明の性格

  • 使っているのは、Kan 置換、pushout、自明 Kan fibration、inner anodyne 置換だけで、モデル構造も straightening も使わない。
  • 得られるのは存在と普遍性で、\(Q\) の写像空間は分からない（\(J\) を貼り付けて置き換えた後の形は具体的に計算しにくい）。写像空間の計算には、§5 の hammock 局所化や、第 5 章の分数を使う。
  • この定理は InfinityCategories/Kerodon/AdjointFunctors/Localization にある（exists_quasicategory_localization、LocalizationResolution）。

5. 判定法：与えられた関手が局所化であることを示す

存在定理は抽象的な \(Q\) を作るだけなので、実際には「手元の具体的な関手 \(F : X \to D\) が局所化である」と示したい場面が多い。 例：Verdier 商の射影、hammock 局所化への関手、反射。InfinityCategories/Kerodon/AdjointFunctors/Localization に、そのための判定法がある。

6. Dwyer–Kan 局所化と Bousfield 局所化

Bousfield 局所化（反射的局所化）とは、充満部分圏 \(C_{\mathrm{loc}} \subseteq C\) の包含が左随伴 \(L\) を持つ状況である。このとき、次が成り立つ。

\[ L : C \to C_{\mathrm{loc}} \ \text{は}\ W_L = \{ f \mid L(f) \text{ が同値} \}\ \text{での局所化},\qquad \mathrm{Map}_{C[W_L^{-1}]}(x, y) \simeq \mathrm{Map}_C(x, Ly) \]

抽象的な局所化を \(C\) の中の部分圏として実現でき、写像空間が \(C\) の写像空間で計算できる。これが Bousfield 局所化の利点である。 presentable な ∞ 圏と射の集合 \(S\) に対しては、\(S\)-局所的な対象への反射が存在する（HTT 5.5.4.15。InfinityCategories/Kerodon/LargeInfinityCategories/PresentableInfinityCategories/BousfieldReflection の bousfieldReflection）。 それが \(S\) の生成する強飽和な集まりでの局所化であることは bousfieldLocalizationFunctor_isLocalization_generatedEdges にある。

逆に、一般の局所化は右随伴を持つとは限らない。例えば、小さい安定 ∞ 圏の Verdier 商は、ふつう右随伴を持たない（第 5 章）。

7. hammock 局所化：写像空間を計算する

入力：普通の圏 \(C\) と射の集合 \(W\)（相対圏、RelativeCategory、EInfinity/SimplicialLocalization/RelativeCategory.lean:27）。

構成（Dwyer–Kan 1980）：\(x\) から \(y\) への hammock の空間の \(n\) 単体は、\(n+1\) 段のジグザグ \(x \to \cdot \leftarrow \cdot \to \cdots\ y\) を縦の \(W\) の射でつないだ可換図式である（逆向きの横の射も \(W\) に属する）。 これを Hom とする単体的圏 \(L^H(C, W)\) ができる。Hom を Ex∞ で Kan 複体にして coherent nerve をとったものが kanHammockNerve C := SimplicialNerve (KanHammockCategory C)（KanComparisonNerves.lean:51）である。 \(C\) の nerve からの関手は hammockLocalizationNerveMap : nerve C.category ⟶ kanHammockNerve C。

主張数学形式化
\(W\) を可逆に送る成り立つhammockLocalizationNerveMap_inverts（一般の相対圏で証明済み）
\(\pi_0\) は 1 圏の局所化（Gabriel–Zisman）の Hom成り立つ証明済み
∞ 局所化（IsLocalization）である一般の相対圏で成り立つ（Hinich 2016 など。参照は要確認）モデル圏の場合だけ証明済み（modelHammock_isLocalization、EInfinity/SimplicialLocalization）。一般の場合は計画の M11

hammock 局所化は ∞ 局所化の一つの模型であり、その価値は写像空間が「ジグザグの空間」として具体的に分かることにある。 §3 の存在定理とは役割が違う。§3 は任意の単体的集合の局所化の存在を与え、hammock は普通の圏の局所化の写像空間を与える。 M11 が証明されれば、モデル圏を使わずに基盤で局所化の写像空間を計算できるようになる。

この章で押さえること

  1. IsLocalization F W は Dwyer–Kan 局所化の普遍性による定義で、行き先が quasicategory であることは要求しない。
  2. 任意の \(W\) での局所化は存在する。可逆な辺の「歩く版」\(J\)（\(\Delta^1\) の Kan 置換）を \(W\) の辺ごとに貼り付け、inner anodyne で quasicategory に置き換えればよい。鍵は、制限写像が自明 Kan fibration になること。
  3. 存在定理は写像空間を教えてくれない。写像空間を計算する道具が、Bousfield 局所化（右随伴があるとき）、hammock 局所化（普通の圏のとき）、分数（Verdier 商のとき、第 5 章）である。
  4. hammock 局所化は ∞ 局所化の模型だが、形式化ではモデル圏の場合しか証明がない（一般の場合は M11）。
