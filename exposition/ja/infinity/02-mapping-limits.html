第 2 章　写像空間・充満忠実性・極限

基準コミット 99e51f2a9（2026-10-23）。対象は PinchedHom/ と Core/ の後半。パスは SerrePositivity/InfinityCategories/ からの相対パス。

第 1 章では、写像空間を使わずに（境界充填だけで）終対象と同値を定義した。この章では写像空間を導入し、それらを写像空間で言い直す。主な結果は次の三つである。

  1. 写像空間は Kan 複体で、\(\pi_0\) がホモトピー圏の Hom になる。
  2. 関手が同値であることは、充満忠実かつ本質的全射であることと同値。
  3. 極限は同値で保たれ、関手 ∞ 圏の極限は各点で計算できる。

1. 写像空間

定義

右 pinched 写像空間 \(\mathrm{Hom}^R_X(x,y)\)（Kerodon §4.6.5、HTT §1.2.2 の \(\mathrm{Hom}^R\)）の \(n\) 単体は、\(X\) の \((n+1)\) 単体 \(\sigma\) のうち、最初の \(n+1\) 頂点が張る面が \(x\) で定値になり、最後の頂点が \(y\) になるものである。

structure Simplex (n : ℕ) where
  val : X _⦋n + 1⦌
  source : X.map (front n).op val = constant x n
  target : X.map (lastVertex n).op val = y

def pinchedHom {X : SSet.{u}} (x y : X _⦋0⦌) : SSet.{u} where
  obj n := PinchedHom.Simplex x y n.unop.len
  map f := ↾fun s => s.pullback f.unop

面・退化写像は、順序写像 \([m]\to[n]\) を最後の頂点を固定したまま \([m+1]\to[n+1]\) に延ばして（PinchedHom.extend）引き戻す。定義そのものは任意の単体的集合に対して意味を持ち、quasicategory の仮定は性質を示すときにだけ使う。

Kan 性の証明の方針：\(\mathrm{Hom}^R(x,y)\) の右ホーン \(\Lambda^{n+1}_i\)（\(0<i\)）は、最後の頂点 \(y\) を加えると \(X\) の内ホーン \(\Lambda^{n+2}_i\) になる。したがって quasicategory 性で充填できる。右ホーンが充填できれば、ホモトピー圏が亜群になることを経由して Kan 複体であることが従う（kanComplex_of_rightHornFillers。第 1 章の Joyal の定理を使う）。

左の写像空間と両者の比較

左 pinched 写像空間 \(\mathrm{Hom}^L(x,y)\) は、反対圏の右写像空間の反対として定義している。

def pinchedHomLeft {X : SSet.{u}} (x y : X _⦋0⦌) : SSet.{u} :=
  (pinchedHom (X := X.op) (SSet.opObjEquiv.symm y) (SSet.opObjEquiv.symm x)).op

Kan 性と \(\pi_0\) の計算は、反対圏を通して右の場合から導かれる（Core/MappingSpaceLeft）。右の場合から双対で導く形になっている。左右の写像空間が同値であること（pinchedHomLeftRightEquivalence）は、区間模型を経由して F1/MappingSpaceModelEquivalence で示されている。Core ではなく F1 にある点に注意する。

2. Kan 複体の言葉

写像空間で同値性を述べるために、Kan 複体の側にも「可縮」と「ホモトピー同値」が必要になる。どちらも Kan–Quillen のモデル構造を使わずに定義されている。

def IsContractibleKan (K : SSet.{u}) : Prop :=
  ∀ (n : ℕ) (b : (boundary n : SSet.{u}) ⟶ K),
    ∃ F : (Δ[n] : SSet.{u}) ⟶ K, (boundary n).ι ≫ F = b

def IsSimplicialHomotopyEquivalence {X Y : SSet.{u}} (f : X ⟶ Y) : Prop :=
  ∃ g : Y ⟶ X, Nonempty (SSet.Homotopy (f ≫ g) (𝟙 X)) ∧
    Nonempty (SSet.Homotopy (g ≫ f) (𝟙 Y))

原典との違い

Kerodon では Kan 複体の間の「ホモトピー同値」と「弱ホモトピー同値」を区別し、両者の一致を Kan–Quillen の理論で示す。ここでは弱ホモトピー同値（ホモトピー群の同型）を使わず、明示的なホモトピー逆だけで話を閉じている。可縮性も「\(\pi_n\) がすべて自明」ではなく境界充填で定義している。

3. 終対象と写像空間

命題（HTT Prop. 1.2.12.4 の写像空間版）. quasicategory の頂点 \(x\) について次は同値。

  1. \(x\) は終対象（第 1 章の境界充填の定義）。
  2. すべての \(z\) について \(\mathrm{Hom}^R(z,x)\) は可縮。

Lean では isTerminalVertex_iff_pinchedHom_isContractibleKan（Core/TerminalMappingSpace）。証明は、§1 の同型 \(\mathrm{Hom}^R(z,x)\cong X_{/x}\times_X\{z\}\) と、第 1 章の「終対象 ⇔ \(X_{/x}\to X\) が trivial」を組み合わせる。trivial Kan fibration の fiber は可縮であり、逆に右 fibration で fiber がすべて可縮なら trivial になる。

あわせて、終対象性は \(hX\) での同型で不変であることが示されている（isTerminalVertex_iff_of_vertexIso、Core/TerminalTransport）。極限についても同じ不変性が isLimitCone_iff_of_vertexIso として成り立つ。

4. 充満忠実性と同値の判定

定義

def IsFullyFaithful {X Y : SSet.{u}} (f : X ⟶ Y) : Prop :=
  ∀ x y : X _⦋0⦌, IsSimplicialHomotopyEquivalence (pinchedHomMap f x y)

def IsEssentiallySurjective {X Y : SSet.{u}} (f : X ⟶ Y) : Prop :=
  ∀ y : Y _⦋0⦌, ∃ x : X _⦋0⦌, Nonempty (VertexIso (f.app (Opposite.op ⦋0⦌) x) y)

充満忠実は「すべての写像空間の写像がホモトピー同値」、本質的全射は「\(hY\) のすべての対象が像と同型」である。

主定理

定理（HTT §1.2.10。コードの docstring は Kerodon Thm. 4.8.4.1・Prop. 4.8.4.5 を参照）. quasicategory の間の \(f\colon X\to Y\) について、\(f\) が同値 ⇔ \(f\) が充満忠実かつ本質的全射。

Lean では isQCatEquivalence_iff_fullyFaithful_essentiallySurjective（Core/EquivalenceFullyFaithful）。難しいのは ⇐ で、次の三段で示す。

  1. isofibration への置き換え（Core/EquivalencePath*）。\(Y\) の可逆な辺がなす path の空間 \(\mathrm{Path}^{\simeq}(Y)\) で \(f\) を引き戻し、\(\tilde X=X\times_Y\mathrm{Path}^{\simeq}(Y)\) を作る。射影 \(\tilde X\to X\) は trivial Kan fibration で、終点の評価 \(\tilde f\colon\tilde X\to Y\)（equivalencePathReplacementMap f）は inner fibration になる。\(f\) が同値であることと \(\tilde f\) が同値であることは同値。
  2. 性質の移送。\(\tilde f\) も充満忠実で、本質的全射性は頂点上の全射に強まる（可逆な辺を経由して像を動かせるため）。
  3. trivial Kan fibration であることの証明（Core/FullyFaithfulBoundary）。頂点上で全射な充満忠実 inner fibration \(p\) が \(\partial\Delta^{n+1}\hookrightarrow\Delta^{n+1}\) を持ち上げることを示す。\(p\) を \(\Delta^{n+1}\) に引き戻す（充満忠実性は引き戻しで保たれる。IsFullyFaithful.pullback_snd）。\(\Delta^{n+1}\) の最後の頂点は終対象で、充満忠実な inner fibration は終対象性を反映するので、引き戻した側でも最後の頂点が終対象になる。終対象の境界充填性から持ち上げが得られる。\(n=-1\)（頂点）の場合が全射性である。

このとき trivial Kan fibration は同値なので、\(\tilde f\)、したがって \(f\) が同値になる。

Lean の構造：写像空間の写像を trivial fibration に上げる

3 段目の「充満忠実な inner fibration は終対象性を反映する」の内部では、次の組み合わせが繰り返し使われる。

  • pinchedHomMap_rightFibration：写像空間の写像は右 fibration、とくに Kan fibration
  • trivialKanFibration_of_fibration_of_simplicialHomotopyEquivalence：Kan fibration かつホモトピー同値なら trivial

二つを合わせると IsFullyFaithful.pinchedHomMap_trivialKanFibration が得られる。「ホモトピー同値」という性質を「持ち上げ性」という具体的な道具に変えることが、この層の証明の基本の型になっている。

5. 極限

定義の復習と一意性

錐は \(\Delta^0\star K\to X\) で、極限錐は slice \(X_{/p}\) の終対象である（第 0 章）。第 1 章の結果から、次がそのまま従う。

  • isLimitCone_iff_trivialKanFibration：\(c\) が極限錐 ⇔ \((X_{/p})_{/c}\to X_{/p}\) が trivial Kan fibration
  • limitConeIso、limitVertexIso：二つの極限錐は \(h(X_{/p})\) で同型で、頂点は \(hX\) で同型

同値による保存

命題. \(f\colon X\to Y\) が同値なら、\(c\) が極限錐であることと \(f\circ c\) が極限錐であることは同値。

Lean では IsQCatEquivalence.isLimitCone_iff（Core/EquivalenceAllLimits）。§4 と同じく path による置き換えを使う。同値の場合は \(\tilde X\to X\) と \(\tilde X\to Y\) がともに trivial Kan fibration になる。trivial Kan fibration \(q\) については、slice の後合成 \(X_{/p}\to Y_{/qp}\) も trivial Kan fibration（trivialKanFibration_sliceOverPostcomp）なので、終対象性を保存・反映する。

引き戻し

引き戻しの四角形は \(\Delta^1\times\Delta^1\to X\) として扱う。鍵は同型 \(\Delta^0\star\Lambda^2_2\cong\Delta^1\times\Delta^1\)（cospanConeSquareIso、Core/Square）で、両辺とも対角線に沿って二つの 2 単体を貼り合わせたものとして表示して比較する。これで四角形を cospan 上の錐とみなせる。

def IsPullbackSquare {X : SSet.{u}} (F : Δ[1] ⊗ Δ[1] ⟶ X) : Prop

規約：右辺と上辺が cospan で、座標 \((0,0)\) が錐の頂点（Core/Pullback）。

関手 ∞ 圏の極限は各点で計算できる

命題（HTT Prop. 5.1.2.2、Kerodon §7.1.8）. 図式 \(p\colon J\to\mathrm{Fun}(K,X)\) について：

  1. 各点 \(k\in K\) で評価した錐が極限錐なら、元の錐も極限錐（isLimitCone_of_pointwise）。
  2. 各点で極限が存在するなら、各点で極限になる錐が存在する（exists_pointwiseLimitCone）。したがって極限が存在する（hasLimit_of_hasPointwiseLimits）。
  3. その状況では、極限錐であることと各点で極限錐であることは同値（isLimitCone_iff_pointwise_of_hasPointwiseLimits）。

2 の難しさは、各点で選んだ極限錐に自然性がないことにある。そこで「相対的な終点境界充填」を使い、選んだ錐を \(K\) の単体に沿って一つずつ自然な族へ延長していく（Core/FunctorPointwiseLimitExistence）。

補助模型：fat join、lax slice、錐の族

関手 ∞ 圏の極限を扱うには、slice \(X_{/p}\) のままでは \(\mathrm{Fun}(K,-)\) との相性が悪い。そこで Kerodon §4.6.2〜4.6.6 に沿って、三つの補助模型を導入し、すべて slice と同値であることを示している。

錐の族の模型では、錐が関手 ∞ 圏の対象になる。そのため \(\mathrm{Fun}(K,-)\) との交換が内部 Hom の curry だけで済む。isLimitCone_iff_isTerminalVertex_coneFamily（Core/LimitConeFamily）が、極限性をこの模型に移す入口である。

原典との違い

HTT は slice \(X_{/p}\) と fat slice \(X^{/p}\) の比較を Joyal のモデル構造で処理する（HTT Prop. 4.2.1.5）。ここでは Kerodon の方針に従い、標準単体の場合を明示的な変形（Core/FatJoinStd*）で示してから、pushout・余極限での閉包性で一般化している（Core/FatJoinLeftColimits、FatJoinRightColimits など）。Core/Precomposition* の判定条件 IsPrecompositionEquivalence（「任意の quasicategory への前合成が同値」）は、quasicategory でない補助模型の比較のために導入されている。

通常の圏との整合性

Core/LimitExamples では、順序圏 \(0\to1\) の二項積が nerve の極限と一致する、という小さな例を検算している（topPair_limit_agreement）。一般の圏 \(C\) について \(N(C)\) の極限が \(C\) の極限と一致することは、ここではまだ示されていない（古典 nerve との比較は F1B 側、第 4 章）。

この章で押さえること

  1. 写像空間は右 pinched Hom で、slice の fiber と同型（同値ではない）。Kan 性は右ホーンを \(X\) の内ホーンに読み替えて示す。
  2. Kan 複体の側でもモデル構造は使わず、可縮性は境界充填、ホモトピー同値は明示的な逆で定義している。
  3. 「同値 ⇔ 充満忠実かつ本質的全射」の証明は、path による isofibration への置き換えと、「充満忠実な inner fibration は終対象性を反映する」ことに帰着する。
  4. 「ホモトピー同値な Kan fibration は trivial」を使って、写像空間についての性質を持ち上げ性に変えるのが、この層の基本の型。
  5. 関手 ∞ 圏の極限は各点で計算できる。その証明のために、fat join・lax slice・錐の族という補助模型が導入され、slice との同値が示されている。
