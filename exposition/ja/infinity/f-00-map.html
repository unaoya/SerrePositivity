3. 数学の依存の順序

配置とは別に、数学としては次の順に積み上がる。各章はこの順で読む。

単体的集合の組合せ論 → quasicategory の基本 ⇄ 空間の理論 → coherent nerve
  → {fibration と straightening, 随伴・局所化, ホモトピー極限} → 安定 ∞ 圏 → 大きな ∞ 圏 → 安定 presentable

3.1 単体的集合の組合せ論が最初

horn や anodyne 射は、∞ 圏の概念を使わずに単体的集合だけで定義できる。 Kan 置換、inner anodyne 置換、Ex∞ はすべて「単体的集合の射の性質」の話で、quasicategory の定義（内 horn の充填）の前提でもある。

3.2 quasicategory と空間の理論の順序

数学的には二通りの順序がある。

  • Kerodon の順序（空間が先）：第 3 章で Kan 複体（ホモトピー群、Whitehead）を扱い、第 4 章で ∞ 圏に進む。Kan 複体の理論は ∞ 圏を使わずに展開できる。今のディレクトリの配置はこの順。
  • quasicategory が先：Kan 複体を「すべての辺が可逆な quasicategory」とみて、quasicategory の道具（同値、同値の道、外 horn の充填）で空間の理論を展開する。

このプロジェクトの Kan 複体の道具の多くは、後者の形で証明されている（例：Kan fibration の道具が quasicategory の同値の道を使う）。そのため、ディレクトリは Kerodon の順でも、ファイルの import は quasicategory の基本を先に使うことがある。境目になるのは、写像空間が Kan 複体であること、Joyal の定理「ホモトピー圏が亜群なら Kan 複体」、Kan fibration の基本的な道具である。

3.3 coherent nerve は空間の後

空間の ∞ 圏 \(\mathcal S\) は、Kan 複体のなす単体的圏の coherent nerve として定義される。 coherent nerve が quasicategory になることを示すにも、Hom が Kan 複体であることを使う。

3.4 安定 ∞ 圏は presentable 性より前

安定 ∞ 圏の基礎（三角構造、完全関手、Verdier 列）は、presentable 性を使わずに展開できる。 逆に「安定 ∞ 圏 \(C\) の \(\mathrm{Ind}(C)\) は安定」（ind_isStable_unconditional）は安定性を使う。

3.5 安定 presentable は両方の後

安定な Bousfield 局所化や Thomason–Neeman は、安定性と presentable 性の両方を使う。

4. ∞ 圏論の基盤に入れないもの

入れないもの理由

モデル圏∞ 圏論はモデル圏なしで展開できる。モデル圏はできるだけ避ける（10-28 決定）

モデル圏の入り込みは、ほとんどが付随的

∞ 圏論の基盤が HomotopicalAlgebra から使っているのは、どれもモデル圏を使わずに証明できる事実である。 例：small object argument による Kan 置換、端点の包含 \(X \to X \times \Delta^1\) が anodyne であること、bisimplicial 集合の対角、宇宙の持ち上げ。 ところが、それらを収めたファイルの末尾に [ModelCategory SSet] を仮定する節があったり、使っていない import があったりする。 そのため、import の閉包にモデル圏が入り込んでいる。最大の経路は（2026-10-28 の調べで）HL.KanEquivalencePaths → AnodyneIntervalEndpoints → FixedBoundaryExtensions（128 行目に Model の節）である。 第 2 章で詳しく扱う。

6. Verdier 商までの道筋

最終目標は、安定 ∞ 圏 \(B\) とその安定な充満部分圏 \(A\) に対して、商 \(B/A\) を一般に構成することである。 9 人論文（Calmès ほか、Hermitian K-theory II の付録 A）にならい、Verdier 列 \(A \to B \to C\) を次の三条件で特徴づける。

  1. \(A \to B\) は充満忠実
  2. \(B \to C\) の核（0 に送られる対象）がちょうど \(A\) の本質像
  3. \(B \to C\) は、cofiber が \(A\) に入る射を可逆にする Dwyer–Kan 局所化

いまの IsVerdierSequence はこの形で書かれている。何がそろっていて何が足りないかを、表にまとめる。

部品状態
任意の辺の集合 \(W\) に対する Dwyer–Kan 局所化 \(X[W^{-1}]\) の存在（同じ宇宙で）証明済み（InfinityCategories/Kerodon/AdjointFunctors/Localization）
Verdier 列の定義と、随伴による判定 isVerdierSequence_of_adjoint証明済み（InfinityCategories/HA/StableInfinityCategories/Verdier）
商の写像空間を分数（屋根の filtered 余極限）で表す証明済み。ただし、商が安定であることを仮定している（InfinityCategories/Project/DerivedCategories/Verdier/Fractions ほか）
M1：IsVerdierSequence ⇒ IsStableVerdierSequence未着手
M2：安定な部分圏の cofiber 辺での局所化は安定で、局所化関手は完全未着手（dg 版だけある）
M7：商の存在。一般には核は \(A\) の厚い閉包。像が厚ければ IsVerdierSequence になる未着手（局所化の存在と M2 から）
M8：商の関手性（部分圏の組と、それを保つ完全関手について）未着手。非連結 K の Calkin 懸垂に必要
M11：一般の相対圏で hammock 局所化が ∞ 局所化であること（写像空間をジグザグで計算する。いまはモデル圏の場合だけ）未着手（数学的には既知の定理）
M3〜M6：Ind を経由する道（安定 Bousfield 局所化、Thomason–Neeman、Karoubi 列）未着手。Ind・Bousfield 局所化・compact ≃ 冪等完備化は InfinityCategories/Kerodon/LargeInfinityCategories にある

つまり、商の構成に必要な「骨組み」（局所化の存在、Verdier 列の定義、分数）は、すでに KST の中にほぼそろっている。 整備の目的の一つは、これらを Stable/ にまとめて、M1・M2・M7 を ∞ 層の中で証明できる状態にすることである。詳しくは第 4・5 章で扱う。
