3. なぜこの順序か

3.1 Simplicial が最下層

horn や anodyne 射は、∞ 圏の概念を使わずに単体的集合だけで定義できる。 Kan 置換、inner anodyne 置換、Ex∞ はすべて「単体的集合の射の性質」の話なので、ここに置く。 これらは quasicategory の定義（内 horn の充填）の前提でもある。

3.2 Core < Kan（Kan 複体の層を quasicategory の上に置く）

数学的には、二通りの順序が考えられる。

  • Kerodon の順序（Kan < Core）：第 3 章で Kan 複体（ホモトピー群、Whitehead）を扱い、第 4 章で ∞ 圏に進む。Kan 複体の理論は ∞ 圏を使わずに展開できる。
  • Core < Kan：Kan 複体を「すべての辺が可逆な quasicategory」とみて、quasicategory の道具（同値、同値の道、外 horn の充填）を使って空間の理論を展開する。

本計画は後者を採る。理由はコードの現状にある。

  • いまある Kan 複体の道具は、quasicategory の理論を使って書かれている。例：Core/KanFibrationTools は Core.EquivalencePath を import している。
  • KST/Spectra（ホモトピー群・Whitehead などの本体）1,622 本のうち、∞ 層を使わないものは 242 本しかない。

Kan < Core にするには、これらの証明を書き換える必要がある。整備は「移動だけ」で行う方針なので、当面は Core < Kan とし、Kerodon の順序に揃えるかは後で判断する（計画 §9-5）。

境目の決め方

quasicategory と Kan 複体をつなぐ結果は Core に置く。例：写像空間が Kan 複体であること、Joyal の定理「ホモトピー圏が亜群なら Kan 複体」、Kan fibration の基本的な道具。 Core を使ってよい「空間そのものの理論」は Kan に置く。例：π_n、長完全列、Whitehead、塔。

3.3 Coherent は Kan の上

空間の ∞ 圏 \(\mathcal S\) は、Kan 複体のなす単体的圏の coherent nerve として定義される。 coherent nerve が quasicategory になることを示すにも、Hom が Kan 複体であることを使う。そのため Coherent は Kan の上に来る。

3.4 Stable < F2

安定 ∞ 圏の基礎（三角構造、完全関手、Verdier 列）は、presentable 性を使わずに展開できる。 逆に、F2 の「安定 ∞ 圏 C の Ind(C) は安定」（ind_isStable_unconditional）は Stable を使う。 いまは F2 → Stable の import が 193 辺あり、この順序と合っている。逆向き（Stable → F2）の辺は、整備の W2b（11-03）で解消した。

3.5 StablePresentable は F2 の上

安定な Bousfield 局所化や Thomason–Neeman は、安定性と presentable 性の両方を使う。どちらの層にも収まらないので、両者の上に新しい層を置く。

4. 中核に入れないもの

入れないもの理由

モデル圏の入り込みは、ほとんどが付随的

中核が HomotopicalAlgebra から使っているのは、どれもモデル圏を使わずに証明できる事実である。 例：small object argument による Kan 置換、端点の包含 \(X \to X \times \Delta^1\) が anodyne であること、bisimplicial 集合の対角、宇宙の持ち上げ。 ところが、それらを収めたファイルの末尾に [ModelCategory SSet] を仮定する節があったり、使っていない import があったりする。 そのため、import の閉包にモデル圏が入り込んでいる。最大の経路は HL.KanEquivalencePaths → AnodyneIntervalEndpoints → FixedBoundaryExtensions（128 行目に Model の節）である。 第 2 章で詳しく扱う。

6. Verdier 商までの道筋

最終目標は、安定 ∞ 圏 \(B\) とその安定な充満部分圏 \(A\) に対して、商 \(B/A\) を一般に構成することである。 9 人論文（Calmès ほか、Hermitian K-theory II の付録 A）にならい、Verdier 列 \(A \to B \to C\) を次の三条件で特徴づける。

  1. \(A \to B\) は充満忠実
  2. \(B \to C\) の核（0 に送られる対象）がちょうど \(A\) の本質像
  3. \(B \to C\) は、cofiber が \(A\) に入る射を可逆にする Dwyer–Kan 局所化

いまの IsVerdierSequence はこの形で書かれている。何がそろっていて何が足りないかを、表にまとめる。

部品状態
任意の辺の集合 \(W\) に対する Dwyer–Kan 局所化 \(X[W^{-1}]\) の存在（同じ宇宙で）証明済み（InfinityCategories/Kerodon/AdjointFunctors/Localization）
Verdier 列の定義と、随伴による判定 isVerdierSequence_of_adjoint証明済み（InfinityCategories/HA/StableInfinityCategories/Verdier）
商の写像空間を分数（屋根の filtered 余極限）で表す証明済み。ただし、商が安定であることを仮定している（InfinityCategories/Project/DerivedCategories/Verdier/Fractions ほか）
M1：IsVerdierSequence ⇒ IsStableVerdierSequence未着手
M2：安定な部分圏の cofiber 辺での局所化は安定で、局所化関手は完全未着手（dg 版だけある）
M7：商の存在。一般には核は \(A\) の厚い閉包。像が厚ければ IsVerdierSequence になる未着手（局所化の存在と M2 から）
M8：商の関手性（部分圏の組と、それを保つ完全関手について）未着手。非連結 K の Calkin 懸垂に必要
M11：一般の相対圏で hammock 局所化が ∞ 局所化であること（写像空間をジグザグで計算する。いまはモデル圏の場合だけ）未着手（数学的には既知の定理）
M3〜M6：Ind を経由する道（安定 Bousfield 局所化、Thomason–Neeman、Karoubi 列）未着手。Ind・Bousfield 局所化・compact ≃ 冪等完備化は F2 にある

つまり、商の構成に必要な「骨組み」（局所化の存在、Verdier 列の定義、分数）は、すでに KST の中にほぼそろっている。 整備の目的の一つは、これらを Stable/ にまとめて、M1・M2・M7 を ∞ 層の中で証明できる状態にすることである。詳しくは第 4・5 章で扱う。
