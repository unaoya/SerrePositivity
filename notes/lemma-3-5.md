# 補題 3.5（通常のノルム比較）

2026-10-07 作成。論文 §3.4（p.14–16）の Lemma 3.5 の主張、証明の構造、仮定の切り分け。補題 3.4 については `notes/lemma-3-4.md`。

## 証明全体の中での位置

主定理の証明の「ステップ 3」（置き換え D → C_D）は Lemma 5.2

  |G_D| · a_D · a_E · χ_R(D, E) = Σ_{σ ∈ G_D} c_σ（式 (5.3)）

で、これは補題 3.5 を A = A_D、T = D′、C = C_{D′}、G = G_D、P = (E′ の自由 R 分解) ⊗_R D′ に適用して得られる。普通の長さで測った元の Euler 特性と、λ で測った量を結びつける最初の橋がこの補題。

## 設定

§3.4 の設定（`notes/lemma-3-4.md` を参照）：

- (A, m_A, k)：次元 e > 0 の完備正則局所 ℤ₍ₚ₎ 代数、剰余標数 p、正則パラメータ系 z₁, …, z_e
- T：A 上有限な局所整域で剰余体は k、r = rank_A T
- C：T 代数。λ は m_A の冪で消される C 加群上の [0, ∞] 値関数で、λ(0) = 0 かつ加法的
- (3.9)：全ての v ≥ 1 で λ Hᵢ(z^v; C) = 0（i > 0）、λ(C / z^v C) = v^e · r

補題 3.5 ではさらに：

- 有限群 G が T に A 代数の自己同型として作用する
- G は Spec T → Spec A の全ての幾何ファイバーの点に推移的に作用する

## 記法

- K₀^{m_A}(T)：V(m_A T)（= T の閉点）に台をもつ perfect T 複体の Grothendieck 群
- ひねり：g ∈ G に対し g*P = P ⊗_{T,g} T。自由複体なら微分の行列成分に g を作用させたもの
- 台の判定法：perfect 複体 P について、P[1/z] = 0 ⇔ ある冪 z^v が id_P をホモトピー圏で消す。有限個の生成元について共通の v がとれる

## 主張

V(m_A T) に台をもつ perfect T 複体 P について、

- χ_T(P) = Σᵢ (−1)ⁱ length_T Hᵢ(P)
- χ_C(P) = Σᵢ (−1)ⁱ λ Hᵢ(P ⊗^L_T C)

はどちらも有限で、K₀^{m_A}(T) 上の準同型を定める。そして

  Σ_{g ∈ G} χ_T(g*P) = Σ_{g ∈ G} χ_C(g*P)（式 (3.11)）

より一般に、2つの準同型は K₀^{m_A}(A) からの引き戻しの像の上で一致し、G 不変な有理類の上でも一致する。

χ_T は整数値、χ_C は実数値。λ の G 不変性は仮定しない。等式は共役の和についてであって、個々の P については主張しない（Remark 3.6）。このおかげで、D 側と E 側の長さ代数を独立に選べる。

## 証明（論文の3段階）

### 段階 1：有限性と加法性

- P を有界な有限自由 T 複体で表す。Hᵢ(P) は有限生成で閉点に台をもつので有限長。よって χ_T は有限。
- 台の判定法から、ある共通の v で全ての z_j^v が P の上でホモトピー的に 0。そのホモトピーで写像錐を順に分解して

  K_v ⊗_T P ⊗_T C ≃ ⊕_{j=0}^{e} (P ⊗_T C)[j]^{(e choose j)}（式 (3.12)、K_v = K(z^v; T)）

- 逆の順序で、先に K_v ⊗ C のホモロジー Hⱼ(z^v; C) をとるスペクトル系列を考える。P は有界な有限自由複体なので、各項は Hⱼ(z^v; C) の有限直和の部分商。(3.9) から λ は有限。
- よって左辺のホモロジーは λ が有限で、Hᵢ(P ⊗ C) はその直和成分（j = 0）なので λ も有限。現れる加群は m_A の固定した冪で消されるので λ の定義域に入る。
- 三角形のホモロジー長完全列から、χ_T も χ_C も K₀^{m_A}(T) 上の準同型。

### 段階 2：A から来る類で一致する（補題 3.4 を使う）

Q を m_A に台をもつ perfect A 複体とする。どちらの Euler 特性も r · Σⱼ (−1)ʲ length_A Hⱼ(Q) になる。

- **λ の側（式 (3.13)）**：(Q ⊗_A T) ⊗_T C = Q ⊗^L_A C。超 Tor のスペクトル系列 E² = Torᵢ^A(Hⱼ(Q), C) ⇒ H_{i+j}(Q ⊗^L_A C) で、Hⱼ(Q) は有限長なので**補題 3.4** から i > 0 の行は λ = 0、i = 0 の行は r · length Hⱼ(Q)。λ は加法的で値は有限なので、交代和はページをめくっても変わらない。
- **普通の側（式 (3.14)）**：A は正則なので T の有限自由 A 分解 L• があり、交代ランクは r（Frac A とテンソルすると Frac T の次元）。有限長の V で Σ(−1)ⁱ length Torᵢ^A(V, T) = r · length V。超 Tor のスペクトル系列から同じ式。剰余体が共通なので T 上の長さと A 上の長さは一致する。

### 段階 3：Galois 共役の和に広げる（定理 3.1 を使う）

- **定理 3.1** を H = A、J = m_A で適用する。A はネーター有限次元 ℤ₍ₚ₎ 代数で p ∈ m_A。A ⊂ T は整拡大なので Spec T → Spec A は全射。ファイバーの推移性は仮定。
- 結論 (3.2)：K₀^{m_A}(A) ⊗ ℚ → (K₀^{m_A}(T) ⊗ ℚ)^G は全射。
- Σ_g [g*P] は G 不変なので、ある有理類の引き戻し。χ_T − χ_C を ℚ 線形に延ばすと、段階 2 から引き戻しの像の上で 0 なので、Σ_g [g*P] の上でも 0。これが (3.11)。

### 3.1 と 3.4 の使われ方

| 段階 | 内容 | 使うもの |
| --- | --- | --- |
| 1 | χ_T, χ_C が有限で K₀ 上の準同型 | 台の判定法、Koszul の分裂 (3.12)、(3.9)（一般の v、ただし有限性のみ） |
| 2 | A からの引き戻しの上で一致 | λ 側：**補題 3.4**（V = Hⱼ(Q)）＋ 超 Tor スペクトル系列。普通の側：T の有限自由分解 |
| 3 | 共役和の上で一致 | **定理 3.1**（H = A、J = m_A）の全射性 (3.2) |

## 仮定ごとの使われ方

補題 3.5 は一般的な設定で述べられていて、A が k[[t₁, …, t_h]] や W(k)[[t₂, …, t_h]] という特別な形であることは使わない。

| 仮定 | 使う場所 | 必要か |
| --- | --- | --- |
| A が正則局所環、z が正則パラメータ系 | 段階 1（台の判定法と Koszul の分裂）、段階 2（補題 3.4、T の有限自由分解） | 必要 |
| A がネーターで Krull 次元が有限 | 段階 3（定理 3.1） | 必要（正則局所環なら自動） |
| A が ℤ₍ₚ₎ 代数で剰余標数 p > 0（p ∈ m_A） | 段階 3（定理 3.1 は J ∋ p を要求） | 必要。補題 3.4 では不要 |
| A が完備 | どこでも使わない | 不要 |
| T が A 上有限 | 全体 | 必要 |
| T が局所環 | V(m_A T) が1点になる | 実質的に使う |
| T と A の剰余体が同じ | 段階 2 の普通の側 | 使う。違えば剰余次数の因子が出る |
| T が整域 | r の定義、交代ランク = r、Spec T → Spec A の全射性 | 使う |
| C が T 代数、λ が加法的で非負 | 全体 | 必要 |
| (3.9) の v = 1 | 段階 2（補題 3.4 経由） | 必要 |
| (3.9) の一般の v | 段階 1（λ Hⱼ(z^v; C) の有限性） | 必要。ただし有限性だけ |
| G の作用、ファイバーへの推移性 | 段階 3（定理 3.1） | 必要 |

完備性が効くのは §5 で正規化基底 A_D をとる段階（Cohen の構造定理、Cohen–Gabber）と、D′ が A_D 上有限で局所的であることを示す段階。剰余標数 p の仮定は、定理 3.1 が「p で台をつけて有理化すると truncating になる」仕組みに依存していることから来る。

## 仮定の重さによる3分割

定理 3.1 のための仮定（剰余標数 p、群作用）は最後の1つにしか要らない。

### 3.5a：Euler 特性が K₀ 上の準同型になる

**仮定**
- A：ネーター局所環。z₁, …, z_e は √(z) = m_A をみたす元（パラメータ系で十分）
- T：A 上有限な代数
- C：T 代数。λ は m_A の冪で消される C 加群上の、加法的で非負な関数
- 有限性：全ての v, j で λ Hⱼ(z^v; C) < ∞

**結論**：V(m_A T) に台をもつ perfect T 複体 P について、χ_T(P) と χ_C(P) は有限で、K₀^{m_A}(T) 上の準同型を定める。

**証明**：段階 1。正則性も (3.9) の値そのものも使わず、λ Hⱼ(z^v; C) の有限性だけを使う。

### 3.5b：A から来る類で一致する

**仮定**：3.5a に加えて
- A は正則局所環で、z は正則パラメータ系
- r を T の A 上の generic rank とする（r = dim_{Frac A} T ⊗ Frac A）
- (3.9) の v = 1：λ Hᵢ(z; C) = 0（i > 0）、λ(C/zC) = r
- 長さの比較：T と A の剰余体が同じ。あるいは χ_T を A 上の長さで定義しておけば不要

**結論**：m_A に台をもつ perfect A 複体 Q について

  χ_T(Q ⊗^L_A T) = χ_C(Q ⊗^L_A T) = r · Σ(−1)ʲ length_A Hⱼ(Q)

**証明**：段階 2。T が整域である必要はなく、局所である必要も（長さを A 上で測るなら）ない。

### 3.5c：共役和で一致する

**仮定**：3.5a・3.5b の仮定に加えて
- A は ℤ₍ₚ₎ 代数で p ∈ m_A
- 有限群 G が T に A 上で作用し、Spec T → Spec A は全射で、G は幾何ファイバーに推移的

**結論**：Σ_g χ_T(g*P) = Σ_g χ_C(g*P)。より一般に、G 不変な有理類の上で一致する。

**証明**：段階 3。定理 3.1 から K₀^{m_A}(A)_ℚ → (K₀^{m_A}(T)_ℚ)^G が全射で、あとは 3.5b を適用するだけ。

この部分は、純粋に形式的な補題として切り出せる：

> アーベル群の準同型 f : K → K′ と、K′ に作用する有限群 G、準同型 φ, ψ : K′ → ℝ があり、φ ∘ f = ψ ∘ f かつ f_ℚ : K_ℚ → (K′_ℚ)^G が全射とする。このとき任意の x ∈ K′ で Σ_g φ(g·x) = Σ_g ψ(g·x)。

証明：Σ_g g·x は G 不変なので、ある ξ ∈ K_ℚ で f_ℚ(ξ) = Σ_g g·x。φ, ψ を ℚ 線形に延ばすと φ_ℚ ∘ f_ℚ = ψ_ℚ ∘ f_ℚ なので、両辺に ξ を入れて Σ_g φ(g·x) = Σ_g ψ(g·x)。定理 3.1 はこの全射性を供給するだけ。

## 分け方の利点

- 3.5a と 3.5b は標数の仮定も群作用も要らない純粋な可換環論で、定理 3.1 を仮定に置かずに形式化できる。
- 3.5c は上の形式的な補題と定理 3.1 の組み合わせ。定理 3.1 を仮定（層 2）として置けば、3.5c 自体は簡単な群論の議論。
- §4 も同じ3段構成になっている：長さの定義と準同型性が Prop. 4.3、A から来る類での一致が Prop. 4.5、共役和が Theorem 4.7。ステップ 4 でもこの分け方を繰り返せる。

## Lemma 5.2 での適用

A = A_D、T = D′、C = C_{D′}、λ = λ_{D′}、G = G_D とし、F を E′ の有限自由 R 分解、P = F ⊗_R D′ とおく。

1. P はホモロジーが Tor^R(D′, E′) の有界自由 D′ 複体で、P + Q が m-準素なので閉点に台をもつ。σ でひねっても R → D′ の核は P のままなので同じ。
2. ひねり σ*P = F ⊗_{R, ι_σ} D′ について、λ の側は χ_C(σ*P) = c_σ。普通の側は σ を成分ごとに作用させると半線形な同型になるので、χ_T(σ*P) は σ によらず χ_R(D′, E′)。補題 3.5 から |G_D| · χ_R(D′, E′) = Σ_σ c_σ。
3. D^{a_D} → D′ の余核は次元 < h なので、消滅定理 (5.1) から χ_R(D′, E′) = a_D · χ_R(D, E′)。同様に χ_R(D, E′) = a_E · χ_R(D, E)。
