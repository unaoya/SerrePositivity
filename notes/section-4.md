## 設定

- (A, J)：優秀な正則局所 ℤ₍ₚ₎ 代数（次元 e > 0、剰余標数 p、J は極大イデアル）、正則パラメータ系 z₁, …, z_e。完備は仮定しない（§3 との違い）。
- T：A 上有限な局所整域で剰余体が同じ、r = rank_A T。
- C：T 代数。λ は J の冪で消される C 加群上の非負・加法的な長さ。0 でない加群の λ が 0 になることを許す。
- 仮定 (4.1)：(3.9) と同じ。λ Hⱼ(z^v; C) = 0（j > 0）、λ(C / z^v C) = v^e r（v ≥ 1）。

## K₀ はどの群か

### 補題 3.5 の場合

K₀^{m_A}(T)：閉点に台をもつ perfect T 複体の三角圏 Perf^{m}(T) の Grothendieck 群。2つの Euler 特性 χ_T, χ_C はこの群からの準同型で、定理 3.1 は H = A の場合に

  K₀^{m}(A)_ℚ → (K₀^{m}(T)_ℚ)^G が全射

を与える。

### §4 の場合

K₀(P_T^J)：「J に台をもつ漸近的な複体」の三角圏 P_T^J の Grothendieck 群。

- P_T = (D_T / N_T)^♮
  - D_T：ランク O(sₙ) の自由 T 加群の列からなる複体の列（共通の有界な次数範囲）、の圏の冪等完備化
  - N_T：ランク o(sₙ) の自由加群の列が生成する thick 部分圏
  - (−)^♮：冪等完備化
- P_T^J：P_T の中で、ある v で全ての z_j^v が id を消す対象（商をとった後で消えればよい）

2つの Euler 特性 χ_ord, χ_C : K₀(P_T^J) → ℝ（Prop. 4.3）は、この群からの準同型。

### 2つの場合の関係

- **定理 3.1 の言葉で同じ形**：Lemma 4.6 で P_A ≃ Perf(H)、P_T ≃ Perf(H ⊗^L_A T)（H は連結な dg A 代数）なので、

  K₀(P_T^J) = K₀^J(H ⊗^L_A T)

  となる。補題 3.5 は H = A の場合で、K₀^{m}(T) = K₀^J(A ⊗ T)。定理 3.1 を任意の連結な係数 H で述べているのはこのため。

- **普通の複体からの埋め込み**：閉点に台をもつ perfect T 複体 P に対し、P ↦ (P^{⊕sₙ})ₙ（各 n で sₙ 個の直和）は Perf^{m}(T) → P_T^J を与え、Euler 特性と両立する。
  - χ_ord((P^{⊕sₙ})ₙ) = lim_𝒰 sₙ · χ_T(P) / sₙ = χ_T(P)。χ_C も同様。
  - 一方、定数列 (P, P, P, …) はランクが O(1) = o(sₙ) なので N_T に入り、P_T では 0 になる。ランク無視の圏で意味をもつのは、ランクが sₙ の程度で増える列。

- **ステップ 4 で使う対象**：Mₙ の極小分解を l 次で切り詰めた有限自由複体を E′ に持っていった列 (F′_{n,γ})ₙ。各 n で1つの複体が決まり、ランクは O(sₙ)、l 次より上を切った誤差は o(sₙ)。

## Remark 4.1：生のホモロジーの長さは商で生き残らない

### 例

A = T を一意化元 z の DVR（e = 1）、sₙ = n とする。各 n について T/(zⁿ) のランク1の自由分解

  Fₙ = [ T --(zⁿ 倍)--> T ]（次数 1, 0）

をとり、列 F = (Fₙ)ₙ を考える。

1. **ランク無視の圏では 0**：各項のランクは 1 = O(1) = o(sₙ) なので、F は N_T に入り、P_T では 0 と同型。
2. **生のホモロジーの正規化長さは 1**：H₀(Fₙ) = T/(zⁿ)、H₁(Fₙ) = 0 なので、length H₀(Fₙ)/sₙ = n/n = 1。生のホモロジーで長さを定義すると、0 と同型な対象に 1 が割り当てられてしまい、P_T の上で well-defined にならない。
3. **一様な消去の冪がない**：z^v が Fₙ をホモトピー的に消すのは z^v が T/(zⁿ) を消すとき、つまり v ≥ n のときだけ。すべての n で共通の v はないので、F は商をとる前の段階では台をもたない（F ∉ S_T）。商をとった後は 0 なので、自明に台をもつ。
4. **Koszul とテンソルすると長さ 0**：v を固定すると Hᵢ(z^v; T/(zⁿ)) = T/(z^{min(v,n)})（i = 0, 1）で、長さは v 以下と n によらず有界。sₙ で割ると 0 に近づく。

### 教訓

- 問題が起きるのは、商をとる前には一様に台をもたない対象だけ。
- 一様に台をもつ列（ある v で z_j^v が列全体をホモトピー的に消す）では、Koszul の分裂 K_v ⊗ F ≃ ⊕ⱼ F[j]^{(e choose j)}（式 (4.3)）により、生のホモロジーは Koszul とテンソルしたホモロジーの直和成分になる。Koszul とテンソルしたホモロジーの長さはランクの小さい列で 0 になるので、生の長さも商と両立する。
- そこで、長さは一様に台をもつ持ち上げの上で先に定義し、それから商と冪等完備化に延ばす。Lemma 4.2 は「台をもつ対象は全て、一様に台をもつ持ち上げの直和因子」であることを保証して、この延長を可能にする。
- 公式 (4.2) (1 + t)^e Σ bᵢ tⁱ = Σ tⁱ · lim_𝒰 len Hᵢ(K_v ⊗ Fₙ)/sₙ は、長さを Koszul とテンソルした生のホモロジーから計算する形になっている。この例では右辺は 0 で、左辺の bᵢ も全て 0 になり、P_T で 0 であることと整合する。

### ステップ 4 との関係

ステップ 4 で使う列 (F′_{n,γ})ₙ（切り詰めた分解を E′ に持っていったもの）は、切り詰めの誤差のために、商をとった後で初めて台をもつ（Lemma 5.5）。まさにこの Remark の状況が起こりうる対象なので、この回りくどい構成が必要になる。

## Euler 特性（Prop. 4.3 の内容、3.5a に対応）

Lemma 4.2 で「台をもつ対象は全て、一様に台をもつ持ち上げの直和因子」が保証されるので、一様に台をもつ持ち上げの上で長さを定義し、それを延ばす。Prop. 4.3 は、補題 3.5 と同じく2種類の長さを定義し、それぞれの Euler 和が K₀(P_T^J) → ℝ の準同型になることを主張する。

### 長さを測る先のアーベル圏

| | 普通の長さ | C での長さ |
| --- | --- | --- |
| 圏 | 𝒜_T | 𝒜_C |
| 対象 | 有限 T 加群の列 (Mₙ)ₙ | C 加群の列 (Nₙ)ₙ |
| 条件 | 共通の冪 J^N で消され、length_T(Mₙ) = O(sₙ) | 共通の冪 J^N で消され、λ(Nₙ) が有限で O(sₙ) |
| 射 | T 線形写像の列 | C 線形写像の列 |
| 無視するもの（Serre 部分圏） | lim_𝒰 length(Mₙ)/sₙ = 0 の列 | lim_𝒰 λ(Nₙ)/sₙ = 0 の列 |
| Serre 商上の長さ | length_T(M) = lim_𝒰 length(Mₙ)/sₙ | λ(N) = lim_𝒰 λ(Nₙ)/sₙ |

- 共通の冪 N と O(sₙ) の定数は対象ごとによい。核・余核・拡大で保たれるので、どちらもアーベル圏。
- 超極限を使うのは、普通の極限は存在するとは限らないが、有界列の超極限は常に存在し、和と両立する（線形）から。
- Serre 商をとるのは、無視できる列の長さを 0 にして、ランクの小さい錐をもつ射が同型になるようにするため。
- 「無視できる」の基準は長さの超極限が 0 という弱い条件。N_T を生成する自由加群の列は、普通の極限で o(sₙ) という強い条件を満たす。

### ホモロジー関手と長さ

一様に台をもつ持ち上げ F = (Fₙ)ₙ（有界な自由複体の列）に対して

- Hᵢ^ord(F) = (Hᵢ(Fₙ))ₙ ∈ 𝒜_T
- Hᵢ^C(F) = (Hᵢ(Fₙ ⊗_T C))ₙ ∈ 𝒜_C

P_T^J の一般の対象 X は、Lemma 4.2 によりこういう持ち上げの直和因子 (F, a)（a は冪等元）として表せる。そこで Hᵢ(X) = im Hᵢ(a) と定義する。a が鎖写像に持ち上がらなくても、アーベル圏の中で像はとれる。

- bᵢ^ord(X) = length_T Hᵢ^ord(X)、bᵢ^C(X) = λ Hᵢ^C(X)（有限、非負、有限個の i 以外で 0）
- χ_ord(X) = Σ(−1)ⁱ bᵢ^ord(X)、χ_C(X) = Σ(−1)ⁱ bᵢ^C(X)。K₀(P_T^J) → ℝ の準同型

### 補題 3.5 との対応

| | 補題 3.5 | Prop. 4.3 |
| --- | --- | --- |
| 対象 | 閉点に台をもつ perfect T 複体 P | P_T^J の対象 X（持ち上げ F = (Fₙ) の直和因子） |
| 普通の長さ | length_T Hᵢ(P) | lim_𝒰 length Hᵢ(Fₙ)/sₙ |
| C での長さ | λ Hᵢ(P ⊗ C) | lim_𝒰 λ Hᵢ(Fₙ ⊗ C)/sₙ |
| Euler 特性 | χ_T, χ_C : K₀^{m}(T) → ℝ | χ_ord, χ_C : K₀(P_T^J) → ℝ |

普通の複体 P を (P^{⊕sₙ})ₙ として埋め込むと、右の定義は左の定義に一致する。

### 2つの長さは共通の一般論で扱える

Prop. 4.3 の証明は、2つの長さを並行に扱っていて、違いは「Koszul ホモロジーの長さが有限であること」の根拠だけ。次の形にまとめられる。

**一般形**：T 代数 C′ と、J の冪で消される C′ 加群上の非負・加法的な長さ ℓ があり、全ての v, j で ℓ Hⱼ(z^v; C′) < ∞ とする。このとき、Hᵢ(Fₙ ⊗_T C′) の列で定まるホモロジー関手 P_T^J → 𝒜_{C′} と、準同型 χ_{C′} : K₀(P_T^J) → ℝ がある。

| | C′ | ℓ | 有限性の根拠 |
| --- | --- | --- | --- |
| 普通の長さ | T | length_T | Hⱼ(z^v; T) は有限生成で z^v で消されるので有限長（自動的） |
| C での長さ | C | λ | 仮定 (4.1)：正次数は 0、0 次は v^e r |

証明の各段階はこの有限性だけから共通に出る。

1. 一様に台をもつ列では、二重複体の Koszul を先にとるスペクトル系列で、Hᵢ(K_v ⊗ Fₙ ⊗ C′) の長さを「定数 × Fₙ のランク」で抑える。よって O(sₙ)。Koszul の分裂 (4.3) で Hᵢ(Fₙ ⊗ C′) 自体も抑えられる。
2. ランクが o(sₙ) の列は、同じ評価で Koszul とテンソルした後の長さが正規化して 0。この性質をもつ対象は thick 部分圏をなすので N_T を含む。よって S_T ∩ N_T の対象のホモロジーは Serre 商で 0 となり、関手は部分商に降りる。
3. 直和因子へは im Hᵢ(a) で延ばす（Balmer–Schlichting によりホモロジー的）。
4. 有限性・非負性・有界性と、長完全列から Euler 和の加法性。

これは補題 3.5a が「λ Hⱼ(z^v; C) の有限性」だけを使っていたのと同じ構造。一方、次の Prop. 4.5（3.5b に対応）は2つの長さで議論が本当に違う（普通の側は T の自由分解の交代ランク、C の側は Lemma 4.4 の Tor の消滅）ので、共通化できるのは Prop. 4.3 まで。

**形式化では**：「Koszul ホモロジーが有限な長さをもつ (C′, ℓ)」を構造体として定義し、Prop. 4.3 を一度だけ証明して (T, length_T) と (C, λ) に2回適用するのが自然。補題 3.5a も同じ構造体で書ける。

## A からの引き戻しでの一致（Lemma 4.4、Prop. 4.5、3.5b に対応）

- **Lemma 4.4**：Prop. 4.5 のための準備。補題 3.4 と同じ主張（λ Torⱼ^A(V, C) = 0、λ(V ⊗ C) = r · length V）を完備性なしで述べたもの。
- **Prop. 4.5**：X ∈ P_A^J について χ_ord(X ⊗^L_A T) = r · χ_A(X) = χ_C(X ⊗^L_A T)。持ち上がらない冪等元で切り出した直和因子についても成り立つ。
- 論文の証明：補題 3.5 の段階 2 と同じスペクトル系列（普通の側は T の自由 A 分解で E¹ = H_b(Y) ⊗ P_u、C の側は超 Tor で E² = Tor_u^A(H_b(Y), C)）が、台をもつ Verdier roof を通して関手的であることを示し、冪等元 a の像を各ページと収束先のフィルトレーションでとる。

### 形式化での 3.5b の方針は使えるか

> 2026-10-10 注：この節から末尾までは 2026-10-08 時点の検討の記録。直和因子の問題は
> [section-4-devissage.md](section-4-devissage.md) で解決した（正則な A 側では一様に台をもつ部分商が既に冪等完備、
> つまり下の補題 L′ の形が成り立つ）。実装の状況は [section-4-plan.md](section-4-plan.md) にある。
> 回避策の検討（特に U を perfect 複体で表せるかという問い）は、数学的な記録として残す。

**形式化での 3.5b の方針**（`PerfectComplex/KoszulGeneration.lean`、`Paper/Lemma3_5/`）：スペクトル系列と補題 3.4 を使わずに、

1. K₀^{m}(A) は [K(z)] で生成される（`K0.exists_eq_zsmul_koszul`。錐と最上段の切り詰めによるホモロジーの長さの総和に関する帰納法）
2. 両辺は 3.5a より K₀^{m}(A) 上の準同型
3. よって K(z) での値を比べれば足りる（普通の側は Koszul の Euler 標数 χ^A(z; T) = rank、C の側は (3.9) の v = 1）

**そのままでは移植できない**：K₀(P_A^J) は [K(z)] のような1つの類では生成されない。

- χ_A は実数値で、列 (K(z)^{⊕aₙ})ₙ（aₙ/sₙ → α）の類は任意のα ≥ 0 をとるので、整数倍では書けない。
- 冪等完備化で加わる直和因子の類もある。

**一様に台をもつ持ち上げでは、各段で適用すれば使える**：Y = (Yₙ)ₙ が一様に台をもつとき、各 Yₙ は閉点に台をもつ perfect A 複体なので、形式化済みの有限版 3.5b（`lemma_3_5b_ord_of_koszul`、`lemma_3_5b_lam_of_koszul`）が各 n で使えて、χ_T(Yₙ ⊗ T) = r · χ_A(Yₙ) = χ_C(Yₙ ⊗ T)。一様に台をもつ列では bᵢ(Y) = lim_𝒰 length Hᵢ(Yₙ)/sₙ で、Euler 和は有限和なので χ(Y) = lim_𝒰 χ(Yₙ)/sₙ。超極限は線形なので、各段の等式を sₙ で割って極限をとれば Prop. 4.5 が出る。Lemma 4.4 もスペクトル系列も要らない。

**残る障害は直和因子**：P_A^J の一般の対象は、持ち上がらない冪等元 a で切り出した直和因子 (Y, a)。a は Verdier roof で表されるので各段に分解できず、上の議論は直接は使えない。δ = χ_ord(− ⊗ T) − rχ_A が Y で 0 でも、得られるのは δ(Y, a) + δ(Y, 1 − a) = 0 だけ。定理 4.7 では定理 3.1 が与える逆像は任意の類になりうるので、直和因子の場合を省くことはできない。

**選択肢**：

- 直和因子の部分だけ論文の議論（スペクトル系列の roof を通した関手性と冪等元の像）を使う。スペクトル系列の形式化が必要で重い。
- 長さの級のレベルで代わりの議論を探す。例えば Serre 商 𝒜̄_A の中で、有限長加群の級 V に対し χ(V ⊗^L T) = r · length V（これも生成元 k への帰着で示せる）を、冪等元の像と両立する形で使う。要検討。
- K 理論の側で、一様に台をもつ部分商の K₀ から K₀(P_A^J) への写像が有理的に全射かを調べる。Thomason の分類では、稠密な部分圏の K₀ は単射だが余核は一般には 0 でないので、この状況に固有の理由が要る。要検討。


## 補題 3.5 と §4 の共通化（抽象的な一般論）

### 補題 3.5 は定理 4.7 の特別な場合

閉点に台をもつ perfect 複体 P を (P^{⊕sₙ})ₙ に送る関手 Perf^{m}(T) → P_T^J は、G 作用、2つの Euler 特性、A からの基底変更と両立する。§3.4 の設定は §4 の設定を満たす（完備正則局所環は優秀）ので、定理 4.7 を (P^{⊕sₙ})ₙ に適用すれば補題 3.5 の (3.11) が出る。ただし、形式化ではこの向きに依存させると補題 3.5 が §4 の重い構成に依存してしまうので、整合性の確認として使うのがよい。

### 「Koszul 複体の生成を極限で」という発想について（2026-10-08）

**K₀ の中で極限をとるのは無理**：一様に台をもつ Y の各段では [Yₙ] = mₙ[K(z)]（mₙ = χ_A(Yₙ)）だが、この関係は錐と切り詰めを homologyLengthSum(Yₙ) = O(sₙ) 回繰り返して得られる。回数が n とともに増えるので、列の圏の有限個の完全三角形としては束ねられず、K₀(P_A^J) の関係 [Y] = [(K(z)^{⊕mₙ})ₙ] は得られない。K₀ は代数的な対象で極限をもたない。

**準同型の側で極限をとるのはできる**：各段で有限版 3.5b（Koszul 複体の生成）を使い、等式を sₙ で割って超極限をとる。上の (4)。これは一様に台をもつ部分にしか使えない。

**直和因子が本質的に現れる理由**：ステップ 4 の Mₙ は B 上で射影次元が無限で、切り詰めないと perfect にならず、切り詰めると一様な台が壊れる。切り詰める前の分解なら共通の m^a が一様にホモトピー的に 0 になるので、問題は「Mₙ が近似的にしか perfect でない」ことに由来する。ただし Prop. 4.5 で問題になるのは A 側の任意の類（定理 3.1 が与える逆像）で、特定の対象をうまく選んでも回避できない。

**考えられる回避策**（いずれも要検討）：

- **冪等元の近似的な持ち上げ**：P_A^J の冪等元を、各段で「aₙ² − aₙ がランク o(sₙ) を経由する」近似冪等元で表し、各段で本物の直和因子に直せないか。一様に台をもつ部分商が既に冪等完備だと示せれば、Lemma 4.2 の ♮ も Prop. 4.3・4.5 の直和因子の処理も不要になる。体上の行列環の積を正規化ランクで割った環は正則環で、冪等元が持ち上がるので、似たことが局所環上の複体で成り立つかが問題。論文が持ち上がらない冪等元を明示的に扱っているので、著者はこの道をとらなかった（あるいは成り立たない）可能性がある。
- **トレースによる表示**：直和因子 (Y, a) の Euler 特性を、a のホモロジー上の「長さのトレース」として線形に表せれば、各段の議論に戻せる。局所環上の有限長加群では一般にはそういう線形のトレースはないが、正規化した極限ではありうる。
- この部分だけを名前つきの仮定（「Prop. 4.5 の直和因子の場合」）として置けば、層 2 の仮定は定理 4.7 丸ごとよりずっと小さくなる。

## 元の問題の再確認と回避策の検討（2026-10-08）

### 何が必要か

ステップ 4 で必要なのは式 (5.18)：|G_E| · c_σ = Σ_γ b_{σ,γ}。これは「E′ と C_E を、C_D から来る試験対象で測って比べる」補題 3.5 型の比較。

- ステップ 3 の試験対象（E′ の R 分解 ⊗ D′）は、閉点に台をもつ本物の perfect 複体。補題 3.5 で済む。
- ステップ 4 の試験対象は U = C_D/xC_D（B = R/(x) 上）から来る。その有限近似 Mₙ は B 上で射影次元が無限で、切り詰めると perfect にはなるが、l 次のホモロジーが syzygy（有限長でない）になって閉点への台が壊れる。台はランク o(sₙ) を捨てた後でしか成り立たない。
- これが Verdier 商、Remark 4.1、冪等完備化、持ち上がらない冪等元、Prop. 4.5 の直和因子の場合、の全ての出どころ。

**根本原因は B が正則でないこと**。B が正則なら Mₙ は長さ l の有限自由分解をもち、共通の零化イデアル m^a は分解上で一様にホモトピー的に 0 になるので、各段で補題 3.5 を使って sₙ で割り超極限をとれば (5.18) が出る。§4 は丸ごと不要になる。

### 回避策の検討

1. **B を正則にできないか**：できない。B = R/(x) は E に全射し、どちらも次元 l。B が正則（特に整域）なら、同じ次元の整域への全射は同型なので E = B が正則。つまり「B が正則 ⇔ E が正則」で、E が正則なら正値性は Serre の古典的な公式 χ = e(x, D) > 0 で既に分かっている。変数を足して線形な生成元を増やす工夫も、必要な個数が同じだけ増えるので効かない。**ステップ 4 の難しさは「E が特異であること」そのもの**で、ステップ 3 の難しさ（D′ が特異）を Galois 和と正則な基底への降下で処理したのと対になっている。
2. **B の代わりに正則な R 上で扱えないか**：U の近似を R 加群として見れば perfect で一様に台ももつ。しかし x は E′ を消すので Tor^R(U, E′) の Poincaré 多項式は (1 + t)^h 倍になり、Euler 特性は (1 − 1)^h = 0（消滅定理と整合）。c_σ は「(1 + t)^h で割ってから t = −1 を入れる」値で、Euler 特性ではなく Poincaré 多項式の情報。補題 3.5 は Euler 特性しか比べないし、基底変更で Poincaré 多項式は保たれないので使えない。同じ障害が別の形で現れる。
3. **具体的な C_E の構造を使う**：実際の構成では G_E が塔の上で C_E に作用するので λ_E は G_E 不変で、b_{σ,γ} は γ によらない（論文は一般性のために不変性を仮定していない）。また almost purity で C_E は塔の底の perfectoid 代数上 almost Galois。ただしこれらは C_E と塔の底を結ぶもので、E′ と C_E の比較そのものは代替しない。概念的には、χ_C は Dutta 型の重複度（局所 Chern 指標の最高次の成分）で、χ_T との差は特異な T の Todd 類の低次の成分から来る。正則な基底では Todd 類が自明なので引き戻しでは一致する。定理 3.1 はこの Riemann–Roch 的な議論を K 理論の降下で置き換えたものと見られる。Roberts の局所 Chern 指標の理論で直接やる道もあるが、重さは消滅定理と同程度。
4. **perfect 複体の実係数の結合で U を表せないか**：U は「λ の意味で射影次元 l 以下」なので、B 上の閉点に台をもつ perfect 複体 P_k の有限個の実係数の結合で、関数 L ↦ Σ(−1)ⁱ λ Torᵢ^B(U, L) を表せれば、各 P_k ⊗ E′ に補題 3.5 を使うだけで (5.18) が出て §4 が不要になる。完全交叉環上の K₀^{m}(B) と G₀(B) の対がどう振る舞うかによる（Dutta–Hochster–McLaughlin の例などで簡単ではないことが分かっている）。研究レベルの問い。
5. **§4 を残して縮小する**：冪等元の近似的な持ち上げ、一様に台をもつ部分は各段の補題 3.5 と超極限、直和因子の場合だけ名前つきの仮定（前節）。

結論：§4 の複雑さは「E が特異」という問題の本質から来ていて、簡単な回避はない。数学的に面白いのは 4（U を perfect 複体で近似できるか）と冪等元の持ち上げ。形式化では 5 が現実的。

## 直和因子の問題の整理と簡略化案（2026-10-08）

§4 は残したうえで、証明を整理する。

### 直和因子が入ってくる場所は1か所だけ

定理 4.7 の証明で、定理 3.1 は K₀(P_A^J)_ℚ → (K₀(P_T^J)_ℚ)^G の全射性を与える。非連結 K 理論は冪等完備化で不変なので、ここの K₀ は必然的に冪等完備化の K₀。逆像は任意の類になりうるので、Prop. 4.5（引き戻しでの一致）が K₀(P_A^J) 全体で要る。それ以外の場所（試験対象 X そのもの、Prop. 4.3）では、直和因子は「定義が通る」ことだけが必要で、Prop. 4.3 の im Hᵢ(a) による処理は比較的素直。

つまり、重いのは「Prop. 4.5 を直和因子に延ばす」こと（論文ではスペクトル系列の roof を通した関手性）の1点。

### 整理案：1つの補題に孤立させる

S̄_A^J := S_A/(S_A ∩ N_A)（一様に台をもつ部分商、Lemma 4.2 で P_A^J = (S̄_A^J)^♮）とおく。

**補題 L（有理稠密性）**：K₀(S̄_A^J)_ℚ → K₀(P_A^J)_ℚ は全射。

Thomason の定理（稠密な部分圏の K₀ は単射で、対象が部分圏に入る ⇔ 類が部分群に入る）により、L は次と同値：任意の直和因子 (Y, a) について、ある n ≥ 1 で (Y, a)^{⊕n} が一様に台をもつ対象と同型。

L があれば：
- Prop. 4.5 は一様に台をもつ対象だけで示せばよく、各段の有限版 3.5b と超極限で出る（スペクトル系列も roof の関手性も不要）。
- Prop. 4.3 の直和因子への延長は、χ が K₀(P_A^J) 上の準同型であることだけが必要で、それは L と単射性からχ を K₀(S̄_A^J)_ℚ → ℝ の延長として定義すればよい（im Hᵢ(a) の構成も不要になる）。ただし T 側（P_T^J）でも同じ L が要る。
- 定理 4.7 = 定理 3.1 の全射性 + L + 各段の 3.5b + 形式的補題 (1)。

**補題 L′（近似冪等元の持ち上げ、L より強い）**：S̄_A^J は既に冪等完備。すなわち P_A^J の冪等元 a は、Y ≅ Y′ と各段の本物の（ホモトピー）冪等元 a′ₙ ∈ End(Y′ₙ) で表せる。このとき (Y, a) ≅ (im a′ₙ)ₙ は一様に台をもつ対象で、♮ が一切不要になる。

### L′ の具体的な形（Lemma 4.6 経由）

Lemma 4.6 で P_A ≃ Perf(H)、H は連結なので K₀(P_A) = K₀(H₀(H))。H₀(H) = Λ_A := ∏ₙ M_{sₙ}(A) / I（I = ランク o(sₙ) の自由加群を経由する写像のイデアル）。よって台の条件を外せば、直和因子の問題は「Λ_A 上の有限生成射影加群」= 「M_k(Λ_A) の冪等元」= 「I を法として冪等な行列の列 (eₙ)」の問題になる。

問い：行列 eₙ ∈ M_N(A)（N = O(sₙ)）で eₙ² − eₙ がランク o(sₙ) の自由加群を経由するとき、本物の冪等元 e′ₙ で eₙ − e′ₙ が o(sₙ) を経由するものがあるか。

- 体上なら正しい：W = im(e² − e) は e で保たれ、V/W 上で e は冪等。補空間をとって持ち上げれば、差は dim W の程度。
- 局所環上での注意：「剰余体で小さい」と「A 上で小さい自由加群を経由」は違う（p·Id は剰余体で 0 だが小さい自由加群を経由しない）。ただし J に台をもつ世界では Koszul とテンソルした後の長さしか見えないので、「長さの意味で小さい」に置き換えて十分かもしれない。要検討。
- 複体のホモトピー圏では、各段の K^b(free A) = Perf(A) は冪等完備なので、問題は「近似冪等（aₙ² − aₙ が小さい対象を経由）を本物のホモトピー冪等に小さな変更で直せるか」。

### 論文がこの道をとらない理由の推測

論文は持ち上がらない冪等元を明示的に扱っている。L′ が成り立たないか、著者が示せなかったか、あるいは一般性のため（任意の優秀正則局所環、任意の sₙ）に避けたか。実際には A = A_D は完備で、sₙ = p^{jh} なので、特別な場合だけ示せばよい。
