# 補題 5.2（置き換え D → C_D）

2026-10-07 作成。論文 §5.1（p.23–24）の Lemma 5.2 の設定、主張、証明、使っているものの整理。補題 3.4・3.5 については `notes/lemma-3-4.md`、`notes/lemma-3-5.md`。

## 証明全体の中での位置

主定理の証明の「ステップ 3」。普通の長さで測った元の Euler 特性 χ_R(D, E) を、λ_D で測った量 c_σ の Galois 共役の和で表す。これで D を「λ の目で CM な代数」C_D に置き換えたことになる。以後は各 c_σ > 0 を示せばよい（ステップ 4 で E′ → C_E の置き換え、ステップ 5 で正値性）。

## 設定（§5.1）

**帰着後の状況**（Lemma 5.1）
- R：完備正則局所環、次元 d、剰余体 k は標数 p > 0 の代数閉体
- P, Q：R の素イデアルで、P + Q は m_R-準素
- D = R/P、E = R/Q、h = dim D > 0、l = dim E > 0、h + l = d

**基底と Galois 閉包**
- A_D ⊂ D、A_E ⊂ E：Lemma 2.2 の正則な正規化基底（完備正則局所、次元 h, l、剰余体 k、有限かつ generically separable）
- D′：Frac(D)/Frac(A_D) の Galois 閉包の中での A_D の整閉包（E′ も同様）。A_D 上有限（優秀性）、D 上も有限。局所（完備局所環上有限な整域なので）で、剰余体は k
- G_D = Gal(Frac D′ / Frac A_D)、G_E も同様。(D′)^{G_D} = A_D で、幾何ファイバーに推移的に作用する
- a_D = rank_D D′、a_E = rank_E E′

**長さ代数**
- 定理 2.5 を D′（基底 A_D）に適用して (C_D, λ_D) = (C_{D′}, λ_{D′}) とおく。E′ 側も同様

**ひねった作用と c_σ**
- σ ∈ G_D に対し ι_σ : R → D → D′ →σ D′ とおき、D′ と C_D にこの R 作用を入れる
- E′ には普通の作用 R → E → E′
- c_σ = Σ_{i=0}^{d} (−1)ⁱ λ_D Torᵢ^R(C_D, E′)（R は C_D に ι_σ 経由で作用）

## 主張

c_σ に現れる長さは全て有限で、

  |G_D| · a_D · a_E · χ_R(D, E) = Σ_{σ ∈ G_D} c_σ（式 (5.3)）

## 証明

### 1. 台つきの perfect D′ 複体を作る

R は正則なので、E′ の有限自由 R 分解 F（有界）がある。P_σ = F ⊗_{R, ι_σ} D′ とおく。

- P_σ は有界な有限自由 D′ 複体、つまり perfect。
- ホモロジーは Torᵢ^R(E′, D′)（D′ には ι_σ で作用）。
- 台：R → D′ →σ D′ の核は σ が単射なので P のままで、D′ は R 加群として V(P) に台をもつ。E′ は V(Q) に台をもつ。よって Tor は V(P + Q) = {m_R} に台をもち、有限長。m_R D′ と m_{A_D} D′ はどちらも m_{D′}-準素なので、P_σ は V(m_{A_D} D′) に台をもつ。

### 2. 補題 3.5 の仮定の確認

A = A_D、T = D′、C = C_D、λ = λ_D、G = G_D として、

- A_D：完備正則局所 ℤ₍ₚ₎ 代数、剰余標数 p
- D′：A_D 上有限な局所整域、剰余体は k
- (3.9)：定理 2.5 の (2.4) と (2.6)。r = rank_{A_D} D′
- G_D は D′ に A_D 上で作用し、幾何ファイバーに推移的

### 3. 補題 3.5 の2つの評価を計算する

補題 3.5 の記法では σ*P_1 = P_1 ⊗_{D′, σ} D′ = F ⊗_{R, ι_σ} D′ = P_σ（σ と σ⁻¹ のどちらになるかは、群全体で和をとるので関係ない）。

- **λ の側**：P_σ ⊗_{D′} C_D = F ⊗_R C_D（ι_σ の作用）なので χ_C(P_σ) = Σ(−1)ⁱ λ_D Hᵢ(F ⊗_R C_D) = c_σ。有限性は補題 3.5（3.5a）から。
- **普通の側**：σ を成分ごとに作用させると P_1 → P_σ の σ-半線形な同型が得られる。σ は D′ の自己同型なので、D′ 部分加群を D′ 部分加群に移し、ホモロジーの長さを保つ。よって χ_T(P_σ) = χ_T(P_1) = Σ(−1)ⁱ length_{D′} Torᵢ^R(E′, D′) は σ によらない。有限長の D′ 加群では D′ 上の長さと R 上の長さが一致する（剰余体がどちらも k）ので、これは χ_R(D′, E′)。
- **補題 3.5 の (3.11)** から |G_D| · χ_R(D′, E′) = Σ_σ c_σ。

### 4. D′ と E′ を D と E に戻す

- D′ は D を含む整域で、D 上の generic rank は a_D。Frac D′ の Frac D 上の基底を D′ の中からとると、単射 D^{a_D} → D′ で余核 K がねじれ加群になるものが得られる。K の零化イデアルは 0 でないので、Krull の単項イデアル定理から dim K < h。
- 0 → D^{a_D} → D′ → K → 0 に χ_R(−, E′) の加法性を使う（Tor の長完全列。台は V(P + Q) の中なので各項は有限長）。
- dim K + dim E′ < h + l = d（E′ は E 上有限なので dim E′ = l）。消滅定理 (5.1) から χ_R(K, E′) = 0。よって χ_R(D′, E′) = a_D · χ_R(D, E′)。
- E 側も同様に、単射 E^{a_E} → E′ の余核 K′ について dim D + dim K′ < d なので χ_R(D, E′) = a_E · χ_R(D, E)。

### 5. まとめ

  |G_D| · a_D · a_E · χ_R(D, E) = |G_D| · χ_R(D′, E′) = Σ_σ c_σ ∎

## 一般的な補題への分解

### 5.2a（ノルム比較の適用）

R を正則局所環、M を有限生成 R 加群とする。(A, T, C, λ, G) を補題 3.5 の仮定を満たすものとし、環準同型 ι : R → T があって、全ての g ∈ G で Tor^R(M, T)（g ∘ ι による作用）が閉点に台をもつとする。このとき

  |G| · χ_R(T, M) = Σ_g Σᵢ (−1)ⁱ λ Torᵢ^R(C, M)（g ∘ ι による作用）

ステップ 1–3 の内容で、補題 3.5 と初等的な事実だけで出る。C_D が何であるかは使わない。

### 5.2b（ランクの因子）

R を正則局所環、D ⊂ D′、E ⊂ E′ を R 上有限な整域の有限拡大で generic rank が a_D, a_E、dim D + dim E = dim R、D ⊗ E が有限長とする。このとき

  χ_R(D′, E′) = a_D · a_E · χ_R(D, E)

ステップ 4 の内容で、消滅定理が唯一の深い入力。

### 組み立て

Lemma 5.2 = 「5.2a を (A_D, D′, C_D, λ_D, G_D, ι, E′) に適用」＋「5.2b」。状況固有なのは、5.2a の仮定の確認（上の2つ目の表）だけ。

## 形式化に向けて

- 5.2a と 5.2b は一般論として証明し、状況固有の事実は「§5.1 の構成が満たす性質」としてまとめて扱う。
- 5.2a は補題 3.5（特に 3.5c）を入力とする。補題 3.5 を 3.5a・3.5b・3.5c に分けておけば、5.2a の層 2 への依存は定理 3.1 だけになる。
- 5.2b の入力は消滅定理（層 3b）と、Tor の長完全列（層 3a）。
- Mathlib の Tor の規約（`notes/PLAN.md` §1.3：対称性を使わない）に合わせて、Torᵢ^R(C_D, E′) は E′ の自由分解で計算する。論文もこの順で計算している。
