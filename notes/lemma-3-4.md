# 補題 3.4（有限長加群の基底変更）

2026-10-07 作成。論文 §3.4（p.14）の Lemma 3.4 と、それに関連する Corollary 2.6 の整理。

## 証明全体の中での位置

主定理の証明の「ステップ 3」（置き換え D → C_D、Lemma 5.2）は、補題 3.5（通常のノルム比較）から出る。補題 3.5 の証明は次の3段からなり、補題 3.4 はその (ii) の λ 側の計算に使われる。

1. χ_C の有限性と加法性
2. A から引き戻した類の上で、普通の Euler 特性と λ の Euler 特性が一致する（式 (3.13)、(3.14)）← **補題 3.4 を使う**
3. 定理 3.1（有理 K 理論の降下）で Galois 共役の和に広げる

ステップ 4（置き換え E′ → C_E）でも、§4 の Prop. 4.5 で同じ形の計算を使う。

## 記法

### λ の定義域と値域

- 定義域：m_A の冪で消される C 加群の全体 { M : C 加群 | ある N で m_A^N · M = 0 }。m_A は A → T → C を通して作用する。T は A 上有限なので、「m_T の冪で消される」と同じ条件。
- 値域：[0, ∞]（非負の実数に ∞ を加えたもの）。
- 条件：λ(0) = 0、および定義域内の C 加群の短完全列 0 → M′ → M → M″ → 0 について λ(M) = λ(M′) + λ(M″)。
- 帰結：加法性と非負性から、同型不変性と、部分加群・商加群に対する単調性が出る。特に λ = 0 の加群の部分商は λ = 0。
- 0 でない加群の λ が 0 になることを許す（§1.4 の規約）。

### Koszul 複体と Koszul ホモロジー（§1.4 の規約）

元の列 a = (a₁, …, a_r) と A 加群 V に対して、

- K(a; A)：次数 i の項が ∧ⁱ A^r（i = 0, …, r）、微分は d(e_{j₁} ∧ … ∧ e_{jᵢ}) = Σ_k (−1)^{k+1} a_{j_k} · e_{j₁} ∧ … ê_{j_k} … ∧ e_{jᵢ}。複体 0 → A →(a_j) A → 0 の r 個のテンソル積と同じ。
- K(a; V) = K(a; A) ⊗_A V、Hᵢ(a; V) = Hᵢ(K(a; V))。
- H₀(a; V) = V / (a)V、H_r(a; V) = { x ∈ V | 全ての j で a_j x = 0 }。
- Hᵢ(a; V) は全ての a_j で消される。
- z^v は列 (z₁^v, …, z_e^v) のことで、イデアル (z)^v ではない。

## 設定（§3.4）

- **基底環 A**：(A, m_A, k) は次元 e > 0 の完備正則局所 ℤ₍ₚ₎ 代数で、剰余体 k の標数は p。z₁, …, z_e は正則パラメータ系（m_A = (z₁, …, z_e)）。
- **有限拡大 T**：T は A 上有限な局所整域で、剰余体は k と同じ。r = rank_A T = [Frac T : Frac A]。
- **代数 C と長さ λ**：C は T 代数。λ は上の定義域・値域・条件をみたす。
- **仮定 (3.9)**：全ての v ≥ 1 について
  - λ Hᵢ(z₁^v, …, z_e^v; C) = 0（i > 0）
  - λ(C / (z₁^v, …, z_e^v) C) = v^e · r

λ は抽象的に与えられたデータで、その具体的な中身（塔の上の正規化長さ）は補題 3.4 では使わない。

## 主張

有限長の A 加群 V について、Torᵢ^A(V, C)（i ≥ 0）は λ の定義域に入り、

- (a) λ Torᵢ^A(V, C) = 0（i > 0）
- (b) λ(V ⊗_A C) = r · length_A(V)

が成り立つ。特に、これらの値は全て有限。

**実際に使う仮定**：A が正則局所環で z が正則パラメータ系であること、C が A 代数であること、λ の加法性と非負性、(3.9) の v = 1 の場合。完備性、ℤ₍ₚ₎ 代数であること、T が整域であることは使わない。

## 証明

### 準備：Tor が λ の定義域に入ること

V の自由分解 F• → V をとると Torᵢ^A(V, C) = Hᵢ(F• ⊗_A C) で、これは C 加群。a ∈ Ann_A(V) なら V 上の a 倍は零写像なので、関手性により Torᵢ^A(V, C) 上の a 倍も零。V は有限長なので、ある N で m_A^N V = 0 であり、Torᵢ^A(V, C) は m_A^N で消される。

以下、length_A(V) = n に関する帰納法で (a)・(b) を示す。

### n = 0

V = 0 なので全ての Tor が 0 で、λ(0) = 0 から成り立つ。

### n = 1（V ≅ k）

A は正則局所環なので正則パラメータ系 z は正則列。よって Koszul 複体 K(z; A) は A/(z) = k の自由分解で、

  Torᵢ^A(k, C) = Hᵢ(K(z; A) ⊗_A C) = Hᵢ(z; C)。

(3.9) の v = 1 から、

- i > 0 で λ Torᵢ^A(k, C) = λ Hᵢ(z; C) = 0。これが (a)。
- λ(k ⊗_A C) = λ(C / zC) = r = r · length(k)。これが (b)。

### n → n + 1

length V = n + 1 とする。A は局所環なので単純 A 加群は k だけで、組成列から短完全列

  0 → V′ → V → k → 0（length V′ = n）

がとれる。Tor の長完全列

  … → Torᵢ(V′, C) →α Torᵢ(V, C) →β Torᵢ(k, C) → Torᵢ₋₁(V′, C) → …
  … → Tor₁(k, C) →∂ V′ ⊗ C → V ⊗ C → k ⊗ C → 0

は C 加群の完全列で、全ての項は m_A^{n+1} で消されるので λ が使える。

**(a)**（i ≥ 1）：短完全列 0 → im α → Torᵢ(V, C) → im β → 0 を考える。

- im α は Torᵢ(V′, C) の商。0 → ker α → Torᵢ(V′, C) → im α → 0 と帰納法の仮定から λ(ker α) + λ(im α) = 0。非負性から λ(im α) = 0。
- im β は Torᵢ(k, C) の部分加群。0 → im β → Torᵢ(k, C) → 余核 → 0 と n = 1 の場合から λ(im β) = 0。

加法性から λ Torᵢ(V, C) = 0。

**(b)**：I = im ∂ ⊂ V′ ⊗ C、Q = (V′ ⊗ C) / I とおく。

- I は Tor₁(k, C) の商なので、(a) と同じ議論で λ(I) = 0。
- 0 → I → V′ ⊗ C → Q → 0 から λ(V′ ⊗ C) = λ(I) + λ(Q)。帰納法の仮定で左辺は rn なので λ(Q) = rn。
- 長完全列の完全性から V′ ⊗ C → V ⊗ C の像は Q と同型で、0 → Q → V ⊗ C → k ⊗ C → 0 は完全。よって λ(V ⊗ C) = rn + r = r(n + 1)。

途中の値は全て有限なので、有限性も同時に示されている。∞ を許す加法性のもとでも、引き算を使わない順序で議論している。∎

## Corollary 2.6 との関係

Corollary 2.6（§2、p.8–9）は、定理 2.5 で作った具体的な (C_D, λ_D)（基底 A、r = rank_A D）についての主張：

1. λ_D Torᵢ^A(V, C_D) = 0（i > 0）
2. λ_D(V ⊗_A C_D) = r · length_A(V)
3. λ_D(C_D / d C_D) > 0

- 1 と 2 は補題 3.4 を (C, λ) = (C_D, λ_D) に当てはめたもの。定理 2.5 が (3.9) を保証する。論文では Corollary 2.6 の方が先に出てきて、同じ組成列の帰納法で証明している。論文自身、補題 3.4 を「Corollary 2.6 を (3.9) だけを使う形にした形式的な版」と書いている。
- 3 は補題 3.4 にない新しい主張。D のパラメータイデアル H をとり、D/H の組成列を C_D とテンソルすると、右完全性から C_D / H C_D は C_D / d C_D の商を因子とするフィルトレーションをもつ。よって 0 < e(H, D) = λ_D(C_D / H C_D) ≤ length_D(D/H) · λ_D(C_D / d C_D)（左の等号は (2.5)）。Lemma 5.6 の η_E > 0 で使う。

抽象版を別に立てているのは、§3（補題 3.5）と §4（Theorem 4.7）の比較の議論が (3.9) 型の性質しか使わないため。比較を一般の (C, λ) について証明し、§5 で具体的な (C_{D′}, λ_{D′})、(C_{E′}, λ_{E′}) を代入する構成になっている。

## 形式化に向けて

- 「(3.9) をみたす (C, λ)」を構造体として定義し、補題 3.4・3.5 はその構造体について証明する。
- 定理 2.5 は「D′ に対してそういう構造体が存在する」という仮定（層 3）として置く。perfectoid の入力はここ1か所に閉じ込められる。
- Corollary 2.6 は「補題 3.4 の適用 ＋ 3 の正値性」として書く。
- 必要な基盤：
  - 正則局所環における剰余体の Koszul 分解（Mathlib に Koszul 複体がない）
  - A 加群 V と A 代数 C の Tor が C 加群になること、その長完全列
  - 局所環上の有限長加群の組成列による帰納法（Mathlib の `Module.length` まわり）
- λ の値域は `ENNReal`（[0, ∞]）が自然。定義域は「m_A の冪で消される C 加群」なので、述語つきの加法的関数として定義する。
