**結論：正則な基底環 A 側では、この方針で Proposition 4.5 を証明できる。** 一様に台をもつ部分商は既に冪等完備であり、任意の対象に一様に台をもつ自由複体の列の持ち上げを選べる。さらに、その K₀ は個数が変わる Koszul 複体の列の類で生成される。したがって Proposition 4.5 の証明で、スペクトル系列を Verdier roof と冪等元の像に通す操作を置き換えられる。

## 1. 設定と主張

A を次元 e の Noether 正則局所環、J をその極大イデアル、k = A/J とし、z₁,…,zₑ を正則パラメータ系とする。sₙ は正の整数の列とする。このノートの主定理に sₙ → ∞ は不要である。

- E_A：自由加群の列 (A^{aₙ})ₙ、aₙ = O(sₙ)、を対象とし、任意の行列の列を射とする加法圏。
- D_A = Kᵇ(E_A)^♮：各対象について全ての n に共通の有限な次数範囲をもつ複体の圏の冪等完備化。
- N_A：aₙ = o(sₙ) の自由加群の列が生成する thick 部分圏。
- S_A：ある v ≥ 1 について全ての j で zⱼ^v id_X = 0 となる X ∈ D_A の部分圏。
- W_A = S_A ∩ N_A、Q_A = S_A/W_A。
- P_A = (D_A/N_A)^♮、P_A^J は商の後で同じ台の条件を満たす部分圏。

O と o は、原論文 §4.1 と同じく通常の極限についての条件である。非単項超フィルター U は Euler 特性を評価する段階で初めて必要になる。

**定理。** この設定で次が成り立つ。

1. S_A には各段の通常のホモロジーから定まる有界な t 構造がある。
2. X ∈ S_A について、X ∈ W_A と、全ての i で ℓ_A Hᵢ(Xₙ) = o(sₙ) であることは同値。
3. Q_A は有界な t 構造をもち、既に冪等完備である。原論文 Lemma 4.2 と合わせて Q_A ≃ P_A^J。
4. G_s = { (cₙ) ∈ ℤ^ℕ : |cₙ| = O(sₙ) }、g_s = { (cₙ) ∈ ℤ^ℕ : |cₙ| = o(sₙ) } とおくと、

   K₀(S_A) ≅ G_s、K₀(W_A) ≅ g_s、K₀(P_A^J) ≅ G_s/g_s。

最後の同型で、一様に台をもつ列 F の類は (Σᵢ (−1)ⁱ ℓ_A Hᵢ(Fₙ))ₙ の剰余類に対応する。

## 2. 各段での操作を列の圏へ戻せる理由

最初に、列の圏での射と各段の導来圏の射の関係を固定する。共通の有界範囲をもつ自由複体の列 F、G について、

  Hom_{Kᵇ(E_A)}(F,G) ≅ ∏ₙ Hom_{Dᵇ_fg(A)}(Fₙ,Gₙ)。

各 Fₙ は有界な射影的複体なので、右辺の各射は鎖写像で表される。各段で鎖写像を選ぶと行列の列になり、各段で零ホモトピックなら選んだホモトピーもそのまま列になる。行列の係数やホモトピーに一様な大きさの制限は課されていない。

したがって Kᵇ(E_A) は ∏ₙ Dᵇ_fg(A) に完全忠実に入る。後者は冪等完備なので、この埋め込みは D_A にも完全忠実に延びる。D_A の抽象的な直和因子 X にも各段の対象 Xₙ とホモロジー Hᵢ(Xₙ) を割り当ててよい。

この埋め込みは、列の圏の対象を各段で識別するために使う。任意の列が D_A に属すると主張しているのではなく、以下で共通の次数範囲とランクの評価を別に証明する。

## 3. 一様な台からホモロジーの O(sₙ) 評価を得る

I_v = (z₁^v,…,zₑ^v)、K_v = K(z₁^v,…,zₑ^v;A) とおく。正則性から

  K_v ≃ A/I_v、ℓ_A(A/I_v) = v^e。

有界な自由複体 Fₙ について、

  K_v ⊗_A Fₙ ≃ (A/I_v) ⊗_A Fₙ

であり、右辺の各項は有限長なので、

  ℓ_A Hᵢ(K_v ⊗_A Fₙ) ≤ v^e rank_A Fₙᵢ。

この評価にはスペクトル系列を使わない。

X ∈ S_A を、D_A の中で自由複体の列 F の直和因子として表す。v を zⱼ^v id_X = 0 となるように選ぶと、零写像の錐の分裂を繰り返すことで X は K_v ⊗ X の直和因子であり、したがって K_v ⊗ F の直和因子である。よって全ての i で

  ℓ_A Hᵢ(Xₙ) = O(sₙ)。

ホモロジーは F の次数範囲の外で零である。また各 zⱼ^v が全てのホモロジーを消すので、例えば N = e(v−1)+1 とおけば、

  J^N Hᵢ(Xₙ) = 0

が全ての i、n で成り立つ。これは J の次数 N の単項式が、どれかの zⱼ^v で割れるためである。

## 4. 有限長加群の自由分解に一様な評価がある

有限長 A 加群 M、L = ℓ_A(M) に対して、次数 0,…,e の自由分解 P(M) を

  rank_A P(M)_j ≤ binom(e,j) L

となるように選べる。

この事実には二つの証明がある。

**組成列と Horseshoe による構成。** k の Koszul 分解の j 次のランクは binom(e,j)。M の組成列に沿って Horseshoe 補題を繰り返すと、分解の長さは e のままで、各項のランクは binom(e,j)L になる。構成に必要な回数は L とともに増えるが、完成した分解の次数範囲は増えない。

**極小分解による確認。** βⱼ(M) = dim_k Torⱼ^A(k,M)。Koszul 分解で Tor を計算すると、そのホモロジーの長さは j 次の項 M^{binom(e,j)} の長さ以下なので、βⱼ(M) ≤ binom(e,j)L。j > e では Tor が零になり、極小分解もそこで終わる。

特に M = (Mₙ) が共通の J^N で消され、ℓ_A(Mₙ) = O(sₙ) なら、上の分解を各 n で選ぶことで、共通の次数 0,…,e、項のランク O(sₙ) の自由複体の列ができる。Mₙ に対する zⱼ^N の作用は零であり、分解上では零ホモトピックなので、この列は S_A に属する。

ℓ_A(Mₙ) = o(sₙ) なら分解の全ての項のランクも o(sₙ) である。その列は、有限個の項から錐とシフトで作られるので N_A に属する。

ここでは分解を選ぶ操作の回数を n に関して一様にする必要はない。列の対象に要求されるのは、選んだ結果の次数範囲とランクの制御である。

形式化の最小範囲では、固定された Koszul 分解の各項のランクを抑える定数 C を一つ選び、rank P(M)_j ≤ C·ℓ_A(M) を示せば十分である。Horseshoe 構成で共通の次数範囲とランクの加法性を保つことを実装し、二項係数の厳密な公式は必須としない。

## 5. S_A 上の有界な t 構造

次のアーベル圏を B_s と書く。

  B_s = { (Mₙ) : Mₙ は有限 A 加群、ある共通の J^N で消され、ℓ_A(Mₙ) = O(sₙ) }。

射は A 線形写像の列である。核、余核、拡大で条件が保たれる。拡大では消去冪を足し合わせればよい。

§3 により、S_A の各ホモロジーは B_s に入る。§4 により、B_s の対象は共通有界な自由分解の列として S_A に入る。

積の導来圏での各段の Postnikov 三角形を考える。ホモロジーの非零な次数は共通の有限範囲にあり、各ホモロジーは既に S_A 内に実現された。§2 の完全忠実性により、Postnikov の接着射を列の圏で表し、有限回の錐をとることができる。このため、i 次以下・i 次以上への通常の切り詰めも S_A に属する。

したがって、各段のホモロジーの消滅条件で S_A に有界な t 構造が入り、その heart は B_s である。この議論は同時に、S_A の対象が、抽象的な直和因子という表示から、実際の一様に台をもつ有界自由複体の列の表示へ移れることも示す。

ここで S_A ≃ Dᵇ(B_s) という、より強い同値は必要としない。また D_A 全体が通常の切り詰めで閉じるとも主張しない。

## 6. ランクの小ささとホモロジーの小ささが一致する

X ∈ S_A について、

  X ∈ N_A ⇔ 全ての i で ℓ_A Hᵢ(Xₙ) = o(sₙ)

を示す。

**左から右。** v を固定し、全ての i で ℓ_A Hᵢ(K_v ⊗ Yₙ) = o(sₙ) となる Y ∈ D_A の部分圏を考える。これは、長完全列、長さの非負性、直和因子についての不等式により thick である。ランク aₙ = o(sₙ) の自由加群の列については、Koszul ホモロジーは次数 0 の (A/I_v)^{aₙ} だけで、長さが v^e aₙ = o(sₙ)。したがってこの thick 部分圏は N_A を含む。

X ∈ S_A ∩ N_A に対して、その台を消す v を選ぶと X は K_v ⊗ X の直和因子なので、X 自身のホモロジーの長さも o(sₙ) になる。

**右から左。** 各ホモロジーの列を §4 の自由分解で表す。この分解の各項のランクは o(sₙ) なので、ホモロジーを一つの次数に置いた対象は N_A に入る。§5 の有限な Postnikov 三角形で X を組み立てると、N_A の厚さから X ∈ N_A が従う。

この同値の o は通常の極限である。「超極限で長さが 0」への置き換えはできない。

## 7. 商が既に冪等完備である

§6 により W_A は通常の切り詰めで閉じ、有界な t 構造を継承する。その heart は

  B_s^0 = { M ∈ B_s : ℓ_A(Mₙ) = o(sₙ) }。

長さの非負性と加法性から、B_s^0 は B_s の Serre 部分圏である。つまり部分対象、商対象、拡大で閉じる。

この Serre 条件により、Verdier 商 Q_A = S_A/W_A に有界な t 構造が降り、商関手は t 完全になる。有界な t 構造をもつ三角圏は冪等完備である。従って

  Q_A ≃ Q_A^♮ ≃ P_A^J。

最後の同値は原論文 Lemma 4.2 による。

一般論としては Antieau–Gepner–Heller, *K-theoretic obstructions to bounded t-structures*, Proposition 2.20 の証明が、冪等完備化前の Verdier 商に有界な t 構造を構成する。Corollary 2.14 がその商の冪等完備性を与える。適用に heart の Noether 性は不要であり、必要なのは上で確認した Serre 条件である。

この結果の意味は、任意の X ∈ P_A^J に、別の一様に台をもつ自由複体の列 Y を選んで X ≃ q_A(Y) とできる、ということである。固定した F 上の商の冪等元 a が、同じ F 上の鎖写像の冪等元に持ち上がる、という主張ではない。原論文が射影の持ち上がりを仮定しないこととは両立する。

## 8. Koszul 複体の列による生成と K₀ の計算

K = K(z₁,…,zₑ;A) とし、非負整数列 a = (aₙ)、aₙ = O(sₙ)、に対して

  K(a) = (K^{⊕aₙ})ₙ

と書く。

M ∈ B_s に対して J^N Mₙ = 0 を全ての n で満たす N を選ぶ。共通の長さ N のフィルトレーション

  Mₙ ⊇ JMₙ ⊇ … ⊇ J^N Mₙ = 0

の各商は k^{a_{j,n}} と同型であり、a_{j,n} = O(sₙ)。従って B_s の K₀ で

  [M] = Σ_{j=0}^{N−1} [(k^{a_{j,n}})ₙ] = [(k^{ℓ_A(Mₙ)})ₙ]。

これと長さの加法性から、座標ごとの長さは同型 K₀(B_s) ≃ G_s を与える。逆写像は、整数列 c を正負に分け、[(k^{cₙ⁺})ₙ] − [(k^{cₙ⁻})ₙ] に送る写像である。

有界な t 構造の Postnikov 三角形から K₀(S_A) ≃ K₀(B_s)。同じ議論を o(sₙ) の部分圏に適用すると K₀(W_A) ≃ g_s。Verdier 商の K₀ の完全列

  K₀(W_A) → K₀(S_A) → K₀(Q_A) → 0

と §7 により、K₀(P_A^J) ≃ G_s/g_s を得る。この計算に負の K 群の消滅は使わない。

K(a) は列 a 自身に対応する。特に一様に台をもつ F に対して、

  uₙ = Σ_{i 偶数} ℓ_A Hᵢ(Fₙ)、wₙ = Σ_{i 奇数} ℓ_A Hᵢ(Fₙ)

とおくと、uₙ,wₙ = O(sₙ) であり、既に K₀(S_A) 内で

  [F] = [K(u)] − [K(w)]

となる。これは K₀ 内で極限をとった式ではなく、共通の有限な Postnikov 分解と J 進フィルトレーションから得た有限個の三角形関係である。§7 により任意の X ∈ P_A^J についても同じ型の式が成り立つ。

## 9. Proposition 4.5 の代替証明

原論文の T、C、λ の設定を加え、r = rank_A T とする。Proposition 4.3 により、次の三つは K₀(P_A^J) 上の準同型である。

  X ↦ χ_ord(X ⊗ᴸ_A T)、X ↦ rχ_A(X)、X ↦ χ_C(X ⊗ᴸ_A T)。

§8 により、全ての K(a) でこれらが一致することを示せばよい。Koszul 生成元の計算は

- χ_A(K) = 1。
- χ_T(K ⊗_A T) = r。これは正則な A 上のパラメータの Koszul Euler 特性の標準的な階数公式で、有限版 3.5b の Koszul による証明でも同じ入力を使う。
- χ_C(K ⊗_A T) = r。仮定 (4.1) の v = 1 により、高次 Koszul ホモロジーの λ は 0、0 次の λ は r。

したがって aₙ = O(sₙ) に対して三つの値は全て

  r lim_{n→U} aₙ/sₙ

となる。準同型性と生成から、任意の X ∈ P_A^J で

  χ_ord(X ⊗ᴸ_A T) = rχ_A(X) = χ_C(X ⊗ᴸ_A T)

が従う。

この証明は Lemma 4.4 や、Proposition 4.5 のスペクトル系列を商に降ろして冪等元の像を取る構成を用いない。

**既存の有限版 3.5b を再利用する書き方。** §7 だけでも、X ≃ q_A(Y) となる一様な自由持ち上げを選び、各 n に有限版 3.5b を適用し、sₙ で割って超極限を取ればよい。共通の有界な次数範囲と Proposition 4.3 の評価により、有限な Euler 和と超極限を交換できる。§3 の補題の記述には完備性の仮定があっても、Koszul 生成による有限版の証明は完備性を使わないので、ここではその版を用いる。

## 10. 実数値の役割

上の同型の下で Euler 特性は

  χ_A : G_s/g_s → ℝ、[c] ↦ lim_{n→U} cₙ/sₙ

である。個々の直和の個数は常に整数であり、実数は正規化した超極限の値として現れる。

この写像は一般に単射ではない。E ⊆ ℕ を無限集合で E ∉ U となるように選び、cₙ = sₙ（n ∈ E）、cₙ = 0（n ∉ E）とおく。すると χ_A([c]) = 0 だが cₙ/sₙ = 1_E(n) は通常の極限で 0 に行かないので、[c] ≠ 0。従って一つの Euler 特性の実数値だけでは K₀ の類を分類できない。

追加で sₙ → ∞ を仮定すると、

  G_s/g_s ≅ ℓ∞(ℕ,ℝ)/c₀(ℕ,ℝ)

という加法群の同型が [c] ↦ [(cₙ/sₙ)] で与えられる。全射性は有界実数列 x に対し cₙ = floor(sₙxₙ) とし、丸め誤差が 1/sₙ → 0 になることから従う。この同定を通せば自然な実ベクトル空間の構造も入るが、一般には実一次元ではない。

逆に sₙ が一様有界なら、G_s は有界整数列、g_s は有限台の整数列である。従って「任意の実数が値として現れる」「固定した複体の定数列が零になる」という主張は、一般の §4 の設定では追加条件が必要になる。sₙ = n や、論文の応用で sₙ → ∞ となる場合には問題ない。

Remark 4.1 の Fₙ = [A →^{zⁿ} A]、sₙ = n は、この結果への反例ではない。この列は N_A に入るが S_A には入らないので、§6 の同値の適用範囲外である。商で零になる対象には一様な持ち上げとして零列を選べる。元の非一様な持ち上げの生のホモロジーを使うことは依然できない。

## 12. 既存の議論の修正点と形式化上の評価

`section-4.md` にある「K₀ 内で極限は取れない」は、そのまま正しい。しかし「各段の帰納法の回数が増えるので、列の K₀ の生成関係は得られない」という結論は強すぎる。共通の J 進フィルトレーションを用いれば有限個の三角形関係として束ねられる。負の Euler 特性には、負の個数の直和ではなく二つの非負個数の直和の差を使う。

また「商の直和因子は処理できない」という一般的な懸念は、正則な A 側では §7 により解消できる。一般の T 側の冪等完備化を省けるという結論にはならない。

紙上の証明では、重いスペクトル系列の関手性を、有限長加群の一様な分解と t 構造の標準的一般論へ置き換えられる。Lean での実装が直ちに短くなるかは別問題である。列の圏、支持つき部分圏、Verdier 商、t 構造、冪等完備化の基盤が必要で、現状の有限複体に特化した K₀ の実装だけでは足りない。

2026-10-10 の整備で、Koszul 関手の完全性・シフトとの両立、有限自由複体の項による帰納法、Koszul 複体への retract を用いた 3.5a の有限性が実装された。まずこの有限性をランクに比例する上界へ強め、その後に商への t 構造の降下と有界 t 構造からの冪等完備性を進める。一様自由分解、S_A の切り詰め閉性、W_A のホモロジーによる特徴付けを接続し、有限版 3.5b を再利用する数学的方針は維持する。任意の X ∈ P_A^J に対する Proposition 4.5 までが代替証明の最小範囲で、K₀ の明示計算は追加課題。Lemma 4.2、Proposition 4.3、Lemma 4.6、Theorem 4.7 は引き続き必要であり、Theorem 3.1 は現在の引用方針に従う。
