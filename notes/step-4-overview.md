# ステップ 4 の全体像（置き換え E′ → C_E）

2026-10-07 作成。論文 §5.2–5.5 の流れと、ステップ 3（`notes/lemma-5-2.md`）との共通構造の整理。定理 4.7（§4）は結論を認めて扱う。

## 目標

σ ∈ G_D を固定し、C = C_D、λ = λ_D と書く。ステップ 3（Lemma 5.2）で

  |G_D| · a_D · a_E · χ_R(D, E) = Σ_{σ ∈ G_D} c_σ、c_σ = Σ(−1)ⁱ λ Torᵢ^R(C, E′)

が得られたので、各 c_σ > 0 を示せばよい。

E′ は λ の目で CM ではないので、c_σ のままでは高次の項が残り、正とは言えない。そこで E′ も C_E に置き換える。

## ステップ 3 と 4 に共通する構造

**状況**：2つの因子 L（左）と T（右）の交点の Euler 特性 χ(L, T) があり、右の T を、λ の目で CM な代数 C_T に置き換えたい。

1. **対象を作る**：X = (L の自由分解) ⊗ T。L と T の台は閉点でしか交わらないので、X のホモロジーは閉点に集中する（台つき対象）。ホモロジーの長さが有限になり、Euler 特性が測れる。
2. **普通に測ると元の量**：普通の長さで測った X の Euler 特性は χ(L, T)。Galois でひねった g*X でも同じ値。
3. **C で測ると新しい量**：X ⊗_T C_T を λ で測ると χ(L, C_T)、つまり T を C_T に置き換えた量。こちらは g によって変わりうる。
4. **比較定理**：Σ_g（普通の測り方）= Σ_g（C での測り方）。したがって

  |G| · χ(L, T) = Σ_g χ_λ(L, g でひねった C_T)

| | ステップ 3 | ステップ 4 |
| --- | --- | --- |
| 左の因子 L | E′ | C_D（λ_D で測る） |
| 右の因子 T（置き換えるもの） | D′ | E′ |
| 置き換え先 C_T | C_D | C_E |
| 群 | G_D | G_E |
| 元の量 χ(L, T) | χ_R(D′, E′) | c_σ |
| 新しい量 | c_σ | b_{σ,γ} |
| 対象 X | E′ の自由 R 分解 ⊗ D′ | Mₙ の切り詰めた分解 ⊗ E′ の列 |
| 比較定理 | 補題 3.5 | 定理 4.7 |

ステップ 4 では左右の役割が入れ替わり、すでに置き換え済みの C_D が左の因子になる。

## なぜ 5.3–5.5 が必要か

自由分解は Tor を計算するための道具。型の 1 では「左の因子 L の自由分解」が要る。

- ステップ 3 では L = E′ は有限生成 R 加群なので、有限自由分解がそのままある。
- ステップ 4 では L = C_D は有限でない巨大な代数なので、有限自由分解がない。

ステップ 4 では **C_D の自由分解そのものは作らない**。作るのは各 n ごとの本物の有限自由複体の列で、それが「誤差を無視すれば C_D（のパラメータ商）の自由分解のように振る舞う」。実数を有理数の列で近似するのに似ている。

### 補題 5.3：扱う対象を C_D から U に取り替える

Q の元 x₁, …, x_h（R の正則列で、D のパラメータ系）をとり、B = R/(x)（次元 l の完全交叉）、U = C_D / ι_σ(x) C_D とおく。

- **環を R から B に替えてよい理由**：環の取り替えのスペクトル系列 Tor_p^B(Tor_q^R(C, B), L) ⇒ Tor_{p+q}^R(C, L) で、Tor_q^R(C, B) は Koszul ホモロジー H_q(x; C)。C は λ の目で CM なので q > 0 では λ が 0。よって λ で測る限り C ⊗^L_R B は U と同じで、B 加群 L について λ Torᵢ^R(C, L) = λ Torᵢ^B(U, L)。
- **i > l で消える理由**：xL = 0 なので K(x; R) ⊗^L_R L はシフトの直和 ⊕ⱼ L[j]^{(h choose j)} に分裂し、Torᵢ^R(C, L) が全体の次数 i + h に現れる。全体は次数 d より上で λ が 0 なので、i + h > d、つまり i > l で消える。
- **得られたもの**：U は m_B の冪で消され（式 (5.6)）、0 < λ(U) < ∞（定理 2.5、式 (5.5)）。λ の目では B 上の射影次元が l 以下。B は正則でないので本物の加群なら射影次元が無限になりうるが、U は λ の意味では「長さ l の自由分解をもつ」ように振る舞う。
- E′ は B 加群（x ∈ Q）なので c_σ = Σ(−1)ⁱ λ Torᵢ^B(U, E′)。

### 補題 5.4：U を有限長加群で近似する

U は B 上有限生成ではない。塔の有限段まで降りて、有限長の B 加群 Mₙ と sₙ → ∞（塔の段の次数 p^{jh}）を作る。

- length(Mₙ)/sₙ → λ(U)
- length Torᵢ^B(Mₙ, L)/sₙ → λ Torᵢ^B(U, L)（L = k, E′）
- 全ての Mₙ は共通の m_B^a で消される
- 生成元数 β₀(Mₙ)/sₙ の極限 ν_σ は正（ν_σ ≥ λ(U)/length(B/m_B^a)）

これで c_σ = lim Σ(−1)ⁱ length Torᵢ^B(Mₙ, E′)/sₙ と、本物の有限長加群の普通の Tor で書ける。

### 補題 5.5：Mₙ の分解を切り詰めて、有限の複体にする

Mₙ は有限長の B 加群なので極小自由分解 Fₙ^∞ が作れる。B は正則でないので、この分解は一般に無限に続く。

- i 次のランクは length Torᵢ^B(Mₙ, k)。5.3・5.4 から、i > l ではこれが o(sₙ)。
- l 次で切り詰めた Fₙ は長さ l の有限自由複体で、ステップ 3 の「有限自由分解」の代わりになる。
- 切り詰めた Fₙ はもう Mₙ の分解ではなく、l 次に余分なホモロジーが出る。しかしその誤差はランク o(sₙ) の項を経由するので、sₙ で割った極限では消える。
- m_B^a の元は Mₙ を消すので分解の上でホモトピー的に 0。切り詰めで生じる誤差も l + 1 次の項（ランク o(sₙ)）を経由するので、ランク無視の圏では 0。よって列は閉点に台をもつ。
- これを B → E → E′ →γ E′（γ ∈ G_E）で E′ に持っていった列 X = (F′_{n,γ})ₙ が、型の「対象 X」。誤差を無視すれば閉点に台をもち、普通の長さで測った Euler 特性はどの γ でも c_σ。

| | ステップ 3 | ステップ 4 |
| --- | --- | --- |
| 本来ほしいもの | E′ の自由分解 | C_D の自由分解 |
| 実際に使うもの | E′ の有限自由 R 分解（そのまま） | 各 n で Mₙ の極小分解を l 次で切った有限自由複体の列 |
| 誤差 | なし | ランク o(sₙ)。sₙ で割ると消える |
| そのための準備 | 不要 | 5.3（λ 有限な U へ）、5.4（有限長加群で近似）、5.5（切り詰め） |

この「誤差を無視する」ことを正確に扱う枠組みが §4 のランク無視の圏で、そこでの比較定理が定理 4.7。

### c_σ の書き換えの一覧

## 比較と正値性

- **式 (5.18)**：定理 4.7 を A = A_E、T = E′、C = C_E、λ = λ_E、G = G_E と列 X に適用して |G_E| · c_σ = Σ_γ b_{σ,γ}。b_{σ,γ} は F′_{n,γ} を C_E と λ_E で測った Euler 特性。
- **補題 5.6**：b_{σ,γ} では両側が CM もどきなので 0 次の項だけが残り、b_{σ,γ} ≥ ν_σ η_E > 0。η_E = λ_E(C_E / m C_E) > 0 は Corollary 2.6 の3つ目の主張。ステップ 3 には正値性の段階はなく、ここで初めて「両側が CM もどきなので 0 次だけが残る」議論が使われる。
